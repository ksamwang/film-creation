# 声音

## 这个模块解决什么

在 AIGC 里，声音不是拍摄现场收进来的，而是后期生成与叠出来的层。模块只回答四个决定：观众站在哪里听、画外有什么、什么时候撤走声音、环境/事件/音乐/沉默/人声各自负责什么。四个决定做完，才轮到音色与风格。

## 先读哪篇

先读 `01-perspective.md`。听点定了，画外、沉默、音乐、对白才有位置。其余四篇按当前问题读，不要一次全读。

## 子文件

| 文件 | 一句话 |
|---|---|
| `01-perspective.md` | 听点、视听场景、三种聆听模式：先定观众从哪儿听 |
| `02-offscreen.md` | 相对与绝对画外、扩展域、无形音角色：画外怎么造世界 |
| `03-silence.md` | 言语的中断、非情感共鸣、空无：沉默怎么撤层 |
| `04-music.md` | 情感共鸣与非情感共鸣、乐池与银幕：音乐的位置先于风格 |
| `05-dialogue.md` | 人声中心与词语中心、戏剧言语与文本言语：对白作为声音物体 |

## 共同前提

五篇共用《视听：幻觉的构建》的框架：增值让观众以为意义来自画面；同步整合把声音与影像粘在一起；视听场景没有装声音的容器，只有声音之间的关系。AIGC 把这三点落到同一条工作流：分层生成 stem、按听点过滤、在剪辑里对齐同步点。视频模型自带音频不可靠时，声音全部走独立音频模型与后期。

## 怎么用

- 先定听点，再定画外；这两项写完，沉默、音乐、对白才有位置。
- 每个镜头在分镜表里留一列声音：层、声源、距离、进入与退出。
- 每个子文件的检查清单，在生成前和定剪前各跑一遍。
- 音频提示写声源、距离、空间、混响、电平；不写情绪形容词。

## 产出物

读完一个子文件，至少产出一行可执行决定：听点句、画外地图、撤层表、音乐位置表、人声规则。再加一个音频提示包：环境底、事件 one-shot、人声 stem、音乐 cue、room tone。没有产出，就等于没读。

## 模块边界

这一模块只管听觉判断与声音层分工，不教音频软件操作，也不替故事模块决定一场戏该不该存在。若一场戏在声音上找不到功能，先回 `story/` 或 `staging/`，不要用音乐和音效补戏。

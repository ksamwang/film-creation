## 骨架（写正文前先填）

| 段 | 时间 | 内容 |
|---|---|---|
| 钩子 | 0–3 秒 | 第一帧画面： |
| 立住 / 接上集 | 3–30 秒 |  |
| 回合 | 30–75 秒 | 施压： → 回应： → 局势变化： |
| 顶点 + 断章 | 75–90 秒 | 断章公式： 停在： |

## 正文

```text
第__集  标题

场 1-1  日/夜  内/外  地点
人物：

△ 动作（起点 → 动作 → 落点）
角色（情绪）：台词
角色（OS）：……
【字幕】……

【本集断章】停在哪个画面或哪句话（黑屏）
```

## 检查

- [ ] 前 3 秒冲突，第一帧能看懂？
- [ ] 回合有新增量，有一个小情绪点？
- [ ] 动作一行一个主导动作，写了接触点和落点？
- [ ] 每句台词能在一个镜头内说完，一镜一个说话人？
- [ ] 场景 ≤2、有名角色 ≤4（标准档）？
- [ ] 断章不靠独白？

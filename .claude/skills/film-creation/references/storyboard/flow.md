# 镜间承接：让镜头连成一条因果链

分镜的单位不只是镜头，还有**镜头之间的接点**。每一镜都在完成一个功能（建立、插入、反应），镜头之间却只能读成「然后……然后……」，观众看到的就是一串打卡：信息都交代了，戏却是断的。

这一篇讲接点怎么设计：先把一场戏写成一条因果句再切镜（§1），每个剪辑点选一种承接（§2），查三种断层（§3），给呼吸留预算（§4），场与场之间单独设计接点（§5），最后用读链测试验收（§6）。它是 `storyboard/breakdown.md` 第三步之后的「镜流」一步；镜长与注意中心的衔接见 `storyboard/pacing.md` §2，转场的具体做法见 `camera/lexicon-transition.md`。

---

## 0. 打卡式分镜长什么样

| 症状 | 表现 | 根子 |
|---|---|---|
| 每镜一句事件摘要 | 画面栏写「他发现车票」「两人争执」，一镜 8–15 秒装一个 beat | 按 beat 或按必看信息一对一出镜，没问「观众为什么在这一刻看这个」 |
| 场头固定建立、场尾停在事件上 | 每场先来一个全景，事件一完就切走 | 把建立镜和「事件完成」当成场的边界，没有余韵 |
| 场间一律硬切 | 「硬切到另一日」「时间省略」 | 没有设计场与场之间的接点 |
| 视点无因 | 切到谁全看剧情需要：上一镜在他身上，下一镜忽然在她身上 | 不知道这场戏是谁的戏、为什么在这一刻离开这个人 |
| 物件凭空 | 关键物件只在剧情要用的那一镜出现，之前在哪、谁动过，看不出来 | 物件只登记了外观一致，没当作一条线索来传 |
| 空间每镜重建 | 每镜都重新写一遍「在桌边」「在门口」，人物的路径没有拍出来 | 空间只在建立镜里交代一次，之后靠文字补，不靠视线和动作带 |

**一句话判断**：把分镜按顺序读一遍，镜与镜之间只能填「然后」，就是打卡。能填「因为 / 所以 / 但是 / 同时」，才是戏。

## 1. 镜流句：先写因果，再切镜头

拆镜之前，把整场戏写成一段话，每一步用「→」连，并在箭头上写清它是**因此**、**但是**还是**同时**。主语写观众此刻注意的那个人或东西。

```text
场 5（`storyboard/breakdown.md` 的示例）
林晚核对报告 → 但是屏幕上的数字和打印稿不一样 → 因此她去翻修订记录 → 看见修改人是顾言
→ 同时电梯「叮」了一声 → 因此她抬头 → 看见顾言提着咖啡走来 → 他把一杯放在她桌上
→ 但是她没有接这个好意，把屏幕转向他 → 因此他不得不回答 → 他笑着承认，还要她照念
→ 这句话落在她脸上 → 因此她看着那杯咖啡，不碰 → 他走了，她没有动
```

**从镜流句到镜头**

- 每个「→」都是一个可以下刀的位置；不一定每个都切，但每个切点都必须落在某个「→」上。
- 「看见 / 听见 / 发现」这类感知动词，自动生成一组「看 → 看到什么 → 反应」（`storyboard/breakdown.md` 第三步）。
- 「因此」后面的那一镜要能看出原因：林晚抬头，是因为上一镜那一声「叮」。
- 「但是」是转折，在它前后找停留或景别变化（§4）。
- 写不出连接词、只能写「然后」的地方：要么缺了一个接点（补一个视线、一个反应、一个物件），要么这两件事该合成一镜。

**镜流句不是剧本复述。** 剧本写「发生了什么」；镜流句写「观众的注意力怎么从这里被带到那里，为什么」。

## 2. 七种承接

每个剪辑点至少用一种承接。一个接点叠两种（视线 + 声音），接得最牢。

### 问答承接
- **是什么**：上一镜留下一个问题，下一镜回答它（《电影镜头设计》7.3 问答模式）。是所有承接的底子。
- **上一镜留**：一个没有结果的动作、一个没有回应的话、一个没看清的东西。
- **下一镜接**：结果、回应、看清。
- **用在**：每一个切点都先问一句「观众此刻想知道什么」。
- **AIGC 落法**：分镜表的「接 / 出」写成问句和答句，生成时两镜各写各的，不需要特殊处理。
- **失败**：下一镜回答的是观众没在问的问题——那一镜就是打卡。

### 视线承接
- **是什么**：上一镜有人在看，下一镜给他看见的东西；或者反过来，先给东西，再给看的人。
- **上一镜留**：视线方向（画左 / 画右、高低）。
- **下一镜接**：视线对象，方向和高度与上一镜一致（`storyboard/continuity.md` 视线匹配）。
- **用在**：发现、等待、对峙、思念；切到另一个人之前，先让当前的人看过去。
- **AIGC 落法**：两镜都写画面方位：上一镜「她看向画右」，下一镜「从画左一侧看过去的角度」。
- **失败**：人物看了，下一镜却不是他看的东西；或视线方向相反，观众以为看的是别处。

### 动作承接
- **是什么**：一个动作在上一镜开始，在下一镜做完（动接动，《电影镜头设计》7.10）。
- **上一镜留**：动作的前半：手伸出去、开始转身、推门。
- **下一镜接**：同一个动作的后半，换景别或角度。
- **用在**：换景别；把观众从一个人身上带到他手里的东西上。
- **AIGC 落法**：两镜提示词里动作描述一致，下一镜第一句写动作的中段起点；生成时两镜各留 0.5–1 秒余量，剪辑找切点（`camera/lexicon-transition.md` 动作剪接）。
- **失败**：动作在两镜里各做了一遍，或中间跳掉一段。

### 声音承接
- **是什么**：声音跨过剪辑点。下一镜的声音先进来（J-cut），或上一镜的声音拖进下一镜（L-cut），或一个声音连起两段（声音桥）。
- **上一镜留**：一声响、一句没说完的话、一段持续的环境声。
- **下一镜接**：声源、听者、或新的空间里同一个声音。
- **用在**：有人闯入（先闻其声）；话落在听者脸上（L-cut）；场间过渡（§5）。
- **AIGC 落法**：声音在剪辑里铺，不靠模型同步生成；分镜表的声音栏写「（先于画面）」「（拖入下一镜）」。生成听者镜时写明她不说话（`storyboard/breakdown.md` 第五步）。
- **失败**：每镜的声音都在剪辑点上一刀切断，镜头之间就像幻灯片翻页。

### 物件承接
- **是什么**：同一个物件跨过剪辑点：从这只手到那只手、从这个空间到那个空间、从这一场到下一场。
- **上一镜留**：物件在画面里，而且观众知道它重要。
- **下一镜接**：同一个物件，状态或位置变了，变化本身就是信息。
- **用在**：母题物件、证据、礼物、信；场间过渡。
- **AIGC 落法**：物件进资产表，每次出现用同一张参考图（`references/aigc/assets.md`）；分镜表写清它在每一镜的位置和状态（§3 物件流转表）。
- **失败**：物件只在剧情要用它的那一镜出现；前一镜还在桌上，下一镜已经在手里，没人看见是谁拿的。

### 运动与构图承接
- **是什么**：运动方向、注意中心的位置、形状在两镜之间延续（`storyboard/pacing.md` §2）。
- **上一镜留**：向右的运动、画面右上的注意中心、一个圆形。
- **下一镜接**：继续向右、注意中心在附近、另一个圆形（匹配剪接）。
- **用在**：追逐与行走；场间过渡的形状匹配。
- **AIGC 落法**：两镜写同一个画面方位；匹配剪接两镜用同一张构图草图做首帧（`camera/lexicon-transition.md` 匹配剪接）。
- **失败**：运动方向反了，观众以为人物往回走；注意中心每镜跳到画面另一边，剪辑点很扎眼。

### 情绪承接
- **是什么**：上一镜的情绪没有在剪辑点结束，而是留在下一镜里：反应多停一拍，或者切到一个还带着那股情绪的画面。
- **上一镜留**：一个刚落下的打击、一句刚说完的话。
- **下一镜接**：听者的脸、人走后的空间、留下来的物件（§4）。
- **用在**：转折之后；场尾。
- **AIGC 落法**：反应镜和余韵镜低运动、不张嘴，是最稳的镜头；时长写够（3–5 秒），不要在生成时压短。
- **失败**：情绪刚到就切走，下一镜开始一件新事。

## 3. 三种断层：查法与修法

### 物件断层

**症状**：物件出现得突然，位置和状态在镜头之间跳，观众看不出它是怎么到这里的。

**查法**：给每个关键物件列一张流转表。

| 物件 | 第一次出现 | 每次出现的位置 / 状态 / 谁拿着 | 跨过哪些剪辑点 | 落点 |
|---|---|---|---|---|
| 车票（§8 示例） | 3-01 小禾夹进账本 | 3-01 账本里，露一角 → 3-04 同上，老周看见 → 3-09 同上，灯熄 → 4-01 被抽出来压在账本上，旁边一张字条 → 4-02 在小禾手里 | 3-09 → 4-01（场间） | 小禾手里 |

**修法**

- 关键物件在它「起作用」的那一镜之前，先在画面里出现一次（埋）。
- 物件换了位置或状态，要么拍出是谁动的，要么让「变了」本身成为信息（观众看见变化，就知道中间发生过事）。
- 跨场的物件优先当场间接点（§5）。
- 外观一致靠资产表；**位置和状态的连续**靠流转表（`storyboard/continuity.md` 道具的位置与状态）。

### 空间断层

**症状**：每镜都在重新交代人在哪；人物从门口突然到了桌边；两场之间观众不知道人从哪来。

**查法**：每场写一行空间链：锚点在哪、轴线在哪、每个人从哪进、往哪出、中间怎么移动。

**修法**

- 一场只完整交代一次空间；之后靠视线、动作和入画出画把空间带过去，不要每镜重写。
- 建立空间不一定要空景全景：一个带纵深的中景（前景一人、背景一人）就交代了两人的距离。
- 人物移动，要么拍出路径，要么用出画 → 入画把路径合法地省掉（`storyboard/continuity.md` 出画与入画）。
- 场头先接上一场的尾，空间可以在第二、三镜再交代（由近到远，`storyboard/breakdown.md` 第四步）。

### 动机与视点断层

**症状**：镜头切到谁没有理由；关键台词说完，镜头跟着下一个说话的人走了，没人接住这句话。

**查法**：每场写一行视点链：这是谁的戏，视点在哪一镜交给谁，为什么交。再对每个切点问一句：**为什么现在离开这个人？**

能成立的理由只有几种：

| 离开的理由 | 例 |
|---|---|
| 他在看，我们去看他看的东西 | 视线承接 |
| 他在听，我们去看说话的人；或他在说，我们去看听的人 | 问答、声音承接 |
| 他的动作做完了，结果在别处 | 动作承接 |
| 有东西闯进来（声音、人、物） | 声音承接 |
| 我们想知道另一个人怎么接这件事 | 反应 |

**修法**

- 视点交出去之前，先让当前的人看向、听向或伸手向下一镜的对象。
- 关键台词之后，先给听的人，不给下一个说话的人（`storyboard/breakdown.md` 第五步）。
- 一场戏里视点最多交接一两次；每次交接都在镜流句里写出来。

## 4. 呼吸：余韵与停留的预算

**呼吸镜不是空镜。** 它带着上一刻的情绪，或者带着下一场的信息；只为好看而塞的空镜才会拖节奏。

| 呼吸的形式 | 是什么 | 例 |
|---|---|---|
| 事件后的停留 | 打击落下之后，留在接住它的那张脸上 | 她听完，下巴绷紧，两秒不动 |
| 人走后的空间 | 人物出画后，画面多留一拍 | 门关上，走廊空着 |
| 物件余韵 | 切到事件之后留下来的东西 | 没碰的咖啡、桌上的车票 |
| 环境呼吸 | 同一时空里的风、光、声音 | 台灯熄了，窗外有车灯扫过 |

**预算**

- 每场至少一处呼吸；情绪戏、转折戏两三处。
- 时长约占全场的 10–15%（行业惯例的经验值；文艺片更多，动作戏放在动作结束之后）。
- 呼吸的时长在第二步定镜头数时就留出来，不要等剪辑时发现没素材。

**场尾规则**

- 场尾不切在事件上，切在事件之后的第一个余韵上。
- 最后一镜比你以为的长 1–2 秒（`storyboard/pacing.md` §1）。
- 场尾的余韵最好同时是下一场的入口（§5）。

## 5. 场间接点：每两场之间单独设计

每两场之间写一行：上一场的最后一镜留下什么，下一场的第一镜怎么接住它。

| 接点 | 上一场尾 | 下一场头 | 在说什么 |
|---|---|---|---|
| 声音先入（J-cut） | 画面还在上一场 | 下一场的声音已经进来 | 有事在等着她 |
| 声音拖后（L-cut） | 上一场的声音延续 | 画面已在下一场 | 那句话还压在他心上 |
| 声音桥 | 一首歌、一个钟声 | 同一个声音在新时空继续 | 这两段是一回事 |
| 物件匹配 | 一个物件 | 同一个物件，状态或位置变了 | 中间发生过事 |
| 动作 / 形状匹配 | 一个动作或形状 | 相似的动作或形状 | 这两件事有关 |
| 光 / 时间 | 夜里灯熄 | 同一个地方，晨光 | 一夜过去了 |
| 带信息的过渡镜 | — | 一个预告下一场的画面 | 下一场是雨夜，就先下雨 |
| 有意硬切 | 安静 | 巨响；或反过来 | 断裂本身就是意思 |

做法见 `camera/lexicon-transition.md` §4–§5。

**规则**

- 场头不默认建立镜。先接上一场的尾，观众真的会迷路时再给空间。
- 下一场的第一镜要回答（或加剧）上一场最后一镜留下的问题。场与场之间写得出「因此」或「但是」（`craft/story/04-scene.md`），镜与镜之间也要写得出。
- 硬切可以用，但要写明为什么硬切。一个片子里全是无理由的硬切，等于没有设计过场间。

## 6. 读链测试

分镜写完，按顺序只读每个切点的「接 / 出」，把每个切点写成一个连接词加一句理由：

```text
3-01 → 3-02  因此：票角露着，镜头退开，让观众看见老周正往这边擦过来
3-02 → 3-03  然后：？？？
```

- 写得出「因为 / 所以 / 但是 / 同时 / 于是」的，留下。
- 只能写「然后」的，标出来。它要么缺了一个接点（回到 §2 补一种承接），要么这两镜该合并，要么后一镜该删。
- 一场里超过三分之一的切点是「然后」，回到 §1 重写镜流句。

每个切点再问三句：观众此刻想知道什么？这一镜回答了吗？它留下什么问题给下一镜？

## 7. AIGC：剪辑单位和生成单位分开

- **先按剪辑设计镜流，再合并成生成单位。** 「一镜一动作」是生成的约束，决定在哪里拆开生成；它不决定故事在哪里切。几个相邻镜头可以合成一次生成，再在剪辑里切开（`references/video-prompt/compile.md`）。
- **承接靠剪辑完成的部分，生成时要留料。** J / L 剪接、声音桥、动作承接都在剪辑里做；每镜生成时长比分镜多 0.5–1 秒（`storyboard/pacing.md` §6）。
- **物件承接靠资产，视线和运动承接靠画面方位。** 物件用同一张参考图；视线和运动方向在两镜里都写画面左右。
- **呼吸镜是最便宜的镜头。** 低运动、不张嘴、常常没有人脸，生成最稳；删镜时最后才删它们（`storyboard/breakdown.md` 第二步）。

## 8. 示例：打卡版和承接版

本包原创的两场戏：

```text
场 3  夜  内  面馆
△ 打烊后，老周擦桌子。女儿小禾在柜台后算账。
△ 小禾把一张车票夹进账本，合上。
△ 老周擦到柜台，看见账本里露出的车票一角。
老周：明天几点的车？
小禾：不去了。店里离不开人。
△ 老周没说话，继续擦桌子。

场 4  晨  内  面馆
△ 小禾下楼。店里没开灯，卷帘门半开。
△ 柜台上，账本压着那张车票，旁边一张字条：「车是九点的。店有我。」
△ 小禾拿起车票。
```

**打卡版**（一个 beat 一镜）：

| 镜 | 画面 | 时长 |
|---|---|---|
| 3-01 | 全景：面馆打烊，老周擦桌，小禾在柜台后算账 | 4 s |
| 3-02 | 特写：小禾把车票夹进账本 | 3 s |
| 3-03 | 中景：老周擦到柜台，看见车票 | 4 s |
| 3-04 | 双人：老周问「明天几点的车？」，小禾答「不去了。店里离不开人。」 | 6 s |
| 3-05 | 中景：老周继续擦桌子 | 4 s |
| 4-01 | 全景（硬切）：清晨的面馆，卷帘门半开 | 3 s |
| 4-02 | 特写：账本压着车票和字条 | 3 s |
| 4-03 | 近景：小禾拿起车票 | 3 s |

读链：3-01 然后 3-02 然后 3-03……八个切点全是「然后」。

- 3-03 老周「看见」，观众没看见他看的东西（视线断层）。
- 3-04 两人在一镜里说话，「不去了」这句话没有落在任何人脸上（视点断层）。
- 场 3 停在「继续擦桌子」这个事件上，没有余韵。
- 4-01 用建立镜重启。车票从账本里跑到账本上，看不出是谁动的，也没让观众意识到「夜里有人动过它」（物件断层）。

**承接版**：

镜流句：

```text
小禾把车票夹进账本 → 但是票角露在外面 → 同时老周正往柜台擦过来 → 抹布碰到账本，停住
→ 因此他看见票角 → 因此他问几点的车 → 但是她不抬头，说不去了 → 这句话落在他脸上
→ 他没接话，抹布又动起来 → 镜头留给她：笔停着，没写 → 灯熄，只剩票角
→ 一夜过去：同一个账本，晨光里，车票被抽出来压在上面 → 因此她拿起来，读到字条
```

| 镜 | 画面 | 接（从上一镜接住什么） | 出（留给下一镜什么） | 时长 |
|---|---|---|---|---|
| 3-01 | 中近：小禾在柜台后把车票夹进账本，合上；票角露在外面 | 场头从动作开始，不建立 | 票角 | 3.5 s |
| 3-02 | 中景：前景是柜台和账本，背景老周弯腰擦桌，一路擦向柜台 | 物件：票角在前景；一镜交代两人的距离 | 抹布在逼近 | 4 s |
| 3-03 | 近：老周的抹布擦到账本边，停住；他的视线落向画面下方 | 动作：擦过来的动作做完 | 他在看什么？ | 2.5 s |
| 3-04 | 特写（老周的视线）：账本里的票角 | 视线 | 他会问吗？ | 2 s |
| 3-05 | 中近：老周没抬头，问「明天几点的车？」 | 问答 | 她怎么答？ | 3 s |
| 3-06 | 近：小禾不抬头，笔还在动，「不去了。」 | 问答 | 这句话落在谁身上？ | 2.5 s |
| 3-07 | 近：老周看着她；小禾（画外）「店里离不开人。」他没接话，抹布又动起来 | 声音：话拖到听者脸上 | 抹布声 | 4.5 s |
| 3-08 | 近：小禾的笔停在账本上，没写；抹布声在画外渐渐远了 | 情绪：视点交给她 | 呼吸 | 4 s |
| 3-09 | 特写：账本和票角；台灯熄灭，只剩窗外微光；尾部早班车喇叭先进来 | 物件；光 | 车票，一夜 | 3 s |
| 4-01 | 特写（同一构图）：晨光里的账本，车票已被抽出来压在账本上，旁边一张字条 | 物件 + 构图匹配；喇叭声（先于画面） | 谁动的？ | 3 s |
| 4-02 | 近：小禾的手入画拿起车票，读字条「车是九点的。店有我。」 | 问答 | 他在哪？ | 4 s |
| 4-03 | 中近：小禾抬头，看向画右的后厨；后厨传来揉面声 | 声音；视线 | 她看见什么？ | 2.5 s |
| 4-04 | 中景（小禾的视线）：门帘后老周的背影在揉面，没有回头 | 视线；情绪 | 余韵 | 4 s |

读链：十二个切点，每个都写得出连接词。

- 3-08 和 4-04 是两处呼吸，约占 8 秒。
- 3-09 → 4-01 是场间接点：物件、构图和光三重匹配，加一声喇叭（J-cut），观众一看就知道一夜过去了、有人动过车票。
- 4-03、4-04 是分镜补的：剧本没写老周在后厨，补上这一组视线，场 4 才有回应。补戏要回给编剧确认。

**生成**：13 镜不等于 13 次生成。3-02 / 3-03 可以合成一次缓推；3-05 至 3-07 用两次生成，剪辑时把台词铺到听者镜上；3-09 和 4-01 用同一张构图关键帧，换光生成（`storyboard/shot-functions.md` 时间流逝）。

## 9. 常见错误

| 错误 | 改法 |
|---|---|
| 先切镜，再想怎么接 | 先写镜流句（§1），切点落在箭头上 |
| 每场先来一个全景 | 场头先接上一场的尾；空间在第二、三镜交代（§5） |
| 事件完成就切走 | 在事件之后的第一个余韵上切（§4） |
| 场间全是硬切 | 每两场之间写一行接点；用硬切要写明理由（§5） |
| 镜头切到谁没有理由 | 问「为什么现在离开这个人」（§3） |
| 物件只在要用的那一镜出现 | 先埋一次；列流转表（§3） |
| 为了呼吸塞空镜 | 呼吸镜要带着上一刻的情绪或下一场的信息（§4） |
| 让「一镜一动作」决定故事在哪里切 | 剪辑单位和生成单位分开（§7） |

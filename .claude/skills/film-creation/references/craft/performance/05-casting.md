# 角色设计与一致性

## 核心判断

AIGC 里没有真人可挑，只有角色设计。要判断的不是“谁最像这个角色”，而是这个角色资产能不能完成角色的动作清单，以及跨镜头能不能保持一致。长相不是先决条件；能否在缩略图尺寸被认出、能否支撑全片最重的动作，才是。

## 书里的原则

阿德勒在《表演的艺术》第 1 课讲“位置”：每个角色在整体配置里有适合自己的位置，没有人能覆盖所有类型；位置先定，能力才有上限。她还拆掉“被发现”的神话：没有经过工具验证的设定，机会来了也撑不住。对应到 AIGC，角色不是从一张脸里挑，而是按位置设计，并先验证它能否执行角色所需的动作。

哈根在《尊重表演艺术》第 1 章《基本概念》把才华拆成可观察清单：敏感性、易受伤的心灵、敏锐知觉、活泼想象、对现实的领悟、想传达经验的欲望、想被看见的冲动；同时强调身体、声音、语言这些外在工具必须训练。她说外表美不是先决条件：习惯被赞美的一方容易被动，不被注意的一方反而更早学会争取视线；才气纵横的心智也不是必要条件。第 21 章又补一句：真正高超的技巧应能演出任何角色——位置是配置问题，能力是上限问题。对应到角色 token：辨识度与可执行动作范围，优先于通用美型。

## AIGC 执行

角色设计先写动作清单，不写性格形容词：这个角色要推、要等、要挡、要递、要退。再看设计的工具能否覆盖这份清单。AIGC 的“工具”是可见项：年龄、体型、脸型、眼睛、发型、肤色、服装、配饰、疤痕、默认姿态、表情基线；有声时再加音色与语速。

一个角色只写一条固定 token，字段顺序不变，逐字复用：

```text
C1: 30s East Asian woman | slim | sharp jaw | narrow eyes | shoulder-length black hair | pale skin | grey wool coat | black turtleneck | scar above left eyebrow | upright | guarded
```

设计判据有四条。第一，辨识度：缩小到缩略图仍能靠轮廓或一个特征认出。第二，动作范围：体型与服装允许角色完成最难的那场动作，不因长外套或高跟鞋而只能站桩。第三，位置区分：主角、对手、摇摆者、旁观者各有不同剪影，多人同框不混脸。第四，稳定性：token 越短越稳，只留决定身份的词；情绪词不进身份 token。

一致性先靠参考图：身份 token 定稿后出一张角色表，之后每镜挂图，正文只写动作不重复外貌；没有参考图时才靠文本锁，每镜原样粘贴同一串 token，不改写、不换同义词，漂移时用原 token 重跑，而不是换词试。服装变体另建 token（C1-W2），标明继承关系，不把两套衣服写进同一条。道具归属写进 P token（谁的手、哪个口袋），避免下一镜换手。

## 检查清单

- [ ] 角色的动作清单是否先于外形写完？
- [ ] 设计能否覆盖全片最难的动作？
- [ ] 缩略图尺寸还能认出这个角色吗？
- [ ] 主要角色的剪影是否彼此区分？
- [ ] 身份 token 是否逐字复用、没有同义改写？
- [ ] 服装与道具变体是否有独立 token 和继承关系？
- [ ] 多人镜头是否挂齐每人的参考图、只让一人占最显眼的正脸？
- [ ] 我是否因为“好看”而牺牲了辨识度或动作范围？

## 常见错误

- 每条 prompt 重写外貌 → 脸、发长、衣服逐镜漂移；固定 C token 原样复用。
- 堆“beautiful | stunning | gorgeous” → 生成通用偶像脸，角色之间无法区分；换成一个具体特征。
- 给两个角色写相似剪影 → 同框时脸和衣服互相污染；先拉开体型、发型、服装轮廓。
- 把情绪写进身份 token → 下一镜无法回到基线；身份与表情分开，表情进表演 token。
- 角色设计只服务正面特写 → 全景动作做不了；先测动作范围，再定服装与体态。

## 与风格层接口

角色 token 是资产层，风格 token 是视觉层；两者在 prompt 里分开写。导演/摄影档案决定光色与镜头，角色设计决定这个人在该光色下的轮廓是否还读得清。与调度模块的分界是：角色设计给可执行的动作范围，调度给这个范围内的人物位置与移动；与制作模块的分界是：这里判断设计能否撑住全片，生成次数与一致性 pass 在那边算。

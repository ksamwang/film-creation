# 场面调度

## 这个模块解决什么

剧本写“两人在厨房争吵”，但没有写谁站在灶台边、谁堵住门口、摄影机在冰箱这一侧还是窗那一侧。场面调度就是把这句话变成一组可执行的决定：这场戏占用空间中的哪一块，人物按什么顺序移动，摄影机从哪里看，这些镜头又如何被剪成一个连续的空间。它同时处理三个对象——场景、演员、摄影机——并让三者的变化互为依据。

## 先读哪篇

先读《01-space》，确定这场戏的空间边界与动作范围；再读《02-blocking》，把人物关系写成走位；《03-camera-movement》处理机器如何参与；《04-coverage》决定用哪些镜位保住空间与因果；《05-multi-character》处理三人以上；《06-scene-analysis》把以上决定固化成开拍前的拆析表。

## 子文件

- `01-space.md` 场景空间、动作的戏剧性范围、受限与开阔空间。
- `02-blocking.md` 区域调度、逐个角色调度、反向运动。
- `03-camera-movement.md` 运动动机、反推镜头、移动兴趣中心。
- `04-coverage.md` 主镜头、长镜头、备用镜头与剪辑覆盖。
- `05-multi-character.md` 表演区域、三角群、三人与四人调度。
- `06-scene-analysis.md` 三遍剧本拆析、视觉化方案与镜位表。

## 使用方式

每次只回答一个问题：这场戏的空间事件是什么？答案必须能落成位置、距离或朝向的变化，而不是情绪形容词。若一个调度决定无法在平面图上画出，也无法在剪辑台上被验证，就不算决定。工作顺序固定：先定空间事件，再定走位，最后定机位；顺序反过来，每一层都在给前一层打补丁。

## 模块边界

本模块不处理镜头美学、灯光与色彩（见 visual），也不处理演员如何建立内心动作（见 performance）。它只回答位置问题：人物在哪、机器在哪、观众先看到什么。同一个走位可以被拍成冷静或压迫，那属于风格层；但走位本身必须先成立，风格才有东西可附着。

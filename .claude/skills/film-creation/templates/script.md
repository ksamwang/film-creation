# Script（短片剧本）

> 通用短片剧本（30 秒–10 分钟）。竖屏短剧用 `drama-episode.md`，台词与格式规则以 `references/drama/04-script.md` 为准。
> 完整填写示例见 `references/writing/example.md`。

## 片头信息

- 片名：
- 一句话（谁 + 想要什么 + 被什么挡住 + 最后怎样）：
- 主类型 / 副类型（`references/writing/genres/`）：
- 时长档（60 秒 / 3–5 分钟 / 其他）：
- 知识关系（观众大于 / 等于 / 小于人物；在哪一拍切换）：
- 结尾要留下的感受：

## 正文

```text
场 1  {日 / 夜 / 晨 / 昏}  {内 / 外}  {地点}
人物：{角色名}

△ {谁} {做什么}，{停在哪}。
{角色}（{情绪}）：{台词}
{角色}（VO）：{画外音}
{角色}（OS）：{内心独白}
【字幕】{必须让观众读到的字}
```

动作行写成起点 → 动作 → 落点，一行一个主导动作，不写镜头术语（`references/drama/04-script.md` §2）。

## 检查

- [ ] 一句话复述得出来，有赌注（`references/writing/doctor.md` 第 1 层）？
- [ ] 主角主动，真相由他的行动揭开，不是别人告诉他？
- [ ] 每场结束时局面都变了，场与场之间是「因此 / 但是」？
- [ ] 开场在类型约定内（`references/writing/genres/` 的「观众在等什么」）？
- [ ] 每个伏笔都有回收，回收前至少再提醒一次？
- [ ] 台词在做事、人物声口分得开，最重要的那句没有直接说出口（`references/writing/dialogue.md`）？
- [ ] 每句台词能在所在镜头里说完，一镜一个说话人？
- [ ] 写下的每一行都画得出来，资产数量在预算内（`references/aigc/assets.md`）？

# 音乐：情感共鸣、非情感共鸣与位置

## 核心判断

音乐的第一决定不是风格，是位置和功能：它从哪儿来、角色听不听得见、它站在人物这边还是拒绝参与。位置定错，再好听的配乐也只是贴片。

## 书里的方法

**情感共鸣与非情感共鸣。** 书里把电影音乐分两类：情感共鸣的音乐顺着场景的情绪走，用文化编码放大悲伤、喜悦；非情感共鸣的音乐故意无动于衷，用稳定、天真、近乎机械的方式继续，反而把情绪压得更重。八音盒、钢片琴、自动钢琴、伴舞乐队常干这件事。书里还提到第三种情况：既不共鸣也不冷漠，只当路标用的音乐。非情感共鸣那种有秩序的漠不关心，暴露了电影本身的机械性。

**音乐产生的增值。** 音乐让观众觉得情绪是从画面里自然长出来的，其实是被加进去的。增值越成功，观众越不觉得有音乐。所以判断音乐是否必要，不是听它好不好听，是看把它拿走之后画面还剩下什么。

**位置先于风格。** 书里区分乐池音乐与银幕音乐：乐池音乐在故事世界之外，评论、引导、穿越时空；银幕音乐有可见或可指认的声源，角色也听得见。还有第三类，远距离传播的音乐（收音机、邻居的音响、电话里的音乐），它把另一个空间带进来。位置决定音乐能知道什么、能做什么。

**音乐不是节拍器。** 书里把音乐当标点，也提醒同步点过密会让音乐变成动作的音效。音乐一旦逐帧跟着动作，它就失去了自己的时间，观众只会听见“配合”。

## 可执行规则

1. 每条音乐先写位置：乐池、银幕或远距离传播；位置决定角色是否听见。
2. 每条音乐只选一个主功能：共鸣、拒绝（非情感共鸣）、结构标点；不要一条兼三职。
3. 非情感共鸣的音乐不跟动作、不渐强、不变速；它要像什么都没发生。
4. 音乐不在情绪转折点上进入；提前或延后，让转折属于画面和表演。
5. 音乐不落在动作同步点上；要落，就把它做成音效，而不是配乐。
6. 用音乐跨时间或空间省略，不用音乐盖烂剪辑；没有音乐也成立的转场，不要加。
7. 画内音乐当物体处理：距离、失真、被打断；它不能像配乐一样干净。
8. 关掉音乐试一遍；如果只少了气氛，考虑去掉；如果少了结构，保留但把结构写清楚。

## 检查清单

- [ ] 音乐位置写了吗？角色听不听得见？
- [ ] 主功能是一个还是三个？
- [ ] 非情感共鸣的音乐是否真的无动于衷？
- [ ] 音乐进入点是否避开了情绪转折？
- [ ] 有没有音乐砸在动作同步点上？
- [ ] 音乐是在跨省略，还是在盖剪辑？
- [ ] 画内音乐有空间处理吗？
- [ ] 关掉音乐，这场戏还剩下什么？

## 与风格层接口

导演档案的音乐栏写四件事：位置、功能、进入时机、编制；不写“温暖”“紧张”。摄影与剪辑据此决定段落的呼吸：乐池音乐可以跨剪辑，画内音乐必须被空间约束。AI 视频提示把音乐写成可执行的声源或明确的“无音乐”：`diegetic radio, distorted, offscreen` 或 `no music`；不要写 `emotional score`，模型既不会作曲，也会把“情绪”翻译成廉价的画面滤镜。

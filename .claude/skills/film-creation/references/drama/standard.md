# 短剧数据标准 v1

> 竖屏短剧从创意到成片的**产物契约**：每个阶段交什么、字段叫什么、取值范围多大。
> 平台照这份标准落表，编剧和 LLM 照这份标准出稿，两边不需要互相猜。
> 字段名用英文（便于落表），说明文字用中文。

## 两种语言

| 语言 | 管什么 | 来源 |
|---|---|---|
| **台词语言** `dialogue_lang` | 台词、vo、os、字幕卡、剧名、人名的文化 | 项目设定，BCP 47（`en-US`、`zh-CN`、`zh-TW`…） |
| **说明语言** | 动作行、场景名、情绪、大纲文字、造型描述、分镜描述 | 使用者的界面语言 |

- `zh-TW` / `zh-HK` / `zh-MO` 台词用繁体字和当地用词；`zh-CN` / `zh-SG` / `zh-MY` 用简体字。
- 分镜描述用说明语言写，台词**原样保留**剧本里的台词语言，不翻译、不改写。
- 中日韩文字按字计数，其余按词计数。

## 项目参数（不进提示词）

画幅、模型、分辨率、时长档、线路、生成音频开关都是**平台参数面板**的事，不写进任何提示词或描述。

| 字段 | 取值 | 说明 |
|---|---|---|
| `market` | 国家/地区码，如 `US`、`CN`、`TW` | 决定人名、地名、货币、节日、题材偏好 |
| `dialogue_lang` | BCP 47 | 见上 |
| `aspect_ratio` | 默认 `9:16` | 片段画幅；造型图画幅另有规格（P5） |
| `style` | 预设名，或一句视觉风格描述 | 项目级视觉风格，只由平台拼进生成参数；写法见 `10-look.md` |
| `episodes` | 1–200 | 计划集数 |
| `segment_s` | `15` 或 `30` | 每个片段的时长上限，分镜前选定 |
| `video_model` | 模型标识 | 能力（最长时长、参考图上限、是否收参考音频）从模型能力表读 |

## P1 立项设定 setting

```json
{
  "title": "剧名（台词语言）",
  "episodes": 60,
  "logline": "一句话故事：谁 + 处境 + 目标 + 阻碍 + 亮点",
  "synopsis": "全剧走向与结局，300–600 字/词",
  "audience": "目标受众与情绪导向（获得感 / 关系感）",
  "genre": "赛道，如 重生复仇 / CEO romance",
  "hook": "核心梗：观众为之而来的那个套路",
  "characters": [{
    "name": "按台词语言的文化起名",
    "role": "lead | support | villain | extra",
    "visual": "外形特征卡：年龄、体型、五官、发型、服装（含 hex 色）",
    "tags": ["标签"],
    "background": "出身与处境",
    "history": "关键经历",
    "personality": "性格与说话方式",
    "relations": "与其他角色的关系",
    "arc": "全剧弧线"
  }]
}
```

- `characters` 是**全量列表**；改名用 `"renamed_from": "旧名"`，只写新名视为新角色。
- 最多 40 个角色。`visual` 是之后所有造型图的源头，写得能画出同一个人（见 `05-breakdown.md`）。

## P2 分集大纲 outline

```json
{"episodes": [{
  "number": 1,
  "title": "集标题",
  "summary": "本集发生什么（3–5 句）",
  "anticipation": "期待点：观众本集在等什么",
  "payoff": "爽点：本集兑现的那一下",
  "hook": "结尾钩子：停在哪一个未完成的瞬间"
}]}
```

三个字段缺一不可：没有 `anticipation` 观众不知道为什么看，没有 `payoff` 观众觉得白看，没有 `hook` 观众不点下一集。写法见 `02-season.md`、`03-episode.md`。

## P3 单集剧本 script

```json
{"scenes": [{
  "heading": {"number": "1-1", "time": "day", "place": "int", "location": "地点（说明语言）"},
  "cast": ["出场角色名"],
  "lines": [
    {"type": "action", "text": "△ 看得见的动作"},
    {"type": "dialogue", "who": "角色名", "emotion": "语气", "text": "台词（台词语言）"},
    {"type": "vo", "who": "角色名", "text": "画外音"},
    {"type": "os", "who": "角色名", "text": "内心独白"},
    {"type": "caption", "text": "画面字卡"}
  ]
}]}
```

| 字段 | 取值 |
|---|---|
| `time` | `day` / `night` / `dawn` / `dusk` |
| `place` | `int`（内景）/ `ext`（外景） |
| `type` | `action` / `dialogue` / `vo` / `os` / `caption` |
| `who` / `cast` | 角色名，与设定**逐字一致**；`action`、`caption` 不填 `who`、`emotion` |

渲染成剧本格式时：`场 1-1 日 内 地点`、`△动作`、`角色（情绪）：台词`、`角色（VO）：`、`角色（OS）：`、`【字幕】`。中日韩台词用全角标点。写法见 `04-script.md`。

## P4 资产拆解 breakdown

```json
{
  "characters": [{"name": "林晚", "role": "lead", "looks": [
    {"label": "重生前·基础形象", "visual": "特征卡", "episodes": [1, 2]},
    {"label": "重生后·职场形象", "visual": "特征卡", "episodes": [3, 4, 5]}
  ]}],
  "scenes": [{"name": "顾氏集团", "looks": [
    {"label": "开放办公区_白天", "visual": "空间、陈设、材质、光", "episodes": [1, 3]}
  ]}]
}
```

- 只有**角色**和**场景**两类，**没有道具**：剧情关键物件写进所属造型或子场景的 `visual`。
- **造型名** = `角色名 · 标签`（中间是空格 + 间隔号 + 空格）；只有一个造型时标签叫「基础形象」/「Base look」。
- 每个角色或场景最多 6 个造型；第一个是**基础**，其余是它的**变体**（以基础图为参考生成）。
- 增量合并：列出本次涉及的全部造型（已有的写原名原标签），只新增、不删除。
- `visual` 只写人或地方，不写画幅、构图、风格词。拆法见 `05-breakdown.md`。

## P5 造型图 look image

**一个造型 = 一张参考图。** 片段引用几个造型就带几张图；多角度、表情图需要时另做，不是必填。

| 造型 | 规格 |
|---|---|
| 角色（立绘） | 3:4，白底，正面全身，自然站立，空手 |
| 角色（设定稿，可选） | 3:2 三格：左去头正面全身 · 中背面全身 · 右四分之三胸像；纯浅灰底；全稿只有一张脸。格式见 `templates/character-sheet.md` |
| 子场景 | 16:9 横构图，**不含人物**；与项目画幅无关（视频模型要从参考图读空间布局，竖图会把两侧裁掉） |
| 变体 | 以基础图作参考图生成，提示词开头写明「与参考图是同一个人，只改服装、妆容和状态」或「同一个地点，只改区域、视角或时间」 |

## P6 分镜 storyboard

**片段（segment）= 一次视频生成**，里面按顺序放 1–8 个**分镜（shot）**，分镜之间硬切。

```json
{"segments": [{
  "scene": "顾氏集团 · 开放办公区_白天",
  "shots": [{
    "duration_s": 3,
    "size": "medium",
    "angle": "eye_level",
    "move": "static",
    "text": "@[林晚 · 重生前·基础形象] 站在画左工位旁，双手攥着辞职信；@[顾言 · 基础形象] 从画右走近，停在她面前一臂远。",
    "dialogue": [{"who": "顾言", "emotion": "冷笑", "text": "签了它，你就自由了。"}]
  }]
}]}
```

| 字段 | 取值 |
|---|---|
| `scene` | 一个子场景造型的**完整名字**（不带 `@[]`） |
| `duration_s` | 0.5–15，保留一位小数 |
| `size` 景别 | `extreme_wide` 大远景 · `wide` 远景 · `full` 全景 · `medium` 中景 · `medium_close` 中近景 · `close` 特写 · `extreme_close` 大特写 |
| `angle` 角度 | `eye_level` 平视 · `high` 俯拍 · `low` 仰拍 · `overhead` 顶拍 · `dutch` 倾斜 · `over_shoulder` 过肩 · `pov` 主观 |
| `move` 运镜 | `static` 固定 · `push_in` 缓推 · `pull_out` 缓拉 · `pan` 横摇 · `tilt` 竖摇 · `tracking` 跟随 · `orbit` 环绕 · `crane` 升降 · `handheld` 手持 · `zoom` 变焦 |
| `text` | 画面描述（说明语言）：站位、动作链、表情；造型写成 `@[造型名]`；≤1500 字 |
| `dialogue[]` | `who` 角色名 · `emotion` 一两个词 · `text` 台词原文；每镜 ≤8 句 |

- 景别、角度、运镜**只放枚举字段**，不写进 `text`；枚举之外的值会被丢弃。
- 三个枚举都可省略；省略即交给模型。
- 片段时长 = 各分镜之和，不超过 `segment_s` 与模型上限中较小的一个。
- 引用的造型数（**含场景**）≤ 模型的参考图上限。
- 同一场景的连续镜头尽量塞满一个片段（目标：上限前 2 秒到上限）；只有换场景、或再加一镜就超出镜数/参考图上限时才提前结束。相邻两段同场景且合起来放得下 = 不合格，要合并。
- 规划写法见 `06-storyboard.md`。

## P7 片段提示词 compiled prompt

由分镜**机械编译**，不手写。编译器按分镜描述所用的说明语言选框架（以 `zh` 开头用中文框架，其余用英文框架）：

**中文框架**

```text
本片段场景设定在：@[{scene}]。生成一个由以下{N}个分镜组成的视频，按顺序播放，分镜之间直接硬切。

分镜1 {duration}s：{景别}，{角度}，{运镜}。{text} {who}（{emotion}）说：“{台词}”

音频里不要有背景音乐。
画面中不要出现任何文字、字幕或标题。
```

单镜头时第二句换成「生成一个一镜到底、中间不切镜的视频。」

**英文框架**

```text
This segment is set in @[{scene}]. Generate one video made of the following {N} shots, in order, with hard cuts between them:

Shot 1 ({duration} s): {Size}, {angle}, {move}. {text} {who} says ({emotion}): “{line}”

No background music in the audio.
No text, captions or subtitles in the picture.
```

单镜头时第二句换成 `Generate one continuous shot:`。

- 景别/角度/运镜由枚举翻成固定词表（中英各一套），值见 P6 表。
- 结尾两句是**固定约束**，由编译器加，分镜里不要再写。
- 视频时长取模型可选时长中能装下本段的最小值；画幅取项目画幅。
- 台词由视频模型直接说出；模型有生成音频开关时固定打开。
- 角色有音色参考时，平台把参考音频随 `@[名字]` 一起带上。
- 编译结果就是最终提交内容；可以手动微调后再生成。提示词写法与模型差异见 `07-segment-prompt.md`。

## P8 成片 cut

成片阶段统一处理片段里刻意不做的事：

| 项 | 来源 |
|---|---|
| 片段顺序、掐头去尾、原声开关 | 每集一条时间线，按片段当前版本 |
| 字幕 | 由分镜台词生成，后期烧录或外挂 SRT，不让视频模型画字 |
| 配乐 | 整集统一加 |
| 配音 | 只做补录：某段没出声或台词错了 |
| 动态漫 / 静帧（例外） | 片段不靠模型出声，成片阶段整集配音，镜头时长按配音定；台词仍写在 `dialogue`（`10-look.md` 第 3 节） |

写法见 `08-cut-qc.md`。

## 引用规则 @[名字]

- 在分镜 `text` 里提到造型，一律写 `@[造型完整名]`，名字逐字照抄造型列表。
- 角色本人（非造型）在 `who`、`cast` 里用纯名字，不加 `@`。
- 不带方括号的 `@名字` 会按「`@` 后最长匹配的造型名」处理；匹配不上就是错误，要重写。
- 带方括号但对不上任何造型的引用会被保留并标警示。
- 删掉的造型在文字里退化成不带 `@` 的纯名字，句子不缺主语。
- 平台存库时可把 `@[名字]` 换成内部 ID，读写时再换回名字，改名不断引用。

## 上限总表

| 项 | 上限 |
|---|---|
| 集数 | 200 |
| 角色（设定） | 40 |
| 每个角色/场景的造型 | 6 |
| 每集场次 | 30 |
| 每场行数 | 200 |
| 单行字数 | 1500 |
| 每集片段 | 60 |
| 每片段分镜 | 8 |
| 每分镜时长 | 0.5–15 s |
| 每分镜台词 | 8 句；每句 ≤400 字，`who` ≤40，`emotion` ≤40 |
| 每片段引用造型 | 模型参考图上限（未知时按 3） |

上限是硬约束；**创作上的建议值远小于上限**，见各阶段文件。

## 输出约定

- 有工具或接口规定输出格式时，**以工具为准**，本标准只提供写法。
- 在对话里交付时：先给人读的版本（剧本格式 / 分镜表），再给一个可直接落表的 JSON 代码块，字段与本标准一致。
- 不在 JSON 里写注释、不加多余字段；没有值的可选字段直接省略。

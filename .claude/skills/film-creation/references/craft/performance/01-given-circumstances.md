# 规定情境：把上下文写成可生成的 token

## 核心判断

模型没有“相信”，只有上下文。一个生成人物看起来假，通常不是脸不够细，而是提示词没有交代他此刻身处什么事实之中。规定情境要做的，是把这些事实写成模型能执行的条件，让人物的动作从环境里长出来，而不是从“表演”里长出来。

## 书里的原则

哈根在《尊重表演艺术》第 11 章《基本的目标训练》里把这项工作拆成六类：时间、地点、周围环境、情况（过去、现在、未来）、关系、目标与障碍。第 23 章《情况》把它单列为独立研究对象。她的示范是七月湿热的一天：人物跑遍经纪人的办公室被拒，穿薄底凉鞋走肿了脚，爬了三层楼，回屋看见一团糟——这些事实决定他先脱鞋还是先开窗。

阿德勒在《表演的艺术》第 2 课把颗粒度再推细。她引斯坦尼斯拉夫斯基：艺术的真实就是情境的真实，情境统摄一切，证实我身处何处。她要求回答“我身处何处”时不能停在“房间里”，要能说出周围建筑、年份、季节、听者阶层与衣着、树种与花期。她还用一把椅子做检验：颜色、背面每处划痕、哪里掉漆、弹簧从哪里顶出、哪条腿不稳，以及它要求人笔直坐还是瘫着坐。情境越具体，生成的人物越松弛；情境笼统，模型只能给他一个通用站姿。

## AIGC 执行

先写一个 CONTEXT 块，只放事实，不放情绪：

```text
CONTEXT: 1973 | New York | third-floor walk-up | July heat | swollen heel | unopened mail | man at window across street | 10:00 audition
```

然后逐条问：这个事实能不能变成画面里看得见的东西。时间落到光与汗；地点落到墙面、窗框、楼层；过去落到身上的痕迹；关系落到距离和物件归属；目标与障碍落到动作对象。写不出来的事实，等于没写。

图像 prompt 用可观察状态替换氛围词。不写 `tense atmosphere`，写 `sweat at hairline | shirt stuck to back | one sandal off | stack of unopened mail`。视频 prompt 的首帧继承情境，运动从一个情境事实启动：热就抬手擦汗或推窗，门外有脚步就先看门再起身。

资产 token 承接情境：场景用 S 编号，关键道具用 P 编号，人物加一条 body-state token（湿发、手上的灰、没换的衬衫）。这些 token 在同一场里逐字复用，情境才不会在镜头之间漂移。

NEGATIVE 写具体失败模式：`generic apartment | clean clothes | studio backdrop | empty surfaces | symmetrical pose`。

## 检查清单

- [ ] CONTEXT 是否包含时间、地点、环境、过去、现在、未来、关系、目标与障碍？
- [ ] 每条情境事实是否都有一个可见对应物？
- [ ] 关键道具是否写清了材质、磨损和使用方式？
- [ ] 人物身上是否带着上一件事留下的痕迹？
- [ ] 首帧是否已经能读出情境，而不是靠运动补？
- [ ] 情境 token 在整场里是否逐字复用？

## 常见错误

- 把情境写成人物小传 → 模型读到一堆抽象关系，画面仍是通用房间；改成物件、痕迹、距离。
- 用“压抑的房间”代替具体陈设 → 生成的是模板化暗调内景；改为墙面材质、光源、桌面状态。
- 每镜重写情境 → 场景 token 漂移；固定 S/P token，只改动作与景别。

## 与风格层接口

导演与摄影档案提供光色、镜头和材质的上限，情境决定这些 token 能具体到什么程度。两者冲突时先保情境事实，再收风格：人物脚是肿的，就先给脱鞋与坐姿，再谈低机位和暖调。写 prompt 的顺序是 subject → context → action → shot → light，情境块不抢主体，但它必须在场。

# 叙事：视点归属、聚焦与时间折叠

## 核心判断

叙事决定每一镜属于谁的眼睛、观众比人物多知道还是少知道、过去与现在靠什么区分。AIGC 最容易出的问题不是“讲不清”，而是镜头没有归属：模型给一个漂亮的漂移镜头，观众不知道在跟谁看。

## 书里的原则

**视点即表意（《电影叙事学研究》第 10 章 10.1）。** 三个版本的《金刚》出场，镜头数从 15 到 31 再到 49，真正的变化是视点分配：1933 年版以观众为主，1976 年版近一半镜头给金刚，2005 年版回到观众。分配变了，金刚的含义就变了。

**暗隐叙述者与明现叙述者（同书附录一，若斯特访谈）。** 真实作者不等于陈述者；组织画面与声音的是看不见的“大影像师”，即暗隐叙述者；片中说话的人物是明现叙述者。AIGC 里每镜都要回答“谁在组织这一眼”。

**三种聚焦（同附录）。** 认知聚焦、视觉聚焦、听觉聚焦：谁比谁多知道、镜头跟谁的眼睛、声音贴谁的耳朵。若斯特把热奈特的公式改成“观众大于、等于、小于人物”。

**加叙（同书附录二）。** 内聚焦文本里突然插入主要人物不可能知道的事件，就是加叙；观众要先判断这是失误还是意图。AIGC 里这种镜头必须标记并回收，否则按穿帮处理。

**心理时空（《从文本到影像》剧作）。** 《白色栀子花》让现实、回忆与幻觉交替，作者叫它心理时空。AIGC 里不是加滤镜，而是给每个时空独立的风格 token 与声音层。

**电影时空像弹簧（《21天搞定电影剧本》第 3 章 3.6）。** 电影可自由穿梭过去、现在和未来；序列里，时间折叠由剪辑和声音完成，不靠字幕写“多年以前”。

## AIGC 执行

1. **每镜标 POV。** 在分镜表加一列：`POV: C1 / C2 / objective / omniscient`。没有归属的镜头删掉，或明确改成零聚焦并说明理由。
2. **先定聚焦策略。** 内聚焦：少给全景，多用限制景别、前景遮挡、主观插入；零聚焦：客观构图、大全景、双方都看见；外聚焦：不给脸，只用环境与背影。一部短片只用一种主策略。
3. **用信息差写悬念。** 观众多于人物：先给威胁镜头，再看人物不知情；等于人物：一起发现；少于人物：藏住关键信息，让人物先看见。
4. **加叙要标记。** 写 `PARALEPSIS:` 注明超出谁的认知，并在后文用一个镜头回收；没有回收的删。
5. **闪回至少改两项。** 从色温、颗粒、画幅、焦段、声音混响里选两项以上同时变；只做棕褐色滤镜不算区分。
6. **旁白当成一个角色。** 给旁白写 voice token：音色、语速、句长、可知范围；旁白知道的和画面聚焦不一致时，改旁白或改镜头。
7. **心理时空分层。** 现实、回忆、幻觉各写一组 STYLE / TEXTURE / SOUND token；转场用声音或动作匹配，不用字幕卡。
8. **声音跟随视点。** 内聚焦时环境声贴着人物耳朵，切到零聚焦才放开全景声；限制视点里不给全知音乐。

## 检查清单

- [ ] 这场戏的视点属于谁？镜头在谁的眼睛位置？
- [ ] 观众此刻比人物知道得多、少，还是一样？这个差被用了吗？
- [ ] 视点是否在无关处跳来跳去，让观众失去方位？
- [ ] 闪回与现在是否有至少两项可辨的视听差异？
- [ ] 时间折叠是否改变了当下这场戏的含义？

## 常见错误

- **镜头没有归属。** 后果：不知道在跟谁看，情绪无法累积。替代：每镜写 POV，没有归属就删。
- **一场混用三种聚焦。** 后果：悬念与代入互相抵消。替代：先定主策略，越界必须标记。
- **闪回只加棕褐色。** 后果：分不清回忆与现在。替代：色温、颗粒、画幅、声音至少改两项。
- **旁白替画面解释。** 后果：画面变插图。替代：旁白只给画面给不出的认知。
- **加叙不回收。** 后果：被判穿帮。替代：标记并在一到两场内兑现。

## 与风格层接口

每场标注“镜头属于谁”，写进分镜与视频提示的 `POV` 字段；否则模型会给漂移镜头。聚焦策略决定导演参考：内聚焦用限制景别与前景遮挡；零聚焦用客观构图与大全景；外聚焦用背影与环境。闪回转成摄影参数：色温、颗粒、画幅、镜头质感，至少两项同时变。心理时空用声音或动作匹配转场；旁白 voice token 与画面 style token 分开锁。

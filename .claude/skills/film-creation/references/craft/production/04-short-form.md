# 短片与生成：15–90 秒的可交付约束

## 核心判断

短片的约束不是生成时才出现，它从第一句概念就生效。15–90 秒不是把长片压短，而是用更少的场景、角色和镜头，讲一个必须在三到五个 beat 内成立的故事。判断标准不是它多好，而是它能不能被生成、被剪辑、被交付。

## 书里的原则

**"写一些你能拍的东西"是第九章最硬的一句。** 书里把它展开：你勾勒的不是梦幻小屋，而是即将亲手建造的施工蓝图。AIGC 版是"写一些你能生成的东西"：先定场景、角色、特殊元素的上限，再写故事。

**短片剧作规则可以直接映射到 beat。** 第九章列了迅速确立情境、让故事晚些开始尽快结束、总是推进故事、增加紧迫感、精简对白、坚信你的选择、用"大爆炸"结束、避免俗套。AIGC 里：第一个镜头交代谁、在哪、要什么；每个 beat 只回答一个问题；不能推进的镜头在生成前删；对白能用画面、字幕或声音替代就不写。

**"一切免费"是一种选择，不是寒酸。** 书里说很多短片在现成环境、自然光下完成，把资源从"造世界"移到"拍清楚"。AIGC 里对应固定角色 token、单一环境底、自然光或单光源、少切点；把额度从"造复杂世界"移到"把主体生成清楚"。

**自我批评六问仍然有效。** 第九章的六问里，"真的能做到吗"和"哪些内容能调整"最具体。AIGC 版：这个镜头在单条时长和资产数量内能稳定生成吗？哪些元素能拆层、复用或降级？

**故事板最重要的产物是镜头清单。** 第九章说故事板不要求画功，可以用照片、视频，分镜太多就删。AIGC 里，故事板换成关键帧：先出六到十二张关键帧，检查节奏和资产一致性，再决定哪些进视频。

## AIGC 执行

1. 先写一句"为什么做这条短片"和交付场景（展映、社交、作品集），用它决定时长、镜头数和完成度。
2. 定上限再写：场景不超过三个，角色不超过三个，特殊元素不超过两个（火、水、动物、群像、复杂车辆），镜头六到十二个，每镜三到八秒。
3. 写三到五个 beat：建情境一到两镜，升级两到三镜，转折一到两镜，结果一到两镜。
4. 第一个镜头给情境，最后一个给强结束，中间每镜必须推进；不能推进的在生成前删。
5. 精简对白：能用动作、视线、道具、字幕说的不用台词；必须说的写短句，并定好口型或字幕方案。
6. 镜头清单字段：shot ID、时长、beat、资产、运动、首尾帧、是否可剪掉，先标出可剪的。
7. 先做关键帧或视频故事板，每个 beat 一到两张；资产不一致的在生成前改，不留到剪辑。
8. 为每个镜头写降级版：静帧加运动、剪影、画外、字幕卡，保证交付时限内能交出一条完整片。

## 检查清单

- [ ] 为什么做这条短片？交付场景写了吗？
- [ ] 前五秒观众知道情境了吗？
- [ ] 有没有不推进故事的镜头还在清单里？
- [ ] 定时炸弹是什么？它在第几秒响？
- [ ] 哪些对白可以删掉而不损失信息？
- [ ] 最贵的一个元素是什么？有没有拆层、复用或降级方案？
- [ ] 关键帧产出镜头清单了吗？够剪成 15–90 秒吗？

## 常见错误

- 按长片思路写十几场 → 每个 beat 都要重建资产，90 秒装不下 → 先定上限，再写 beat。
- 第一个镜头只做气氛 → 观众前五秒不知道看什么 → 第一镜交代谁、在哪、要什么。
- 对白承担全部信息 → 生成口型难、剪辑节奏慢 → 改动作、视线、道具和字幕。
- 分镜数量超过尝试额度 → 每镜只能试一次，质量崩 → 先删镜头，再谈增加尝试。

## 与风格层接口

短片的资源约束会直接改写镜头语言。场景少，就用同一空间的反复出现建立世界；角色少，就用画外音、遮挡和反应镜扩展画外空间；特殊元素贵，就用影子、反射、声音和剪辑暗示，不正面生成。关键帧和镜头清单是风格层与制作层的共同货币：每增加一个运动镜头、一个新机位、一个新资产，清单多一行，尝试额度多一份。AI 生成更适合固定机位、少切点、连续画面，因为一致性成本随切点数量上升；把复杂动作压进一个镜头，往往比生成十个短镜头更可控。

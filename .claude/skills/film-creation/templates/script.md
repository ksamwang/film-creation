# Script（短片剧本）

> 通用短片剧本（30 秒–10 分钟；更长的片子或只写其中几场，正文格式和规则相同）。竖屏短剧用 `drama-episode.md`，台词与格式规则以 `references/drama/04-script.md` 为准。
> 完整填写示例见 `references/writing/example.md`。
> 写台词前通读 `references/writing/dialogue.md`：§1 潜台词、§2 攻防、§3 交代信息、§4 人物声口、§7 修剪与检验。事实规则管拍得连，这一篇管台词好不好。

## 片头信息

- 片名：
- 一句话（谁 + 想要什么 + 被什么挡住 + 最后怎样）：
- 主线问题（全片只问一个：主角能不能 + 做成什么；结尾回答它，`references/craft/story/01-premise.md`）：
- 主类型 / 副类型（`references/writing/genres/`）：
- 时长档（60 秒 / 3–5 分钟 / 其他）：
- 知识关系（观众大于 / 等于 / 小于人物；在哪一拍切换）：
- 结尾要留下的感受：

## 场表

一行一场。场不是一个关键事件，是主角为主线问题做的一次努力：带着想要进场，用一个办法，被挡住，局面转了，他做出下一个决定（`references/craft/story/04-scene.md`）。

| 场 | 进场时主角想要 | 办法 → 被什么挡住 | 转折 | 反应 → 决定 | 离主线答案（近 / 远） | 主情绪 | 连接（因此 / 但是：原因观众在哪看到） |
|---|---|---|---|---|---|---|---|
| 1 |  |  |  |  |  |  | — |
| 2 |  |  |  |  |  |  |  |
| 3 |  |  |  |  |  |  |  |

- **一场有几拍**：进场、办法、阻碍、转折、反应和决定，一拍可以只是一行动作。只有一拍的场（进场就是事件，事件完就出场）读起来是梗概；它要么补成戏，要么并进相邻的场，要么改成在别处带过。
- **转折之后写反应和决定**：哪怕一行动作（「他看了老仆很久，目光落到案上的裁纸刀」）。观众从这一拍知道他下一步要干什么，下一场才接得上。
- **连接栏写原因在哪**：「因此」后面写观众在哪一场、哪一行看到了这个原因。原因只在写的人脑子里、画面上没有的，等于「然后」。
- 相邻场的主情绪要有落差（`references/writing/intent.md` 组合与节奏）：连着几场都拉满，中间放一处变化——一个暖的瞬间、一点松动、一次安静。
- 撑起全片的那段关系，在它被考验之前，至少有一场让观众正面看到它（两人同场，有一次交集）。

**容量校验**（不设场数上限，场数由故事定）：时长 ÷ 场数 = 每场约几秒，再看这些秒数够不够把上面五拍演出来——一拍至少要一个镜头（约 3–5 秒）。不够时三选一：加长时长；合并或删掉场；把某一场改成在别的场里用一句台词、一个物件、一个画面带过。改编长篇原著，先定从哪里进、从哪里出，切片之外的事用台词、物件、字幕带过。

## 场间

每两场之间一行。不写这一节，场与场之间的事就只在写的人脑子里。

| 场间 | 隔了多久，怎么看得出 | 画外发生了什么（推动下一场的） | 在哪交代、用什么（一场 / 一句台词 / 物件 / 画面） | 上一场留下的想要或问题 → 下一场开头怎么接 |
|---|---|---|---|---|
| 1 → 2 |  |  |  |  |
| 2 → 3 |  |  |  |  |

- 每场最后给主角留下一个想要、一个问题或一个承诺；下一场开头先兑现或打破它。
- 推动下一场的事发生在画外（病了、答应了、反悔了、被裁决了），必须在某处交代；交代不了，就把它演出来。
- 隔了多久要看得出：季节、伤口、衣服、物件的状态，或一句台词。

## 正文

```text
场 1  {日 / 夜 / 晨 / 昏}  {内 / 外}  {地点}
人物：{角色名}

△ {谁} {做什么}，{停在哪}。
{角色}（{情绪}）：{台词}
{角色}（VO）：{画外音}
{角色}（OS）：{内心独白}
【字幕】{必须让观众读到的字}
```

动作行写成起点 → 动作 → 落点，一行一个主导动作，不写镜头术语（`references/drama/04-script.md` §2）。每场按场表那一行写成几拍，转折之后写出主角的反应和决定；场间表里要交代的画外事件，写进对应场的动作行或台词里。

**写清事实，分镜才不用猜。** 剧本不写镜头，但要写清四件事：谁在场、东西在谁手里、在哪个时空、说了什么。分镜怎么接是分镜的事（`references/storyboard/flow.md`），这四件事剧本没写，分镜只能替你猜，猜完还得回来问。

- **在场**：人物第一次动作或开口之前，先写他在场或进来（「△ 柜台后，掌柜在拨算盘。」）；原本就在的人也写一句（「△ 连城坐在桌前。」）。场头的「人物：」列全这场出现的人，群角写准人数（「三名仆从」，不写「仆从」后面又多出一个）。
- **物件**：同类物件起名，全剧逐字沿用（原花笺、和诗、回笺，不写成「纸」）。每次交接写成一行「谁把什么交给谁」，接的人这时已经在场；同一件东西不交接两次。
  - 物件第一次出现写它原来在哪（桌上、袖里、书架上），不要一出现就在某人手里；人物手里拿着东西又去拿别的，写他先把哪样放下。
  - 起名是为了分得清，不是每句都挂标签：同一场里只有一张纸在动，用「它」「那张笺」就行；第一次出现、交接、和同类物件同时在场时，才用全名。
- **时空**：一场只有一个地点、一个时段（同一地点同一时段 = 同一场）。几个时空连着写，就每段单独写场头；要成段落，标「蒙太奇」，段与段之间仍要写得出「因此 / 但是」。人物换地方，写他怎么过去，或带着什么出现在新地方。
- **一种读法**：每行动作只能拍出一种样子。「念出后一句」要写明念的是哪一句；「接过纸」要写明哪一张。
- **事实写在动作行，不写进台词**：东西从哪来、谁答应过什么，用 △ 让观众看见，不让人物开口替观众交代（阿绣不必说「这书是掌柜给的」；连城不必说「爹前日才答应过他」）。台词照旧按 `references/writing/dialogue.md` 走潜台词。
- **台词**：写了「说」，就给出词；不想让观众听清，写明「听不清」或放到画外。「连声称好」这类只给说明、不给词的写法，到分镜只能变成气声。

## 检查

- [ ] 一句话复述得出来，有赌注（`references/writing/doctor.md` 第 1 层）？
- [ ] 主角主动，真相由他的行动揭开，不是别人告诉他？
- [ ] 主线问题只有一个，每场都看得出离答案近了还是远了，结尾回答了它？
- [ ] 每场都有主角的想要、办法、阻碍、转折、反应和决定，不是只写一个关键事件（`references/writing/doctor.md` #26）？
- [ ] 每场结束时局面都变了，场与场之间是「因此 / 但是」，原因在画面上看得到？
- [ ] 场间表填了：画外推动下一场的事都有交代，隔了多久看得出，上一场留下的想要下一场接住了？
- [ ] 撑起全片的关系在被考验之前正面出现过；相邻场的情绪有落差？
- [ ] 容量校验过：每场的秒数够演完它的几拍？
- [ ] 开场在类型约定内（`references/writing/genres/` 的「观众在等什么」）？
- [ ] 每个伏笔都有回收，回收前至少再提醒一次？
- [ ] 台词在做事、人物声口分得开，最重要的那句没有直接说出口（`references/writing/dialogue.md`）？
- [ ] 每句台词能在所在镜头里说完，一镜一个说话人？
- [ ] 写下的每一行都画得出来，资产数量在预算内（`references/aigc/assets.md`）？
- [ ] 每行动作只有一种读法；人物出手或开口之前已经在场？
- [ ] 同类物件有名字，每次交接写了谁给谁，没有一件东西交接两次、凭空出现或消失？
- [ ] 一场一个时空；人物换地方写了怎么过去（`references/writing/doctor.md` #25）？
- [ ] 每场停在事件之后看得见的余波上（一个反应、留下的物件、空下来的地方），不停在事件刚完成的那一刻？

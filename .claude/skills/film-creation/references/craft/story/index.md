# 故事

把“我想做一个关于 X 的片子”变成一条能生成的概念—beat—镜头序列链。

## 这个模块解决什么

故事层只决定三件事：这个想法有没有一个能在首帧看见的钩子；冲突是否升级到退路全部关闭；每一场是否改变局面并把下一场变成必然。它不规定机位、走位和景别，那些属于调度与视觉层。但它给出的每一条判断，最后都要落到 AIGC 产物：概念、beat、镜头序列、图像 token、motion token、资产 token、negative、剪辑/声音。

默认用于 AI 图像与视频；需要实拍建议时，由用户明确要求。

## 先读哪篇

先读 `03-structure.md`：先定不归点，才知道前面要建置什么、中间每一步往哪推。只有一句模糊想法，从 `01-premise.md` 开始。读完一篇，按它指向的相邻篇再读一篇，不要从头读到尾。

## 子文件怎么选

按你卡住的位置选：只有一句想法，读 `01`；人物像模特、每镜变脸，读 `02`；30–90 秒排不出 beat、分幕像硬切，读 `03`；单场好看但整体不动、台词一直在解释，读 `04`；观众不知道在跟谁看、闪回和现在分不清，读 `05`。

一次最多读两篇：先读判断问题的那篇，再读它指向的相邻篇。

## 子文件

| 文件 | 解决什么 | 关键概念 |
|---|---|---|
| `01-premise.md` | 想法值不值得做、能不能一句话说清 | 钩子、稳赚因素、视点、载体、议题 |
| `02-character.md` | 人物扁平、配角多余、对手不成立 | 动态人物、逆向工程、功能位 |
| `03-structure.md` | 短片没有不归点、beat 排不出 | 不归点、第一幕落幕、九分钟路标、三段式/四段式 |
| `04-scene.md` | 单场不成立、台词解释太多、场与场接不上 | 展示、潜台词、并置、转折—展示—转折 |
| `05-narrative.md` | 视点乱、旁白多、闪回与现在分不清 | 视点、聚焦、暗隐叙述者、加叙、心理时空 |

## 模块规则

1. 每条判断都要能转成一个 AIGC 动作：一个 beat、一个镜头、一条 token、一条 negative，或一处剪辑/声音决定。
2. 书里的原则保留术语，但必须写清“生成时怎么用”；没有出处的规则不进本模块。
3. 故事与风格冲突时，故事优先；风格不能替代“谁想要什么、什么变了”。
4. 一致性先靠参考图，纯文本时靠资产描述逐字复用，不靠形容词重复。

## 使用边界

本模块的规则来自五本书的章节，正文只标模块锚点，明细见 `craft/sources.md#story`。不写通用鼓励语；故事层只决定“必须发生什么变化”，不规定机位与走位。

# 转场词典：镜头之间怎么接

字段与可靠性分级见 `camera/index.md`。转场大多是**剪辑**的工作，生成只负责给剪辑提供能接上的素材。所以本篇的「写法」分两半：**生成侧**（两个镜头各自怎么写、怎么准备）和**剪辑侧**（在剪辑里怎么做）。

转场的分类按《电影镜头设计》第二十一章（剪切、叠化、聚焦—失焦、匹配镜头、划变、动作划变、变形、淡接、淡入淡出、停格、蒙太奇、分割画面）和《电影镜头入门》Step7 剪接技巧整理。剪辑表的转场栏见 `templates/edit-sound.md`。

**选转场的一条规则**：**硬切是默认值**。其他转场都在说一句话（「时间过去了」「这两件事有关」「这是梦」），说不出那句话就用硬切。

## 1. 剪切类

### 硬切 Cut
- **生成侧**：无特殊要求。两镜的光、色、时段一致，人物位置和道具状态接得上（`references/drama/06-storyboard.md` 第 5 节）。
- **剪辑侧**：直接接。剪辑点优先落在运动上：出画、手放下、门关上（`craft/staging/04-coverage.md`）。
- **作用**：不被察觉的连续；也可以是突然的冲击（安静 → 巨响）。
- **生成**：稳。

### 动作剪接 Match on action / cut on action
- **生成侧**：上一镜的结尾和下一镜的开头是**同一个动作**的两半：上一镜她开始转身，下一镜从转身的后半开始。两镜的提示词里动作描述逐字一致，只是景别、角度不同；动作起点写在下一镜的第一句。
- **剪辑侧**：在动作进行中切，让动作带着观众跨过剪辑点。可以重叠几帧。
- **作用**：最流畅的换景别方式，观众注意动作，忽略剪辑（《镜头的语法》6.6 为剪辑而拍摄重叠动作）。
- **生成**：稳。动作方向必须一致：模型转身方向不对时，在动作开始前切（`references/drama/08-cut-qc.md`）。

### 跳切 Jump cut
- **生成侧**：同一机位、同一景别，人物位置、姿势或时间跳变。用一张基准关键帧改出多张。
- **剪辑侧**：硬切，不补过渡。
- **作用**：时间被跳过、焦虑、不耐烦、日常的重复；也是刻意的「不连续」风格（《电影镜头入门》Step7「跳切」「跳切段落」）。
- **用 / 不用**：有意为之时才用；无意的跳切（相邻两镜景别、角度都差不多）是错误，要补 30° 以上的角度变化或插入镜头。
- **生成**：稳。

### 交叉剪接 Cross-cutting
- **生成侧**：两条线分别生成，每条线的屏幕方向和节奏各自统一。
- **剪辑侧**：两条线交替，越接近交汇，镜头越短。
- **作用**：同时发生的事、追逐、营救、平行对比（《电影镜头入门》Step7；`recipes/chase.md`）。
- **生成**：稳。

### 闪切 / 闪白 Flash cut / white flash
- **生成侧**：准备几帧极短的画面（回忆片段、闪回的脸）。
- **剪辑侧**：插入 2–6 帧，或用全白帧过渡。
- **作用**：记忆闪回、创伤侵入、相机闪光、冲击（《电影镜头入门》Step7「瞬白，闪切，闪跳切」）。
- **生成**：后期。

## 2. 光学类

### 叠化 Dissolve
- **生成侧**：两镜的构图最好有呼应（亮区叠亮区、人物位置相近），叠化时不会糊成一团。
- **剪辑侧**：上一镜淡出的同时下一镜淡入，常用 0.5–2 秒。
- **作用**：时间流逝、地点转换、两件事之间的联系；比硬切柔和、带抒情（《电影镜头设计》21.2；《电影语言的语法》光学转换）。
- **用 / 不用**：段落之间、回忆进出；同一场戏内部不用。
- **生成**：后期。不要让模型生成「叠化」，在剪辑里做。

### 淡入 / 淡出 / 切黑 Fade / cut to black
- **生成侧**：上一镜结尾留 1–2 秒静止或缓慢的画面，给淡出留时间。
- **剪辑侧**：淡到黑（或白、或某个颜色）再淡入；切黑是不经过渡直接黑。
- **作用**：一个段落结束、时间大跳跃、死亡、昏迷。淡到白偏梦境、天堂、失去意识；淡到颜色是风格化标记（《电影镜头设计》21.8–21.9）。短剧的断章常用音乐推到最高后切黑（`references/drama/08-cut-qc.md`）。
- **生成**：后期。

### 聚焦—失焦 Focus transition
- **生成侧**：上一镜结尾焦点虚掉（`the image slowly goes out of focus`），下一镜从全虚开始聚焦。两镜分别生成，或各生成清楚的版本再后期加虚。
- **剪辑侧**：在全虚处切。
- **作用**：意识模糊、昏厥、进入回忆或梦境、醉（《电影镜头设计》21.3；《电影镜头入门》Step6「散焦、昏厥」「调焦转场」）。
- **生成**：后期加虚最稳；生成的失焦常常糊得不均匀。

### 分割画面 Split screen
- **生成侧**：两边各自生成，构图按分割后的形状来（竖屏上下分，横屏左右分）。
- **剪辑侧**：合成。
- **作用**：同时发生、对比、通话（《电影镜头设计》21.12；《电影镜头入门》Step7）。
- **生成**：后期。不要让模型直接生成分割画面。

## 3. 遮挡与运动类

### 划变 Wipe
- **剪辑侧**：新画面从一侧推入，替换旧画面。
- **作用**：老派、明快、刻意的形式感；今天多用于喜剧或复古风格（《电影镜头设计》21.5）。
- **生成**：后期。

### 动作划变 / 遮挡转场 Natural wipe
- **生成侧**：上一镜结尾，一个人或物从镜头前挡过（`A passer-by crosses close to the lens and fills the frame with dark`）；下一镜开头同样从遮挡中露出来。遮挡物最好在两镜里方向一致（都从左往右）。
- **剪辑侧**：在画面被完全挡住的那一帧切。
- **作用**：不被察觉的转场；也是长镜头藏剪辑点的主要办法（《电影镜头设计》21.6；《电影镜头入门》Step7「填充，揭示画面」「过人，揭示画面」）。
- **生成**：定帧。遮挡物走过的时机不稳，用首尾帧锁住「全黑 / 全挡」的那一帧。
- **短剧**：续接片段时最好用的接法：上一段结尾被遮挡，下一段从遮挡开始。

### 甩镜转场 Whip-pan transition
- **生成侧**：上一镜结尾、下一镜开头各生成稳定的画面。
- **剪辑侧**：在接点各加几帧方向一致的横向运动模糊。
- **作用**：快节奏、时间或空间的跳跃、喜剧（`lexicon-move.md`「甩镜」）。
- **生成**：后期。

### 推进黑物 / 穿越转场 Push into black
- **生成侧**：上一镜结尾推近到一个暗的物体（背影、门、衣服）直到全黑；下一镜从另一个暗物体拉开。
- **剪辑侧**：在全黑处切。
- **作用**：无缝跨空间，常用来伪造一镜到底。（行业惯例）
- **生成**：定帧。首尾帧锁住全黑的落幅。

## 4. 匹配与变形类

### 匹配剪接 Match cut
- **生成侧**：两镜的接点**形状、位置、大小、运动方向**相同：圆形的月亮接圆形的盘子，摔下的杯子接落下的雨。先出两张接点帧并排对照修改，再分别生成视频。
- **剪辑侧**：硬切。
- **作用**：跨越时间和空间，同时说「这两件事有关」（《电影镜头入门》Step7「匹配剪接」；《电影镜头设计》21.4 匹配镜头）。相反的版本是对立剪接：形状或运动相反，表达冲突（《电影镜头入门》Step7「对立剪接，对立运动」）。
- **生成**：定帧。接点帧要在图像阶段精确对齐。

### 变形 Morph
- **生成侧**：首帧是 A，尾帧是 B，提示词写变化的路径（`the clock face slowly becomes the full moon`）。
- **剪辑侧**：无。
- **作用**：超现实、梦、魔法、时间的转变（《电影镜头设计》21.7）。
- **生成**：定帧。首尾帧是 AIGC 最擅长的转场之一，但中间常常是溶化；两帧差别越小，变形越清楚（`references/aigc/workflow.md`）。

### 由照片到场景 Photo to scene
- **生成侧**：一张静止的照片作为首帧，首帧生视频让它动起来：照片里的人开始呼吸、风吹动树叶。
- **剪辑侧**：先让照片静止停留，再接动起来的部分。
- **作用**：回忆进入、旧时光复活（《电影镜头入门》Step7「由照片到场景」）。
- **生成**：稳。首帧生视频天然就是这个手法。

### 停格 Freeze frame
- 见 `lexicon-move.md`「定格」（《电影镜头设计》21.10）。后期做。

## 5. 声音转场

- **声音先入（J-cut）**：下一场的声音先响起，画面再切过去。观众被声音拉进新场景。
- **画面先走（L-cut）**：画面切到下一场，上一场的声音还在延续。上一场的情绪拖进来。
- **声音桥**：一个声音跨过剪辑点（同一首歌、同一个钟声），把两个时空连起来。
- 生成侧：声音转场需要的是「干净的、能分离的」声音素材。模型原生音频和画面绑在一起，做 J / L 剪接时可能要分离或重配。声音的分工见 `craft/sound/` 和 `templates/edit-sound.md`。

## 6. 速查：想表达什么用什么

| 想表达 | 转场 |
|---|---|
| 连续、不被察觉 | 硬切、动作剪接、遮挡转场 |
| 时间过去了一点 | 跳切、叠化 |
| 时间过去了很久 / 段落结束 | 淡出到黑、切黑 |
| 进入回忆 / 梦 | 叠化、聚焦—失焦、由照片到场景、淡到白 |
| 两件事有关 | 匹配剪接、声音桥 |
| 两件事冲突 | 对立剪接、硬切（安静 → 巨响） |
| 同时发生 | 交叉剪接、分割画面 |
| 节奏、能量 | 甩镜转场、闪切 |
| 超现实 | 变形 |
| 伪造一镜到底 | 遮挡转场、推进黑物 |

## 7. 失败与修法

| 失败 | 原因 | 修法 |
|---|---|---|
| 让模型生成「叠化」「淡出」，结果画面糊 | 光学转场写进了提示词 | 生成干净的两镜，剪辑里做 |
| 匹配剪接对不上 | 两镜分别生成，接点没对齐 | 接点帧在图像阶段并排对照修改 |
| 遮挡转场露馅 | 遮挡物没有完全挡住画面 | 首尾帧锁住全挡的那一帧 |
| 变形中间糊成一团 | 首尾两帧差别太大 | 让两帧只差一个主要变化；形状相近 |
| 转场太多，像 PPT | 每个镜头都在用花哨转场 | 默认硬切；只在段落之间用其他转场 |
| 动作剪接的动作方向反了 | 下一镜模型做了反方向动作 | 在动作开始前切，或重新生成 |

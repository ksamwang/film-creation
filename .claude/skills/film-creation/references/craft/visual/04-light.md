# 光位、光质与灯具

## 核心判断

光在画面里只做三件事：让人看见、让人看不见、让人怀疑看见的是不是真的。做到这三件事靠四个变量：方向、硬度、强度与光比、色温。灯具只是工具，先定变量再选灯：先定暗部，再定主光，最后补光。

## 书里的方法

《镜头的语法》把光拆成：光作为能量、色温、自然光与人工光、强度与曝光、硬光与柔光、对比度、三点布光法。三点布光是人物照明的基本模型：主光定方向与性格，辅光控暗部，轮廓光分离人物与背景。主光与辅光的比例是光比：光比大，暗部深，适合威胁与隐藏；光比小，暗部浅，适合安全与喜剧。硬光来自小面积光源，阴影锐利、皮肤纹理明显；柔光来自大面积光源或柔光材料，阴影渐隐、适合修饰。对比度是画面最亮与最暗的关系，不是“亮不亮”。

《导演的摄影课》把照明风格与类型挂钩：高调照明整体亮、阴影少，常用于喜剧；低调照明暗部多、光比大，常用于惊悚与黑色电影。导演要能说出“视觉基调”：光服务主题，不只是曝光。

《电影照明器材与操作》按灯具类型给出选择表。钨丝卤素灯是3200K低色温；菲涅尔聚光灯可调聚散，中心亮、边缘软，俗称软光灯；回光灯亮度高、干扰光多，适合轮廓和远景；散光型卤钨灯（天幕灯、地排灯、太空灯）给大面积均匀底子光。金属卤素灯即镝灯，高色温气体放电，功率通常是钨丝灯的四倍，适合大面积日景或窗光。Kino Flo 是柔光荧光灯，光质柔和、无频闪，适合人物近景和狭小空间。特图利是小功率精密灯，适合局部勾边和眼神光。LED 体积小、可控。附件与灯同等重要：蝴蝶布把硬光变成大面积柔光，旗板或黑旗切光，柔光纸降低硬度，色温校正型滤光纸在3200K与5600K之间转换，柔光箱把点光源变成面光源。

光源必须有画内动机：窗、台灯、霓虹、火、门缝；没有动机，观众会注意“为什么这么亮”。

## 可执行规则

1. 先写这场戏的光比，再选灯。
2. 主光只给一个方向；辅光只负责让该看见的看见，不制造第二主光。
3. 硬光给纹理与威胁，柔光给安全与修饰；不要全片一种硬度。
4. 高调或低调是整场的决定，不是单镜的曝光。
5. 每个光源写画内动机；没有动机就移动光源或加动机。
6. 大景别用大面积柔光或反射；近景用小灯加柔光箱或柔光纸。
7. 轮廓光只勾一侧，不要给头发打满。
8. 混合色温必须被动机解释，否则校正到同一基准。

## 检查清单

- [ ] 暗部在哪？暗部还有细节吗？
- [ ] 主光方向是什么？有画内动机吗？
- [ ] 光比是多少？为什么是这个数？
- [ ] 硬光还是柔光？皮肤与材质对吗？
- [ ] 高调还是低调？整场统一吗？
- [ ] 轮廓光是否过强，形成双主光？
- [ ] 色温混合有理由吗？
- [ ] 灯具是否在镜头外、藏好了？

## 与风格层接口

- 导演档案的“光”格写四项：主光方向、硬度、光比、色温基准。
- 风格参考只取光位与光比，不取“氛围”形容词。
- AI 提示按光源、方向、硬度、光比、色温写：`window side light, soft, 4:1, 5600K` 或 `single tungsten practical, hard top light, 16:1, 3200K`。
- 负面提示：`no even fill, no flat studio lighting, no multiple key lights`。

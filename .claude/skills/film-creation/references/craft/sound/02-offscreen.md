# 画外：扩展域与无形音角色

## 核心判断

画外不是“没拍到的地方”，而是声音替画面造出来的一块空间。画外处理得好，观众知道世界比画框大；处理得坏，画外只是给画面配的装饰音。

## 书里的方法

**画外要分相对与绝对，非叙境另算。** 书里把画内、画外与非叙境分开；画外内部又分相对画外和绝对画外：相对画外是紧贴画框外、仍属同一空间的声源；绝对画外是画框永远够不到的地方，比如旁白、乐池音乐。非叙境则根本不属于故事世界。环境声给出地域，内部的声音给出人物体内感，远距离传播的声音（电话、广播）把另一个空间压进现场。这几种声音不能共用一种空间处理。

**声音位置不等于声源位置。** 书里区分二者：声源在画外的某一点，声音却从影院的某只扬声器出来。观众判断的是声音位置，不是物理声源。所以画外声源要稳定，移动要有过程；否则观众无法把它钉在画外的某一点上。

**扩展域。** 多声道环绕声把环境声铺到银幕边界之外，形成一圈连续、半自主的空间，书里叫扩展域。它让定场镜头不再是建立空间的唯一手段：声音先把房间四周建好，画面可以一直停在特写。书里描述过这个后果：声音铺得越宽，镜头越敢往近处走，画面像独奏，声音承担乐队。

**无形音角色。** 只听见声音、看不见身体的人，书里叫无形音角色。它的力量正来自身体缺席：声音可以无处不在、全知、控制场面。一旦身体被看见（书里叫解除无声源化），这些能力就消失。所以揭示画外声音不是补充信息，是改变权力关系。

**视听幻象。** 书里用“视听合约”描述观众同意把声音和影像当成一个整体；由这种合约产生的效果叫视听幻象。画外声音让影像有了“另一侧”，观众相信画框外继续存在，哪怕画面从没拍过。

## 可执行规则

1. 每场画一张画外地图：列出画框外的主要声源，标相对、绝对或非叙境，标持续或进出。
2. 用一个连续画外声源串起多个镜头，替代定场镜头；画面可以更近，空间由声音建立。
3. 画外声源给稳定方位与距离；要移动就让人听见移动轨迹。
4. 无形音角色先定能力：全知、全视、无处不在、控制局面；再定是否解除无声源化。
5. 解除无声源化必须付出代价：身体出现后，声音失去的能力要被人看见。
6. 绝对画外少用；用一次是“世界之外”，用多了世界就失去边界。
7. 隔墙、隔门的声音必须被墙体处理（高频衰减、混响变化），不能和画内一样清楚。
8. 非叙境音乐不参与画外定位；不要给它加房间混响，除非它故意进入故事世界。

## 检查清单

- [ ] 画外地图写了吗？主要声源分别属于哪一层？
- [ ] 画外声源有稳定方位吗？移动有过程吗？
- [ ] 是否用画外声替代了不必要的定场镜头？
- [ ] 无形音角色的能力是什么？观众能感到吗？
- [ ] 解除无声源化发生在哪一刻？代价是什么？
- [ ] 绝对画外用了几次？世界还有边界吗？
- [ ] 隔墙声是否真的像隔墙？
- [ ] 非叙境声音是否被误当成画外声源？

## 与风格层接口

调度上，画外声源决定是否给空镜、是否让人物回头、是否越轴；声音说“在左边”，镜头却往右切，观众会迷路。导演档案写“画外规则”：允许哪几层、每层几个声源、是否解除无声源化。AI 视频提示写清声源与遮挡：`voice from adjacent room, muffled through wall, no visible speaker`；若模型不生成可靠音频，这段提示真正约束的是画面——门缝、墙面、人物朝向必须和声源一致。

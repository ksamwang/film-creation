# 场景：因果的一步，与转折后的停顿

## 核心判断

场景不是信息的容器，是冲突升级的一步：它必须改变局面，并把下一个场景变成必然。场景内部则要处理两件事：哪些背景必须给、以什么方式给；人物嘴上说的和真正想要的是否错开。

## 书里的方法

**每场必须推进下一场。** 奥班农在论步调时说，动态运动对叙事不可或缺，每个场景都应当自然导致并推进下一个场景。他提醒，光有好场景不够：如果场景只是好看，却不能暗示出下一个，叙事就断了。写场景有两条路——完全即兴，常在第二幕后半段走进死胡同；或预先列表，但预先拟好的场景又常常不"暗示"下一场，必须重写每场结尾，让它制造下一场的麻烦。

**展示：只给理解当前故事必需的信息。** 奥班农把背景信息叫"展示"，并说它极难写，硬塞会像假耳朵一样突兀：人物不是对彼此说话，而是对观众说话，所以虚假。他的判据是：如果一句背景说得不自然，那它对叙事就是不必要；观众进场晚了也能跟上动作，缺失的信息他们会自己补，而且补得常常更好。给得太满，观众无聊；略有不足，观众警觉、猜测、投入。首要规则是：除了理解当前故事必需知道的，其他都去掉。

**转折—展示—转折。** 他用"享乐适应"解释节奏：人对持续刺激会迅速迟钝。所以一次转折或震惊之后，要给一个停顿，让人物和观众消化新现实；这个停顿正是放入展示的最佳位置。等观众刚适应，再用更强的转折击中他们。转折本身要先用"虚假的可怕之事"把期待引到一个方向，真正的可怕之事发生时既出乎意料又更合乎逻辑，观众才会喊"哦，天哪，当然了"。

**展示，不要告知；潜台词。** 《21天搞定电影剧本》把这条叫剧本戒律：我们只看得到行为，看不到思维；人物常常言行不一，剧作家要找到表现行动与内心矛盾的手法，让观众读出潜台词——行为表面之下的真正含意。例子里，两个即将赴死的人讨论去澳大利亚，说的是旅行，含意是告别。

**并置。** 同书用一个短对话说明：甲问"你妻子怎么样了"，乙答"她很好，你听说杰克要离婚了吗"。两个看似无关的句子放在一起，关系状态就出来了。场景不必解释，靠并置让观众自己连线。

**一个细节同时承重。** 《从文本到影像》谈《白色栀子花》的场景设计：茶几玻璃上映出两张相爱的脸，也映出 1930 年代上海大户人家夜晚的光影气氛。一个反光同时承担人物关系与时代信息，省掉一句解释。

## 可执行规则

1. 每场开头写"谁想要什么"，结尾写"什么变了"；两头有一头空着，这场就不成立。
2. 用"因此/但是"检查场与场的连接；只能写"然后"的，重写前一场结尾。
3. 把每句解释性台词标出来，能改成动作、道具、环境或并置的，改；改不掉的删。
4. 转折之后留一个展示停顿，用人物和观众共同的问题填满；下一次转折必须比上一次更强。
6. 找一个空间细节（反光、声音、物件）同时承担信息与情绪，替代一句台词。

## 检查清单

- [ ] 这场戏谁想要什么？能写成带宾语的动词句吗？
- [ ] 结束时局面具体变了什么：信息、关系、权力、位置、资源？
- [ ] 变化是人物选择造成的，还是巧合？
- [ ] 删掉这场，下一场是否仍成立？若是，为什么还留着？
- [ ] 哪句台词是在向观众解释背景？能否改成可见证据？
- [ ] 人物说的和做的是否错开？潜台词落在哪个动作上？
- [ ] 转折后有没有给观众消化的停顿？停顿里给的信息是否必要？
- [ ] 这场和上一场是"因此/但是"，还是"然后"？

## 与风格层接口

- 每场只交三行给调度：谁想要什么、谁挡着、结束时什么变了；走位与机位由此生成。
- 展示停顿是剪辑的呼吸点：此处允许较长镜头与完整空间，转折处才切碎。
- 潜台词转成表演的 action 与镜头距离：嘴上说一套时，镜头给手、给背、给空处。
- 给 AI 的场景提示写可见的变化，不写"紧张""悲伤"；并置靠两个具体物件的同框。

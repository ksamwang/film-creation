# 资产分解：概念到镜头与资产清单

## 核心判断

分解不是"记录概念"，而是把概念里的形容词换成一串能被生成、被复用、被计数的名词。三十秒的戏，元素不同，生成难度可以差十倍；秒数只说明长度，资产密度才说明重量。

## 书里的原则

**分解表是路线图。** 第二章的方法核心不是表格本身，而是顺序：先把作品拆成要素，再把要素转成可执行计划。AIGC 保留这个顺序，产物换成三张互相引用的表：镜头清单、资产清单、生成状态表。

**编号是索引。** 书里用编号把元素挂到具体位置，改一处能追到相关行。AIGC 里索引单位换成 shot ID：图像 token、运动 token、资产 ID、negative、尝试记录都挂在同一个 shot ID 下，改一个镜头就能找到受影响的资产与批次。

**页数只说明长度，不说明重量。** 书里用页数累计负载，同时提醒同页不同重。AIGC 对应"生成单元"：镜头时长可以加总，却不能直接换算成生成次数；一个三秒的双人镜头，可能比一个八秒的单人特写更贵。

**元素要逐项点清。** 书里用分类表把要素全部列出来，漏一项就多一处缺口。AIGC 的资产表照这个原则建，类别换成：角色、群像、入画车辆、动物、道具、服装状态、发型化妆状态、环境底、光色状态、动作特效、环境特效、场景状态。漏一类，画面就多一处漂移。

**看起来小，不等于生成量小。** 书里提醒，短篇幅也可能因为年代服装、道具、动物、群像和场景转移而变重。AIGC 同样：一个二十秒、看似两人一屋的镜头，叠加这些元素后，生成量并不小。

**只有入画资产进清单。** 书里把运输车辆排除在元素外。AIGC 同理，工具文件、参考图、模型版本不进清单，只有画面里的资产才计入。

## AIGC 执行

1. 每个镜头一行，字段固定：shot ID、时长、场景、角色、动作、环境、道具、动物/车辆/群像/特效、服装发型化妆状态、图像资产 token、motion token、negative、模型版本、尝试上限。
2. 先建资产 ID 和定稿参考图，再写 prompt。角色 `char_01`、道具 `prop_flag`、环境 `env_bar_01` 一旦定名，后续挂图引用；纯文本时描述逐字复用。
3. 按"同屏元素数"估难度：一个角色加一个环境是基数；多一个角色、动物、群像、火、水、烟，各加一档，并各加一次一致性 pass。
4. 把资产分成可复用与一次性：角色表、核心道具、主环境是可复用 token；一次性光效、临时背景、单镜粒子不进长期资产表。
5. 每个镜头标生成方式：单条可完成、需首帧或续接、需分层合成、需剪辑拼接。多参考图模型能直接生成多人同框；复杂接触动作、动物与火仍优先拆镜或拆层。
6. 动作摘要只写会改变生成的内容：谁进入、拿起什么、是否接触或变形。
7. 标出最贵的三镜，各写一个降级方案：固定机位、剪影、画外、局部特写、分层合成。
8. 概念定稿后再做最终分解；定稿后只改台词、字幕和 negative，不改资产 token。

## 检查清单

- [ ] 每个镜头有唯一 shot ID，且能追到所属场景？
- [ ] 每个出场角色、道具、动物、群像都有资产 ID 吗？
- [ ] 同屏元素数算过吗？最多的那一镜有几个？
- [ ] 哪些镜头必须分层合成，哪些可以单条完成？
- [ ] 最贵的三镜是哪三镜？降级方案写了吗？
- [ ] 有没有无法用文字 token 稳定描述的元素？
- [ ] 是否把秒数直接当成了生成次数？

## 常见错误

- 按概念逐句生成，不先建资产表 → 同一角色每镜重建，脸和服装漂移 → 先分解资产，再排顺序。
- 一个提示塞进多人、动物和火 → 特征互相污染 → 多人挂参考图，动物与火拆层或拆镜。
- 只写角色，不写道具状态 → 关键道具每镜变形 → 挂道具参考图，状态变化写进正文。
- 把"页面短"当成"生成少" → 低估迭代 → 用资产密度和同屏元素数估算。

## 与风格层接口

分解表的资产密度直接决定能用哪种镜头语言。单角色、单环境可以多做景别和机位变体；多人、动物、火、水同时出现，只能固定机位、少切点、分层合成。导演档案给两三条视觉约束，摄影档案给光色 token；分解表把这些 token 落到每个镜头的资产字段里。超出资产上限的镜头，改拍法，不改已锁 token。

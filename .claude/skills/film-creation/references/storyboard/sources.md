# 分镜查阅层 · 来源

书目同 `craft/sources.md`。《电影镜头设计》《导演创作完全手册》在 `docs/_text/` 中只有试读部分正文，本层对它们的引用以目录中的章节名为准。标「行业惯例」的内容书里没有专门讲，按当代影视与 AIGC 制作的通行做法写成。所有示例场景为本包原创。

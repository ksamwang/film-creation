# 创作引导：用选项卡代替开放提问

用户说「帮我做一个雨夜复仇的短片」，没说要什么风格、什么色调、怎么讲。问「你想要什么风格？」，多数人答不上来：他们不知道这个包里有 125 位导演、十几种调色、四档光比可选。把选择摆出来，用户挑一个比自己描述一个容易得多。

这一篇规定什么时候出选项卡、卡上放什么、选项从哪里来。

## 1. 什么时候出，什么时候不出

**出卡**：用户要做一部作品或一段完整的戏（故事、剧本、分镜、风格卡、成片方案），而下面某个决定他没说、又会明显改变结果。

**不出卡**：

- 用户已经说清了，或者给了参考片、参考图、风格卡，从那里推。
- 小请求：改一句台词、写一条单镜提示词、解释一个术语、诊断一处毛病。直接做，需要假设的写一行说明。
- 后续轮次里已经选过的，不再问；用户改主意时再出。

**不卡住流程**：第一轮回复就是「选项卡 + 按推荐做出的初稿」，不是只出卡等回答。用户没答、答「随便」「你定」，就沿用推荐；初稿开头写一行「按推荐：……，要换告诉我」。

## 2. 卡上放哪些决定

按创作阶段，在用到的时候才问；一轮最多四项，每项最多四个选项。

| 阶段 | 决定 | 选项从哪来 |
|---|---|---|
| 立项 | 类型与时长档；平台与画幅（横屏、竖屏短剧、院线宽银幕） | `writing/genres/index.md`；竖屏走 `drama/01-premise.md` |
| 故事 | 故事设计（大情节、小情节）；讲述顺序（顺叙、结果前置、倒叙冷开场、信息先给观众、多线交叉）；结局的价值（正、负、反讽） | `craft/story/03-structure.md`；短剧 `drama/03-episode.md` §3 |
| 视觉 | 主参考（导演或摄影，1 主 + 0–1 副）或类型影调卡 | `taxonomy.md` 选族 → 档案；`camera/looks.md` |
| 视觉 | 色彩风格 | `camera/lexicon-gear.md` §5；`craft/visual/05-color.md` |
| 视觉 | 光的基调（高调、低调；光比档） | `camera/lexicon-light.md` 光比档位；`craft/visual/04-light.md` |
| 视觉 | 质感与介质（胶片、数字、手绘、三维、漫剧画风） | `camera/lexicon-gear.md`；漫剧 `drama/10-look.md` |
| 生成 | 目标模型与生成方式 | `aigc/models.md`；`aigc/workflow.md` |

**有先后**：主参考定了，色彩和光多半跟着定，只在主参考没覆盖时再问。讲述顺序跟着类型走：竖屏短剧默认结果前置或冷开场插叙，不单独出卡，直接写，在产物末尾附一张「可换」的小卡列另外两种顺序（`drama/03-episode.md` §3）。所以通常一轮就够：立项和故事一张卡，视觉一张卡。

## 3. 选项怎么出

- **从这次的需求里推，不甩通用菜单。** 「雨夜复仇」先在 `taxonomy.md` 找对得上的族（类型解构与暴力、都市感官），从族里挑人，再打开档案确认他的签名真的合用。不要每次都列同样的几位名导。
- **三个方向拉开。** 一个稳妥（最贴类型惯例）、一个贴题（最贴这次的情绪和题材）、一个大胆（换一个角度，有风险也有惊喜）。三个选项长得差不多，等于没给选择。
- **每个选项三句话以内**：叫什么；画面上会是什么样（2–3 个看得见的基元：光从哪来、什么颜色、机位怎么摆）；适合什么、代价是什么（例如「长镜头多，生成成本高」「暗部多，竖屏小屏上看不清」）。
- **标一个推荐，说为什么。** 推荐要对着这次的需求说理由，不是「最经典」。
- **最后一项永远是「按你推荐的来」**，再加一句「也可以直接说你想要的，或者发参考图」。
- **不写导演名进提示词。** 选项卡上可以写名字给用户认，选定后转成视觉基元（`prompting.md`）。

## 4. 选完以后

- 选定的结果冻结成风格卡（`templates/style-brief.md`）或片头信息（`templates/script.md`），后面每一步沿用，不每轮重新发挥。
- 混搭（导演 × 摄影、主卡 + 副卡）按 `mixing.md`、`camera/looks.md` §0 只借 1–2 条。
- 用户中途说「换个感觉」，只重出受影响的那一项卡，不推翻已定的其余决定。

## 5. 示例：雨夜复仇短片，视觉卡

示例只示范格式和取舍的写法。即使用户的需求和示例同题，也要按 §3 重新推选项、打开档案确认，不照搬这里的 A、B、C。

```text
视觉方向，选一个（或直接说你的想法、发参考图）：

A. 冷峻宿命（稳妥）：顶光和硬侧光，脸一半在暗里；湿街反着霓虹，主色青灰配一点钠灯黄；
   机位固定、对称，人物常在画面边缘。适合克制的复仇；暗部多，竖屏上要注意亮度。
B. 湿热欲望（贴题）：钠灯和霓虹的暖色混着雨，手持贴近，浅景深，脸上全是水；
   色彩饱和偏暖。情绪更浓，镜头晃动多，生成要锁住摄影机漂移。
C. 仪式化暴力（大胆）：慢动作、对称构图、雨水在逆光里成线；高反差，红与黑。
   视觉冲击最强，风格化重，和写实剧情放在一起要拿捏。
D. 按你推荐的来。

推荐 A：复仇的戏眼在「等」和「一击」，冷光和固定机位最能把等待撑住，也最好生成。

光比默认 1:8（对峙档）；色彩随方向走，不再单独问。
```

选项背后的依据：A 取类型解构与暴力族（`taxonomy.md` 第 2 族）的冷峻一支，B 取都市感官族（第 5 族），C 取仪式化、歌剧化的一支；具体基元从各自的档案和 `camera/looks.md` 黑色电影卡里取。

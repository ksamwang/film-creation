# 拆解七步：从一场戏到分镜脚本

拿到一场戏，按顺序走七步。前三步决定**拍什么**，后四步决定**怎么排、怎么出**。每一步都有产物，下一步只在上一步的产物上工作。

全篇用同一场戏做示例：

```text
场 5  夜  内  公司·开放办公区
人物：林晚、顾言

△ 办公区只剩林晚工位的台灯亮着。她在核对明天要交的报告。
△ 屏幕上，报告第七页的数据和她手边打印稿上的不一样。
△ 她点开修订记录：最后修改人「顾言」，时间 21:47。
△ 走廊尽头，电梯「叮」了一声。
△ 顾言提着两杯咖啡走过来，把一杯放在她桌上。
顾言：还没走？明天汇报别太紧张。
△ 林晚把屏幕转向他。
林晚：第七页，是你改的？
△ 顾言看了一眼屏幕，笑了笑，把自己那杯咖啡放下。
顾言：数据不好看，我帮你调了一下。汇报的时候，你照着念就行。
△ 林晚看着那杯咖啡，没有碰。
```

---

## 第一步：读戏

**还没读懂戏就动手拆镜头，最后只能给剧本配插图。** 先回答六个问题，写成一张读戏卡（《场面调度：影像的运动》8.1 第一遍拆析只读故事与人物）：

| 问题 | 本场答案 |
|---|---|
| 这场戏结束时什么变了？ | 林晚从「怀疑」变成「确认上司在操纵她」；她第一次没有顺从（不碰咖啡） |
| 这是谁的戏？（视点跟谁） | 林晚。观众和她一起发现，镜头站在她这一侧 |
| beat 怎么分？ | B1 发现异常 → B2 证实 → B3 来人 → B4 对质 → B5 摊牌 → B6 她的回应 |
| 转折在哪一拍？ | B5：顾言承认，而且要她照念。权力关系摊开 |
| 情绪曲线？ | 疑 → 冷 → 紧 → 压 → 静 |
| 观众知道多少？ | 前半等于林晚（一起发现）；顾言出现时观众已经知道他改了数据，他不知道她知道（观众大于顾言，`writing/intent.md`） |

读戏卡决定后面所有选择：视点跟林晚，所以发现部分用她的视线组；转折在 B5，所以 B5 的镜头最密、景别最近。

## 第二步：定镜头数

镜头数从四个方向估，取交集。

**① 时长 ÷ 平均镜长**

先估这场戏在成片里多长（台词按 4 字 / 秒加 1–2 秒，动作和反应按下面的第六步），再按场景类型的平均镜长除。参考值（行业惯例，当代院线与网络剧的常见区间）：

| 场景类型 | 平均镜长 | 说明 |
|---|---|---|
| 平静对话 | 4–6 秒 | 正反打 + 反应 |
| 激烈争吵 | 2–3 秒 | 切换加快，景别收近 |
| 打斗 | 1–2.5 秒 | 一镜一个动作 |
| 追逐 | 1.5–3 秒 | 越接近终点越短 |
| 悬疑 / 潜入 | 3–6 秒 | 慢，给观众时间找东西 |
| 无台词情绪戏 | 4–10 秒 | 留给表演和沉默 |
| 蒙太奇 | 1–2 秒 | 节奏由音乐决定 |
| 文艺 / 作者风格 | 8–20 秒以上 | 长镜头为主 |
| 竖屏短剧 | 2–5 秒（对白 4–8 秒） | 见 `references/drama/06-storyboard.md` §2 |

本场约 40–45 秒，前半悬疑（4 秒左右）、后半对质（3 秒左右）→ 约 **11–14 镜**。

**② 按 beat**：每个 beat 1–3 镜，转折那一拍 2–4 镜。本场 6 个 beat → **8–15 镜**。

**③ 按必看信息**：观众必须看清的每一条信息至少一镜。本场：空间与她的孤立、两组数字不一样、修订人是顾言、有人来了、来的是顾言、咖啡、她转屏幕、他的反应、他的话、她不碰咖啡 → **至少 10 镜**。

**④ 按生成预算**：每多一镜就多一次生成和一次漂移的机会。按项目预算算出这场戏能分到多少镜（`craft/production/03-budget.md`）。AIGC 短片默认镜头偏少、镜长偏长（4–6 秒），因为多数视频模型一次出 4–10 秒，切得越碎浪费越多。

**取交集**：本场定 **13 镜**左右。如果预算只够 8 镜，先删「确认已知信息」的镜头，再合并相邻的同景别镜头；不要删反应镜和视线对象镜——它们是镜头之间的胶水。

**校核**

- 镜头数 < beat 数：有 beat 没被拍出来，或者 beat 本身该合并。
- 一场戏超过 15 镜而不是动作戏：多半是台词被逐句切开了（乒乓），回到问答合并（`craft/staging/06-scene-analysis.md`）。
- 15–90 秒的短片全片 6–12 镜（`craft/story/03-structure.md`）是 AIGC 预算下的默认值；节奏快的类型可以更多，但要有预算。

## 第三步：定每镜拍什么

**每个镜头回答一个问题**（《电影镜头设计》7.3 问答模式）。先按 beat 列出观众在每一刻想问的问题，再给每个问题配一个镜头功能（`shot-functions.md`）。

| beat | 观众想问 | 镜头功能 |
|---|---|---|
| B1 | 在哪？谁？ | 建立镜头 |
| B1 | 她在看什么？ | 视线对象（插入） |
| B1 | 她发现了吗？ | 反应 |
| B2 | 是谁改的？ | 插入（证据） |
| B3 | 什么声音？谁来了？ | 声音先行 + 反应 → 视线对象 |
| B4 | 他要干什么？ | 双人（关系） |
| B4 | 她会怎么做？ | 动作 + 台词 |
| B5 | 他会承认吗？ | 反应（他的笑） |
| B5 | 他怎么说？她怎么接？ | 单人台词 → 听者反应 |
| B6 | 她会喝吗？ | 插入（咖啡） |
| B6 | 现在两人是什么关系？ | 拉开的关系镜 |

**剧本没写、分镜必须补的镜头**——拆完逐条对照：

- [ ] **空间交代**：观众知道人在哪、彼此距离多远吗？
- [ ] **视线对象**：每次有人「看」，观众都看到他看见的东西了吗？
- [ ] **反应**：每个重要的信息、台词、动作之后，有人接住它吗？
- [ ] **插入**：关键的字、物件、手上的动作，观众看得清吗？
- [ ] **入场 / 出场**：人物从哪进、往哪出，方向一致吗？
- [ ] **过渡 / 停顿**：转折之后有没有留一拍让观众消化（`writing/devices.md` 转折与停顿）？

**「看 → 看到什么 → 反应」是最基本的三镜组。** 人物看（近景）、他看到的东西（视线对象）、他的反应（近景），观众就进入了他的视点。本场 B1–B3 就是两组三镜组连起来。

## 第四步：排顺序

**交代方式**

| 方式 | 顺序 | 效果 | 用在 |
|---|---|---|---|
| 由远到近 | 建立 → 关系 → 单人 → 特写 | 清楚、稳 | 大多数场景的默认 |
| 由近到远 | 细节 → 单人 → 拉开揭示环境 | 悬念、意外 | 开场钩子、揭示 |
| 从声音开始 | 声音先于画面 → 反应 → 声源 | 紧张、好奇 | 有人闯入、电话、敲门 |
| 重新交代 | 戏中途再给一次全景 | 人物走位后重建空间；喘一口气 | 长场景中段、转折之后 |

本场：B1 由远到近；B3 从声音开始；结尾拉开（情绪最高点拉远，`writing/intent.md` 哭 / 感动的同一原理）。

**景别的走向**

- 一场戏通常**逐渐推近**，在转折处到最近；转折之后可以突然跳远（《电影镜头设计》8.2 改变景别来交代场景）。
- **相邻镜头要有差别**：景别至少差一级，或者角度变化明显。同一主体、同景别、同角度相接，就是跳切（除非你要跳切）。
- 正反打两边的景别、角度保持对称；某一方的景别突然收近，表示这一刻属于他。

**剪辑点**

- 切在动作中间（坐下的一半、转身的一半），下一镜接着做完——动接动最顺（《电影镜头设计》7.10）。
- 人物出画后再切，或者入画前先切进空景（7.11–7.12 出镜与入镜、清空画面）。
- 视线方向和轴线在整场里保持一致（`craft/staging/04-coverage.md`）。

## 第五步：分配台词与声音

**台词落在谁的脸上**

| 情况 | 落在 |
|---|---|
| 信息在台词里（宣布、揭露、命令） | 说话人 |
| 意义在听者身上（被羞辱、被告白、听到噩耗） | **听者**，台词作画外音 |
| 长台词 | 前半句给说话人，后半句切到听者 |
| 一方一直沉默 | 沉默的一方的反应镜，比说话方更多 |

本场 B5：「数据不好看，我帮你调了一下」给顾言（信息在他身上）；「汇报的时候，你照着念就行」切到林晚（意义在她身上——这是羞辱）。

**声画关系**

- **声音先行**（下一镜的声音提前进来）：制造好奇，带观众进下一场。本场电梯「叮」先于顾言的画面。
- **声音延后**（上一镜的台词延续到下一镜画面）：让观众看到听者，就是上面的台词落在听者。
- **静默镜**：转折之后的一镜不放台词、不放音乐，只留环境声（`craft/sound/03-silence.md`）。

**AIGC 落法**

- 一镜一个说话人（`references/drama/04-script.md` §3）。听者反应镜不张嘴，生成更稳也更便宜。
- 画外台词（落在听者镜里的那半句）用说话人那一镜生成的人声或配音，在剪辑里铺到听者镜上；生成听者镜时提示里写「她没有说话」。

## 第六步：定时长

| 内容 | 时长 |
|---|---|
| 台词 | 中文 ÷ 4 字 / 秒 + 1–2 秒（`references/drama/04-script.md` §3） |
| 动作 | 3–5 秒能看清 2–3 个连续动作 |
| 反应 | 1.5–3 秒：触发 → 落到脸上 → 定住 |
| 插入（字、物件） | 2–3 秒；要读的字按每秒 4–6 个字留时间 |
| 建立 / 过渡 / 空镜 | 2–4 秒 |
| 情绪停顿镜 | 3–5 秒，比你以为的长一点 |

加总后和第二步的估计对比。超了先删「观众已经知道」的镜头，再压动作；不要压台词镜的时长去硬塞——说不完的台词在生成里等于不存在。

## 第七步：评估生成

每一镜标出：

- **可靠性**：稳 / 定帧 / 后期（`camera/index.md`）。
- **生成方式**：参考图生、首帧生、首尾帧、续接上一镜（`references/aigc/workflow.md`）。
- **资产**：用到哪些人物、场景、道具的参考图（`references/aigc/assets.md`）。
- **备选**：高风险镜头写清「不成立时退到什么」（`craft/staging/06-scene-analysis.md`）。例：双人镜脸混 → 两个单人 + 一个插入。

然后**按场景和资产把镜头分组**，写进生成清单（`templates/shot-list.md`）：同一场景、同一光线、同一组参考图的镜头连着出。

**合并还是拆开**

| 选择 | 好处 | 代价 |
|---|---|---|
| 一个运镜镜头代替几个切镜（推近代替全景 → 中景 → 近景） | 少几次生成；镜内连贯 | 镜头越长越容易漂移；运镜失败要整镜重来 |
| 几个切镜代替一个运镜 | 每镜短、可控；可以单独重做 | 生成次数多；镜头之间要靠参考图对齐 |

默认：情绪推进用一个推镜；信息交代用切镜。

## 分镜脚本格式

一镜一行，按剪辑顺序。镜号写成「场-镜」：`5-01`、`5-02`。后来插入的镜头用字母（`5-04A`），删掉的镜号空着不重排——生成清单、文件名、剪辑工程都用镜号对应。

| 镜号 | 功能 | 景别 | 角度 | 运镜 | 画面（起点 → 动作 → 落点） | 台词 / 声音 | 时长 | 生成 |
|---|---|---|---|---|---|---|---|---|

**示例：场 5 的分镜脚本**

| 镜号 | 功能 | 景别 | 角度 | 运镜 | 画面 | 台词 / 声音 | 时长 | 生成 |
|---|---|---|---|---|---|---|---|---|
| 5-01 | 建立 | 全景 | 高角 | 固定 | 空荡的办公区，只有林晚工位的台灯亮着，她在画面下方的一小块光里 | 空调低鸣 | 3 s | 稳 · 参考图生 |
| 5-02 | 视线对象 | 特写 | 平视 | 固定 | 屏幕上的数字和桌上打印稿的数字并排，不一样 | — | 3 s | 后期 · 屏幕与字合成 |
| 5-03 | 反应 | 近景 | 平视 | 缓推 | 林晚的视线在屏幕和打印稿之间来回，停住 | — | 2.5 s | 稳 |
| 5-04 | 插入 | 特写 | 平视 | 固定 | 修订记录：最后修改人「顾言」，21:47 | — | 2.5 s | 后期 · 屏幕合成 |
| 5-05 | 反应 | 中近景 | 平视 | 固定 | 林晚抬头，看向画右的走廊 | 电梯「叮」（先于画面） | 2 s | 稳 |
| 5-06 | 视线对象 | 全景 | 平视 | 固定 | 走廊尽头，顾言提着两杯咖啡走来，从远处走进画面中部 | 脚步声 | 3 s | 稳 · 参考图生 |
| 5-07 | 关系 | 中景 | 平视 | 固定 | 顾言走到桌边，把一杯咖啡放在她桌上；林晚侧对镜头 | 顾言：还没走？明天汇报别太紧张。 | 4.5 s | 稳 · 一人说话 |
| 5-08 | 动作 | 近景 | 过肩（顾言） | 固定 | 林晚把屏幕转向画右的顾言 | 林晚：第七页，是你改的？ | 3.5 s | 稳 |
| 5-09 | 反应 | 近景 | 平视 | 固定 | 顾言看了一眼屏幕，笑了笑，把自己那杯咖啡放下 | — | 2.5 s | 稳 |
| 5-10 | 单人 | 中近景 | 微仰 | 固定 | 顾言看着她，身体靠在桌沿 | 顾言：数据不好看，我帮你调了一下。 | 4.5 s | 稳 |
| 5-11 | 反应 | 近景 | 平视 | 缓推 | 林晚看着他，下巴绷紧，没有说话 | 顾言（画外）：汇报的时候，你照着念就行。 | 4.5 s | 稳 · 林晚不张嘴 |
| 5-12 | 插入 | 特写 | 俯 | 固定 | 桌上那杯咖啡冒着热气，她的手停在旁边，没有碰 | 环境声 | 3 s | 稳 |
| 5-13 | 关系 / 结尾 | 全景 | 平视 | 固定 | 两人隔着桌子，台灯在中间；顾言转身离开，林晚没有动 | 静默 | 3.5 s | 稳 · 参考图生 |

合计约 42 秒、13 镜。逐镜「为什么」：

- 5-01 高角全景：林晚是这场戏的主人，开场先让观众看到她的孤立。
- 5-02 / 5-03 / 5-04：两组「看 → 看到什么 → 反应」的压缩版，观众和她一起发现。
- 5-05 声音先行：观众比画面先知道有人来了。
- 5-07 中景：顾言进入她的空间，咖啡是他的「礼物」也是压迫，给全两个人的关系。
- 5-09 无台词：他的笑比任何回答都更有信息量。
- 5-10 微仰：权力在他手里。
- 5-11 台词落在听者：羞辱的意义在她脸上。
- 5-12 插入：咖啡是这场戏的母题物件，她不碰，就是她的回答。
- 5-13 拉开：转折之后拉远，留一拍静默。

## 审读清单

- [ ] 读戏卡写了吗？能说出这场戏结束时什么变了、是谁的戏、转折在哪一拍？
- [ ] 镜头数在四种估法的交集里？
- [ ] 每一镜都能说出它回答的问题？
- [ ] 每次「看」都有视线对象，每个重要信息之后都有反应？
- [ ] 转折那一拍镜头最密、景别最近？
- [ ] 相邻镜头景别或角度有明显差别（除非有意跳切）？
- [ ] 重要台词落在了对的脸上？一镜一个说话人？
- [ ] 每镜时长够把台词说完、把动作做完？
- [ ] 每镜标了可靠性、生成方式和资产；高风险镜头有备选？

## 常见错误

| 错误 | 改法 |
|---|---|
| 一句台词一镜，正反打来回切（乒乓） | 按问答合并；重要台词切到听者；加关系镜 |
| 全是中景 | 按第四步的景别走向：建立 → 推近 → 转折最近 → 拉开 |
| 有人「看」，但没有他看到的东西 | 补视线对象镜 |
| 信息交代了，没有反应 | 补反应镜；观众要看到信息落在人身上 |
| 镜头只是剧本的插图，不推进 | 删掉不回答新问题的镜头 |
| 先定「每场 8 镜」再填内容 | 先读戏，再按四种估法定数 |
| 为了省生成，把三段戏塞进一个长镜头 | 长镜头的风险见 `three-ways.md`；省钱先删重复信息的镜头 |

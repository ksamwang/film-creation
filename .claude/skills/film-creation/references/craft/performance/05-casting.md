# 选角：位置、工具与“被看见”

## 核心判断

选角不是找最像角色的人，而是判断两件事：这个演员的工具能不能完成角色所需的动作，以及他有没有要被看见的冲动。长相和聪明都不在哈根的先决条件里；阿德勒则提醒，旧剧团的选角逻辑是“位置”，而今天的试镜把每个演员变成了未知数。

## 书里的方法

位置。阿德勒回忆旧剧团制：除非团里已经有一个能胜任罗密欧的人、一个能胜任朱丽叶的人、一个合适的保姆和一个合适的修道士，否则不会动手排《罗密欧与朱丽叶》。演员在不同行当间穿行，演小角色，学会握长矛，最后才轮到哈姆雷特。她的判断很直接：没有人既能演法斯塔夫又能演罗密欧，每个人在剧团里都会找到适合自己的位置。今天这套资源没有了——你和你的位置是一个未知数。她还拆掉了“被星探发现”的神话：即使梦想成真，没有学过握长矛的人也只能是一个可怜的演员。

工具。哈根把才华拆成可观察的清单：高度的敏感性、易受伤的心灵、敏锐的知觉器官、活泼的想象力、对现实的领悟力、想传达自身经验的强烈欲望、想让自己的一切被耳闻目睹的冲动。她同时说，只有才华不够，身体、声音、语言必须训练——就像小提琴手要让琴好用；改不掉口音或步态而演砸罗密欧，只能怪自己太懒。

反类型。哈根反驳了几条常见的偏见。外表的美不是好演员的先决条件：漂亮的孩子习惯被赞美，容易变得被动；不漂亮的孩子反而早早学会说“我在这里，快看着我”。才气纵横的心智也不是绝对必要，知性演员可能把真实的冲动过度理性化。她还说过一句相反的话：演员一旦具备真正高超的表演技巧，是应该有能力演出任何角色的。两句并不矛盾——位置是剧团的配置问题，能力是演员的上限问题。

看什么。哈根在剧本研究里给的比例可以借到试镜：客观只占一成，其余九成是主观。试镜时演员给出的“解释”价值很低；有价值的是他在给定情境里能不能具体化、能不能对对手做出真实反应、有没有非说不可的冲动。

## 可执行规则

1. 先写角色的动作清单：他要做什么，不是他是什么样的人。
2. 试镜给一个及物动作和一个具体情境，不给一段情绪独白。
3. 看演员能否在三十秒内把情境具体化：哪一年、在哪、手里有什么。
4. 看演员是在回应对手，还是在表演“角色”。
5. 不因漂亮、聪明、名气入选；这三项都不在先决条件里。
6. 群戏按位置配齐：主角、对手、摇摆者、旁观者，各有功能。先有朱丽叶和保姆，再谈《罗密欧与朱丽叶》。
7. 不用“发现”逻辑选人：没受过训练的人可以被拍到，但撑不住整部戏。
8. 判断上限时问“他能不能演出这个角色的动作”，而不是“他像不像这个角色”。

## 检查清单

- [ ] 这个角色的动作清单写出来了吗？
- [ ] 演员的工具（身体、声音、语言）够用吗？
- [ ] 他有没有“要被看见”的冲动？
- [ ] 他是在回应对手，还是在展示自己？
- [ ] 我是不是因为外形或名气做的决定？
- [ ] 群戏的位置配齐了吗？
- [ ] 试镜内容是否给足了具体情境？

## 与风格层接口

选角决定摄影机可以怎么用。工具强、反应细的演员可以给近景和长镜头；反应粗、身体强的演员适合全景与群戏，靠调度和剪辑补细节。AI 生成里，选角对应角色外形与行为粒度的设定：提示词能要求多细的动作，取决于你设定的表演尺寸。与制作模块的分界是：这里做适配判断，预算与档期在那边。

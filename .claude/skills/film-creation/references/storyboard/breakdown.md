# 拆解七步：从一场戏到分镜脚本

拿到一场戏，按顺序走七步。前三步决定**拍什么**，后四步决定**怎么排、怎么出**。第三步里每一行动作都要按 `storyboard/decoupage.md` 拆成画面：一行剧本通常是 2–6 个镜头，不是一个。每一步都有产物，下一步只在上一步的产物上工作。

贯穿七步的一条线是**镜头之间的因果**：第一步写镜流句，第三步的问题从镜流句里来，第四步给每个切点设计承接。少了这条线，每一镜都完成了功能，连起来却只能读成「然后……然后……」（打卡式分镜）。**拆镜之前先通读 `storyboard/flow.md`**（不长）：镜流句、七种承接、三种断层、呼吸、场间接点、读链测试与兑现检查都在那里，只读其中一节，学到的只是标签。

全篇用同一场戏做示例：

```text
场 5  夜  内  公司·开放办公区
人物：林晚、顾言

△ 办公区只剩林晚工位的台灯亮着。她在核对明天要交的报告。
△ 屏幕上，报告第七页的数据和她手边打印稿上的不一样。
△ 她点开修订记录：最后修改人「顾言」，时间 21:47。
△ 走廊尽头，电梯「叮」了一声。
△ 顾言提着两杯咖啡走过来，把一杯放在她桌上。
顾言：还没走？明天汇报别太紧张。
△ 林晚把屏幕转向他。
林晚：第七页，是你改的？
△ 顾言看了一眼屏幕，笑了笑，把自己那杯咖啡放下。
顾言：数据不好看，我帮你调了一下。汇报的时候，你照着念就行。
△ 林晚看着那杯咖啡，没有碰。
```

---

## 第一步：读戏

**还没读懂戏就动手拆镜头，最后只能给剧本配插图。** 先回答六个问题，写成一张读戏卡（《场面调度：影像的运动》8.1 第一遍拆析只读故事与人物）：

| 问题 | 本场答案 |
|---|---|
| 这场戏结束时什么变了？ | 林晚从「怀疑」变成「确认上司在操纵她」；她第一次没有顺从（不碰咖啡） |
| 这是谁的戏？（视点跟谁） | 林晚。观众和她一起发现，镜头站在她这一侧 |
| beat 怎么分？ | B1 发现异常 → B2 证实 → B3 来人 → B4 对质 → B5 摊牌 → B6 她的回应 |
| 转折在哪一拍？ | B5：顾言承认，而且要她照念。权力关系摊开 |
| 情绪曲线？ | 疑 → 冷 → 紧 → 压 → 静 |
| 观众知道多少？ | 前半等于林晚（一起发现）；顾言出现时观众已经知道他改了数据，他不知道她知道（观众大于顾言，`writing/intent.md`） |

读戏卡决定后面所有选择：视点跟林晚，所以发现部分用她的视线组；转折在 B5，所以 B5 的镜头最密、景别最近。

**镜流句**：读戏卡的最后一项，把整场写成一段因果话，箭头上写「因此 / 但是 / 同时」（`storyboard/flow.md` §1）：

```text
林晚核对报告 → 但是两组数字不一样 → 因此她翻修订记录 → 看见修改人是顾言
→ 同时电梯「叮」了一声 → 因此她抬头 → 看见顾言提着咖啡走来 → 他把一杯放在她桌上
→ 但是她没接这个好意，把屏幕转向他 → 因此他不得不回答 → 他笑着承认，还要她照念
→ 这句话落在她脸上 → 因此她看着那杯咖啡，不碰 → 他走了，她没有动
```

后面切镜时，每个切点都要落在某个箭头上。只能写「然后」的地方，说明这里缺一个接点，或者两件事该合成一镜。

## 第二步：定镜头数

镜头数从四个方向估，取交集。

**① 时长 ÷ 平均镜长**

先估这场戏在成片里多长（台词按 4 字 / 秒加 1–2 秒，动作和反应按下面的第六步），再按场景类型的平均镜长除。参考值（行业惯例，当代院线与网络剧的常见区间）：

| 场景类型 | 平均镜长 | 说明 |
|---|---|---|
| 平静对话 | 4–6 秒 | 正反打 + 反应 |
| 激烈争吵 | 2–3 秒 | 切换加快，景别收近 |
| 打斗 | 1–2.5 秒 | 一镜一个动作 |
| 追逐 | 1.5–3 秒 | 越接近终点越短 |
| 悬疑 / 潜入 | 3–6 秒 | 慢，给观众时间找东西 |
| 无台词情绪戏 | 4–10 秒 | 留给表演和沉默 |
| 蒙太奇 | 1–2 秒 | 节奏由音乐决定 |
| 文艺 / 作者风格 | 8–20 秒以上 | 长镜头为主 |
| 竖屏短剧 | 2–5 秒（对白 4–8 秒） | 见 `references/drama/06-storyboard.md` §2 |

本场约 40–45 秒，前半悬疑（4 秒左右）、后半对质（3 秒左右）→ 约 **11–14 镜**。

**② 按 beat 和动作拆解**：每个 beat 1–3 镜，转折那一拍 2–4 镜；有身体动作的行按 `storyboard/decoupage.md` §2 取拍（普通动作 1–2 镜，关键动作 5–8 镜）。本场 6 个 beat、动作都很小 → **8–15 镜**。

**③ 按必看信息（只作下限）**：观众必须看清的每一条信息至少一镜。本场：空间与她的孤立、两组数字不一样、修订人是顾言、有人来了、来的是顾言、咖啡、她转屏幕、他的反应、他的话、她不碰咖啡 → **至少 10 镜**。这一条只用来查有没有漏，不用来生成镜头：一条信息配一镜，正是打卡式分镜的来源。镜头从镜流句的箭头里来，信息清单只校核每条都被看到了。

**④ 按生成预算**：预算管的是**生成单位**，不是剪辑镜头。多镜头模型一次生成就能切几个镜头，几个相邻的短镜头可以是一次生成（`storyboard/flow.md` §7、`video-prompt/compile.md`）。按项目预算算出这场戏能分到几个生成单位（`craft/production/03-budget.md`），再看剪辑镜头能不能装进去；装不下时按下面的顺序删镜，不要把几个动作塞进一个镜头。

**取交集**：以 ① 和 ② 为中心，③ 查漏，④ 决定分几次生成。本场定 **13 镜**左右。预算实在装不下时，先删「确认已知信息」的镜头，再删动作拆解里不是重点的细节镜（`storyboard/decoupage.md` §4 没加粗的）；不要删反应镜、视线对象镜、动作的接触和结果镜，也不要删呼吸镜——它们是镜头之间的胶水。

**呼吸预算**：估时长时先留出约 10–15% 给呼吸（事件后的停留、人走后的空间、留下来的物件），情绪戏更多（`storyboard/flow.md` §4）。本场 45 秒，留约 5 秒：5-12 的咖啡和 5-13 的拉开。

**校核**

- 镜头数 < beat 数：有 beat 没被拍出来，或者 beat 本身该合并。
- 一场戏超过 15 镜而不是动作戏：多半是台词被逐句切开了（乒乓），回到问答合并（`craft/staging/06-scene-analysis.md`）。
- 一行动作只有一镜，画面栏里却有两三个动作：没拆开，回到 `storyboard/decoupage.md`。

## 第三步：定每镜拍什么

**每个镜头回答一个问题**（《电影镜头设计》7.3 问答模式）。顺着镜流句列出观众在每一刻想问的问题，再给每个问题配一个镜头功能（`shot-functions.md`）。问题从箭头里来，不是一个 beat 配一镜：上一镜留下什么问题，下一镜就回答什么。

| beat | 观众想问 | 镜头功能 |
|---|---|---|
| B1 | 在哪？谁？ | 建立镜头 |
| B1 | 她在看什么？ | 视线对象（插入） |
| B1 | 她发现了吗？ | 反应 |
| B2 | 是谁改的？ | 插入（证据） |
| B3 | 什么声音？谁来了？ | 声音先行 + 反应 → 视线对象 |
| B4 | 他要干什么？ | 双人（关系） |
| B4 | 她会怎么做？ | 动作 + 台词 |
| B5 | 他会承认吗？ | 反应（他的笑） |
| B5 | 他怎么说？她怎么接？ | 单人台词 → 听者反应 |
| B6 | 她会喝吗？ | 插入（咖啡） |
| B6 | 现在两人是什么关系？ | 拉开的关系镜 |

**剧本没写、分镜必须补的镜头**——拆完逐条对照：

- [ ] **空间交代**：观众知道人在哪、彼此距离多远吗？
- [ ] **视线对象**：每次有人「看」，观众都看到他看见的东西了吗？
- [ ] **反应**：每个重要的信息、台词、动作之后，有人接住它吗？
- [ ] **插入**：关键的字、物件、手上的动作，观众看得清吗？
- [ ] **入场 / 出场**：人物从哪进、往哪出，方向一致吗？
- [ ] **过渡 / 停顿**：转折之后有没有留一拍让观众消化（`writing/devices.md` 转折与停顿）？

**「看 → 看到什么 → 反应」是最基本的三镜组。** 人物看（近景）、他看到的东西（视线对象）、他的反应（近景），观众就进入了他的视点。本场 B1–B3 就是两组三镜组连起来。

**动作拆解**：问题定完，逐行过剧本的动作行。每个身体动作按 `storyboard/decoupage.md` 拆：预兆 → 发起 → 接触 → 结果 → 反应 → 余波，按重要性取拍；景别跟着此刻最重要的东西走（手、脚、脸、物件、整个空间）。拆之前先写这场的视觉设计：关键画面、机位与视点、景别走向、运镜策略（同篇 §5）。本场的动作都小（点开记录、放咖啡、转屏幕），各一镜；要是有人摔倒、动手、割伤，一行就要拆成好几镜。

## 第四步：排顺序，设计接点

**交代方式**

| 方式 | 顺序 | 效果 | 用在 |
|---|---|---|---|
| 由远到近 | 建立 → 关系 → 单人 → 特写 | 清楚、稳 | 大多数场景的默认 |
| 由近到远 | 细节 → 单人 → 拉开揭示环境 | 悬念、意外 | 开场钩子、揭示 |
| 从声音开始 | 声音先于画面 → 反应 → 声源 | 紧张、好奇 | 有人闯入、电话、敲门 |
| 重新交代 | 戏中途再给一次全景 | 人物走位后重建空间；喘一口气 | 长场景中段、转折之后 |

本场：B1 由远到近；B3 从声音开始；结尾拉开（情绪最高点拉远，`writing/intent.md` 哭 / 感动的同一原理）。

**景别的走向**

- 一场戏通常**逐渐推近**，在转折处到最近；转折之后可以突然跳远（《电影镜头设计》8.2 改变景别来交代场景）。
- **相邻镜头的景别先看主体**（`storyboard/continuity.md` 景别衔接）：
  - 同一主体相接：景别跨两档（中景接特写），或跨一档同时换角度 30° 以上；同景别同角度、只差一档不换角度（中近景接近景），都是跳切。要同景别，中间插一个有内容的视线对象、插入或反应镜；先改景别和角度，不靠加镜头躲跳切。
  - 不同主体相接（正反打、视线对象、插入）：同景别可以接，正反打两边应当对称。
  - 连续特写三四个、或近景以内连着半分钟之后，回到一个交代空间的中景或全景。
  - 大远景直接接大特写是强调手段，留给转折那一拍。
- 正反打两边的景别、角度保持对称；某一方的景别突然收近，表示这一刻属于他。

**剪辑点**

- 切在动作中间（坐下的一半、转身的一半），下一镜接着做完——动接动最顺（《电影镜头设计》7.10）。
- 人物出画后再切，或者入画前先切进空景（7.11–7.12 出镜与入镜、清空画面）。
- 视线方向和轴线在整场里保持一致（`craft/staging/04-coverage.md`）。

**接点**

顺序排好后，逐个切点写它靠什么接上：问答、视线、动作、声音、物件、运动与构图、情绪（七种承接见 `storyboard/flow.md` §2）。写不出承接的切点，要么补一镜，要么合并。结果写进分镜脚本的「接 / 出」栏；下表是本场每个切点的展开读法。

| 切点 | 承接 | 读成 |
|---|---|---|
| 5-01 → 5-02 | 视线 | 她盯着屏幕 → 因此给她看的东西 |
| 5-02 → 5-03 | 问答 | 数字不一样 → 她发现了吗 |
| 5-03 → 5-04 | 动作 + 视线 | 她去点修订记录 → 记录上是顾言 |
| 5-04 → 5-05 | 声音（叮，先于画面） | 同时电梯响了 → 她抬头 |
| 5-05 → 5-06 | 视线 | 她看向画右 → 走廊尽头的人 |
| 5-06 → 5-07 | 运动 | 他走近，入画到桌边 |
| 5-07 → 5-08 | 问答 | 他递来好意 → 但是她转过屏幕 |
| 5-08 → 5-09 | 问答 | 是你改的？ → 他笑了 |
| 5-09 → 5-10 | 问答 | 他会怎么说 → 他承认 |
| 5-10 → 5-11 | 声音（后半句拖到听者） | 这句话落在她脸上 |
| 5-11 → 5-12 | 视线 + 物件 | 她的目光落到咖啡上 |
| 5-12 → 5-13 | 情绪 | 她不碰 → 因此拉开，他走，她不动 |

**场头和场尾**

- 场头先接上一场的尾，不默认用建立镜；本场用 5-01 高角全景开场，是因为她的孤立就是这场戏的起点。
- 场尾不切在事件上，切在事件之后的第一个余韵上。本场停在 5-13：他走了，她没动。
- 场与场之间单独写一行接点（声音先入 / 拖后、物件匹配、光与时间、有意硬切……），见 `storyboard/flow.md` §5。

## 第五步：分配台词与声音

**台词落在谁的脸上**

| 情况 | 落在 |
|---|---|
| 信息在台词里（宣布、揭露、命令） | 说话人 |
| 意义在听者身上（被羞辱、被告白、听到噩耗） | **听者**，台词作画外音 |
| 长台词 | 前半句给说话人，后半句切到听者 |
| 一方一直沉默 | 沉默的一方的反应镜，比说话方更多 |

本场 B5：「数据不好看，我帮你调了一下」给顾言（信息在他身上）；「汇报的时候，你照着念就行」切到林晚（意义在她身上——这是羞辱）。

**声画关系**

- **声音先行**（下一镜的声音提前进来）：制造好奇，带观众进下一场。本场电梯「叮」先于顾言的画面。
- **声音延后**（上一镜的台词延续到下一镜画面）：让观众看到听者，就是上面的台词落在听者。
- **静默镜**：转折之后的一镜不放台词、不放音乐，只留环境声（`craft/sound/03-silence.md`）。

**画面里的字和念出来的字**

- 要观众读的字（信、诗、屏幕）写进画面栏，按每秒 4–6 个字留时长；人物念出来的写进台词栏，画外念就标「（画外）」。同一句诗既被看见又被念出来，两栏都写。
- 剧本写了「说话」却没给词（「连声称好」「低声交代了几句」），不要替他编词：声音栏写成「称许的气声，不出词」，或者把这件事放到画外、不让人看见嘴；真要台词，回给编剧。

**AIGC 落法**

- 一镜一个说话人（`references/drama/04-script.md` §3）。听者反应镜不张嘴，生成更稳也更便宜。
- 画外台词（落在听者镜里的那半句）用说话人那一镜生成的人声或配音，在剪辑里铺到听者镜上；生成听者镜时提示里写「她没有说话」。

## 第六步：定时长

| 内容 | 时长 |
|---|---|
| 台词 | 中文 ÷ 4 字 / 秒 + 1–2 秒（`references/drama/04-script.md` §3） |
| 动作 | 3–5 秒能看清 2–3 个连续动作 |
| 反应 | 1.5–3 秒：触发 → 落到脸上 → 定住 |
| 插入（字、物件） | 2–3 秒；要读的字按每秒 4–6 个字留时间 |
| 建立 / 过渡 / 空镜 | 2–4 秒 |
| 情绪停顿镜 | 3–5 秒，比你以为的长一点 |

加总后和第二步的估计对比。超了先删「观众已经知道」的镜头，再压动作；不要压台词镜的时长去硬塞——说不完的台词在生成里等于不存在。

## 第七步：评估生成

每一镜标出：

- **可靠性**：稳 / 定帧 / 后期（`camera/index.md`）。
- **生成方式**：参考图生、首帧生、首尾帧、续接上一镜（`references/aigc/workflow.md`）。
- **资产**：用到哪些人物、场景、道具的参考图（`references/aigc/assets.md`）。
- **备选**：高风险镜头写清「不成立时退到什么」（`craft/staging/06-scene-analysis.md`）。例：双人镜脸混 → 两个单人 + 一个插入。

然后**按场景和资产把镜头分组**，写进生成清单（`templates/shot-list.md`）：同一场景、同一光线、同一组参考图的镜头连着出。

**合并还是拆开**

| 选择 | 好处 | 代价 |
|---|---|---|
| 一个运镜镜头代替几个切镜（推近代替全景 → 中景 → 近景） | 少几次生成；镜内连贯 | 镜头越长越容易漂移；运镜失败要整镜重来 |
| 几个切镜代替一个运镜 | 每镜短、可控；可以单独重做 | 生成次数多；镜头之间要靠参考图对齐 |

默认：情绪推进用一个推镜；信息交代用切镜。

## 分镜脚本格式

一镜一行，按剪辑顺序，十列。镜号写成「场-镜」：`5-01`、`5-02`。后来插入的镜头用字母（`5-04A`），删掉的镜号空着不重排——生成清单、文件名、剪辑工程都用镜号对应。

**「接 / 出」栏**写成「接 {承接方式}；出 {留给下一镜的问题或东西}」：

- 接：问答、视线、动作、声音、物件、运动、构图、情绪，可以叠两种（「视线 + 物件」）；括号里补一句具体的东西（「声音（叮）」）。一场的第一镜写「场头」或「场间」，说明它接住了什么。
- 出：观众此刻想知道的问题（「谁来了」），或者被带到下一镜的东西（「票角」「抹布声」）；呼吸镜和场尾写「余韵」。
- 功能栏说这一镜是干什么的，「接 / 出」说它为什么接在这里。两栏都要写；只有功能栏的分镜，读起来就是打卡（`storyboard/flow.md`）。

多场的分镜，每两场之间在表外写一行**场间接点**：「场间接点 5 → 6：{接点类型}，{上一场尾留下什么，下一场头怎么接住}」（`storyboard/flow.md` §5）。

| 镜号 | 功能 | 景别 | 角度 | 运镜 | 画面（起点 → 动作 → 落点） | 台词 / 声音 | 接 / 出 | 时长 | 生成 |
|---|---|---|---|---|---|---|---|---|---|

- **画面栏**写一张画得出来的图加一个动作：主体、在画面哪里、动作的起点和落点、方向、环境里看得见的东西；不写形容词、比喻和情绪名词（`storyboard/decoupage.md` §6）。
- **运镜栏**默认「固定」；写了运动就要说得出理由：跟、揭示、情绪推进、主观（同篇 §7）。

**示例：场 5 的分镜脚本**

| 镜号 | 功能 | 景别 | 角度 | 运镜 | 画面 | 台词 / 声音 | 接 / 出 | 时长 | 生成 |
|---|---|---|---|---|---|---|---|---|---|
| 5-01 | 建立 | 全景 | 高角 | 固定 | 空荡的办公区，只有林晚工位的台灯亮着，她在画面下方的一小块光里 | 空调低鸣 | 接 场头（孤立就是起点）；出 她在盯什么 | 3 s | 稳 · 参考图生 |
| 5-02 | 视线对象 | 特写 | 平视 | 固定 | 屏幕上的数字和桌上打印稿的数字并排，不一样 | — | 接 视线；出 她发现了吗 | 3 s | 后期 · 屏幕与字合成 |
| 5-03 | 反应 | 近景 | 平视 | 缓推 | 林晚的视线在屏幕和打印稿之间来回，停住 | — | 接 问答；出 她要去查 | 2.5 s | 稳 |
| 5-04 | 插入 | 特写 | 平视 | 固定 | 修订记录：最后修改人「顾言」，21:47 | — | 接 动作 + 视线；出 是顾言 | 2.5 s | 后期 · 屏幕合成 |
| 5-05 | 反应 | 中近景 | 平视 | 固定 | 林晚抬头，看向画右的走廊 | 电梯「叮」（先于画面） | 接 声音（叮）；出 谁来了 | 2 s | 稳 |
| 5-06 | 视线对象 | 全景 | 平视 | 固定 | 走廊尽头，顾言提着两杯咖啡走来，从远处走进画面中部 | 脚步声 | 接 视线；出 他要过来 | 3 s | 稳 · 参考图生 |
| 5-07 | 关系 | 中景 | 平视 | 固定 | 顾言走到桌边，把一杯咖啡放在她桌上；林晚侧对镜头 | 顾言：还没走？明天汇报别太紧张。 | 接 运动；出 她接不接这个好意 | 4.5 s | 稳 · 一人说话 |
| 5-08 | 动作 | 近景 | 过肩（顾言） | 固定 | 林晚把屏幕转向画右的顾言 | 林晚：第七页，是你改的？ | 接 问答（但是）；出 他认不认 | 3.5 s | 稳 |
| 5-09 | 反应 | 近景 | 平视 | 固定 | 顾言看了一眼屏幕，笑了笑，把自己那杯咖啡放下 | — | 接 问答；出 他怎么说 | 2.5 s | 稳 |
| 5-10 | 单人 | 中近景 | 微仰 | 固定 | 顾言看着她，身体靠在桌沿 | 顾言：数据不好看，我帮你调了一下。 | 接 问答；出 这话落在谁身上 | 4.5 s | 稳 |
| 5-11 | 反应 | 近景 | 平视 | 缓推 | 林晚看着他，下巴绷紧，没有说话 | 顾言（画外）：汇报的时候，你照着念就行。 | 接 声音（后半句拖入）；出 她的目光 | 4.5 s | 稳 · 林晚不张嘴 |
| 5-12 | 插入 | 特写 | 俯 | 固定 | 桌上那杯咖啡冒着热气，她的手停在旁边，没有碰 | 环境声 | 接 视线 + 物件；出 她不碰 | 3 s | 稳 |
| 5-13 | 关系 / 结尾 | 全景 | 平视 | 固定 | 两人隔着桌子，台灯在中间；顾言转身离开，林晚没有动 | 静默 | 接 情绪；出 余韵（没动的咖啡） | 3.5 s | 稳 · 参考图生 |

合计约 42 秒、13 镜。逐镜「为什么」：

- 5-01 高角全景：林晚是这场戏的主人，开场先让观众看到她的孤立。
- 5-02 / 5-03 / 5-04：两组「看 → 看到什么 → 反应」的压缩版，观众和她一起发现。
- 5-05 声音先行：观众比画面先知道有人来了。
- 5-07 中景：顾言进入她的空间，咖啡是他的「礼物」也是压迫，给全两个人的关系。
- 5-09 无台词：他的笑比任何回答都更有信息量。
- 5-10 微仰：权力在他手里。
- 5-11 台词落在听者：羞辱的意义在她脸上。
- 5-12 插入：咖啡是这场戏的母题物件，她不碰，就是她的回答。
- 5-13 拉开：转折之后拉远，留一拍静默。

## 审读清单

- [ ] 读戏卡写了吗？能说出这场戏结束时什么变了、是谁的戏、转折在哪一拍？
- [ ] 写了镜流句？每个切点都落在一个箭头上？
- [ ] 镜头数在四种估法的交集里？留了呼吸预算？
- [ ] 每一镜都能说出它回答的问题？
- [ ] 每行动作都拆了：一镜一件事，关键动作拉长成几镜，画面栏里没有两个「然后」（`storyboard/decoupage.md`）？
- [ ] 画面栏写的是看得见的东西，没有形容词、比喻、情绪名词？大多数镜头是固定机位，动的都有理由？
- [ ] 读链测试：每个切点写得出「因为 / 所以 / 但是 / 同时」，「然后」不超过三分之一（`storyboard/flow.md` §6）？
- [ ] 兑现检查：每个承接标签，都能在画面栏或声音栏里找到对应的字？
- [ ] 关键物件的位置和状态在镜头之间连得上？视点每次交接都有理由？
- [ ] 场尾停在余韵上；和下一场之间写了接点？
- [ ] 每次「看」都有视线对象，每个重要信息之后都有反应？
- [ ] 转折那一拍镜头最密、景别最近？
- [ ] 景别衔接：同一主体相接跨了两档或换了角度？连续特写之后回到了整体？生成单位交界处换了主体或跨两档（`storyboard/continuity.md` 景别衔接）？
- [ ] 重要台词落在了对的脸上？一镜一个说话人？
- [ ] 每镜时长够把台词说完、把动作做完？
- [ ] 每镜标了可靠性、生成方式和资产；高风险镜头有备选？

## 常见错误

| 错误 | 改法 |
|---|---|
| 一句台词一镜，正反打来回切（乒乓） | 按问答合并；重要台词切到听者；加关系镜 |
| 全是中景 | 按第四步的景别走向：建立 → 推近 → 转折最近 → 拉开 |
| 有人「看」，但没有他看到的东西 | 补视线对象镜 |
| 信息交代了，没有反应 | 补反应镜；观众要看到信息落在人身上 |
| 镜头只是剧本的插图，不推进 | 删掉不回答新问题的镜头 |
| 一个 beat 一镜，每镜一句事件摘要，镜间只能读成「然后」（打卡） | 先写镜流句，切点落在箭头上；每个切点设计承接（`storyboard/flow.md`） |
| 每场先建立、事件完成就切走、场间一律硬切 | 场头接上一场的尾；场尾停在余韵；场间写接点（`storyboard/flow.md` §4–§5） |
| 先定「每场 8 镜」再填内容 | 先读戏，再按四种估法定数 |
| 为了省生成，把三段戏塞进一个长镜头 | 长镜头的风险见 `three-ways.md`；省钱先删重复信息的镜头 |
| 一行剧本一个镜头，画面栏塞满动作 | 按 `storyboard/decoupage.md` 拆：整体 → 局部 → 整体，一镜一件事 |
| 画面栏写成散文（「阴风惨惨」「如枯木般」），镜镜都缓推 | 写看得见的东西；运镜默认固定（`storyboard/decoupage.md` §6–§7） |

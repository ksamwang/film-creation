# 生成方式：怎么选、怎么串

> 一个镜头用哪种方式生成，决定了哪些东西被锁住、哪些交给模型。**先问这一镜必须锁住什么，再选方式，最后写提示词。**
> 提示词写法见 `prompt-syntax.md`，资产见 `assets.md`，模型支持哪些方式见 `models.md`。竖屏短剧另有标准（`references/drama/`），冲突时以那里为准。

## 0. 决策表

### 图像

| 方式 | 适合 | 强在 | 弱在 | 提示词写什么 / 不写什么 |
|---|---|---|---|---|
| 文生图 | 风格探索、资产第一稿 | 自由、便宜 | 每次都是另一个人、另一个地方 | 写全：主体、环境、镜头、光色；有资产时把资产卡描述逐字放进去 |
| 图生图 / 编辑 | 改一处（服装、表情、光、去杂物）、造型变体、修关键帧 | 原图大部分保留 | 改动大时整张漂；反复编辑画面变脏 | 只写改什么、保留什么：「只把大衣换成红色，脸、姿势、背景不变」；不重写整张画面 |
| 多参考图生图 | **关键帧**：人物 + 场景 + 道具组合进一个构图 | 身份、地点同时锁住 | 站位和构图全靠文字；图多时次要元素被忽略 | 每张图的职责、站位、动作、取景、光；不写外貌 |

### 视频

| 方式 | 适合 | 强在 | 弱在 | 提示词写什么 / 不写什么 |
|---|---|---|---|---|
| 文生视频 | 氛围空镜、风格测试、没有固定角色的镜头 | 运动和运镜最自由 | 身份、地点每次都变 | 主体、环境、动作顺序、运镜、光；纯文生时资产描述写进正文 |
| 参考图生视频 | 对白、多人互动、多镜头一次生成、要原生音频 | 身份跨镜稳；模型自己调度镜头和口型 | 起始构图不稳；景别易偏宽 | 图的职责、**站位**（画面左右、机位前后）、动作链、台词、具体取景；不写外貌 |
| 首帧生视频 | 关键帧先行的主力；构图必须精确的镜头 | 构图、光、风格全由首帧定 | 镜内新入画的人和物没有参考；动作幅度大时脸漂 | **只写运动**：动作、运镜、节奏；不复述画面，不和首帧矛盾 |
| 首尾帧 | 转场、变形、必须精确落位的镜头 | 起点和终点都锁住 | 中间路径不可控；两帧差太多会糊或变成溶化 | 写两帧之间怎么过去：路径、运镜方向；两帧只差一个主要变化 |
| 续接 / 延长 | 长镜头、动作没做完、段与段接上 | 开场与上一段连续 | 越接越漂（画质变软、身份偏移） | 只写接下来发生什么；第一句接住上一段的结束状态 |
| 视频转视频 | 换风格、换服装 / 背景、动作迁移、修局部 | 保留原视频的运动和节奏 | 改得大会闪烁；支持的模型少 | 写改什么、保留什么；不再描述运动 |

## 1. 关键帧先行（非短剧项目的默认流程）

1. **资产定稿**：人物、场景、道具各出参考图（`assets.md`）。
2. **每镜出关键帧**：多参考图生图，按分镜写站位、取景、光。不满意就在图阶段编辑或重出，不进入视频。
3. **首帧生视频**：审过的关键帧做首帧，提示词只写运动。
4. **剪辑**：需要接上的地方按第 2 节处理。

为什么目前最稳：构图问题在图阶段解决，图便宜、可以多抽；首帧一次锁住身份、景别、光和风格，视频只负责动；关键帧就是故事板，可以先给用户审；一个视频模型不行，首帧拿去换另一个接着用。

关键帧怎么出：

- 画**动作的起点**，不画高潮瞬间：要拔刀就画手刚碰到刀柄，不画刀已出鞘。
- 给运动留空间：要推镜就构图稍宽；人要走出画就在走向那侧留空。
- 脸清楚、不要运动模糊；关键帧里的模糊会被视频放大。

什么时候不用：

| 情况 | 改用 | 原因 |
|---|---|---|
| 对白多、要原生音频和口型 | 参考图生视频 | 模型在一次生成里同时调度镜头、口型和声音；拆成单镜首帧会丢掉声音和节奏的连续 |
| 一段里要多个镜头 | 参考图生视频 | 首帧只锁第一镜，后面的镜头仍靠参考图 |
| 镜内有人物新入画 | 参考图生视频，或首帧 + 参考图（模型支持时） | 首帧里没有的人没有身份参考 |
| 竖屏短剧 | 按 `references/drama/` | 短剧标准是参考图生视频、片段塞满时长 |
| 纯氛围空镜、不复用场景 | 文生视频 | 没有要锁的东西 |

## 2. 镜头之间怎么接

| 需求 | 做法 | 注意 |
|---|---|---|
| 下一镜从上一镜结束处继续（同机位、同动作） | 上一镜**实际生成的尾帧**做下一镜首帧；或用续接 / 延长 | 不用关键帧原图；尾帧糊就往前取清楚的一帧，剪掉其后几帧 |
| 转场必须对上（匹配剪辑、A 变成 B） | 首尾帧：首帧 = A 的真实尾帧，尾帧 = B 的关键帧 | 两帧主体位置和明暗接近，过渡才顺 |
| 同一场景切角度（正反打、全景切近景） | 同一张场景主图出各角度关键帧，人物参考不变 | 门窗桌等锚点不许变；守轴线，单人反打视线方向固定 |
| 硬切 | 不需要衔接技术 | 上一镜结束状态 = 下一镜开始状态：位置、朝向、手里的东西 |

尾帧只锁最后一格的构图，不保证动作做完：镜内变化只给首帧，尾帧留给必须对上的转场（`references/drama/06-storyboard.md` 第 5 节）。

**长镜头拆段**：

- 按模型单次时长档位拆，每段一个主导变化。
- 切点放在动作停顿处（坐定后、转身完成后），那里人物稳定、脸清楚，尾帧好用。
- 每段提示词第一句写接住的状态：「她仍站在窗边，右手扶着窗框」。
- 续接越多越漂。漂了就用重出的关键帧重新起头，切点藏在遮挡里（人物走过前景、镜头扫过门框）。

## 3. 按镜头类型推荐

| 镜头 | 首选 | 备选 | 要点 |
|---|---|---|---|
| 对白镜 | 参考图生视频，原生音频 | 关键帧 + 首帧生视频，后期配音 / 对口型 | 一镜一个说话人，其他人不抢正脸；时长按字数估（`references/drama/06-storyboard.md` 第 2 节） |
| 动作镜 | 关键帧 + 首帧生视频；动作长就续接 | 首尾帧锁落点 | 一镜 2–3 个动作；大动作用中景或全景，脸小，漂移不显眼 |
| 空镜 / 建立镜 | 场景主图做首帧生视频 | 不复用的场景用文生视频 | 只写运镜和环境运动（雾、车流、树影） |
| 产品 / 物件特写 | 道具参考 → 关键帧 → 首帧生视频，慢运镜 | 首尾帧（开盖、旋转定格） | logo 和字在图阶段做对，运动幅度小；字仍变形就后期贴回 |
| 转场 | 首尾帧 | 视频转视频；遮挡切 | 两帧构图对齐；差异大就中间加一张关键帧拆成两段 |
| 多人同框 | 多参考图生图出关键帧 → 首帧生视频 | 参考图生视频；分开生成再合成 | 图数 ≤ 上限（含场景）；主导者最显眼；三人以上优先拆镜 |
| 非写实画风 | 画风定稿图做风格参考，关键帧全走首帧生视频 | 参考图生视频 + 首句声明媒介 | 文生视频易变真人（`references/drama/07-segment-prompt.md` 第 4 节） |

## 4. 省钱顺序

1. **先做最难的镜头**：多人、复杂动作、特效、非写实。验证做得到再铺开。
2. **构图在图阶段定完**：关键帧可以多抽，视频只跑审过的关键帧。
3. **预演用低规格**：低分辨率、短时长、同家族的快速版或便宜模型，只看构图、动作和节奏。
4. **定稿再上高规格**：同一首帧、同一提示词升级；换了模型，预演结果不保证复现，先跑一条确认。
5. **重抽设上限**：同一提示词连续三次不行，就改分镜、换方式或换模型。
6. **后期能做的不交给生成**：字幕、配乐、调色、变速、裁切、贴字。

## 5. 失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 首帧很好，一动就崩、脸变 | 运动提示复述画面，或动作幅度太大 | 只写运动；减小幅度；拉开景别 |
| 首帧生视频几乎不动 | 运动写得抽象（「生动」「有活力」） | 写具体动作和运镜方向 |
| 镜内入画的人是陌生脸 | 首帧里没有，也没挂参考 | 让人物在首帧里就在；或改参考图生视频 |
| 动作倒着走、从高潮往回演 | 关键帧画在了动作中段 | 关键帧改画动作起点 |
| 首尾帧中间糊、像溶化 | 两帧差太多 | 缩小差异；中间加一张关键帧，拆成两段 |
| 续接后画质变软、颜色偏 | 误差逐段累积 | 重出关键帧重新起头，切点藏在遮挡里 |
| 编辑几轮后画面发脏 | 编辑累积损失 | 回到原图，一次写清全部改动 |
| 视频转视频闪烁 | 结构改动太大 | 降低改动强度，或只改局部 |

## 检查清单

- [ ] 每镜标了生成方式，理由是这一镜必须锁住的东西？
- [ ] 非短剧项目默认关键帧先行；对白多、多镜头、要原生音频的段改用参考图生视频？
- [ ] 首帧生视频只写运动；参考图生视频写了站位和动作？
- [ ] 关键帧画的是动作起点、留了运动空间，镜内会入画的人都在首帧或参考图里？
- [ ] 需要接上的镜头标了衔接方式（真实尾帧 / 首尾帧 / 续接 / 硬切），长镜头切点在停顿处？
- [ ] 最难的镜头先跑过？预演和定稿规格分开？
- [ ] 选的方式目标模型支持（`models.md`）？

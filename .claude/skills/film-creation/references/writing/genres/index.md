# 类型配方

类型是和观众的一份约定：观众选择一部悬疑片，是在等一个谜被解开；选择一部爱情片，是在等两个人走到一起（或者走不到）。约定要**尽早**交给观众，然后在实现方式上给惊喜。《编剧的策略》第六章把这叫「第一卷协议」：开场那一段就要让观众知道这是什么类型的片子。

| 文件 | 类型 | 观众在等 |
|---|---|---|
| `suspense.md` | 悬疑 / 推理 | 谜底；凶手是谁、真相是什么 |
| `romance.md` | 爱情 | 两个人会不会在一起 |
| `comedy.md` | 喜剧 | 笑；荒唐的局面怎么收场 |
| `horror.md` | 恐怖 / 惊悚 | 害怕，然后活下来（或没有） |
| `crime-action.md` | 犯罪 / 动作 | 计划成不成、谁能赢 |
| `scifi-fantasy.md` | 科幻 / 奇幻 | 一个新规则的世界，和规则带来的代价 |
| `family.md` | 家庭 / 现实 | 关系的裂痕能不能弥合 |
| `brand.md` | 广告 / 品牌短片 | 一个情感瞬间，产品自然地在场 |

## 每份配方的结构

1. **观众在等什么**：这个类型的约定，开场怎么交代。
2. **必备元素**：少了它就不像这个类型。
3. **结构**：两档时长。
   - **60 秒档**（30–90 秒）：3–5 个 beat、6–12 镜、通常 1–2 个场景（`craft/story/03-structure.md`）。
   - **3–5 分钟档**：5–8 个 beat、15–40 镜、2–4 个场景；能放下一个完整的转折和一个次要人物。
4. **示例**：一个原创的一句话概念和 60 秒 beat 表。
5. **陈词滥调 → 替代**：观众已经看腻的写法，以及保留期待、换掉实现的办法。
6. **常用技巧**：链接 `writing/devices.md` 与 `writing/intent.md`。
7. **镜头与画面**：链接 `camera/recipes/`、`camera/lexicon-light.md` 与可借的导演 / 摄影档案。
8. **短剧对应**：在 `references/drama/01-premise.md` 的赛道表里对应哪条。

## 用法

- 先选**一个**主类型。混类型（悬疑爱情、科幻家庭）时，一个做骨架（决定结构和结尾），另一个只提供元素和情绪。
- 百分比节点是体检工具，不是公式（`craft/story/03-structure.md`）：偏了先查因果，不要为了对齐硬加一场。
- 写完用 `writing/doctor.md` 的「俗套」一条检查：观众能猜到结果没关系，猜到**过程**就要改。
- 时长超过 5 分钟的短片，按 3–5 分钟档的节点比例放大，增加场景前先看资产预算（`references/aigc/assets.md`）。

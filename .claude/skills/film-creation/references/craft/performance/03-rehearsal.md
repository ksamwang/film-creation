# 排练：从初次印象到定分

## 核心判断

排练要完成两个方向相反的任务：先把演员从观众席拉到台上，再把台上找到的东西固定下来。哈根给出的顺序是“先读一遍，然后一读再读”，但她同时警告：初次读剧本时的认同属于观众，不属于角色。两件事混在一起，演员交出的会是“一个关于角色的看法”，而不是这个角色。

## 书里的方法

先从初次接触说起。哈根说，演员初读剧本时仍是观众，会跟着剧中人笑和哭，这很正常；危险的是把这种认同当成研究。她自己的经验是，保留初次印象去引领角色，必定陷入困境。所以要先把演员退到台下，再让他到台上运作。具体动作是：读一遍，再读一遍；问编剧到底想表达什么，用一句生动的话说出来；然后检查这出戏到底需要什么。

接着是主题归谁。她用《欲望号街车》示范两种主题：对仁慈的渴望，白兰芝是受害者、斯坦利是敌手；或对踏实生活的追求，白兰芝是入侵者。两种解释导出完全不同的角色关系。哈根的处理很明确：演员参与判断，协助导演执行主题，但最后决定的是导演，或导演与演员的协议。

比例。她给了一个可操作的比例：检视一出戏时，客观性只占百分之十，其余百分之九十是主观的。不是不要分析，而是所有认知都要转成能激发想象的材料，不是剧情报告。她的笔记因此高度私人化，别人看了也不知道在说什么。

研究要落回身体。哈根的问答游戏要一直做到问不出新问题：我为什么总嚼口香糖，为什么反感香烟，为什么每进一个房间就熏香。答案不必“正确”，只要她相信、随时能用。阿德勒把同类工作压进练习：带来一件自然之物，要能分辨花心与叶缘的黄色差多少；带来一种颜色，要交代它在什么灯罩上、什么桌面上、什么年代、什么阶层。做不好就重做——只有经历失败才能达到一定的高度，尺寸感是摔出来的。

最后是定分。哈根专设即兴排演一章，允许排练用即兴发现材料；但她把话说死：不管排练过程里用到多少即兴，最后的工作仍然是把所有举动果决化。定分不是把动作冻住，而是把动作固定到“即使情绪不来也能完成”的程度。

## 可执行规则

1. 初读只读不演：第一遍不做笔记、不设计、不落泪。
2. 第二遍做事实清单：人物、关系、事件、时间；不做形容词清单。
3. 主题写成一两句人话，交给导演确认；确认前不据此设计行动。
4. 角色研究用问答游戏，写给自己；不写成给导演看的报告。
5. 每次即兴后 24 小时内定分，过期作废。
6. 定分写成动作序列：开始做什么、中间改变什么、结束停在什么。
7. 联排后只改尺寸与节奏，不再改结构；结构问题退回排练前解决。
8. 记录每次失败的具体原因，不记录“感觉不对”。

## 检查清单

- [ ] 演员是否还带着初读时的印象在演？
- [ ] 这出戏的主题能否用一句人话说清，并且导演同意？
- [ ] 角色的过去是否只保留了对现在起作用的部分？
- [ ] 即兴里有效的部分是否已经定分？
- [ ] 情绪不来时，演员还能不能完成这条动作线？
- [ ] 联排后改的是尺寸，还是又在改结构？

## 与风格层接口

排练的产物是一张得分表，它应该能直接进分镜：每个动作的起止就是剪辑点，每次尺寸变化对应景别变化。给 AI 提示时，定分后的动作序列比情绪描述稳定得多，可以逐条生成再剪。排练也影响拍摄成本：定分越早，越能按场景集中拍摄；定分越晚，越依赖演员档期。这一点与制作模块接口。

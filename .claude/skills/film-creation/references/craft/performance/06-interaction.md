# 互动与强度：人物彼此改变，情绪按档位外放

## 核心判断

人物呆板，多半不是动作写少了，而是每个人只对着镜头做自己的事：说话的人说完，听的人不动，谁也没被谁改变。一场戏是两个人的谈判。镜头里的每个动作都要由对方的上一个动作触发，并在对方身上留下可见的结果。强度另算：克制不是默认值，按类型和场次选档位；该爆发的地方压平了，和该压的地方演过了，是同一种错误。

## 书里的原则

胡克斯在《Acting for Animators》里说：一场戏就是一场谈判，找不到谈判的戏要重写；思考导向结论，情绪导向行动；人物一直执行同一个行动，直到发生了什么事迫使他换一个。韦斯顿在《Directing Actors》里，把「生气一点」换成指向对手的及物动词：惩罚他、求她、稳住他。迈斯纳训练的核心是倾听与反应：表演就是对此刻对方的反应，不是执行预先想好的情绪。约翰斯通在《Impro》里用地位来写关系：地位高的人静，看人看得慢，不怕冷场；地位低的人小动作多，察言观色，急着把沉默填满。

## AIGC 执行

- **每场先写谈判**：A 要什么，B 要什么，谁让步，靠什么让步。写不出来，就回剧本场表补「办法 → 被什么挡住」。
- **动作 → 反应 → 新动作**：每句台词、每个动作后面，写出对方被改变的样子（停手、后退、松口、抓住）。反应比触发晚半拍。镜头里每个人都有指令，哪怕是「不动，只看着她」。
- **动词指向对手**：写「哀求鬼吏让路：抓住铁链，膝盖往前跪」，不写「很着急」。
- **地位写成身体**：高地位是静止、慢视线、重心稳；低地位是手上找事做、看对方的脸、身体前倾。地位在这一场里交换了，就是转折。
- **强度三档**：克制 / 写实 / 戏剧化，按类型给默认值，按场切换。传奇、古装、聊斋、短剧的重逢和诀别用戏剧化：可以喊名字、哭出声、扑上去，但要用重心、呼吸和接触托住重量。档位写进剧本场表，并传到提示词的 ACTING 段，写法见 `video-prompt/acting.md` §2。

## 检查清单

- [ ] 每场写得出谈判的双方和输赢吗？
- [ ] 每句台词后面，听的人有可见的反应吗？
- [ ] 每一镜里的每个人都有指令吗？
- [ ] 这一场的强度档位，是按类型和场次选的吗？

## 常见错误

- 各演各的：两个人轮流对镜头说话。修法：写出触发和反应，把听者写进同一条 prompt。
- 全片一律克制：重逢不喊、诀别不哭，看起来像默剧。修法：峰值场改用戏剧化档。
- 反应卡在节拍上：一说完就变脸，显得假。修法：晚半拍，先停住再变。

## 与风格层接口

档位决定景别和镜头长度：戏剧化的峰值给近景，并把镜头留够让反应落地；克制档靠中景和沉默。地位决定构图高低和谁占画面中心。

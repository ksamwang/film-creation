# 沉默：言语的中断与空无

## 核心判断

电影里几乎没有真正的静音；观众听到的“沉默”是撤走某一层之后剩下的空间。沉默不是把轨道拉到零，而是在声音流里凿一个洞，并且让观众知道这个洞是被人为留下的。

## 书里的方法

**沉默是分离，不是缺席。** 书里把无声当作声音剪辑的一种标点：它从前后的声音关系里获得意义。没有前景声、没有音乐，但还有房间底噪，观众才相信这是“安静”，而不是设备坏了。

**无声源不等于沉默。** 书里把看不见声源的声音单独讨论：它仍然是声音，只是没有可见来源。把无声源声音误当沉默，会让画外空间塌掉；真正的沉默要靠前后的声音关系来定义，而不是靠声源是否可见。

**言语的中断。** 书里分析恐怖声音时提出：某些声音之所以吓人，是因为它们打断了言语流，在说话中间形成一个空洞。被压碎的身体、被灌油的喉咙，声音本身未必可辨，但它把“还在说话的人”变成了“不能再说话的东西”。这是沉默最具体的用法：不是没有声音，是言语不能再继续。

**非情感共鸣。** 另一种沉默不是安静，而是世界不理会。人物死了，淋浴还在响，风扇还在转；声音继续，情绪反而更重。书里叫非情感共鸣。它比静音更冷，因为世界没有为这件事停下来。

**简化聆听与空无。** 当声音被减到只剩一个点，观众会开始听它的质地；书里说多声道扩大了“空无”的可能，并以黑泽明的《梦》为例：声音世界可以减到只剩雨声，或一个正在消失的回声。沉默不是空，是把注意力逼到一个声源上。

## 可执行规则

1. 永远不要从满混直接切到零；保留底噪和至少一个远声源。
2. 按顺序撤层：先撤言语或前景，再撤音乐，最后只留底噪；每一步给一个动机。
3. 沉默前后各放一个声音事件；后一个声音证明前一个沉默是选择，不是故障。
4. 先定沉默类型：声学沉默、戏剧沉默、结构沉默；一场只选一种。
5. 人物停口时，保留对方的呼吸和房间；洞在言语里，不在世界里。
6. 暴力之后先让一个无关声音继续（风扇、淋浴、机器），再考虑静音。
7. 减到单点时，选内部有变化的声音（雨、虫、回声）；稳定长音会变成死声。
8. 沉默只放在言语失效的位置，不放在情绪最高点；最高点需要声音，不需要空白。

## 检查清单

- [ ] 沉默之前撤走了哪一层？观众知道吗？
- [ ] 轨道是真零，还是保留了底噪？
- [ ] 沉默前后有声音事件吗？
- [ ] 这场是哪一种沉默？有没有混用？
- [ ] 人物停口时，世界还在吗？
- [ ] 有没有一个无关声音在暴力后继续？
- [ ] 单点声音有内部变化吗？
- [ ] 沉默是否被用来代替表演或调度？

## 与风格层接口

沉默在分镜上不是一个空镜头，而是一个“声音撤退点”：先标撤哪层、持续几秒、由什么声音结束。表演上，沉默段必须给演员一个可见的动作或呼吸，否则观众会以为漏音。AI 视频提示无法可靠生成静音，所以把沉默写成画面条件：`no music, room tone, held shot, character stops speaking`；同时避免写“戏剧性静音”这类模型无法执行的词。

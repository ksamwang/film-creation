# 表演 token 与迭代

## 核心判断

生成一条人物镜头，第一次出图相当于初读剧本：它是观众的第一印象，不是最终方案。迭代的任务是把“差点意思”翻译成某一个具体 token 的偏差，再一条一条改。改的不是整段提示词，也不是情绪词，而是视线、呼吸、手、重心、距离这五项里的一个值。

## 书里的原则

哈根在《尊重表演艺术》第 21 章《初次接触一出戏》提出初次印象属于观众、不属于角色：第一版生成也一样，它是对人物的第一印象，不是最终设计，不能拿来定稿。第 9 章《即兴排演》允许用即兴发现材料，但最后要把所有举动果决化；第 28 章把这一收束固定下来——对应到生成，就是先广泛试探，再把有效 token 锁定成可复用的得分。她给的比例是客观一成、主观九成，但主观认知必须转成能激发想象的材料，不是给外人看的报告：迭代笔记写 token 差分，不写观后感。

阿德勒在《表演的艺术》第 2 课用练习—呈现—重做校准尺寸感：分辨花心与叶缘黄色的明暗差，做不好就重做。对生成而言，这就是一次只改一个变量、从失败里校准 token 的循环。

## AIGC 执行

先把表演拆成五元组，每个 token 只写可观察值（字段表；模式 B 可直接当 token 块）：

```text
GAZE: target | direction | duration | blink
BREATH: shallow | held | exhale | visible shoulders
HAND: contact object | grip | still or moving
WEIGHT: front foot | back foot | lean | off-balance
DISTANCE: to partner | to prop | to exit | approach or retreat
```

模式 A 把五项连成句子：`Her eyes stay on his face without blinking; she holds her breath; her right hand grips the chair back; her weight is on the front foot, half a step closer.`

迭代按四步走。第一步探索：用三到五条不同 take 试探情境与动作，不动风格；这一步只回答“哪种动作成立”。第二步命名：对比目标，指出是哪一项 token 不对，例如“视线没有落到对方脸上”“重心还在后脚”。第三步单变量：一条只改这一项，其余逐字不动；一轮最多改两项，否则无法归因。第四步定分：当某条读起来对了，把它冻结成 token 得分表——每镜记录起止的 gaze/breath/hand/weight/distance，后续镜头照此批量生成。

定分的标准是果决：每个值都明确，不写“稍微”“有点”“略微”。情绪不来时仍能执行，才算定分。每条镜头最多三轮；三轮仍不对，说明问题在情境或动作，不在 token，回到 `01` 或 `02` 改条件。

迭代笔记只给自己看，写成“GAZE 从画外左侧改为 C2 眼睛，BREATH 由浅改为屏住”，不写“感觉不对”。失败记录同一格式：哪个 token、往哪个方向偏、下一次改什么。

## 检查清单

- [ ] 我能否说出这条差在哪一个 token？
- [ ] 这一轮是否只改了一个变量？
- [ ] 改的是 token 值，还是又重写了一遍整段提示词？
- [ ] 视线是否有明确目标与方向？
- [ ] 呼吸是否有可见载体（胸、肩、停顿）？
- [ ] 手是否接触到一个具体对象？
- [ ] 重心与距离是否与动作目的一致？
- [ ] 定分后的 token 是否逐字复用？

## 常见错误

- 用“更悲伤”“更有张力”重跑 → 每次随机漂移，无法积累；改成单一 token 差分。
- 第一张就定稿 → 把观众印象当角色；先探索三到五条再收。
- 一次改五个词 → 出图变好也不知道为什么；无法复制到下一镜。
- 定分后每镜重新描述 → 人物状态前后断裂；得分表逐字复用。
- 把迭代笔记写进正向 prompt → 模型读到互相冲突的指令；笔记留在内部，prompt 只留最终值。

## 与风格层接口

token 得分表是分镜与视频提示之间的桥：分镜给景别与动作，得分表给这个景别下的视线、呼吸、手、重心、距离，视频提示只写这些值随时间的变化。风格层的导演/摄影 token 锁光色与镜头，不参与表演迭代；两者分开改，才能判断是表演没到还是画面不对。批量生成时先锁定风格 token，再逐镜套得分，避免每条都重新调风格。

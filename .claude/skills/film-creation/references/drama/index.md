# 竖屏短剧

从一个创意到一集可发布的竖屏短剧：立项 → 大纲 → 剧本 → 拆解 → 造型图 → 分镜 → 片段生成 → 成片。

每个阶段的产物格式由 `standard.md` 规定；本目录其余文件讲**怎么写好**。一次只读当前阶段需要的 1–2 篇。

## 按阶段读

| 阶段 | 用户在说 | 先读 | 产物（见 `standard.md`） |
|---|---|---|---|
| 立项 | 「我想做个短剧」「这个题材行不行」「出海做什么」 | `01-premise.md`（出海再读 `09-overseas.md`） | P1 setting |
| 大纲 | 「排 60 集」「付费点放哪」「分集大纲」 | `02-season.md` | P2 outline |
| 剧本 | 「写第 3 集」「开头不够抓人」「台词太水」 | `03-episode.md` + `04-script.md` | P3 script |
| 拆解 | 「拆角色和场景」「她后来换了身份要不要新形象」 | `05-breakdown.md` | P4 breakdown |
| 造型图 | 「出角色图」「三视图」「场景图」 | `05-breakdown.md` + `templates/character-sheet.md` | P5 look image |
| 分镜 | 「把这集切成片段」「分镜」 | `06-storyboard.md` | P6 storyboard |
| 片段提示词 | 「这段提示词怎么写」「口型对不上」「人站错了」 | `07-segment-prompt.md` | P7 compiled prompt |
| 成片 / 质检 | 「配乐字幕」「怎么剪」「这段能不能用」 | `08-cut-qc.md` | P8 cut |
| 落表 / 对接平台 | 「字段是什么」「输出 JSON」 | `standard.md` | 全部 |

模板：`templates/drama-bible.md`（立项）、`templates/drama-outline.md`、`templates/drama-episode.md`、`templates/drama-breakdown.md`、`templates/drama-storyboard.md`。

## 默认值（用户没说就用）

- 竖屏 9:16；标准档每集 60–120 秒；全剧 60 集；每段 15 秒。
- 每集场景 ≤2（长档 ≤3），出场有名角色 ≤4。
- 台词语言跟目标市场；说明文字跟用户的语言。

## 本目录与通用规则的关系

短剧面向的是**多参考图、原生出声、多镜头一次生成**的视频模型（Seedance 2.x、MiniMax H3、Wan 3.x、Kling 等），属于 `aigc/prompt-syntax.md` 的模式 A。在通用规则之上，短剧再收紧几条，冲突时**以本目录为准**：

| 通用规则 | 短剧里 |
|---|---|
| 资产按人物 / 场景 / 道具建卡 | 只建角色造型和子场景，**不建道具**；造型名固定为「名字 · 标签」，提示词里写 `@[造型名]` |
| 提示词由人按镜头写 | 片段提示词由分镜**机械编译**，问题回分镜改 |
| negative 有参数才写 | 不写；「无背景音乐」「无文字字幕」两条固定约束由编译器加 |
| 声音按层分工 | 台词由模型直接说出；配乐、字幕在成片阶段统一加 |
| 多镜头按需拆 | 同一子场景塞满时长上限，相邻同场景片段必须合并 |

不变的：画幅、模型、分辨率不写进提示词；每条建议都落到可生成的产物。

## 工作原则

1. **先算账再写**：片段 = 一次生成，成本 = 秒数 × 重试次数。场景、角色、打戏、群戏在剧本阶段就控制。
2. **剧本为生成服务**：动作写成看得见的样子，内心戏落到动作和台词上，OS 少用。
3. **上游改了，下游跟着标「待同步」**：不自动重算，由用户决定重拆、重分镜或重拍。
4. **实测数字是起点**：文中的语速、动作容量、延迟来自具体模型的实测，换模型要重测，以实际出片为准。
5. 来源见 `sources.md`。

# 目标、障碍、行动

## 核心判断

表演的最小单位不是情绪，是一个人为得到某样东西而对另一个人做的动作。导演无法命令情绪，但可以设定目标、放置障碍、指定行动；这三样确定之后，情绪会自己出现，而且每次出现得不一样——这正是剪辑需要的材料。

## 书里的方法

哈根的基本目标训练把一场戏拆成层级。演员先定主要目标，再定眼前的目标，然后列出障碍，最后才是行动。她那个回家的例子里，主要目标是准备朗读剧本前的功课，眼前目标是穿上纱袍和拖鞋、倒咖啡、拿出剧本、挑面试衣服；障碍是十点就要面试、宿醉头疼、剧本印得不清楚、对面楼里的偷窥者不肯走开；行动是跳下床、猛拉窗帘、让闹钟面壁、倒掉烟灰缸、找阿司匹林。这些行动全部及物、全部落在身体和物件上，没有一条是“感到委屈”。

目标与行动要分开：目标是他想拿到的东西，行动是他为拿到它做的事。目标可以整场不变，行动必须一条一条具体化。哈根把最后固定下来的行动序列叫作“得分”，并给出一句关键判据——举动的果决化是从特殊化发展出来的。她还说，技艺高低就看演员能不能在固定的模型里保住第一次的自然感。即兴负责发现，定分负责可重复。

阿德勒从另一端进入：第三课的标题就是“表演就是去做”。她讲演员学握长矛：重要的不是姿势，而是搞清为什么要握——为仪式还是为战争；不理解内在理由，动作只是造型。她因此要求演员建立动作的词汇表，给每个动作找到瞬间及内在的理由。她还要求把动作复杂化，并且赋予动作尺寸：同一个动作在舞台上和在特写里不是同一个大小。

两本书在这里合流：哈根给结构，阿德勒给质地（理由、词汇、尺寸）。结构保证有冲突，质地保证冲突不是喊出来的。

## 可执行规则

1. 每场戏为每个角色写一个及物动词短语：对谁做什么。写不出来，先改剧本。
2. 一场戏只保留一个主要目标；第二个目标降为障碍或手段。
3. 障碍必须是人或具体事，不能是无法对抗的“命运”“时代”。
4. 行动要能被摄影机看见：手、脚、视线、距离、物件。落不到身体上的，不是行动。
5. 每个行动追问一次“为什么是现在做”，答不出说明缺内在理由。
6. 即兴只负责发现；开拍前把有效部分定成得分：明确的开始、过程、结束。
7. 尺寸按景别给：全景给身体幅度，中景给手势，特写给视线与呼吸。
8. 演员说“我演不出来”时，不要加情绪，改他的目标，或者换一个障碍。

## 检查清单

- [ ] 这场戏每个人的目标能用一个及物动词说出来吗？
- [ ] 两个目标是否直接冲突？
- [ ] 障碍是具体的吗？它此刻正在起作用吗？
- [ ] 每个动作的内在理由说得清吗？
- [ ] 这场戏的得分能不能写下来，交给另一个演员复现？
- [ ] 这一条的尺寸和景别匹配吗？

## 与风格层接口

给演员的指令必须是及物动词，这直接决定提示词怎么写。AI 视频提示不要写“愤怒地表演”，要写动作与对象：“她把杯子推到桌子对面，手指仍按在杯沿上，看着男人的眼睛。”动作尺寸要与景别绑定：特写写呼吸与视线，全景写位移与手势。剪辑上，得分给出可切的落点——动作完成处，而不是台词结束处。与调度模块的分界是：调度给行动的位置与路线，表演给行动的理由与强度。

# 风险：在开拍前把不可控变成条款

## 核心判断

制作风险不是"现场会不会出事"的运气问题，而是"哪些东西一旦出事，钱和时间都补不回来"。风险控制集中在三处：权利链、剧本可行性、对外承诺。它们的共同点是必须在开拍前变成书面条款，而不是留到后期补救。

## 书里的方法

第一是权利链。策划流程的第一项就是"对原创或改编作品的所有权"，并且明确：不要在取得版权之前就开始剧本创作。需要逐项确认的是：独家还是非独家；版权期限多长；权利人是否真的是权利人；要哪些版权类别（影院、国内电视、有线、国际电视、VOD、DVD、互联网、电影节、手机）；是否需要全球版权；是否涉及真人故事改编权；以及协议里有没有"未来科技载体版权"条款。电影节版权通常不贵，但如果片子成功后要卖电视或网络版权，得回头重谈，价格可能高到让整单交易做不下去，所以最好在拿电影节版权时就把后续价格写进合同。所有这些都应在律师协助下完成。

第二是剧本可行性。短片书里用一组问题把风险提前：真的能做到吗？哪些内容能调整以便在预算和资源内把片子拍出来？我是导演的最佳人选吗？书中的例子是剧本写"燃烧的人"，但除非认识免费做特效的人，否则根本拍不了。这里的原则不是降低野心，而是把每个昂贵元素换成可执行的拍法，或者删掉。

第三是对外承诺。创投文案里有固定的"风险揭示"页：承认这类投资可能损失全部本金，说明材料保密、权益未注册、不是出售要约。这不是形式主义，它把最坏情况先说出来，避免后面用谎言补。电影节环节也有承诺风险：早点提交费用更低，但要确保影片对口、格式符合；想保留首映，要等邀请回复再答应。书里还提到延期支付和股份：用低于通常薪资的条件请到关键人员，能压低前期成本，但会形成后期义务，必须在预算和协议里写清金额、期限和分配顺序。

## 可执行规则

1. 列出所有"不是自己的"素材：故事、剧本、音乐、品牌、地点、人脸、档案影像。
2. 每一项写清：权利人、期限、地域、媒介、费用、书面凭证。
3. 拿不到授权的，改剧本，不留到后期。
4. 最贵、最危险的三场戏各写一个降级拍法，并注明触发条件。
5. 儿童、动物、特技、武器、火、车辆，先确认许可、保险和现场负责人。
6. 电影节材料早于截止日提交，确认影片对口、格式符合，保留副本。
7. 任何延期支付、分成、免费资源，都写金额、期限、条件、违约处理。
8. 承诺独家、首映、交付日期之前，先确认日程和预算能兑现。

## 检查清单

- [ ] 这个故事的原作权利在谁手里？期限和地域够用吗？
- [ ] 音乐、品牌、地点、档案素材的授权在哪一步？
- [ ] 有没有"拍不了"的元素还留在剧本里？
- [ ] 最危险的三场戏，降级方案是什么？
- [ ] 保险覆盖哪些？E&O 列进办公室支出了吗？
- [ ] 延期支付和分成写进协议了吗？总额是多少？
- [ ] 电影节的截止日、格式、材料清单核对了吗？
- [ ] 对外承诺的首映、独家、交付日期，日程支持吗？

## 与风格层接口

风险清单会反向限制风格承诺。不能承诺航拍、大火、人群、特殊场地，除非许可、保险和专人已经到位；不能承诺长镜头调度，除非场地和拍摄天数允许。发行和电影节版本也会反过来约束创作：时长、字幕、音乐授权、画幅和声音格式，都是交付条件，必须在剪辑和混音前知道。AI 流程同样有权利风险：训练素材、参考图、品牌元素、真人肖像，都要在生成前确认可用范围；把"可生成／需授权／必须实拍"标在分镜上，比事后删除便宜。

# 分镜查阅层：分镜脚本

## 这一层做什么

剧本告诉你**发生什么**，分镜脚本告诉你**观众怎么看到它**：一场戏切成几个镜头、每个镜头拍什么、按什么顺序、台词落在谁脸上、每镜几秒、用什么方式生成。它是导演对剧本最详细的一次拆解，也是后面所有生成工作的施工图。

`craft/staging/06-scene-analysis.md` 是**判断层**（三遍拆析、问答模式、备选）；这一层是**查阅层**，把判断变成一张能交给生成的表。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `breakdown.md` | 拆解七步：读戏 → 定镜头数 → 定每镜拍什么 → 排顺序 → 分配台词与声音 → 定时长 → 评估生成；含镜头数估算表、分镜脚本格式、审读清单 | 拿到一场戏要拆镜头；用户问「这段要几个镜头」 |
| `shot-functions.md` | 镜头功能词典：建立、反应、插入、视线对象、切出、揭示、呼吸镜等，每种写什么时候要、一场放几个、剧本里常不常缺、怎么生成 | 拆镜时决定「这一镜是干什么的」；检查有没有漏镜 |
| `three-ways.md` | 同一场戏的三种拆法：经典覆盖、长镜头、碎切，对比镜头数、观众感受、生成代价 | 定一场戏或全片的拆镜风格 |
| `scene-types.md` | 三类场景的拆解示例：雨夜车内对话、小巷追逐、无台词情绪戏，含对比 | 拆对话、动作或情绪戏，想看一个具体的拆法 |
| `example.md` | 完整示例：一部 4 场短片的全片分镜脚本（31 镜），含读戏卡、镜头数估算、逐镜理由、预算紧时的删减顺序、按批次重排的生成清单 | 想看全流程；配合 `templates/storyboard-script.md` |
| `sources.md` | 出处 | 需要核对出处时 |

一次只读一篇，不整层加载。

## 几个容易混的产物

| 产物 | 排列方式 | 回答什么 | 本包位置 |
|---|---|---|---|
| 剧本 | 按故事顺序 | 发生什么、谁说什么 | `writing/`、`templates/script.md` |
| scene card | 一场一张 | 这场戏的 beat、轴线、空间事件 | `craft/staging/06-scene-analysis.md`、`templates/scene-card.md` |
| **分镜脚本** | **按剪辑顺序，一镜一行** | 每镜的功能、景别、角度、运镜、画面、台词、时长、生成方式 | 本层 |
| 分镜图（故事板） | 按剪辑顺序，一镜一格 | 每镜的构图长什么样 | 关键帧，见 `references/aigc/workflow.md` |
| 生成清单 | **按场景 / 资产分组** | 先生成哪些、用哪些参考图、每镜几次迭代 | `templates/shot-list.md` |
| 竖屏短剧分镜 | 按片段，JSON | 片段切分、`size` / `angle` / `move` 枚举 | `references/drama/06-storyboard.md`（短剧以它为准） |

分镜脚本按**剪辑顺序**写，因为它服务观众；生成清单按**场景和资产**重排，因为它服务生成（同一场景、同一组参考图的镜头放在一起出，一致性最好）。两者是同一批镜头的两种排列，镜号不变。

## 五条总规则

1. **每个镜头回答一个问题。** 观众在这一刻想知道什么（在哪？谁来了？他看到了什么？她会怎么反应？），这一镜就回答它。说不出这一镜回答什么问题，就删（《电影镜头设计》7.3 问答模式）。
2. **剧本没写的，分镜要补。** 剧本只写戏，分镜要补上空间交代、视线对象、反应、插入、过渡。缺了这些，镜头之间接不上（`shot-functions.md`）。
3. **镜头数由戏决定，再被预算修正。** 先按戏剧需要估，再按生成预算删；不要反过来先定「每场 8 镜」。
4. **反应比台词更有戏。** 一句重要的台词，经常应该落在听的人脸上。
5. **在 AIGC 里，成本按镜头数算，不按秒算。** 一个 1.5 秒的镜头也要一次完整生成（多数视频模型一次出 4–10 秒）。碎切很贵，长镜头风险高，`three-ways.md` 有对比。

## 和其他文件的关系

- 场景类型的现成序列（对话、追逐、打斗、悬疑……）：`camera/recipes/`。分镜脚本拆到一场戏时，先看有没有对应配方作起点。
- 每镜的景别、角度、运镜、光、构图怎么写：`camera/lexicon-*.md`；按效果反查：`camera/intent.md`。
- 生成方式（参考图生、首帧、首尾帧、续接）：`references/aigc/workflow.md`。
- 台词时长估算与一镜一个说话人：`references/drama/04-script.md` §3。
- 剧本上游：`writing/`；剧本到分镜的交接示例：`writing/example.md` §7。

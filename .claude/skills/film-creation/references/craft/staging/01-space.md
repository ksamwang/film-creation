# 空间：场景空间与动作的戏剧性范围

## 核心判断

一场戏的空间不是景的大小，而是动作实际发生、观众需要记住的那一块。先划定这块空间，再决定摄影机站在里面还是外面；否则再大的景也只是背景。

## 书里的方法

**场景空间**：把整场戏落到一张地面图上，只圈出本场真正启用的区域——人物从哪进门、停在哪、绕过什么、从哪离开。没有被走到的空间不参与调度，只作为气氛。圈定的范围就是本场的场景空间。

**动作的戏剧性范围**：书中把镜头要呈现的那部分动作所占的空间称为动作的戏剧性范围。摄影机可以放在范围之中，成为参与者；也可以放在范围之外，成为旁观者。前一种让观众和人物共享空间，后一种让观众看见人物被空间困住。同一个场景，两种放法产生不同的立场，必须在开拍前选定。

**受限空间**（车厢、电梯、走廊、审讯室）：边界由墙和家具给出，调度资源是纵深、前后景、人物在轴线上的小位移，以及摄影机在角落里的摇与俯仰。空间越窄，越不能靠人物大幅走动，要把变化压到距离和朝向上。

**开阔空间**（街道、田野、大厅、广场）：没有天然边界，必须用走位、道具、光线或人群临时划出表演区。否则人物一散，观众就失去“该看哪里”。书中把这类场景的处理重点放在重新建立边界，而不是展示辽阔。

**视点与戏剧性重点**：同一空间里，谁在前景、谁被遮挡、摄影机高一点还是低一点，会改变观众站在谁一边。空间位置本身就是态度，不需要额外加台词解释。

## 可执行规则

1. 每场先画地面图，标出所有入口、固定障碍和人物必经点，再圈出本场实际使用的区域。
2. 用一句话写出本场的空间事件：谁从哪到哪，改变了什么位置关系。
3. 先决定摄影机在动作范围之内还是之外，再选景别；两者混着改，空间会失去立场。
4. 受限空间只保留一个主要机位方向，其余变化用景别、前后景和摇镜完成。
5. 开阔空间先设三个地标或一条动线，把表演区收在可记忆的范围内。
6. 每换一次机位，检查观众是否仍知道入口在哪、人物和出口的关系是否清楚。
7. 不用大全景代替空间交代；大全景只交代环境，不交代关系。

## 检查清单

- [ ] 本场的场景空间能否在地面图上圈出？
- [ ] 空间事件能否用位置变化说清？
- [ ] 摄影机在动作范围之内还是之外，是否明确？
- [ ] 受限空间是否把变化压进了纵深和朝向？
- [ ] 开阔空间是否建立了可记忆的边界？
- [ ] 前景、中景、后景是否各自承担信息？
- [ ] 观众是否始终知道入口、人物和出口的相对位置？

## 与风格层接口

把地面图交给摄影和美术：机位高度、可用墙面、光源位置都由空间边界决定。写提示词时，先写“空间类型 + 摄影机在范围内/外 + 谁在前景”，再写景别与光线；空间关系不清，风格词只会堆在画面上。

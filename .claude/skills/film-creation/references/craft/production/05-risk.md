# 交付与导出：把不可控变成交付规格

## 核心判断

交付风险不是"导出时会不会出错"的运气问题，而是"哪些东西一旦出错，时间和版本都补不回来"。风险控制集中在三处：素材权利链、生成可行性、对外交付承诺。它们的共同点是必须在生成前变成书面规格，而不是留到导出时补救。

## 书里的原则

**第一是权利链。** 第一章的策划流程第一项就是"对原创或改编作品的所有权"，并明确不要在取得版权之前开始创作。需要逐项确认：独家或非独家、期限、权利人是否真实、版权类别、全球版权、真人故事改编权、未来科技载体版权条款。AIGC 版扩到所有生成素材：原创、授权、公共领域；真人肖像与真人故事；品牌、商标、字体、音乐；参考图与训练素材；模型与工具许可；输出用于电影节、商业或社交的权限。

**第二是剧本可行性。** 第九章用"真的能做到吗"和"哪些内容能调整"提前排雷，例子是"燃烧的人"最终靠家用电脑做火焰解决。AIGC 里，每个镜头先标状态：可生成、需分层合成、需外部素材、必须替换。生成不了的不留到剪辑。

**第三是对外承诺。** 第一章的风险揭示页先承认最坏情况：可能损失全部投资、材料保密、权益未注册、不是出售要约。第十九章讲电影节提交：早交费用更低、确保影片对口、格式符合、想保留首映要等邀请回复再答应。AIGC 版把它改成"交付说明"：已知限制、版本号、时长、画幅、帧率、字幕、声音、首映状态，全部写清。

## AIGC 执行

1. 建素材来源表：每项写来源、权利人、许可范围（电影节/商业/社交）、期限、署名要求、凭证。没有来源的不用。
2. 每个镜头标状态：可生成、需合成、需授权、必须替换；不清的不进批量。
3. 敏感元素清单：真人脸与真人故事、品牌标识、可识别建筑、音乐与字体、儿童形象；逐项写授权或替换方案。
4. 最危险的三镜各写降级：剪影、画外、静帧加运动、局部特写、替换环境；写明触发条件，如授权未到或连续失败。
5. 交付规格先定：时长、画幅、帧率、字幕语言与样式、声音响度、片头片尾、文件命名、版本号。生成前锁，不在导出时改。
6. 版本分阶段：v01 粗剪、v02 锁画、v03 锁声音、v04 锁字幕、v05 交付。每次导出留副本和变更说明。
7. 写交付说明：哪些镜头是降级版、哪些素材待授权、哪个版本是首映版。不把未完成说成完成。
8. 提交前核对：截止日、影片是否对口、格式、首映状态、字幕、海报与静帧素材。早交留缓冲。

## 检查清单

- [ ] 每个素材的来源、许可范围、期限、署名都写了吗？
- [ ] 真人肖像、真人故事、品牌、音乐、字体的授权在哪一步？
- [ ] 有没有"生成不了"的镜头还留在清单里？
- [ ] 最危险的三镜，降级方案和触发条件写了吗？
- [ ] 交付时长、画幅、帧率、字幕、声音规格锁了吗？
- [ ] 电影节或平台的截止日、格式、首映状态核对了吗？

## 常见错误

- 先做画面，最后才查素材来源 → 成片里带着不能用的人脸、品牌、音乐 → 生成前建来源表。
- 把"能生成"当"能交付" → 格式、字幕、时长不合要求，返工整条 → 交付规格先锁。
- 所有失败镜头都用同一套补救 → 有些镜头越补越假 → 按镜头写降级，剪影、画外、静帧各有适用处。
- 对外承诺首映或截止日，却没留缓冲 → 版本赶不出来 → 承诺前核对生成与后期余量。

## 与风格层接口

风险清单会反向限制风格承诺。不能承诺航拍、大火、人群、复杂特效，除非资产和合成方案已经就位；不能承诺长镜头运动，除非 motion token 和首尾帧稳定。发行与电影节版本也约束创作：时长、字幕、音乐授权、画幅和声音格式都是交付条件，必须在剪辑和生成前知道。AI 流程的权利风险同样在生成前处理：训练素材、参考图、品牌、真人肖像，标成"可生成、需授权、必须替换"，比事后删便宜。风格层选导演或摄影 token 时，只用公共领域的视觉基元，不复制在世作者或品牌的具体作品。

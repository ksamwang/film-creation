# 对白：人声中心与词语中心

## 核心判断

电影声音以人声为中心，尤其以词语为中心；对白不是剧本里的文字，而是有距离、有方向、会被打断的声音物体。AIGC 里先决定这句话要让观众“听懂”还是“感到”，再决定随视频原生出声还是单独配音，以及后期怎么处理。

## 书里的原则

**人声中心与词语中心。** 书里说电影是词语中心的奇观：人声总被单独拎出来，音乐与音响像伴奏；录音技术也一直优先保证语音清晰，而不是音质保真。这不是自然事实，是电影工业与文化习惯养成的听觉等级。

**文字产生的增值。** 旁白或解说能让你在画面里“看到”本来没有的东西：说画面里有三个人，你就数出三个；说“第四个人呢”，你就开始找那不存在的第四个。书里把这种由语言添加的意义叫文字产生的增值，其效果是文字构成的幻象。旁白不是画面的说明，是画面的另一种导演。

**戏剧言语与文本言语。** 戏剧言语依附于人物和情境，被身体、空间、动作支撑；文本言语更独立、更文学，可以脱离画面，甚至和画面唱反调，旁白多属后者。两种言语混用要有理由，不能一会儿让声音属于人物，一会儿让它属于作者。

**正向人声与背向人声。** 面向听者说话，语义优先；背向、侧向、隔着门说话，存在优先。言语还会被物理声音打断；打断的位置，就是这句话再也说不下去的位置。

## AIGC 执行

1. 每场先写人声功能：告知、隐瞒、咒语、质地；四者都不是的台词删掉。
2. 台词分两级：必须逐字听清的，和只需要感到存在的；两级用不同语音设置与电平，不要全部一样清楚。
3. 旁白先定知识关系：比画面多、比画面少、还是说错；和画面等量的旁白是冗余。旁白声线与角色声线分开生成，音色 token 不复用。
4. 语音提示写年龄感、音色、语速、停顿、呼吸；不写“悲伤地说”。按句生成，留可剪辑的气口。
5. 对白先定媒介：贴耳、房间、电话、墙后；提示写距离、遮挡、混响。同一场不要在同一种媒介里漂移。
6. 视频模型能原生出对白时，台词写进视频提示并注明谁说、什么语气，一镜一个说话人，口型落在最显眼的正脸上；同一角色绑定音色参考。例：`Lin keeps her eyes on the sink and says flatly, "You're late again."` 重叠对白分开生成两条 stem，后期再叠；视频提示注明 `two people talking over each other, partly masked by traffic`。
7. 听不清时，在音乐与环境声的同频段让路，不推高对白；人物该听不清的地方，让观众也一起听不清。
8. 台词停在说不下去的位置，用一个物理声收尾。长句拆短，口型同步最不可靠的往往是长句。

## 检查清单

- [ ] 这场人声的功能一句话说得清吗？
- [ ] 哪些台词必须逐字听清？哪些只需要存在？
- [ ] 旁白和画面是知识差，还是复述？
- [ ] 旁白与角色是两条独立声线吗？
- [ ] 正向或背向人声的选择有理由吗？
- [ ] 对白有距离、房间、遮挡吗？
- [ ] 听不清时是让路还是推音量？
- [ ] 打断的位置是言语的极限吗？

## 常见错误

- 所有台词同一电平、同一清晰度 → 观众分不清主次 → 分两级生成与混音。
- 旁白把画面复述一遍 → 文字增值为零，显得啰嗦 → 让旁白多于、少于或说错画面。
- 用“悲伤、愤怒”当语音提示 → 模型给刻板语调 → 改写语速、停顿、呼吸、音色。
- 长句直接丢给语音模型 → 口型与重音错位 → 拆成短句，按句生成。
- 听不清就推高对白 → 整体变吵，语义仍不清 → 在音乐与环境声同频段让路。

## 与风格层接口

人声功能决定台词是说给对面的人、说给自己，还是说给观众；调度决定正向或背向，景别决定近场声还是房间声。导演档案写“人声规则”：旁白知识关系、允许的听不清比例、是否使用重叠对白、画外人声的处理。语音生成与视频提示要写清谁在对谁说、距离、遮挡和重叠：`two people talking over each other, partly masked by traffic, medium shot`；台词本身要短，因为长句的口型同步最不可靠。失败模式：旁白念出舞台提示、外景里的棚内干声、口型错位；模式 B 进 NEGATIVE，模式 A 写正面的距离、遮挡与说话人。

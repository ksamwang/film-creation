# 规定情境：把角色换成“我”

## 核心判断

演员不能“变成”另一个人，他只能在虚构的环境里用自己相信的具体事实行动。规定情境要做的，就是把这些事实一格一格填满，直到演员不必“演”，只需要应对。它解决演员不知道自己在哪的问题——虚假常从这里开始，也最容易在这里修好。

## 书里的方法

哈根把这项工作拆成一张可填的表。在基本的目标训练里，她要求演员复现生活中两分钟的事，写清六类内容：时间、地点、周围环境、情况（过去、现在、未来）、关系、目标与障碍。她的示范是：七月湿热的一天，演员跑遍经纪人的办公室被拒，穿着薄底凉鞋走肿了脚，爬了三层楼，进屋发现屋子一团糟——此时他的目标只是让自己舒服一点。这些事实决定他先脱鞋还是先开窗。

阿德勒把同一件事推到更细的颗粒度。她引斯坦尼斯拉夫斯基：艺术的真实就是情境的真实，情境统摄一切，证实我身处何处。她要求回答“我身处何处”时不能停在“舞台上”，要能说出周围的建筑、国家的位置、哪一年、什么季节、听众的阶层与衣着、什么树、什么花。情境越具体，演员越松弛；情境笼统，演员只能用力。

她还有一个检验物：一把椅子。演员必须知道它的颜色、背面每一处划痕、哪里掉了漆、弹簧从衬垫哪个位置顶出来、哪条腿不稳；更要知道它要求他笔直坐还是瘫着坐。不了解这些，演员就会被迫作假。她看《贝西·史密斯之死》，从门廊上一件破柳条家具就读出了父亲的处境和制度的崩溃——道具的具体程度就是情境的具体程度。

哈根另给了一条把“她”换成“我”的路径：不要问“她是谁、她生在何地”，要问“我是谁、我在何地何时出生”。她研究《乡下女郎》时，把乔琪的母亲替换成小学同学的母亲，父亲替换成自己的父亲，只把职业从写作换成变魔术。这套操作叫替换，配合“如果我……”使用：能找到相同经验的直接调用，找不到的就用观察和想象补。她强调这是秘密实验，不跟编剧、导演、演出伙伴讨论。

## 可执行规则

1. 开拍前为每个主要角色填全情境表：时间、地点、周围环境、过去、现在、未来、关系、目标与障碍。缺项不排。
2. 时间地点要落到底：年份、季节、街区、楼层。写不出就是没做完。
3. 过去只保留对这场戏起作用的事件，不写完整生平。
4. 每个抽象关系配一件具体物件：坐塌的椅子、没洗的杯子、门廊上的旧家具。
5. 角色小传一律用“我”写，不用“她”写。
6. 演员的替换材料属于私人工作，不进排练记录，导演不追问。
7. 情境一旦确定，拍摄期不再改动；改情境等于换角色。

## 检查清单

- [ ] 演员能说出这场戏发生在哪一年、哪个城市、哪个房间吗？
- [ ] 他上一件事是什么？身上留下痕迹了吗（汗、泥、酒气、没睡）？
- [ ] 这个空间里哪些东西他熟悉，哪些陌生？
- [ ] 他和对手之间有没有一笔未结的账？
- [ ] 演员是在应对环境，还是在等台词？
- [ ] 拿掉台词，这些事实还撑得住两分钟的行为吗？

## 与风格层接口

情境决定美术、道具、光线可以具体到什么程度，也决定摄影机可以站多近。演员对空间越熟，近景越松；环境事实是空的，特写只会放大“他在演”。给 AI 的生图与生视频提示里，情境要写成可观察事实：地点、时间、天气、物件状态、人物身上的痕迹，而不是“忧郁的氛围”。与调度模块的分界是：情境回答“他在什么里”，调度回答“他在哪里动”。

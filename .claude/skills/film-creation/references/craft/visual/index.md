# 视觉语言

## 这个模块解决什么

把剧本里的关系——谁有权力、谁在隐瞒、谁在看谁、这里是什么地方——翻译成观众一眼能读出的画面变量。变量只有六组：景别与镜头关系、画幅内构图、焦距与景深、光、色、影像表面。六个变量不是清单，是一条决策链：先定观众必须知道什么，再选景别；景别定了，构图才有意义；构图定了，再选焦段；光决定暴露与隐藏；色与质感最后统一。前置判断没做，后面全在补救；顺序倒了，画面就会漂亮而空洞。

## 先读哪篇

1. `01-shot-grammar.md` — 景别、主镜头、平行剪辑、三角形原理。先保证一场戏看得懂、剪得顺。
2. `02-composition.md` — 画幅内的位置、留白、角度、纵深。解决“画面里谁重谁轻”。
3. `03-lens.md` — 焦距、景深、变形镜头。把“站多远”变成光学选择。
4. `04-light.md` — 光位、硬软、光比、灯具。解决“看见什么、藏住什么”。
5. `05-color.md` — 色温、色板、色彩关系。解决“这场戏属于哪个世界”。
6. `06-texture.md` — 画幅、介质、颗粒、柔化、后期。解决“影像表面是否一致”。

只问一个镜头怎么拍，读 01 和 02；要写视觉方案，按 01→06 走一遍；要做 AI 提示，读 03、04、05、06 的“与风格层接口”。如果只有十分钟，先读 01 的三角形原理与 05 的色温，它们最容易在片场出错。

## 三条使用原则

- 一个镜头一个视觉主语；一场戏最多让两个变量“说话”，其余服从。
- 先建立空间地图，再切近景；先定暗部，再定补光。
- 每条规则要能对应一个画面变量，不写“要有电影感”。没有出处的判断，删掉。

## 与其他模块

分镜、走位、覆盖读 `craft/staging/`；故事与场景读 `craft/story/`；导演/摄影风格读 `references/directors/` 与 `references/cinematographers/`。本模块只给画面判断，不给导演名字堆砌。

# 成片与质检

> 产物：P8 cut（`standard.md`）。片段里刻意不做的事——配乐、字幕、补录配音——都在这里统一做。
> 一句话：**先逐段验收再剪；剪辑按节拍不按秒数；字幕和配乐全集统一加。**

## 1. 片段验收（生成后、进成片前）

AI 片段的问题大多在**中段**，只看首尾帧不够。逐段看完整视频，按下表打勾；不过的回到对应阶段改。

| 项 | 看什么 | 不过怎么办 |
|---|---|---|
| 身份 | 脸、发型、服装、标记（痣、疤）与造型图一致；没有多出来或复制的人 | 删外貌描述重生成；检查参考图是否带对 |
| 台词 | 逐字说完，没有丢句、赶词、多出的台词 | 加长镜头或拆句（`06-storyboard.md` 第 2 节） |
| 口型 | 嘴动的是说话人 | 改说话人安排（`07-segment-prompt.md` 第 5 节） |
| 音色 | 同一角色跨段是同一个声音 | 绑音色参考重出，或补录配音 |
| 空间 | 门、窗、家具位置跨镜一致；站位不跳侧；没有凭空出现的陈设 | 按镜序拼首尾帧对照；改锚点或场景图 |
| 动作 | 动作完整、接触点读得出；状态只改变一次 | 减少动作数或拆镜 |
| 切点 | 多镜片段的切点数量对、位置大致对 | 记下实际切点，剪辑时按实际处理 |
| 干净 | 无配乐、无字幕、无浮层文字、无水印 | 正面描述想要的效果后重拍 |
| 画风 | 与项目画风一致，没有跑成写实或别的风格 | 声明媒介、挂起始帧 |

**节约原则**：先生成每集第一个片段，用户看过再批量；能用预演（便宜、低分辨率的模型）先看节奏的就先预演。重拍产生新版本，旧版本保留，成片始终用片段的**当前版本**。

## 2. 剪辑

- **顺序与掐头去尾**：片段按分镜顺序排；每段开头常有约 1–2 秒没人动的起势、结尾有定住段，按节拍剪掉。
- **对白镜留够**：模型开口有延迟，剪的时候以「台词说完 + 半拍反应」为准，不按计划秒数硬切。
- **大变化切点放长反应**：句子说完立刻切到景别、站位都变了的下一镜会显得硬，句后反应留长一点。
- **动作方向相反时在动作前切**：模型转身方向不对时，不要在转身中途切到下一镜。
- **只露眉眼的镜头可以句中切**，口型不在画面里就不怕对不上。
- **原声开关**：某段原声有杂音或多余人声时关掉，用配音补。
- 成片比计划长一些很正常（对白延迟累积），验收按节拍，不按总秒数。

## 3. 字幕

- 字幕由分镜台词生成，后期烧录或导出 SRT，**不让视频模型画字**。
- 竖屏字幕放在画面下方约 20% 的区域内，避开平台按钮；单行不超过约 16 个汉字 / 42 个英文字符。
- 剧本里的 `caption`（时间卡、短信内容）在这里作为字卡加入。
- 台词语言与字幕语言可以不同（出海项目常配多语字幕），台词原文不改。

## 4. 配乐与音效

- 全集统一配乐：开场钩子、回合升级、断章各一个情绪点；对白下压低。
- **断章处**：音乐推到最高后戛然而止或切黑，配合「下滑解锁」的停顿。
- 环境底噪各段电平先拉近，再铺统一的环境声，否则片段之间会听出接缝。

## 5. 补录配音

只在两种情况下用：某段没出声或台词错了；同一角色跨段音色不一致且无法重出。配音只能整句对齐口型，比模型自带的同步差，所以**优先重出片段**，配音是兜底。配音用角色绑定的音色，逐句听读音。

## 6. 交付前总检

- [ ] 每段都过了第 1 节验收？
- [ ] 剪辑按节拍，开头 3 秒有冲突、结尾停在钩子上？
- [ ] 字幕与台词一致、在安全区内？
- [ ] 配乐统一，断章处有停顿？
- [ ] 全集人物音色一致？
- [ ] 输出画幅与项目一致（竖屏 9:16）？

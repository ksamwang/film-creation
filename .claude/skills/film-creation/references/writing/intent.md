# 按效果反查：想让观众感到什么 → 叙事机制

用户说「要让人哭」「要爽」「要好笑」「要吓人」时读这篇。每条给：机制（为什么会产生这种感受）、故事层怎么写、镜头怎么配合、别这样做。技巧细节查 `writing/devices.md`，镜头拍法查 `camera/intent.md`。

## 前提：知识关系决定情绪

很多情绪的差别，在于观众和人物谁知道得多（`craft/story/05-narrative.md`；《电影叙事学研究》附录二：观众大于 / 等于 / 小于人物）：

| 知识关系 | 产生的情绪 | 例 |
|---|---|---|
| 观众 **大于** 人物 | 悬念、戏剧反讽、心疼 | 观众知道杯里有药，她不知道 |
| 观众 **等于** 人物 | 好奇、共同发现、紧张 | 和她一起推开那扇门 |
| 观众 **小于** 人物 | 惊奇、反转、谜 | 她早就知道，最后才告诉我们 |

先定一场戏用哪种关系，再选机制。一场戏里中途切换关系，就是一次转折。

## 速查

| 想要 | 核心机制 |
|---|---|
| 悬念 | 先把危险告诉观众，再拖延爆发 |
| 惊奇 / 反转 | 藏住信息，误导，揭晓时意外又必然 |
| 好奇 | 先抛问题，延迟答案 |
| 紧张 | 倒计时 + 阻碍升级 + 退路关闭 |
| 爽 | 先压后扬：痛点 → 信号 → 反派变脸 → 众人改观 |
| 笑 | 预期违背；铺垫—反转；人物一本正经地做荒唐事 |
| 哭 / 感动 | 克制；延迟的认识；小物件承载大感情；不说出口 |
| 恐惧 | 未知大于已知；安静之后的打破；熟悉的东西出错 |
| 温情 | 小动作代替表白；被看见的付出 |
| 心疼 | 不公 + 隐忍：人物受了委屈却不反抗 |
| 震撼 | 尺度对比；代价；沉默 |
| 余韵 | 开放式或闭环结尾；最后一个画面不解释 |

## 悬念
- **机制**：观众知道危险，人物不知道。紧张来自等待（`writing/devices.md` 戏剧反讽）。
- **故事层**：尽早把危险交给观众（炸弹、药、门外的人），然后让人物一步步靠近它；每次回到人物，都离危险更近一步。
- **镜头**：危险的插入镜放在前面；人物镜头越来越长，节奏越来越慢（`camera/recipes/suspense.md` 序列 B）。
- **别这样**：把危险藏到最后才给——那是惊奇，不是悬念。

## 惊奇 / 反转
- **机制**：观众知道的比人物少，或者被误导了；揭晓时，前面所有线索突然有了新意义（`writing/devices.md` 误导、反转）。
- **故事层**：误导线索比真线索更显眼；真线索放在别的事情发生时。揭晓用一个画面或一句话，不用一段解释。
- **镜头**：揭晓后快速重放两三个关键镜头（复用之前的关键帧）；后拉揭示或焦点转移（`camera/intent.md`「揭示 / 反转」）。
- **别这样**：真相没有任何线索——观众觉得被作者骗了。

## 好奇
- **机制**：一个问题被提出，答案被推迟（`writing/devices.md` 延迟揭示）。
- **故事层**：开场先给一个奇怪的结果（一个人浑身湿透地坐在婚礼现场），再回头讲原因；或者让人物说一半（`writing/dialogue.md` §3「只说一半」）。
- **镜头**：先反应、后原因；画面边缘藏一个没有解释的细节。
- **别这样**：同时抛出太多问题——观众一个都不在乎。一次一个主问题。

## 紧张
- **机制**：时间不够、退路越来越少、阻碍越来越强。
- **故事层**：倒计时（`writing/devices.md`）+ 每个 beat 关掉一条退路（`craft/story/03-structure.md` 不归点）。
- **镜头**：镜头越来越短；手持只在失控时用（`camera/recipes/chase.md`）。
- **别这样**：紧张持续太久不释放——观众会麻木。转折之后给停顿（`writing/devices.md` 转折与停顿）。

## 爽
- **机制**：先压后扬。痛点越深，翻身越爽；对手越强，打败他越值钱（`references/drama/01-premise.md` 获得感）。
- **故事层**：压（羞辱至少两拍）→ 亮（一个信号：电话、文件、一个人走进来）→ 转（反派变脸）→ 收（旁观者改观）。打脸对象必须是主要反派。
- **镜头**：角度交换，反派变脸给足 3 秒（`camera/recipes/reversal.md`）。
- **台词**：让步再反扑、底牌后置（`writing/dialogue.md` §2）；金句一场一句。
- **别这样**：没有压就扬；主角翻身后得意地大笑——主角越平静越爽。

## 笑
- **机制**：预期被违背，而且违背得合理。（喜剧手法为行业惯例）
- **故事层**：
  - **铺垫—反转**：建立一个预期，最后一拍打破它。
  - **三次法则**：同一件事发生两次建立模式，第三次打破模式。
  - **一本正经**：人物非常认真地做一件荒唐的事，自己不觉得好笑。
  - **错位**：人物和环境不匹配（黑帮老大在幼儿园家长会）。
  - **回扣**：前面的笑点换情境再出现（`writing/devices.md` 回扣）。
- **镜头**：固定、正面、对称的构图，让观众看清；反应镜比笑点本身更好笑；重音用急推或定格（后期）（`camera/intent.md`「喜剧节拍」）。
- **台词**：笑点放在句子的最后一个词；笑点之后不要解释。
- **别这样**：人物自己在笑；用手持和快速剪辑——观众来不及看清。

## 哭 / 感动
- **机制**：克制比宣泄更催泪。观众替人物哭，前提是人物忍着不哭。
- **故事层**：
  - **延迟的认识**：人物（或观众）很晚才明白一个人为他做了什么——父亲的病历、母亲省下的钱。
  - **小物件**：用一个具体的东西承载感情：一双磨破的鞋、一张没寄出的信（`writing/devices.md` 视觉母题）。
  - **不说出口**：最重要的那句话不说，或者说了对方已经听不到。
  - **迟到**：赶到时已经晚了一步。
- **镜头**：固定、中近景、浅景深；情绪最高点反而拉开距离；音乐晚进（`camera/intent.md`「结局 / 告别」）。
- **台词**：沉默作答、说不下去的那句（`writing/dialogue.md` §1、§5）。
- **别这样**：人物大哭、大段告白、煽情音乐从头铺到尾——观众会抗拒。

## 恐惧
- **机制**：未知比已知可怕；安静比吵闹可怕；熟悉的东西出错最可怕。
- **故事层**：延迟怪物（威胁）的出现，只给痕迹和声音；把恐惧放在日常空间（卧室、浴室、家人的脸）；规则先建立再被打破。
- **镜头**：大面积暗部、背后留白、前景遮挡；惊吓靠剪辑和声音（`camera/recipes/suspense.md` 惊吓）。
- **别这样**：太早给威胁全貌；每隔一分钟一次惊吓——观众会习惯。

## 温情
- **机制**：被看见的付出；小动作代替表白。
- **故事层**：一个人默默为另一个人做一件小事，被对方（或观众）发现：剥好的橘子、留着的灯、伞往对方那边偏。
- **镜头**：插入镜给手和物件；暖色的画内光源（台灯、厨房灯）（`camera/lexicon-light.md`）。
- **别这样**：用台词说「我很感动」「谢谢你一直对我这么好」。

## 心疼
- **机制**：不公 + 隐忍。人物受了委屈却不反抗、不解释，观众替他着急。
- **故事层**：观众知道真相（知识关系：观众大于人物），身边的人误解他，他选择沉默。
- **镜头**：俯拍、画面边缘、大面积留白；不给他特写的眼泪，给背影（`camera/intent.md`「渺小」「孤独」）。
- **别这样**：隐忍过头变成窝囊——观众会从心疼变成不耐烦。短剧里隐忍要有期限，后面必须翻身。

## 震撼
- **机制**：尺度对比（一个人对一座山、一个决定对一万人）；代价的分量。
- **故事层**：让观众看清代价是什么：主角放弃了什么、失去了什么。
- **镜头**：大远景、航拍拉升、声音抽空的沉默（`camera/intent.md`「宏大 / 史诗」）。
- **别这样**：用台词宣布「这是一个伟大的决定」。

## 余韵
- **机制**：故事结束了，问题还留在观众心里。
- **故事层**：开放式结尾或闭环结构（`writing/devices.md`）；最后一个画面不解释。
- **镜头**：最后一镜停得比你以为的久一点；回到开场的机位（`camera/recipes/opening-ending.md`）。
- **别这样**：结尾用旁白或字卡总结主题。

## 组合与节奏

- **一场戏一个主情绪**。悬念和笑可以交替，但不要在同一拍里。
- **情绪要有对比**：笑之后的哭更重，安静之后的惊吓更响，压之后的爽更爽。排 beat 时标出每个 beat 的主情绪，相邻 beat 尽量不同。
- **短剧的情绪密度**：每集至少一个小情绪点（`references/drama/02-season.md`），开场 3 秒内给出第一个情绪钩子（`references/drama/03-episode.md`）。

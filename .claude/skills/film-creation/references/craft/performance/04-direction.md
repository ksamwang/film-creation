# 导演层：只调 token，不发情绪指令

## 核心判断

导演在 AIGC 里能做两件事：设定条件和做剪裁。条件包括情境、动作、景别、token 值；剪裁包括选哪条 take、在哪一帧切。导演不能直接生成“内心”，只能通过可见行为逼近它。提示词里每多一个形容词，模型就多一分自由发挥；每多一个 token 值，画面就多一分可控。

## 书里的原则

哈根在《尊重表演艺术》第 21 章把权责划清：主题的最终决定权在导演层；模型只负责在给定条件下生成外在行为，而这条生成是否成立由人负责。导演层需要把模型带入剧情、做最后剪裁，但不能替它决定每一帧；只告诉模型“该怎么演”，会让它依赖表面提示，只在这一条有效。第 22 章把替换材料划为私密实验，不与合作者讨论——对应到生成，就是私密背景不进 prompt，只留可见后果。

阿德勒在《表演的艺术》第 2 课要求生成层完全理解剧本提出的要求，否则会因无法交流而虚假——模型缺什么条件，就会用通用动作补什么。第 13 课把笔记的内容规定为尺寸与景别的关系，而不是情绪的强弱。第 1 课讲独立性：人可以和模型协作，但不能靠一句“帮帮我”代替条件设定。

## AIGC 执行

把生成拆成三层，改一层时锁住另外两层：

1. 主题与风格层：故事决定这场戏要证明什么，视觉层锁光色、镜头、材质。开生成前拍板，序列中途不改。
2. 表演 token 层：视线、呼吸、手、重心、距离，可逐镜调。
3. 剪辑层：选 take、定切点、排顺序。

一条调整只给一个 token 差分。不写“更脆弱”，写 `GAZE: down-left | held | no blink`；不写“更爱他”，写 `DISTANCE: 20cm closer | hand stops at his sleeve`。一次只改目标、障碍、尺寸、节奏中的一项。

不做整段示范。要参照就只给一个动作或一个节奏点：一只手停住、一次呼吸断开。不要粘贴一段“参考表演”让模型模仿，那会把风格和表演混成一个不可归因的变量。

尺寸写在调整里：先声明这条是特写还是全景，再给 token 幅度。特写不写手臂大幅动作，全景不写眼睑微动。模型不理解“克制”，但理解“手指不动，只有视线移动”。

私密背景不进 prompt。人物的童年、动机解释、导演对他的同情，都不产生可见差异；只写这些事实留下的后果：他进门先看出口、坐下时把椅子往后拖半尺。

## 检查清单

- [ ] 这条调整指向的是可见 token 吗？
- [ ] 我改的是 token 值，还是又加了形容词？
- [ ] 这一轮改了几个变量？
- [ ] 景别与 token 幅度是否匹配？
- [ ] 主题与风格是否在生成前已经锁定？
- [ ] prompt 里是否混入了不可见的背景解释？
- [ ] 我是在选 take，还是在替模型演？

## 常见错误

- 写“再悲伤一点” → 模型给通用哭脸，下一镜无法延续；改成视线、呼吸、嘴角的具体值。
- 同时改光、景别和表演 → 出图变了也归不了因；锁两层，只动一层。
- 把人物小传整段塞进 prompt → 注意力被背景词分走，主体变弱；只留可见后果。
- 用导演或表演流派的名字当指令 → 模型模仿的是风格壳，不是动作；换成动作 token。
- 序列中途改主题 → 前后镜头情绪逻辑断裂；主题在 story/style 层一次定死。

## 与风格层接口

导演档案与摄影档案给的是视觉约束：一个机位、一个光源、一个色彩关系，转成 STYLE/LIGHT/SHOT token。这些 token 不决定人物怎么看、手放哪、重心在哪。写 prompt 时先放表演 token，再放风格 token；风格词过多会挤掉动作。若画面“有风格但人像假的”，先查表演 token 是否为空，而不是继续加风格。

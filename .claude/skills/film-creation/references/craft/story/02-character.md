# 人物：把 want / need / flaw 写成可观察动作

## 核心判断

人物在 AIGC 里有两层：固定 token 保证“一直是同一个人”，动作 token 保证“在压力下做出选择”。只有前者是模特，只有后者每镜变脸；两层都锁，观众才相信他有内在生活。

## 书里的原则

**动态人物：障碍逼出选择，选择揭示内在生活（《剧本结构设计》第 6 章）。** 奥班农引霍华德与马布里：电影不能叙述内心，只能让人物在障碍前作选择。生成时别写“她很矛盾”，写她伸手又收回、把杯子推远、视线避开对方的手；模型能画动作，画不了心理。

**逆向工程（《编剧的策略》第 3 章 3.1）。** 从钩子倒推人物：钩子通常已含主角和对手，每个新人物都立足在已有人物上。对手是主角的硬币正反面——共享议题，答案相反。AIGC 里要写成视觉对照：同构图、反打、冷暖两套光，而不是给对手加更多坏行为。

**功能位（同章 3.1）。** 爱慕对象或密友、解说者、跟班，各有功能。AIGC 的诱惑是“多生成几个人显得丰富”，后果是特征污染与镜头失焦；每个功能位先问：删掉他，哪个镜头不成立？答不出就不建资产。

**扁平人物与无用人物（第 3 章章首）。** 只做情节需要的事、不真实的是扁平人物；生动却不推动故事的是无用人物。生成时前者表现为“动作正确但没有细节”，后者表现为“每镜都在抢注意力”。两者都要改：前者加一个固定小动作，后者删或合并。

**人物声音与基调（《21天搞定电影剧本》第 3 章 3.9）。** 书中认为语气一变，整个故事就变。AIGC 里基调由 TTS 音色、语速、句长锁定；音色一变，同一句台词的意思就变。

## AIGC 执行

1. **C1 固定 token。** 按 `年龄 | 体型 | 脸型 | 眼睛 | 发型 | 肤色 | 服装 | 配饰 | 疤痕 | 姿态 | 表情` 写一条，逐字复用。只保留决定身份的词，别把性格形容词塞进去。
2. **want / need / flaw 各写一个动作。** want 是带宾语的动词句（“把钥匙放进口袋”）；need 是他回避的东西（“不看墙上的照片”）；flaw 是压力下重复的微动作（“先摸左眉的疤”）。三条都进动作 token。
3. **对手做镜像。** C2 与 C1 共享一个视觉特征（同款外套、同种站姿、同焦段），再用相反的光色与构图方向区分。negative 写 `identical twins | same face | matching wardrobe`，防止模型把两人合成一张脸。
4. **功能位变成资产，不是人数。** 密友只需一个反应镜头资产；解说者改成画外音或插入物；跟班只在全景里作为第二身体；没有镜头需求就不建 token。
5. **压力写成 beat。** 每个 beat 拿走一条退路：门被关上、手机被收走、最后一个盟友离开。人物在 beat 里的选择必须改变下一镜的空间关系。
6. **多人物分开生成。** 一个提示只写一个资产；同框镜头用分层合成或分别生成再拼。negative 加 `merged faces | extra limbs | feature bleed`。
7. **声音定基调。** 给 C1、C2 各写一条 voice token：`音色 | 语速 | 句长 | 口音`；对白长度跟着句长走，不随意换语域。

## 检查清单

- [ ] 主角在压力下做过的哪个选择，能在一个镜头里看见？
- [ ] want、need、flaw 是否各有一个可画的动作，而不是形容词？
- [ ] 对手与主角是否共享一个议题，只是答案相反？
- [ ] 每个配角能否说出他推动了哪一镜、改变了什么？
- [ ] 有没有“很好看但不推动故事”的人物？删掉或合并。
- [ ] C1 / C2 的固定 token 是否逐字复用，没有同义改写？
- [ ] 多人同框是否分开生成，negative 是否防特征污染？

## 常见错误

- **在人物 token 里写小传。** 后果：注意力被分走，脸和服装反而不稳。替代：小传留在 beat sheet，token 只留身份与外观。
- **用“悲伤”“愤怒”当动作。** 后果：模型给通用表情，每镜强度不同。替代：写手、眼、呼吸、重心、距离。
- **对手只是“更坏的坏人”。** 后果：冲突变成音量比赛。替代：让对手回答同一个问题，答案相反。
- **一场塞四个人。** 后果：脸糊、手多、关系读不出。替代：拆镜或合并功能重复的人。

## 与风格层接口

人物的“障碍—选择”交给表演层，写成 action token，不写情绪形容词。主角与对手的镜像关系交给视觉层：同构图、反打、冷暖两套语法；风格层只取强化对照的 2–3 条约束。功能位决定景别：密友给反应，解说者给插入物或画外音，跟班只在中景和全景。voice token 与视觉 token 一起锁进资产表；台词与动作冲突处用近景或插入剪辑。

# 场景手法配方

按场景类型给一套能直接改用的镜头序列。词典回答「这个拍法怎么写」，意图表回答「这种感觉用什么拍法」，配方回答「**这类戏从头到尾怎么排**」。

| 文件 | 场景类型 | 典型用途 |
|---|---|---|
| `dialogue-two.md` | 双人对话 | 谈判、摊牌、告白、审问、走着说 |
| `dialogue-group.md` | 三人以上 / 群戏 | 饭桌、会议、家庭冲突、宴会 |
| `chase.md` | 追逐 | 徒步、车辆、逃离、追赶 |
| `fight.md` | 打斗 / 动作 | 徒手、武器、一对多、动作后的余波 |
| `suspense.md` | 悬疑与揭示 | 潜入、跟踪、发现证据、惊吓 |
| `romance.md` | 亲密 / 浪漫 | 相遇、靠近、亲吻、分别 |
| `montage.md` | 蒙太奇与时间流逝 | 训练、准备、日常重复、季节流转 |
| `opening-ending.md` | 开场与结尾 | 建立世界、人物出场、收尾、告别 |
| `reversal.md` | 反转 / 打脸 | 身份揭晓、当众翻盘、真相大白（竖屏短剧高频） |

## 每份配方的结构

1. **这场戏要什么**：观众必须读到的信息和情绪，以及失败时观众会误读成什么。
2. **默认序列**：镜头表，每镜写景别 / 角度 / 运动、这一镜回答的问题（Q）、推荐生成方式、时长。
3. **示例**：模式 A 的逐镜提示，可直接改名字套用。
4. **变体**：同类戏的常见变化。
5. **竖屏 / 短剧**：按 `references/drama/standard.md` 的枚举和 15 秒片段写法怎么落。
6. **失败与修法**：这类戏在生成里最常见的崩法。
7. **可借的档案**：适合这类戏的导演 / 摄影档案，只取 2–3 条约束（`references/prompting.md`）。

## 用法

- 先做 scene card（`craft/staging/06-scene-analysis.md`）：beat 写完再套配方，不要先选配方再编戏。
- 配方是默认值，不是模板：每个 beat 都要改变关系，不改变的镜头删掉。
- 生成方式和可靠性分级见 `camera/index.md`；示例里的人物和场景都假定已经有参考图（`references/aigc/assets.md`），所以提示词里不写外貌。
- 一场戏超过 8 镜，多半是台词被逐句切开了，回到问答合并（`craft/staging/04-coverage.md`）。

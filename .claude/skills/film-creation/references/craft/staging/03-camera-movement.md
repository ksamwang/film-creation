# 摄影机运动：反推镜头与运动动机

## 核心判断

摄影机运动的价值是替观众换一个观看位置。没有改变距离、角度或信息量的运动，只是画面在动；有动机的运动，才让观众感到“必须跟过去看”。

## 书里的方法

**运动镜头的调度**：先把镜头内的动作分成建构单位——起、转、落。起幅要能独立成立，落幅要给出新的信息，中间的转向由一个具体事件触发（人物起身、门被推开、另一人入画）。机器沿着这三个节点走，而不是从头跟到尾。

**移动兴趣中心**：一个运动镜头里，把观众的注意力从一个主体交给另一个。交接可以靠走位交叉、前景遮挡、焦点转移或光线变化完成。它让一个长镜头内部产生“切换”，而不必剪开。

**反推镜头**：摄影机与主体沿同一轴线反向移动——主体向前，机器后撤；或主体后退，机器前推。相对速度因此加倍，背景透视迅速变化。它适合表现留不住、追不上、被空间推开的关系。使用时要把透视变化的最大点对准情绪节点，否则只是速度炫技。

**反向运动**：两个主体朝相反方向移动，制造画面内的对冲；摄影机保持不动或只做小幅调整。它和反推镜头的区别在于：反向运动发生在人物之间，反推镜头发生在人物与摄影机之间。

**后拉揭示**：从局部拉到全景，先给观众一个细节，再给出它所在的环境；推近则相反，从环境收进细节。两者都改变信息顺序，不只是改变景别。

**摇镜、升降、推轨的分工**：摇镜换关注点，升降换视平线与权力关系，推轨换距离与透视。受限空间优先用摇和升降，开阔空间才用长距离推轨；在窄空间里硬推，轨道会出卖空间。

运动必须有画面内动机：人物走动、车辆经过、门被打开、光线变化。找不到动机，就改成固定机位加人物移动。

## 可执行规则

1. 每个运动镜头先写起幅、转折事件、落幅三句话，缺一句就不动。
2. 运动必须改变信息：新人物、新空间、新关系，至少一项。
3. 反推镜头只用在关系断裂或追赶的节点，一场戏不超过一次。
4. 移动兴趣中心优先用走位和遮挡，其次用焦点，最后才用剪。
5. 受限空间用摇、俯仰和小幅升降；开阔空间才安排长距离推轨。
6. 起幅和落幅都要能单独作为构图成立。
7. 机器动之前，先问画面里是什么在动；没有就保持固定。

## 检查清单

- [ ] 这个运动改变了距离、角度还是信息量？
- [ ] 起幅、转折、落幅是否各有明确内容？
- [ ] 运动是否有画面内动机？
- [ ] 反推镜头是否只出现在真正的转折点？
- [ ] 移动兴趣中心的交接是否清楚？
- [ ] 受限空间是否避免了不必要的长推轨？
- [ ] 起幅和落幅能否单独成立？

## 与风格层接口

运动方案决定镜头提示里的“机位—运动—落点”。写提示词时按“起幅内容 → 触发事件 → 落幅内容”组织，不要只写“缓慢推近”。摄影指导需要知道运动是否改变透视、是否越轴、是否要清理轨道；这些信息比“电影感”更有用。

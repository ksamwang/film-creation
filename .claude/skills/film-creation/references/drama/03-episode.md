# 单集节奏：开场、回合与断章

> 产物：一集剧本的骨架；正文写法见 `04-script.md`，格式见 `standard.md` P3。
> 一句话：**前 3 秒见冲突，前 30 秒交代身份、困境、目标，中间一个有增量的回合，结尾停在高潮前一秒。**

## 1. 时长与体量

| 档位 | 时长 | 中文正文 | 英文正文 | 场景 | 对白行 |
|---|---|---|---|---|---|
| 标准档 | 60–120 秒 | 350–500 字 | 180–260 词 | ≤2 | ≥4 |
| 长档 | 165–195 秒 | 650–850 字 | 330–450 词 | ≤3 | ≥8 |
| 微型档 | 60–90 秒 | 260–400 字 | 140–200 词 | ≤2 | ≥4 |

正文 = 对白 + 动作行。估时：中文台词 3.5–4.5 字/秒（快念可到 5.5–6），英文约 2.5–3 词/秒；动作、停顿、反应另算。**AI 视频的对白镜实际会比字数估计多 1.5–2.5 秒**（开口延迟），所以剧本宁短勿长。

## 2. 单集骨架（标准档，以 90 秒为例）

| 段 | 时间 | 任务 |
|---|---|---|
| 钩子 | 0–3 秒 | 直接切进冲突顶点，不铺垫 |
| 立住 | 3–30 秒 | 黄金三角：**我是谁、我在什么困境、我要什么**（第 1 集必须完整；之后各集用一两句接上上集） |
| 回合 | 30–75 秒 | 施压 → 反击（或反击未遂）；必须有新信息、新行动或新代价 |
| 顶点 + 断章 | 75–90 秒 | 情绪顶点落地，停在下一个高潮的前一秒 |

比例口径：铺垫 30% / 冲突 50% / 转折卡点 20%。每集一个**小情绪点**落在回合里。

**长档**（约 3 分钟）不是把标准档注水：钩子 0–8 秒 → 回合 A 8–80 秒 → **中段小钩**约 90 秒（新信息或新威胁，只抬价不放大招）→ 回合 B 95–170 秒（施压和反击**各升一档**，不复读 A）→ 顶点 + 断章。每 30 秒至少一个新增量；第 2、3 场必须换空间、换对手或换压力等级。

## 3. 开场

**前 3 秒的五种起手**（选一种，第一帧就能看懂）：

| 起手 | 例 | 第一帧画面 |
|---|---|---|
| 羞辱当场 | 岳母把茶泼在他脸上：「废物！」 | 茶水溅开的特写 |
| 绝境倒计时 | 「签了认罪书，否则你女儿今晚手术台见。」 | 推到面前的文件 + 握笔的手 |
| 身份反差 | 外卖员走进董事会，全场起立 | 门开，西装人群齐刷刷站起 |
| 死亡 / 重生 | 她从楼顶坠落——下一秒在订婚宴前睁眼 | 坠落的仰拍 → 猛然睁眼 |
| 证据亮出 | 亲子鉴定被拍在桌上 | 报告上的「亲生」二字 |

**开场五要素**：人设靠事件立（被泼茶，比旁白说「我是赘婿」有力）；目标具体；困境即时且有压迫感；情绪密集反转；台词一句多用（推进 + 关系 + 矛盾 + 人设）。

**AIGC 提示**：第一镜就是第一个片段的第一帧。开场选一个**能用一张图看懂**的冲突画面，比靠台词解释更稳、也更好生成。

**六个坑**：节奏拖沓（两集才交代主角是谁）；寒暄式台词；人设模糊；自嗨、和受众经验脱节；只套「下跪扇巴掌」的形式而没有尊严被践踏的内核；桥段旧、表达更旧。

## 4. 回合怎么写

一个回合 = 一次**施压**和一次**回应**：

1. 施压方抛出具体筹码（证据、命令、威胁、条件）。
2. 主角回应：反击、化解、或反击未遂但换来新信息。
3. 结果改变局势：地位、证据、关系、资源、风险至少变一项。

本集的回应不能和上集同一招。连续使用同类机制时，检查行动、代价、知情或关系有没有递进。

**主角要主动**：受压不等于没有策略。关键转折要能说出主角做了什么选择、付了什么代价。

## 5. 断章：停在高潮前一秒

「人会为冲动付费，不会为已经得到的东西付费。」一集讲成完整的起承转合，观众心满意足就走了。短剧的「合」必须**悬而未决**。

**四大断章公式**

| 公式 | 原理 | 例（停在） |
|---|---|---|
| 身份掉马前一秒 | 马甲即将被识破 | 反派翻到合同最后一页，看清印章，瞳孔骤缩：「怎么会是你？！」 |
| 物理危机悬停 | 伤害造成前 0.1 秒 | 车灯直扑女主，男主扑出、指尖刚够到她衣角 |
| 反差金句落地 | 全场嘲讽到顶点，主角一句话震住 | 「这栋别墅写的是我的名字。现在，请你们全家出去。」全场死寂 |
| 绝境二选一 | 两个同样惨烈的代价 + 倒计时 | 「左边是你妈的氧气管，右边是你妹妹的录取通知书，十秒。」 |

**钩子机制**（换着用，别一种用到底）：

| 机制 | 需要已有的依据 | 下一集至少回应 |
|---|---|---|
| 即将兑现 | 目标、阻碍、等待都已建立 | 结果及代价 |
| 错误认知被推翻 | 谁误判了什么、证据为何有效 | 是否承认、怎么反应 |
| 权力转移 | 资源或身份的来源和边界 | 新权力怎么用、旧权力怎么反扑 |
| 关系选择 | 已有关系与动机 | 选择结果与关系后果 |
| 规则的意外后果 | 规则此前已讲清 | 谁付代价、如何应对（不凭空改规则） |
| 不可逆行动 | 理由与损失已建立 | 是否完成、付出什么 |

**两种落法**：一句有指向的台词（未说完的质问、身份暗示、带情绪的宣言），或一个有冲击的画面（对视未开口、门推开一半、信封拆开一角、监控里一闪而过的脸）。

**钩子诊断**（不过关先修）：观众知道在等什么吗？结果和人物处境有关吗？后果是否迫近？是否来自已有的冲突和证据？**不靠解说也能看懂吗？**——用内心独白复述目标不算钩子。

**大小交替**：每集都有钩子，但不是每集都炸。小钩子可以是一句话停在半截；大钩子留给单元接缝和付费卡点。

## 6. 集与集的衔接

- 每集开头 15 秒内回应上集的钩子（付费后第一集尤其如此）；回应可以是兑现，也可以是反向回答（等来的人选择了别人）。
- 写本集前读上一集的结尾和下一集的大纲；本集结束状态 = 下一集开始状态（谁在哪、谁拿着什么、谁知道什么）。
- 同一个场景跨集出现时，沿用同一个子场景造型；人物外形没变就沿用同一个形象。

## 7. 对照：一集 90 秒

```text
0–3s    △ 订婚宴大屏亮起，播放的却是林晚和陌生男人的酒店监控。全场哗然。
3–20s   未婚夫顾言（痛心）：「晚晚，我给过你机会。」
        △ 林晚盯着大屏，没有哭，指节在手机上一点点收紧。
20–60s  △ 林晚走上台，没有辩解，接过话筒。
        林晚：「视频是真的。只是你们没看到前十秒。」
        △ 她按下手机。大屏切换：画面前段，顾言亲手把房卡交给那个男人。
60–80s  △ 全场转向顾言。闺蜜苏蔓悄悄往门口退。
        顾言（强笑）：「这是AI合成的——」
80–90s  △ 宴会厅大门被推开，两名警察走进来。
        警察：「请问，谁是苏蔓？」（黑屏）
```

要点：开场即羞辱（核爆）；她「不哭」用动作立住人设，不靠内心独白；反击带新信息（前十秒）；反派反扑（AI 合成）；断章把矛头转向一个观众没料到的人。全集只有一个场景（宴会厅），生成成本低。

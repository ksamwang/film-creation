# 画幅内的构图

## 核心判断

构图不是把东西摆好看，而是在一个固定矩形里安排注意力：观众第一眼看谁、第二眼看哪、什么被挤出画外。画幅先于构图存在——4:3、16:9、1.85:1、2.39:1 决定横向能放多少关系，但不改变语法。

## 书里的方法

《镜头的语法》把取景法则拆成三个可测的量：头顶留白、视线留白、九宫格。头顶留白是画面顶端到头发或帽顶的距离；过多会让眼睛和脸下沉，过少会切额头。两者必选其一时宁可少留：头顶不动、下巴会动。正反打之间要保持一致的头顶留白，否则剪辑会跳。视线留白是人物看向一侧时眼睛前方留出的空间；小景别尤其要留，不然人物像撞墙。九宫格把画面横竖各三等分，主体放交点比正中更有张力；正中构图是刻意选择，不是失误。

摄影角度分水平与垂直：水平有正面、四分之三侧面、侧面、背面，越转越少信息、越多态度；垂直有平视、俯拍、仰拍，机位高度改变权力，不改变景别。双人镜头有三种基本布局：侧面双人、直接面向摄影机的双人、过肩双人；过肩镜头用前景肩背建立纵深和“谁在看谁”。

第三维是构图进阶：地平线高度决定天空与地面的比例；荷兰角制造失衡；斜线法用画面中的斜线引导视线；前景、中景、后景分层，让人物分布在不同的深度平面上。深度线索包括重叠、相对大小、透视、焦点与空气感；多人镜头靠这些线索把人排开。

《电影语言的语法》给出对话构图的量化方案：外反拍中面向镜头的演员占三分之二画面，背向者占三分之一，背向者可虚化。宽银幕近景容易跳，可把画面三等分，主要演员始终落中央区，前景偏左或偏右，余下空间用后景细节平衡。重要被摄对象放在画面上半部，是现场常用惯例：观众先扫上方。

## 可执行规则

1. 先定画幅，再定构图；画幅是交付参数，不写进 AI 提示。
2. 每个小景别都留头顶留白；宁可少留，不可多留。
3. 人物看向画外时，眼睛前方留出视线空间；不要让人贴边。
4. 主体放九宫格交点或中央，二选一；不要落在两者之间。
5. 对话双人镜头优先过肩；前景肩背要暗、要虚。
6. 用前景、中景、后景三层安排多人；人脸不重叠，身体可重叠。
7. 拍摄前检查安全框，重要信息不放边缘。
8. 清场：背景不要有从头上长出的物体、亮窗、开着的电视。

## 检查清单

- [ ] 画幅比例是多少？构图按它排了吗？
- [ ] 头顶留白是否过多或过少？相邻镜头一致吗？
- [ ] 视线前方有空间吗？
- [ ] 主体在九宫格交点还是中央？为什么？
- [ ] 机位高度是选的吗？它给了谁权力？
- [ ] 双人镜头是侧面、正面还是过肩？前景抢戏吗？
- [ ] 画面有前景、中景、后景吗？还是所有人都站一排？
- [ ] 背景有干扰物吗？安全框内吗？

## 与风格层接口

- 构图规则写成允许或禁止句：允许过肩前景遮挡，不允许背景亮窗；允许中央对称，不允许无理由荷兰角。
- 导演档案的“构图”格只填一两项：例如“低机位、人物压画面上半部、前景肩背常驻”。
- AI 提示用构图 token：`centered / off-center / rule-of-thirds / over-the-shoulder / foreground obstruction / deep staging / low horizon`；不写“唯美构图”。
- 分镜草图标注：地平线、主体交点、前景层、安全框。

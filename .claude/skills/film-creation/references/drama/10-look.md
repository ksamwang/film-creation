# 画风：写实与漫剧

> 产物：项目参数 `style` 里的「视觉风格」一句 + 一张风格基准图（`standard.md` 项目参数、P5）。
> 一句话：**画风是项目级决定，定一次，全片不变；写在项目设定里，不写进每个分镜。**先按题材和预算选，再写成一句「媒介 → 线条/渲染 → 光 → 色 → 质感」，用基准图钉死。

## 1. 选画风

| 画风 | 适合题材 | 成本与稳定性 | 对模型的要求 | 最常见的跑偏 |
|---|---|---|---|---|
| 写实真人 | 都市、甜宠、职场、家庭、出海 | 最稳，口型和微表情最好 | 主流模型都行 | 塑料感：磨皮、过亮、网红脸 |
| 写实电影感 | 复仇、悬疑、年代、古装 | 稳；暗部易脏、看不清脸 | 暗部和画内光源处理好 | MV 滤镜；夜戏死黑 |
| 二维国漫 | 仙侠、玄幻、男频逆袭 | 中；线条、平涂跨段易变 | 守得住非写实；支持起始帧 | 滑向真人或厚涂；线条闪烁 |
| 日式赛璐璐 | 校园、恋爱、异世界 | 中；多数模型见得多，较好守 | 同上；嘴能简单开合 | 眼型脸型跨镜变；画出写实牙齿 |
| 韩漫 / 条漫风 | 霸总、重生、都市恋爱 | 中；一致性全靠造型图 | 精致半写实人物与光泽 | 滑向真人偶像剧或日漫大眼 |
| 三维 CG（国创） | 仙侠、科幻、打戏多 | 中；身份较稳，大动作不易崩 | 守得住 CG 材质 | 塑料感、游戏过场；滑向真人 |
| 动态漫 / 静帧 | 网文漫画改编、旁白多、预算低 | 最省：少动、少重试 | 出图 + 图生视频 | 动太多变形；各镜画风不一 |

- 拿不准选写实真人。非写实要有理由：题材是幻想、原作是漫画、或真人做不出。
- 换画风 = 全部造型图重出，立项时就定。

## 2. 「视觉风格」一句

**落点**：项目参数 `style`；造型图提示词结尾的「视觉风格：{风格}」（`05-breakdown.md` 第 5 节）就是它。**不进特征卡，不进分镜 `text`。**

**结构**：媒介（第一词定死：真人实拍质感 / 二维国漫动画 / 三维 CG 动画）→ 线条/渲染（非写实写线和阴影阶数；写实写反差）→ 光（一个主光源和方向）→ 色（2–3 主色 + 1 点缀）→ 质感（一两个具体材质）。

- **长度**：中文 40–80 字，英文 30–60 词，最多两句。再长通常会被挑着听，还会和参考图打架。
- **不写**：导演名、作品名、`masterpiece` `8K` 等画质词、画幅、镜头型号、角色外貌。

**写实**

```text
真人实拍质感的都市剧，柔和的大面积窗光从侧前方进来，低反差，暗部通透；奶油白、浅杏和雾粉为主色，点缀藏青；皮肤保留自然纹理，衣料有真实的褶皱和光泽。
```

```text
写实电影感，夜景以画内台灯和走廊灯为光源，单侧硬光，半边脸落入阴影但暗部有细节；冷青灰为底，只有灯光一处暖黄；墙面和皮革哑光，轻微颗粒。
```

**非写实**

```text
二维国漫动画，干净的细线条，赛璐璐两阶平涂阴影；柔和天光，人物边缘有淡淡轮廓光；青绿、月白为主色，点缀朱砂红；背景是手绘水彩质感，比人物略淡。
```

```text
三维 CG 动画，国创风格，角色比例接近真人、面部美化；高侧方的体积光穿过薄雾；墨蓝与暗金为主色；发丝分明，布料与金属材质清晰，表面不过度光滑。
```

## 3. 非写实的专门规则

**造型图**

- 先出风格基准图（第 6 节），过了再出立绘、设定稿、子场景。
- 规格不变（P5），只换写实用语：「纯白色摄影棚背景，柔和均匀的布光」→「纯白背景，平光」。
- 角色和场景**同一画风**：人物二维、背景照片感，片段里通常会被一起拉向写实。
- 特征卡照常只写人：银发 `#E8E8EE`、琥珀色瞳孔是外形，可以写；「动漫风」「大眼」是画法，不写。

**片段里保持**

| 做法 | 说明 |
|---|---|
| 第一句声明媒介 | `style` 由平台拼进生成参数；直接调原生接口时，手改编译结果，开头加「二维国漫动画。」（`07-segment-prompt.md` 第 6 节） |
| 挂同画风起始帧 | 只有身份参考没有起始帧时，多数模型更易滑向写实；每集首段尽量从同画风关键帧起 |
| 不写写实词 | photorealistic、真实皮肤、毛孔、镜头型号、焦段、光圈、摄影棚、演员 |
| 运镜收敛 | 以固定、缓推为主；环绕、手持、长跟随最易让线条抖动变形 |

**口型与表演**

三维接近写实，按写实写；二维有三处不同：

- 口型：幅度小、形状少；分镜写「嘴部简单开合」，对白镜多用中景、侧脸。
- 表情：线条读不出微表情，写眉眼嘴的形状（「眉毛压低，眼睛眯成一条线」），不写「眼神里闪过不甘」。
- 动作：大而清楚，一个姿势落定再下一个；细碎小动作看着像抖动。

**动态漫 / 静帧配音**

1. 先画再动：每个分镜用图像模型出一张同画风关键帧（挂基准图），作起始帧。
2. 少动：图生视频只做眨眼、发丝、衣摆、烟雾、光影；人物大动作换下一张图硬切。
3. 摄影机代替表演：推、拉、摇，一镜一种，慢速。
4. 配音驱动：台词照写进 `dialogue`（字幕从这里出），成片整集配音，镜头时长按配音定；说话镜多用侧脸、背影，避开口型。

**跑偏与修法**（跑成真人按上表三条处理）

| 症状 | 修法 |
|---|---|
| 线条闪烁、轮廓沸腾 | 缩短动作，改固定镜头 |
| 脸型眼型跨镜变 | 造型图重出到满意；同段少换景别 |
| 嘴里画出写实牙舌 | 「嘴部简单开合」；对白改侧脸或中景 |
| 背景与人物两种画风 | 场景图按基准图重出 |
| 三维塑料感 | 写具体材质（发丝、布纹、金属划痕），删「光滑」「完美」 |

## 4. 写实的专门规则

**题材基调**（光与妆造全剧统一，写进风格句）

| 题材 | 光 · 色 · 妆造 |
|---|---|
| 甜宠 | 高调柔光、低反差 · 奶油粉杏 · 通透淡妆、柔软面料 |
| 重生复仇 | 前期冷灰平光，翻盘后反差加大 · 低饱和底 + 一个强点缀（红或金） · 妆造随阶段由素到锐利 |
| 古装 | 天光、窗纸透光、烛火，不要影楼光 · 按朝代定 3 色 · 绸缎、刺绣、发饰写具体 |
| 悬疑 | 低调单侧硬光、画内光源 · 冷青底一处暖 · 素颜感、暗色哑光衣着 |
| 都市职场 / 总裁 | 冷白日光、玻璃反射 · 灰、藏青、白 · 西装面料、利落发型 |
| 家庭 / 萌宝 | 暖日光 · 暖米、木色 · 居家衣物有使用痕迹 |

**竖屏取向**

- 中近景为主，主光放侧前方，脸要有明暗面。
- 背景亮度低于脸；下方约 20% 是字幕区，不放大面积纯白或高亮细节。
- 单人镜可浅景深；两人前后站位时别太浅，后面的人糊了就认不出是谁。

**避免塑料感**：多半是造型图带来的（磨皮立绘会进每一镜），先修造型图。用具体光源和材质代替画质词：「超写实、8K、完美皮肤」→「皮肤保留自然纹理，轻微颗粒」；「电影级光影」→「阴天散射光从画左窗户进来」；「豪华客厅」→「哑光胡桃木地板，米色布艺沙发」。

## 5. 从导演 / 摄影库借视觉基元

只借**看得见的**，不借叙事和剪辑。

1. **只借 1 位**：用 `references/taxonomy.md` 按「要什么光和色」选人（摄影指导看文末「五族」；二维项目可看第 11 族），不读整个 `references/index.md`。
2. **只取 2–3 条**：一个光源、一个色彩关系、一个构图习惯；从档案「视觉配方」和 `prompts/` 的「一致性锚点」里取，且限于「混搭接口 · 可借出的层」。
3. **翻成可见描述并入风格句**：不写名字，不抄画幅、焦段、`Cinematic film still`。
4. **短剧规则不让位**：说话人正脸、竖屏取景、片段节奏优先，冲突的基元直接丢。

**示范**：王家卫 → 都市复仇剧夜戏

| 档案里 | 处理 | 并入 |
|---|---|---|
| 实用光，霓虹混钨丝 | 取：光源 | 光来自台灯和窗外霓虹 |
| 饱和绿红黄 | 取：色彩关系 | 祖母绿与暗红同框 |
| 前景遮挡，门框切割 | 改：遮脸会害口型 | 边缘有虚化门框前景，不挡脸 |
| 手持、抽帧、1.66:1 | 不取：运镜归分镜，画幅归参数 | — |

```text
写实电影感，夜里的光来自台灯和窗外霓虹，祖母绿与暗红同框、饱和偏高，暗部保留细节；画面边缘常有虚化的门框或玻璃前景，不挡人脸；轻微胶片颗粒。
```

## 6. 跨集一致

| 手段 | 做法 |
|---|---|
| 风格基准图 | 立项后先出 2 张：主角在主场景的代表画面 + 同场景空景。不是造型、不占片段参考图名额；造型图都对照它，能挂风格参考时挂它 |
| 色板 hex | 主色、辅色、点缀、肤色、暗部 5 色，记在立项单；服装 hex 尽量从中取 |
| 风格句冻结 | 全剧不改；改了 = 全部造型图标「待同步」 |
| 每集首段验收 | 首段和基准图并排看媒介、色调、线条（`08-cut-qc.md`「画风」项），过了再批量 |
| 换模型 | 基准图同一画面先跑一段对照 |

## 画风检查

- [ ] 画风有理由，立项时定死？
- [ ] 风格句五段、长度合规，无导演名、画质词、画幅；只在 `style` 和造型图结尾？
- [ ] 基准图已出，角色与场景同一画风？
- [ ] 非写实：首句媒介、同画风起始帧、无写实词？
- [ ] 写实：题材基调统一，用光源和材质代替画质词？
- [ ] 借导演只借 1 位 2–3 条；色板记在立项单，每集首段对照基准图？

### 镜流

整场写成一段话，箭头上写「因此 / 但是 / 同时」；切点都要落在箭头上（`references/storyboard/flow.md` §1）。从主角进场时想要什么写起，写到他的反应和决定；最后注明这场让主线答案近了还是远了。

```text
{起点} → 因此 {…} → 但是 {…} → 同时 {…} → … → {余韵}
```

### 分镜脚本

镜号：场-镜（`{N}-01`）；插入用字母（`{N}-04A`）；删除的镜号空着，不重排。一场里有几个时空时，表内加小标题行（`| **地点 · 时段** | | … |`），镜号照常连续，换时空那一镜的「接 / 出」写段间接点。

| 镜号 | 功能 | 景别 | 角度 | 运镜 | 画面（起点 → 动作 → 落点） | 台词 / 声音 | 接 / 出 | 时长 | 生成 |
|---|---|---|---|---|---|---|---|---|---|
| {N}-01 |  |  |  |  |  |  | 接 场头 / 场间（…）；出 … |  |  |
| {N}-02 |  |  |  |  |  |  | 接 …；出 … |  |  |
| {N}-03 |  |  |  |  |  |  | 接 …；出 … |  |  |
| {N}-04 |  |  |  |  |  |  | 接 …；出 余韵 |  |  |

- 画面：一张画得出来的图加一个动作——主体、在画面哪里、起点 → 落点、方向、看得见的环境；不写形容词、比喻、情绪名词。一格里出现两个动作就拆成两镜（`references/storyboard/decoupage.md` §2、§6）。
- 景别：用八档的名字（大远景、远景、全景、中景、中近景、近景、特写、大特写），不写「近景至特写」；运镜改变景别时写起止（「中景 → 近景」）。
- 运镜：默认「固定」；动的镜头写清理由（跟 / 揭示 / 情绪推进 / 主观）。
- 功能：建立 / 重新交代 / 入场出场 / 关系 / 过肩 / 单人 / 视线对象 / 主观 / 反应 / 插入 / 揭示 / 动作 / 结果 / 切出 / 过渡 / 停顿 / 时间流逝 / 情绪强调 / 拉远 / 母题（`references/storyboard/shot-functions.md`）。
- 接：问答 / 视线 / 动作 / 声音 / 物件 / 运动 / 构图 / 情绪，括号里写具体的东西；出：观众此刻想知道的问题，或被带到下一镜的东西（`references/storyboard/flow.md` §2）。
- 声音栏写清跨剪辑点的声音：「（先于画面）」「（拖入下一镜）」。
- 生成：稳 / 定帧 / 后期 + 生成方式（参考图生、首帧、首尾帧、续接）。

合计：{n} 镜、约 {秒}。

### 审读

- [ ] 每一镜都能说出它回答的问题？
- [ ] 剧本每行动作都拆开了：一镜一件事，关键动作拉长成几镜，先整体再局部、事件后回到整体（`references/storyboard/decoupage.md`）？
- [ ] 画面栏只写看得见的东西；大多数镜头固定，动的都有理由？
- [ ] 景别衔接：同一主体相接跨了两档或换了角度？连续特写之后回到了整体？生成单位交界处换了主体或跨两档（`references/storyboard/continuity.md` 景别衔接）？
- [ ] 读链：只读「接 / 出」，每个切点写得出「因为 / 所以 / 但是 / 同时」，「然后」不超过三分之一？
- [ ] 兑现：每个承接标签都能在画面栏或声音栏里找到对应的字；「出 余韵」的镜头画面里写了停留？
- [ ] 每次「看」都有视线对象，每个重要信息之后都有反应？视点每次交接都有理由？
- [ ] 关键物件的位置和状态在镜头之间连得上（流转表）？
- [ ] 转折那一拍镜头最密、景别最近？相邻镜头景别或角度有明显差别？
- [ ] 重要台词落在对的脸上？一镜一个说话人？
- [ ] 每镜时长够说完台词、做完动作？加总接近估计？留了呼吸？
- [ ] 场头接住了上一场的尾；场尾停在余韵上；场间接点写了？
- [ ] 上一场最后一镜的「出」在这一场回答了？剧本场间表里的画外事件都落到了某一镜？镜流句看得出离主线答案的远近？
- [ ] 方向和轴线全场一致？
- [ ] 每镜标了可靠性、生成方式；高风险镜头有备选？

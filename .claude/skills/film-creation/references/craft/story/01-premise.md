# 前提：钩子与只有你能给的视点

## 核心判断

前提要同时回答两个问题：这个故事用一句话说，别人想不想知道结果；这个看法是不是只有你能给。前者是钩子，后者是视点。缺一个，项目要么卖不出去，要么拍出来谁都不像。

## 书里的方法

**钩子是一句话引出故事的新想法。** 爱泼斯坦把钩子定义为"一部电影的概念"，不是随便一个概念，而是能让业内人马上想读剧本、让观众想看片的那个新想法。判断标准很直接：听完这句话，谁都想知道结果。他举的例子都是"某人落入一个反常处境"：律师突然丧失说谎能力、广告高管能听见女人心声。钩子不必等于影片真正讲的故事——《自由进取号》真正拍的是爱情喜剧，但卖出去的是"星际迷撞上柯克船长"。他也提醒：有明星、名导、畅销原著这些"稳赚因素"时可以没有钩子；新人没有，就必须有。

**钩子之后要落到一个人和一件事。** 爱泼斯坦说电影基本上是一篇短篇小说：一个中心人物，一个想要实现的目标，和达成目标必须面对的阻碍。缺一项，提案就不成立。他进一步拆成四元素：主要人物、目标（风险/赌注）、损失、阻碍。

**视点是作者看世界的方式。** 《21天搞定电影剧本》把它叫 point of view：同一只兔子被折磨后淹死，一个人记住的是"与死神恶斗后淹没在泪水中"，另一个人记住的是"威廉先生没把水桶装满"。两种都真，差别在视点。书中认为作者真正值钱的只有这个视点。

**先判断载体，再谈前提。** 同一章给了一条硬标准：故事靠人物动作和外部事件视觉化推进，才是电影；靠深度谈话探究观点，是戏剧；要钻进人物内心，是小说；一个能涵盖主题的清晰概念，可以写成歌。判断错了，后面所有结构工作都是白做。

**议题与冲突要能一句话锁定。** 奥班农的第一幕定义冲突：介绍人物与情境——谁、何处、何时、为何——从这个聚合物里产生"争论的议题"，主要人物与反面人物对如何处理议题产生分歧，冲突具体化，第一幕结束。前提若说不出双方在什么议题上对立，就还没有可拍的故事。

## 可执行规则

1. 用一句话写钩子，句式是"某人/某群人 + 一个反常处境 + 由此引出的麻烦"；写完自问：外人会不会想知道结果。
2. 再写一句"谁想要什么、谁挡着、失败失去什么"；写不出就是人物或赌注还没定。
3. 用"如果……那么……"追问十轮，每轮把故事往真正的源头推一步；绕开的地方记下来，那通常是漏洞。
4. 先判载体：动作和外部事件能否承载它；不能，就改成戏剧、小说或歌，不要硬写成电影。
5. 写一句只有你能写的视点句：这件事你看见而别人看不见的是什么。
6. 钩子不等于剧情简介；宣传时用钩子，写作时用冲突。

## 检查清单

- [ ] 钩子能不能在电梯里说完，并让对方追问"后来呢"？
- [ ] 钩子里有没有一个具体的人，而不是一种现象或一个主题？
- [ ] 目标、阻碍、损失三样是否齐全？
- [ ] 主角与对手是否在同一个议题上给出不同答案？
- [ ] 这个故事非用画面和动作讲不可吗？换成谈话或内心独白是否更顺？
- [ ] 你的视点句是否真的排除了别人也能写的通用故事？
- [ ] 钩子是否被误当成全片内容，导致第二幕无话可说？

## 与风格层接口

- 钩子直接成为 logline 与片名策略；风格层不得改写钩子里的反常处境。
- 视点句决定全片的镜头归属与信息分配：是跟一个人看，还是让观众先看见。
- 载体判断决定篇幅与生产方式：短片从冲突已发生处开始，长片才铺建置。

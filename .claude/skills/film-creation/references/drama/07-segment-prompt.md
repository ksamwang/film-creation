# 片段提示词：编译、模型差异与失败修法

> 产物：P7 compiled prompt（`standard.md`）。片段提示词由分镜编译，**问题优先回分镜改**，不在提示词上打补丁。
> 一句话：**自然语言、按镜头顺序、造型用 `@[名字]` 带图、台词写进去让模型说、结尾两条固定约束；其余交给参数面板。**

## 1. 为什么是自然语言而不是 token 块

短剧用的视频模型（Seedance 2.x、MiniMax H3、Wan 3.x、Kling、Veo 等）用大语言模型做文本编码，读得懂按顺序写的镜头描述、引号里的台词和「镜头1 / Shot 1」这样的结构。`|` 分隔的 token 块对它们没有优势，还会丢掉动作的先后和因果。

| 通用图像 token 规则 | 片段提示词 |
|---|---|
| token 块、`|` 分隔 | 按镜头顺序的自然语言 |
| NEGATIVE 必填 | 模型有 negative 参数才用；多数视频模型没有，**不写** |
| 一致性靠逐字复用 token | 一致性靠 `@[造型名]` 带参考图 |
| 视频只写运动 | 每镜写站位、动作链、表情、台词 |

没有参考图的**纯文生视频**才退回文字锁定：人物外貌、服装、地点、光线都要写进正文（写法见 `aigc/assets.md`）。

## 2. 编译出来长什么样

框架见 `standard.md` P7。一个中文片段编译后：

```text
本片段场景设定在：@[顾家别墅 · 客厅_夜]。生成一个由以下4个分镜组成的视频，按顺序播放，分镜之间直接硬切。

分镜1 3s：中景，平视，固定镜头。@[顾言 · 基础形象] 坐在画右沙发上，把一份协议推到茶几中央；@[林晚 · 重生前·基础形象] 站在画左茶几另一侧，双手垂在身侧。

分镜2 4.5s：中近景，过肩镜头，固定镜头。越过林晚的左肩看向顾言，他抬眼看她，身体后靠进沙发。 顾言（冷淡）说：“签了吧，房子留给你。”

分镜3 2.5s：特写，平视，缓慢推镜。林晚的脸，视线从协议移到画右，下巴一点点绷紧。

分镜4 5s：中近景，平视，固定镜头。林晚俯身，指尖按在协议上，把它推回茶几中央，抬眼直视画右。 林晚（平静）说：“这只手，昨晚也在我的首饰盒里吧？”

音频里不要有背景音乐。
画面中不要出现任何文字、字幕或标题。
```

- `@[名字]` 由平台解析成对应的参考图（在提示词里写成「参考图 N」并说明它是谁）；直接调用原生接口时，要在正文里写明每张参考图的职责（「人物 @图片1」「地点 @图片3」），按挂载顺序编号。
- 角色有音色参考且模型收参考音频时，平台把音频一起带上，并写明「林晚说话时使用参考音频 1 的音色」。
- 时长取模型可选时长里能装下本段的最小值；画幅、分辨率、生成音频开关在参数里。

## 3. 两条固定约束

「音频里不要有背景音乐」「画面中不要出现任何文字、字幕或标题」由编译器统一加，分镜里不要再写。

- 配乐在成片阶段统一加（片段各自带的配乐风格不一，剪到一起会乱）。
- 字幕在成片阶段由台词生成（模型画的字会错、会乱码，也擦不掉）。
- 这两句**不能完全保证**：实测个别模型仍会自补配乐、把手机通知画成浮在画面上的气泡。生成后检查（`08-cut-qc.md`），要的效果写正面（「通知只在手机屏幕里亮起」）。

## 4. 模型差异（实测，换版本要重测）

| 模型 | 写法要点 | 已知坑 |
|---|---|---|
| **Seedance 2.0** | 用「镜头1、镜头2」按事件顺序写；秒数作内部预算 | 官方说明精确时间支持不稳定；尾帧锁构图但动作常停在半路 |
| **Seedance 2.5** | 镜头序号或整数秒时间段都可；参考图上限高；有延长模式 | 不提配乐时约一半样本自补配乐；手机通知易画成浮层；参考模式下起始构图不稳，连续动作优先用延长 |
| **MiniMax H3** | 写「固定镜头」明显减少意外推拉；反应镜：点名情绪 + 两处可见泄露 + 1.5 秒内落下定住 | 开口晚 1.3–2.4 秒；首帧模式下转身方向常与提示相反（方向相反时在动作前切）；同时只写文字音色时两个男声区分度低 |
| **Wan 3.x** | 中文约 4.6 字/秒；引号写台词即可 | 超出容量时说一段就静默丢掉其余；多切的切点误差大于 H3；景别容易被地点图拉宽 |
| Kling / Veo 等 | 按各自官方提示词指南 | 本包暂无实测，先小样验证再批量 |

**通用实测**（多个模型）：

- 写接触点比写距离有效：「指尖碰到杯沿后停住」4/4 生效，「伸出约二十厘米停住」基本无效。
- 只有身份 / 地点参考、没有首帧时，「中景」常出成远景；写具体取景（切在哪、脸在画面哪）才稳。
- 参考图挂得多不一定变差（7 张不比 3 张差）；必须认得出的物件，挂图比只写文字稳。
- 正文里写人名不会被念出来，也不会出现在画面里；按名字区分人物是安全的。
- 非写实画风（二维国漫、三维 CG）用文生时易变成真人：第一句先声明媒介，最好挂一张该画风的起始帧。

## 5. 失败与修法（优先改分镜）

| 症状 | 原因 | 修法 |
|---|---|---|
| 口型落在不说话的人脸上 | 不说话的人是画面里最显眼的正脸 | 改分镜：说话人正脸，其他人背对 / 侧脸 / 出画 |
| 台词没说完、赶词 | 镜头太短 | 按「字数 ÷ 语速 + 1–2 秒」加长，或拆句分镜 |
| 动作挤成一团、跳帧 | 一镜写了太多动作 | 一镜 2–3 个动作，或拆镜 |
| 人站错侧、隔桌变同侧 | 只写了关系，没写机位前后 | 左右写画面方位，前后写相对机位的前景 / 背景 |
| 凭空多出家具 | 锚点不在场景图里 | 换成场景图里有的锚点，或回去改场景描述重出图 |
| 景别偏宽 | 只有地点图，没写取景 | 写「切在腰部」「脸在上三分之一」，或给首帧 |
| 脸 / 衣服跟参考图不一样 | 文字重复描述外貌，和图打架 | 删掉文字里的外貌，只留动作；身份交给 `@[]` |
| 同一角色跨段换嗓子 | 没绑音色参考 | 定音色参考（`05-breakdown.md` 第 6 节），或成片阶段配音 |
| 两段接不上 | 各段独立从参考图开场 | 用上一段真实尾帧 / 视频续接；或把两段合成一段 |
| 出现配乐 / 字幕 / 浮层 | 模型自补 | 正面写想要的效果；生成后检查，不行就重拍 |
| 意外推拉摇移 | 没写机位 | `move` 填 `static`（对话镜默认） |

## 6. 什么时候手改编译结果

编译结果可以在提交前手改，但**下次重新编译会被覆盖**（改了造型名、换了模型、重新同步时）。所以：

- 内容问题（站位、动作、台词、时长）→ 改分镜。
- 只对某个模型生效的小技巧（一句额外的取景说明）→ 可以手改，记得重新编译后再看一眼。

## 片段提示词检查

- [ ] 每个造型都以 `@[完整名]` 出现，名字逐字对得上？
- [ ] 文字里没有外貌重复、画幅、风格、画质词？
- [ ] 每镜的台词在 `dialogue` 里，没在 `text` 里重复？
- [ ] 没手写 negative（模型无此参数时）、没重复写两条固定约束？
- [ ] 目标模型的已知坑已在分镜层面避开？

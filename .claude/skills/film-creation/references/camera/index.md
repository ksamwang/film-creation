# 镜头语言查阅层

## 这一层做什么

`craft/visual/` 和 `craft/staging/` 是**判断层**，回答「这场戏为什么这样拍」。这一层是**查阅层**，回答两件事：

1. 某个拍法叫什么、怎么写进提示词、模型做不做得出来。
2. 想要某种效果（压迫、孤立、揭示……），该用哪几个拍法组合。

一次只读一篇，不整层加载。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `lexicon-shot.md` | 景别、角度、关系视角、焦段、景深与焦点 | 写取景句；用户点名某个角度或镜头 |
| `lexicon-move.md` | 运镜、航拍与穿越、速度与时间 | 写运动句；用户点名某种运镜 |
| `lexicon-light.md` | 人物光型、画内光源、时段与天气、整场调性、光的变化 | 写光；用户点名某种光（伦勃朗光、逆光、霓虹） |
| `lexicon-frame.md` | 构图：位置、线条、层次与纵深、画框、竖屏构图 | 写取景句里的位置与层次；用户点名某种构图 |
| `lexicon-transition.md` | 转场：剪切、光学、遮挡与运动、匹配与变形、声音转场 | 写剪辑方案；两个镜头怎么接 |
| `intent.md` | 按目的反查：效果 → 手法组合 → 示例 → 别这样用 | 用户只说想要什么感觉，没说怎么拍 |
| `recipes/` | 场景手法配方：对话、群戏、追逐、打斗、悬疑、亲密、蒙太奇、开场与结尾、反转 | 要排一整场戏的镜头序列；先读 `recipes/index.md` |
| `sources.md` | 每个拍法的出处 | 需要核对出处时 |

拍完一组镜头，回 `craft/staging/04-coverage.md` 和 `craft/staging/06-scene-analysis.md` 检查序列是否连得上；风格化约束从导演 / 摄影档案取（`references/prompting.md`）。

## 条目字段

每个拍法按同一格式写：

- **写法**：模式 A 的英文短句（可直接放进提示词）；`B:` 后是模式 B 的 token。
- **作用**：它让观众得到什么——信息、位置、权力还是情绪。
- **用 / 不用**：什么时候选它，什么时候选别的。
- **生成**：可靠性分级（见下）和推荐的生成方式。
- **失败**：常见崩法，以及模式 A 的正面写法。
- **短剧**：对应 `references/drama/standard.md` 的 `size` / `angle` / `move` 枚举；枚举里没有的写落到哪个值。

## 生成可靠性分级

| 级别 | 含义 | 怎么做 |
|---|---|---|
| **稳** | 文生或参考图生通常一次就能出 | 直接写进提示词 |
| **定帧** | 文字常被忽略或中途漂移 | 先出关键帧，走首帧生视频；要求落点的走首尾帧（`references/aigc/workflow.md`） |
| **后期** | 生成里基本不可控 | 生成素材，剪辑或后期完成；提示词里不写 |

分级是 2026-11 时的通用经验，不点名模型。模型差异大：排进流程前跑一条最便宜的小样，结论记进项目备注（同 `references/aigc/models.md`）。

## 三条通用规则

1. **一镜一个景别、一个角度、一个运动。** 复合运镜拆镜头，用剪辑连。
2. **写后果，不写术语堆。** `low angle` 之外写「他的头顶顶到画框上沿，天花板压在身后」，模型更听话。
3. **每个拍法都要有理由。** 说不出它给观众多了什么，就用平视、固定机位、中景这组默认值。

# 出海与本地化

> 用在立项（`01-premise.md`）和写台词（`04-script.md`）时。项目的 `market` 与 `dialogue_lang` 决定这里取哪一部分。
> 一句话：**本地化保留戏剧功能，替换的是让观众出戏的东西——名字、钱、机构、习俗和说话方式。**

## 1. 出海格式（行业区间，以具体平台为准）

| 项 | 常见值 |
|---|---|
| 集长 | 60–120 秒 |
| 季长 | 60–100 集（也有 40–50 集） |
| 免费集 | 约 8–13 集；付费墙多在第 8–12 集 |
| 每集 | 一个钩子 + 一次升级 + 一个集尾悬念；对白常控制在 10 行左右 |
| 季结构 | 1–3 集立冲突 → 4–9 集升级、两三个情绪峰 → 8–12 集付费墙前最大转折 → 中段反转与至暗 → 最后 10–15 集先收副线再收主关系 |

这些数字来自行业指南和平台从业者的说法，彼此不完全一致；平台没有公开统一规范。确定平台后再调。

## 2. 出海题材

| 题材 | 观众在等什么 | 关键约束 |
|---|---|---|
| CEO / Billionaire romance | 高位者为她破例，最终让渡控制 | 女主要有自己的目标和判断；权力有来源和边界 |
| 隐藏身份继承人（Hidden heir / Secret billionaire） | 被看不起的人亮出身份 | 和国内「隐藏大佬」同构，信息差 D |
| 复仇 / 重生（Revenge, Second chance） | 旧损失一笔笔夺回 | 前世记忆指路，但今生要拿到能公开的证据 |
| 狼人 / 吸血鬼 / 奇幻罗曼史（Alpha, Luna, Fated mate） | 相爱触犯规则，代价越真越好看 | 等级、契约、诅咒先定义清楚；Alpha / Luna 只在本剧体系里成立 |
| 黑帮 / 契约婚姻（Mafia, Contract marriage） | 危险环境里的选择性保护 | 债务或契约不能代替同意；关系要走向平等 |
| 禁忌情感 | 克制、选择与代价 | 角色必须成年；职业或身份边界造成持续阻力 |
| 萌宝 / 家庭 | 孩子改变家庭 | 孩子有自己的愿望和弧线，不只负责撮合 |
| 末世 / 魔法逆袭 | 被低估者凭有代价的能力翻身 | 能力的触发、限制、代价提前写清 |

**地区偏好只是假设**：「北美喜欢 X、东南亚喜欢 Y」的说法大多没有核实，按具体平台数据和用户提供的资料判断。

## 3. 本地化：先保功能，再换符号

替换前问：这个元素在剧里承担什么功能（证明身份？制造羞辱？限制行动？）。保留功能，换成目标市场里**承担同一功能**的东西。

| 类别 | 中文原稿 | 美国市场候选 |
|---|---|---|
| 通讯 | 微信 / 朋友圈 / 抖音 | text / iMessage、Instagram、TikTok |
| 支付 | 支付宝转账 | Venmo、Zelle、wire transfer（视金额） |
| 报警 / 法律 | 110、派出所、律师函 | 911、police station、cease-and-desist letter |
| 证件 | 房产证、户口本 | property deed；户口本无对应，按剧情功能换成身份或亲缘证明 |
| 地点 | 上海 / 北京 / 深圳 | Los Angeles / New York / San Francisco |
| 宴请 | 包厢、茅台、火锅 | private dining room、whiskey / wine、dinner party |
| 金额 | 1000 万 | 约 $1.5M（**按当时汇率和城市房价重算**，台词用口语「a couple million」） |

- 美国人物也可以是华裔、喝茶、吃火锅；只换确实会出戏的部分。
- 法律、继承、股权、医疗等制度性情节按目标地区核实，不要把直译当事实。
- 人名、姓氏按目标文化起；同一部剧里命名风格统一。名字确定后写进人物小传，`who` 逐字使用。

**华语市场**（`zh-TW`、`zh-HK`、`zh-SG`、`zh-MY`）：台湾、香港用繁体字和当地用词（「捷运」「的士」「便利店 / 超商」），新马用简体但有本地词汇；货币、学制、节日按当地。

## 4. 英文台词

- **口语、短、带缩写**：「I'm not signing this.」不要「I will not sign this document.」
- 不要直译中文俗语和四字成语；找功能相同的英文说法，或者干脆用动作表达。
- 称呼按关系：直呼名字为主；「Mr. / Ms.」只用在职场距离或刻意冷淡时。
- 骂人和威胁要具体、有身份感，不堆脏话；平台尺度按具体平台。
- 英文语速约 2.5–3 词/秒，一句 15 个词就要 6 秒以上的镜头，长句拆开。
- 一个片段里的台词保持一种语言（模型在一个生成里切换语言容易口音混乱）。

## 5. 尺度与合规

亲密关系须双方成年、选择清楚；用职权、债务或魔法代替同意不可写成浪漫。暴力写受力结果。宗教、种族、真实机构不做娱乐化反派。具体平台规则不清楚时标「待核」，不臆造禁令，也不默认「海外更宽松」。

## 出海检查

- [ ] 题材主卡明确，钩子在目标观众的文化里成立？
- [ ] 人名、地点、货币、机构、通讯方式本地化，剧情功能没丢？
- [ ] 金额按当前汇率重算，制度性情节核实或标待核？
- [ ] 台词口语、短，一个片段一种语言？
- [ ] 付费墙位置按目标平台，不照搬单一数字？

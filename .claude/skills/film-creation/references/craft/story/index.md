# 故事

把"我想拍一个关于 X 的片子"变成可执行的冲突链、人物选择与场次。

## 本模块解决什么问题

故事层不生产灵感，它做三件判断：这个想法有没有一个让人想知道结果的钩子；冲突是否升级到人物再也退不回去的那一刻；每一场戏是否改变了局面并把下一场变成必然。三件事对应五个子文件，从前提一直落到叙事视点。

模块只回答"必须发生什么变化"，不规定机位、走位和景别。那些属于调度与视觉层。故事与风格冲突时，故事优先；风格不能替代一场戏里谁想要什么、什么变了。

## 先读哪篇

先读 `03-structure.md`：先定不归点，才知道前面要建置什么、中间每一步往哪推。读完再按问题选读其余篇。只有一句想法、还没成型，从 `01-premise.md` 开始。

## 子文件怎么选

按你卡住的位置选，不要从头读到尾。只有一句模糊想法，读 `01`；人物像说明书、配角比主角抢戏，读 `02`；写到第二幕后半段失去方向、分幕像硬切，读 `03`；单场戏好看但整体不动、台词一直在解释，读 `04`；观众不知道在跟谁看、闪回和现在分不清，读 `05`。一次最多读两篇：先读判断问题的那篇，再读它指向的相邻篇。

## 子文件

| 文件 | 解决什么 | 关键概念 |
|---|---|---|
| `01-premise.md` | 判断这个想法值不值得写、能不能一句话说清 | 钩子、稳赚因素、视点、议题 |
| `02-character.md` | 人物扁平、配角多余、对手不成立 | 障碍—选择、逆向工程、功能位 |
| `03-structure.md` | 第二幕塌、不知道怎么分幕、结局无力 | 不归点、第一幕落幕、九分钟路标、三段式/四段式 |
| `04-scene.md` | 单场戏不成立、台词解释太多、场与场接不上 | 展示、潜台词、并置、转折—展示—转折 |
| `05-narrative.md` | 视点乱、旁白多、闪回与现在分不清 | 视点、聚焦、暗隐叙述者、加叙、心理时空 |

## 路由

- 只有一句想法 → `01`
- 人物像说明书 → `02`
- 写到第二幕后半段没方向 → `03`
- 单场戏好看但整体不动 → `04`
- 观众不知道在跟谁看 → `05`

## 使用边界

模块内的规则来自五本书的章节，引用见 `_sources.md`，合并后见 `craft/sources.md#story`。不写通用鼓励语；没有出处的规则不进入本模块。故事层只决定"必须发生什么变化"，不规定机位与走位。

# 叙事技巧

视点、聚焦、闪回的基本判断见 `craft/story/05-narrative.md`；结构的骨架（不归点、beat）见 `craft/story/03-structure.md`。本篇查的是具体技巧：叫什么、怎么用、在 AIGC 里落到哪一镜、哪个资产。

每条按同一格式写：

- **是什么**：一句话定义。
- **作用**：观众因此得到什么。
- **落到产物**：在 beat 表、分镜、资产表里具体怎么做。
- **用 / 不用**：什么时候选它。
- **失败**：常见的用坏方式。
- **短剧**：竖屏短剧里的写法（有差异时）。

**一条总规则**：技巧服务于观众和人物之间的**知识关系**——观众比人物知道得多、一样多、还是少（`craft/story/05-narrative.md`；《电影叙事学研究》附录二）。用一个技巧之前，先说清它改变了谁知道什么。

## 1. 信息的分配

### 伏笔与回收 Setup / payoff
- **是什么**：前面让观众看到一样东西或一个信息，后面它变得关键。只出现一次、后面用不上的重要物件，就是没有回收的伏笔。
- **作用**：结局让人意外，回头看又必然（《编剧的策略》2.5 惊奇与必然）。也是治「靠巧合解决」的主要办法（`writing/doctor.md` #11）。
- **落到产物**：伏笔物件进资产表，有参考图；**至少出现两次**：一次建立（插入镜或在背景里清楚可见），一次回收。回收镜头的构图最好呼应建立镜头，观众才会连起来。
- **用 / 不用**：每个能解决问题的工具、每个反转的依据，都要在前面埋好。伏笔太明显（特写 + 音乐重音），观众会提前猜到——让它出现在一个「别的事情正在发生」的镜头里。
- **失败**：伏笔埋了没回收；回收时观众已经忘了（中间隔太久，没有第二次提醒）。
- **短剧**：伏笔可以跨集，但回收那集要有一个画面提示（物件再次出现、一句台词回扣），不能指望观众记得三集前的细节。

### 戏剧反讽 Dramatic irony
- **是什么**：观众知道人物不知道的事。
- **作用**：观众看着人物一步步走向他看不见的危险或真相——每一句无心的台词都有了双重意思。
- **落到产物**：先给观众一个人物不在场的镜头（反派在密谋、礼物里藏着窃听器），再回到人物。之后人物的台词可以写得天真，观众自己会听出另一层（`writing/dialogue.md` §1）。
- **用 / 不用**：悬念、悲剧、喜剧都好用。真相揭晓的那一刻，镜头要给人物的反应，因为观众早就知道了。
- **失败**：观众知道的信息太模糊，反讽不成立；或者人物蠢到不合理才不知道。

### 误导 Misdirection / red herring
- **是什么**：先用线索把观众的期待引向 A，再揭示更合乎逻辑的 B。书里叫「虚假的可怕之事」（《剧本结构设计》第 10 章 论转折）。
- **作用**：反转的前提。观众被骗了，但回头看，真相的线索一直都在。
- **落到产物**：误导线索要比真线索**更显眼**（特写、音乐、人物的怀疑台词）；真线索放在背景里、放在别的事情发生时。两组线索都进资产表，标明哪个是真的。
- **用 / 不用**：悬疑、反转。误导必须公平——真相的线索要真的出现过。
- **失败**：真相没有任何线索，观众觉得被作者骗了，而不是被故事骗了。

### 麦格芬 MacGuffin
- **是什么**：人物拼命争夺的东西，但它到底是什么并不重要（一个箱子、一份文件、一个密码）。（行业惯例）
- **作用**：给人物一个清楚的目标，让戏集中在争夺和关系上，而不是解释这个东西。
- **落到产物**：一个外形鲜明、容易认出的道具资产，每次出现都一样。不需要解释它的内容。
- **用 / 不用**：类型片、短片。观众开始追问「里面到底是什么」时，说明戏不够好看。
- **失败**：花很多时间解释它是什么、怎么来的；或者它在各镜里外观不一，观众认不出是同一样东西。

### 延迟揭示 Delayed reveal
- **是什么**：先给结果或反应，后给原因。
- **作用**：观众带着一个问题看下去。
- **落到产物**：先给人物的反应镜（她看见了什么，脸色变了），过一两镜再给她看到的东西（`camera/recipes/suspense.md` 先反应后证据）。也可以整场戏延迟：开场给结果，后面倒回去讲原因。
- **用 / 不用**：悬疑、开场钩子。延迟太久观众会失去耐心——短片里一个问题最多悬置全片的三分之一。
- **失败**：答案拖到观众已经不在乎；或者揭示的东西配不上前面的等待。

### 不可靠叙述者 Unreliable narrator
- **是什么**：讲故事的人（旁白、视点人物）说的或看到的不是真相。（行业惯例；暗隐 / 明现叙述者的区分见 `craft/story/05-narrative.md`）
- **作用**：结尾的真相会改写观众对前面所有内容的理解。
- **落到产物**：旁白和画面之间留出细小的矛盾（旁白说「我们很幸福」，画面里妻子在躲他的手）。真相揭晓时，重放关键镜头的「真实版本」：同一机位、同一构图，内容不同。
- **用 / 不用**：心理惊悚、回忆、反转。需要在前面留足可以回头核对的线索。
- **失败**：前面没有任何矛盾，结尾突然说「都是假的」——观众觉得被耍了。

## 2. 时间

### 倒计时 Ticking clock
- **是什么**：一个截止时间：婚礼在明天、船一小时后开、电量只剩 5%（《编剧的策略》4.8 计时器；《短片的法则》第九章 定时炸弹）。
- **作用**：把「想做」变成「必须现在做」，每一秒都有了分量。
- **落到产物**：计时器做成画面里看得见的东西（时钟、倒计时屏幕、电量、沙漏、日落），进资产表，在片中反复出现，每次都更接近零。字和数字在图阶段做对，视频不画字；不行就后期贴。
- **用 / 不用**：追逐、营救、告白、任何需要紧张感的故事。截止时间要早早建立。
- **失败**：计时器出现一次就忘了；或者到点了也没有后果。

### 倒叙开场 In medias res / flash-forward
- **是什么**：开场先给结尾附近的一个高潮瞬间，然后回到「三天前」从头讲。
- **作用**：开场就有钩子；观众知道结果，好奇的是「怎么会走到这一步」。
- **落到产物**：开场镜头和后面真正讲到那一刻时用**同一个镜头**（同一张关键帧），观众会认出来。中间用字卡或声音标出时间跳跃（字卡在剪辑阶段加）。
- **用 / 不用**：开场太慢、前面需要较多铺垫时（`writing/doctor.md` #8）。短剧非常常用。
- **失败**：开场给的瞬间太完整，后面没有悬念；或者回到开场那一刻时和开场对不上。

### 闪回 Flashback
- **是什么**：插入过去的片段。基本判断见 `craft/story/05-narrative.md`。
- **作用**：揭示动机、创伤或真相。
- **落到产物**：闪回至少改两项视觉 / 声音元素（色温、颗粒、焦段、声音混响），同一部片里所有闪回用同一组设定（`craft/story/05-narrative.md` AIGC 执行第 5 条）。人物在闪回里的造型是单独的资产（年轻版、旧发型）。
- **用 / 不用**：闪回要在观众**想知道**的时候出现，回答一个已经提出的问题。为了交代背景而闪回，等于把交代换了个形式。
- **失败**：闪回和现在时视觉上分不开，观众不知道时间跳了；闪回里的信息观众早就猜到了。
- **短剧**：「重生前」「前世」这类闪回是造型的变体，需要单独的造型图（`references/drama/05-breakdown.md`）。

### 非线性 / 多视角重复 Non-linear / repeated perspective
- **是什么**：打乱时间顺序；或者同一事件从不同人物的视角讲几遍，每遍都多一点信息。（行业惯例）
- **作用**：观众自己拼图；同一件事的意义随视角改变。
- **落到产物**：重复的事件用同一个场景资产、同一组关键帧，只改视点（谁的主观镜头、谁在画面中心）和新增的细节。观众要能认出「这是同一刻」。
- **用 / 不用**：悬疑、关系片。片子越短越难用：90 秒以内最多重复一次。
- **失败**：重复时没有新信息，观众只觉得在看重播；时间线乱到观众不知道「现在」是哪一刻。

### 闭环结构 Bookend
- **是什么**：结尾回到开场的场景、画面或台词，但意义变了。
- **作用**：故事有了完整感；开头和结尾的差别就是人物的变化。
- **落到产物**：结尾镜头以开场关键帧为参考图生成，构图不变，状态改变（`camera/recipes/opening-ending.md` 回到开场机位）。
- **用 / 不用**：短片最可靠的结尾手法之一。
- **失败**：开场和结尾一模一样，人物没有变化；或者结尾镜头构图偏了，观众没认出是在回到开场。

## 3. 结构与对照

### 并置 Juxtaposition
- **是什么**：两个看似无关的东西放在一起，关系就出来了（《21天搞定电影剧本》2.5 并置的力量）。
- **作用**：不解释，让观众自己连线。
- **落到产物**：两种方式：同框（`the wedding ring lies on top of the unpaid bill`，`craft/story/04-scene.md`），或相邻两镜硬切（豪宅的宴会 → 外卖员在雨里等电梯）。
- **用 / 不用**：主题表达、阶级对比、讽刺。并置的两样东西要都具体。
- **失败**：两样东西的对比太直白（「富人吃牛排、穷人吃馒头」），变成说教。

### 镜像场景 Mirror scenes
- **是什么**：两场戏结构相同、位置相反：第一场 A 求 B，最后一场 B 求 A。
- **作用**：人物的变化和权力的交换一目了然。
- **落到产物**：两场用同一个场景资产、同样的机位和构图，只交换人物的位置（`camera/intent.md`「权力反转」）。台词可以回扣（`writing/dialogue.md` §6）。
- **用 / 不用**：复仇、成长、关系反转。短剧的「追妻火葬场」就是一整季的镜像结构。
- **失败**：两场之间相隔太远、构图又不一样，观众连不起来；或者交换位置没有经过足够的过程，翻盘显得廉价。

### 交叉叙事 Parallel storylines
- **是什么**：两条或多条故事线交替推进，最后汇合或形成对照。
- **作用**：同时发生的紧张（营救），或两种命运的对比。
- **落到产物**：每条线的视觉要能一眼区分（不同的场景、色调、时段）；越接近汇合，交替越快（`camera/lexicon-transition.md` 交叉剪接）。资产按线分组。
- **用 / 不用**：90 秒以内最多两条线；短剧单集一般只走一条主线。
- **失败**：两条线没有因果或主题上的联系，观众不知道为什么要来回切。

### 框架叙事 Frame story
- **是什么**：一个外层故事包着内层故事：一个老人对孙女讲他年轻时的事。（行业惯例）
- **作用**：给内层故事一个讲述的理由和情感视角；结尾可以回到外层，揭示讲述者的身份或目的。
- **落到产物**：外层和内层用两套视觉设定（同闪回的区分方式）。外层场景只要一个，戏份少。
- **用 / 不用**：回忆、传说、证词。外层不能只是装饰——它要在结尾提供一个转折或意义。
- **失败**：外层只是开场和结尾各一个镜头的装饰，删掉也不影响；外层和内层视觉分不开。

### 反转 Twist
- **是什么**：一个新信息让观众重新理解前面的一切。
- **作用**：惊奇 + 必然：意外，但回头看所有线索都指向它（《编剧的策略》2.5）。
- **落到产物**：反转依赖误导和伏笔（见上）。反转揭晓后，用两三个闪回镜头快速重放前面的关键线索，帮观众完成「原来如此」——这几个镜头直接复用之前的关键帧。
- **用 / 不用**：一部短片一个大反转就够；短剧可以每集一个小反转，但要层层升级（`camera/recipes/reversal.md` 连环反转）。
- **失败**：为反转而反转，没有线索；反转之后人物的行为变得不合理。

### 转折与停顿 Turn and settle
- **是什么**：一次转折后给观众一个停顿，消化新现实；观众刚适应，再用更强的转折击中。书里把观众对刺激的适应叫享乐适应（《剧本结构设计》第 10 章）。
- **作用**：控制节奏，让每一次转折都比上一次更有力。
- **落到产物**：转折之后接 2–4 秒低运动的反应镜或环境镜；停顿里放必要的交代（`craft/story/04-scene.md` 转折后留停顿）。
- **用 / 不用**：所有有多次转折的故事。转折一个接一个不停顿，观众会麻木。
- **失败**：停顿太长，节奏塌了；停顿里放新的转折，等于没有停。

## 4. 母题与象征

### 视觉母题 Visual motif
- **是什么**：一个物件、颜色、动作或画面在片中反复出现，每次意义都推进一点。
- **作用**：把分散的场景缝成一个整体；不用台词就能表达人物的变化。
- **落到产物**：母题物件进资产表；在 beat 表加一列「母题状态」：第一次完整，第二次有裂痕，最后一次碎了或被修好。每次出现都给它一个清楚的镜头。
- **用 / 不用**：短片最好只有一个母题。母题太多，观众一个都记不住。
- **失败**：母题只是重复出现，状态从不改变——那只是道具，不是母题。

### 象征物 Symbol
- **是什么**：一个具体的东西代表一个抽象的意义：笼中鸟、枯萎的花、断掉的风筝线。书里讲人生的隐喻（《21天搞定电影剧本》3.13）。
- **作用**：让主题有画面。
- **落到产物**：象征物必须首先是故事里真实存在、有功能的东西（她真的在养那只鸟），而不是突然出现的意象。
- **用 / 不用**：越自然越好。观众一眼就看出「这是象征」时，它就俗了——换一个更具体、更个人的物件。
- **失败**：象征物凭空出现，只为表达主题；或者用台词点破它的意义。

### 回扣 Callback
- **是什么**：前面出现过的一句台词、一个动作、一个笑话，在后面换情境再出现，意义变了。台词回扣的写法见 `writing/dialogue.md` §6。
- **作用**：观众认出来的那一刻有满足感；喜剧里是第二次笑点，正剧里是情感重击。
- **落到产物**：回扣的台词逐字一致；动作回扣用同样的构图。
- **失败**：回扣的台词措辞变了，观众没认出来；或者第一次出现时太不起眼，回扣时没有人记得。

## 5. 人物关系

### 陪衬 Foil
- **是什么**：一个和主角形成对比的人物，让主角的特点更清楚（《编剧的策略》4.9 陪衬）。
- **作用**：不用解释主角是什么样的人，看他和陪衬的差别就知道。
- **落到产物**：陪衬和主角在同一场里出现，面对同一件事做出不同反应。声口表里两人的「句长」「用词」要明显不同（`writing/dialogue.md` §4）。
- **用 / 不用**：主角性格需要被看见时。陪衬不需要自己的完整弧线。
- **失败**：陪衬只是一个工具人，出场就为了被主角比下去；两人声口一样，对比出不来。

### 亲密对手 Intimate opponent
- **是什么**：对手是主角爱的人或亲近的人（《编剧的策略》2.4）。
- **作用**：冲突没法用打败对方解决——赢了也是输。
- **落到产物**：对手和主角至少有一场温情的戏，在冲突爆发之前，让观众知道两人失去的是什么。
- **失败**：没有温情的前史，冲突只是普通的对抗；或者和解来得太轻易，前面的伤害像没发生过。

## 6. 结尾

### 开放式结尾
- **是什么**：故事停在人物做选择之前，或结果未知。
- **作用**：观众带着问题离开，自己完成故事。
- **落到产物**：停在特写，固定机位，切黑；不要用远景收尾——远景是句号（`camera/recipes/opening-ending.md`）。
- **用 / 不用**：前面的问题必须已经清楚——开放的是答案，不是问题。观众不知道问题是什么，那不是开放，是没讲完。
- **失败**：用开放式掩盖没想好的结局；或者最后一镜用远景和完整的音乐收尾，观众以为故事结束了。

### 虚假结局 False ending
- **是什么**：故事看起来结束了，接着又来一个转折。（行业惯例）
- **作用**：观众放下防备后再击中一次。
- **落到产物**：虚假结局用标准的结尾镜头（拉远、音乐收尾），然后硬切到新信息。
- **用 / 不用**：惊悚、恐怖、短剧的季末。一部片最多一次。
- **失败**：假结局本身不像结局（音乐、镜头都没收），观众早知道还有；或者后面的新信息没有前面的伏笔，像硬加的。

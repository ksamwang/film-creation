# 人物：把 want / need / flaw 写成可观察动作

## 核心判断

人物在 AIGC 里有两层：固定 token 保证“一直是同一个人”，动作 token 保证“在压力下做出选择”。只有前者是模特，只有后者每镜变脸；两层都锁，观众才相信他有内在生活。

## 书里的原则

**动态人物：障碍逼出选择，选择揭示内在生活（《剧本结构设计》第 6 章）。** 奥班农引霍华德与马布里：电影不能叙述内心，只能让人物在障碍前作选择。生成时别写“她很矛盾”，写她伸手又收回、把杯子推远、视线避开对方的手；模型能画动作，画不了心理。

**逆向工程（《编剧的策略》第 3 章 3.1）。** 从钩子倒推人物：钩子通常已含主角和对手。对手是主角的硬币正反面——共享议题，答案相反。AIGC 里要写成视觉对照：同构图、反打、冷暖两套光，而不是给对手加更多坏行为。

**功能位与扁平人物（同章）。** 删掉一个配角，如果没有哪个镜头不成立，就不给他建资产。只做情节需要的事的人物是扁平的，生成出来“动作正确但没有细节”。

**记忆点：矛盾与标志。** 塞格在《Creating Unforgettable Characters》里说，过于一致的人物记不住，让人记住的是矛盾：温和的人也会动手。契诃夫的心理姿态，是把人物最核心的需要做成一个外在动作。拉班用重、轻、急、缓描述人物动起来的质感。AIGC 里，这些都要落成可见的标志。

**选择与对立统一（`references/dramaturgy.md` §2 第 4–6 条）。** 性格是取舍；对手和主角一样强，两人被走不掉的纽带绑住。

**声音（《21天搞定电影剧本》3.9）。** 音色和语速一变，同一句台词的意思就变。

## AIGC 执行

1. **C1 资产。** 先出定稿参考图，再按 `年龄 → 体型 → 脸 → 发型 → 服装 → 配饰 → 疤痕` 写描述；有图时正文不重写外貌、只留 2–4 条识别特征锁，纯文本时逐字复用。
2. **want / need / flaw 各写一个动作。** want 是带宾语的动词句（“把钥匙放进口袋”）；need 是他回避的东西（“不看墙上的照片”）；flaw 是压力下重复的微动作（“先摸左眉的疤”）。三条都进动作 token。
3. **对手做镜像。** C2 与 C1 共享一个视觉特征（同款外套、同种站姿、同焦段），再用相反的光色与构图方向区分。各挂参考图、写清谁在画左谁在画右，防止模型把两人合成一张脸。
4. **记忆点。** 主要人物写五样：一处矛盾（落在哪一场）；核心动作与动作质感（乔生：重、直、急；连城：轻、迂回、缓）；一个标志动作、物件或口头禅，出现三次，最后一次有变化；出场第一个动作；音色。写进 `templates/character-sheet.md`，按资产锁定。
5. **压力写成 beat。** 每个 beat 拿走一条退路：门被关上、手机被收走、最后一个盟友离开。人物在 beat 里的选择必须改变下一镜的空间关系。
6. **多人物靠参考图区分。** 同框镜头每人挂参考图、写清在画面哪侧。失败模式：`merged faces | feature bleed`。
7. **声音定基调。** C1、C2 各写一句声音描述，原生对白时写进视频提示：`a low, unhurried voice with a slight northern accent`。对白不随意换语域。

## 检查清单

- [ ] 主角在压力下做过的哪个选择，能在一个镜头里看见？
- [ ] want、need、flaw 是否各有一个可画的动作，而不是形容词？
- [ ] 对手与主角是否共享一个议题，只是答案相反？
- [ ] 每个配角能否说出他推动了哪一镜、改变了什么？
- [ ] 遮住名字，能认出是谁吗？矛盾、标志、出场动作有没有落到镜头里？
- [ ] C1 / C2 的固定 token 是否逐字复用，没有同义改写？
- [ ] 多人同框是否每人有参考图和画面位置，防止特征污染？

## 常见错误

- **在人物 token 里写小传。** 后果：注意力被分走，脸和服装反而不稳。替代：小传留在 beat sheet，token 只留身份与外观。
- **用“悲伤”“愤怒”当动作。** 后果：模型给通用表情，每镜强度不同。替代：写手、眼、呼吸、重心、距离。
- **对手只是“更坏的坏人”。** 后果：冲突变成音量比赛。替代：让对手回答同一个问题，答案相反。
- **标志写成怪癖。** 后果：和剧情无关，像贴上去的。替代：从处境和欲望里长出来，最后一次出现时用来做决定。

## 与风格层接口

人物的“障碍—选择”交给表演层，写成 action token，不写情绪形容词。主角与对手的镜像关系交给视觉层：同构图、反打、冷暖两套语法；风格层只取强化对照的 2–3 条约束。功能位决定景别：密友给反应，解说者给插入物或画外音，跟班只在中景和全景。voice token 与视觉 token 一起锁进资产表；台词与动作冲突处用近景或插入剪辑。

# Shot Prompt List（生成清单）

> 分镜脚本（`storyboard-script.md`）按剪辑顺序写；生成清单把同一批镜头**按场景 / 时段 / 资产重排**，镜号不变。同一批次连着生成，一致性最好。
> 模式：A 自然语言 / B token 块（`references/aigc/prompt-syntax.md`）。生成方式见 `references/aigc/workflow.md`。

## 进度

| 镜号 | 关键帧 | 视频 | 版本 | 选用 | 备注 |
|---|---|---|---|---|---|
|  | 待出 / 通过 / 退回 | 待出 / 通过 / 退回 | v1 |  |  |

- 状态只用这几个词：待出、通过、退回、定稿。
- 版本按镜号记：`5-03_v2`；退回时在备注写原因（脸漂、方向反、字错、动作糊），下次迭代对症改提示词或换备选。
- 迭代到预算上限仍不通过的，换分镜脚本里的备选方案，不要继续抽卡。

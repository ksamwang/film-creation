### 拆解、分镜、提示词、成片（05–08）

| 规则 | 来源 | 等级 |
|---|---|---|
| 造型 = 一张参考图；按剧情阶段拆形象；无道具 | JM | 产品观察 |
| 场景先出全视图母版，各视角从母版派生、逐张核对 | ZS 2026-11-06 | 实测 |
| 参考图挂 7 张不比 3 张差；必须认得出的道具挂图有用 | ZS Seedance 2.0 | 实测 |
| 参考图超限时的取舍顺序 | ZS 2026-10-20 | 编辑归纳 |
| 5 秒内能看清约 2–3 个动作；多写不会被删，会被压扁 | ZS Seedance 2.0 | 实测 |
| H3 中文自然语速约 4.1 字/秒；Wan 3.0 约 4.6 字/秒；超量会赶词或截断 | ZS | 实测 |
| 对白镜比计划多约 1.5–2.5 秒（开口延迟 + 说完） | ZS H3 | 实测 |
| 口型落到画面里最显眼的正脸；让非说话人背对或出画更稳 | ZS H3、Wan | 实测 |
| 前后深度按机位写；站位锚点必须存在于场景图里，否则模型会凭空造物 | ZS Seedance 2.0/2.5 | 实测 |
| 只有身份/地点参考时写具体取景，否则景别偏宽 | ZS H3 | 实测 |
| 尾帧锁构图不保证动作做完；镜内变化默认只给首帧 | ZS Seedance 2.0 | 实测 |
| 用上一段真实尾帧续接，开场连续性显著更好 | ZS H3 | 实测 |
| 反应镜写法因模型而异（H3：点名情绪 + 两处可见泄露；Seedance：可见反应链） | ZS | 实测 |
| 音色参考有作用但不稳定，生成后逐镜核对 | ZS Seedance 2.5、Wan 3.0 | 实测 |
| 「无背景音乐」「无字幕」不能完全保证，生成后检查 | ZS；火山引擎 Seedance 指南 | 实测 |

# 同一场戏的三种拆法

同一场戏可以拆成 3 镜，也可以拆成 18 镜。镜头数不只是节奏问题，也是**导演态度**：观众离人物多近、导演替观众选择多少、给观众多少自由。在 AIGC 里，它还决定生成次数、风险和返工成本。

下面用 `breakdown.md` 的场 5（林晚发现报告被改、顾言送咖啡）做三种拆法。经典覆盖的完整分镜脚本见 `breakdown.md`。

---

## A. 经典覆盖：13 镜，平均约 3.2 秒

建立 → 视线组 → 关系 → 正反打 → 反应 → 插入 → 拉开。镜号与内容见 `breakdown.md` 的示例表。

- **观众感受**：清楚、被引导。观众在每一刻都看到导演认为最重要的东西。
- **导演控制**：最高。节奏、重点、台词落在谁脸上，全部在剪辑里决定。
- **适合**：大多数叙事片、短剧、广告；观众需要准确接收信息的场景。

## B. 长镜头：3 镜，平均约 13 秒

| 镜号 | 运镜 | 画面 | 时长 |
|---|---|---|---|
| 5-L1 | 缓慢推近 | 从办公区全景推到林晚的肩后，屏幕和打印稿进入画面；她点开修订记录，画面停在屏幕上 | 15 s |
| 5-L2 | 固定 | 中景双人，林晚侧对镜头；顾言从画右走入，放下咖啡，两人完成全部对话；他的笑和她的沉默在同一个画面里 | 15 s |
| 5-L3 | 缓慢后拉 | 前景是那杯咖啡，后景两人隔桌；顾言离开，林晚不动，画面拉远到全景 | 10 s |

- **观众感受**：真实、压抑、像在现场旁观。观众自己决定看谁，紧张来自「不能移开视线」。
- **导演控制**：剪辑里几乎没有调整空间，一切在镜头内完成：走位、时机、焦点。
- **适合**：作者风格、现实题材、需要表演连续性的情绪戏（`directors/bela-tarr.md`、`directors/hou-hsiao-hsien.md`、`directors/cristian-mungiu.md`）。

**AIGC 里的长镜头最难。**

- 多数视频模型一次只出 4–10 秒，超过上限的长镜头要靠续接拼接，接缝处容易跳。
- 镜头越长，人物、光线、道具越容易漂移。
- 两人同框完成整段对话，违反一镜一个说话人，口型风险最高；常见做法是台词后期配音，生成时只要求表演。
- 一处失败要整镜重来，返工成本是切镜的好几倍。

## C. 碎切：18 镜，平均约 2.3 秒

| 镜号 | 画面 | 时长 |
|---|---|---|
| 5-F01 | 台灯开关被按下，光亮起 | 1.5 s |
| 5-F02 | 林晚的眼睛，屏幕光映在瞳孔里 | 2 s |
| 5-F03 | 鼠标滚轮滚动 | 1.5 s |
| 5-F04 | 屏幕上的数字 | 2 s |
| 5-F05 | 打印稿上的数字，她的手指按在上面 | 2 s |
| 5-F06 | 她的眼睛，停住 | 1.5 s |
| 5-F07 | 修订记录「顾言 21:47」 | 2.5 s |
| 5-F08 | 走廊尽头电梯门打开（声音先行） | 2 s |
| 5-F09 | 皮鞋踩在地毯上 | 1.5 s |
| 5-F10 | 两杯咖啡在他手里晃 | 1.5 s |
| 5-F11 | 咖啡被放在她桌上 | 1.5 s |
| 5-F12 | 顾言：还没走？明天汇报别太紧张。 | 4.5 s |
| 5-F13 | 她的手把屏幕转过去；林晚：第七页，是你改的？ | 3.5 s |
| 5-F14 | 他的眼睛扫过屏幕 | 1.5 s |
| 5-F15 | 他的嘴角动了一下 | 1.5 s |
| 5-F16 | 顾言：数据不好看，我帮你调了一下。汇报的时候，你照着念就行。 | 6.5 s |
| 5-F17 | 咖啡的热气 | 2 s |
| 5-F18 | 她的手，停在杯子旁边 | 2 s |

- **观众感受**：紧张、主观、碎片化。观众被细节包围，像在惊悚片里。
- **导演控制**：很高，但重点在节奏而不在表演；人物的整体状态被拆碎了。
- **适合**：惊悚、犯罪、动作、广告、MV；人物关系不是重点、氛围和节奏是重点的时候（`directors/david-fincher.md`）。

**AIGC 里的碎切**：大部分是物件和局部特写，单镜很稳，脸少，一致性压力小；但生成次数最多，每镜短于模型一次的最短输出，大部分素材会被剪掉。

## 对比

| | A 经典覆盖 | B 长镜头 | C 碎切 |
|---|---|---|---|
| 镜头数 | 13 | 3 | 18 |
| 平均镜长 | 约 3.2 s | 约 13 s | 约 2.3 s |
| 观众位置 | 被引导 | 旁观、自己选择 | 被包围、主观 |
| 表演 | 分段完成，靠剪辑组合 | 连续完成 | 被拆成局部 |
| 剪辑弹性 | 高 | 几乎没有 | 高 |
| 生成次数（不含重试） | 13 | 3（续接时更多） | 18 |
| 单镜风险 | 低—中 | 高 | 低 |
| 返工成本 | 一镜一镜重做 | 整镜重来 | 一镜一镜重做，最便宜 |
| 一致性压力 | 中（几张脸反复出现） | 高（时间越长越漂） | 低（脸少，物件多） |
| 适合 | 叙事、短剧、广告 | 作者风格、现实题材、情绪戏 | 惊悚、动作、广告、MV |

## 怎么选

1. **先看类型和全片风格**（`writing/genres/`、导演档案）。一部片子里拆法要统一；风格突然变化时，要有理由（比如全片覆盖，只在高潮用一个长镜头）。
2. **再看这场戏的任务**。信息交代用覆盖；表演连续性最重要的情绪戏可以用长镜头；氛围和节奏优先用碎切。
3. **最后看预算和模型**。模型单次时长短、续接不稳时，长镜头改成「伪长镜头」：两三个长度贴近上限的镜头，用遮挡或动作做隐藏剪辑点。

**混用是常态**：一场戏用长镜头开场（建立空间和氛围），在转折处切成覆盖（把重点交给观众），结尾再回到一个长的拉远。三种拆法是工具，不是门派。

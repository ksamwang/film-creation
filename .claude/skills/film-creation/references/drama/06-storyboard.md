# 分镜：把一集切成片段

> 产物：P6 storyboard（`standard.md`）。片段会被机械编译成提示词（P7），所以分镜写成什么样，生成就是什么样。
> 通用的拆镜方法（读戏、镜头数、镜头功能、台词落在谁脸上）见 `references/storyboard/`；短剧的片段切分、字段和枚举以本篇为准。
> 一句话：**片段是一次生成；同一场景塞满时长上限，每个分镜写清站位、从起点到落点的动作和谁在说话。**

## 1. 切片段

| 规则 | 说明 |
|---|---|
| 一个片段只在一个子场景里 | 换场景就开新片段 |
| **按上限塞满** | 同一场景的连续镜头装进同一个片段，目标「上限前 2 秒到上限」（15 秒档 → 13–15 秒） |
| 只在三种情况下提前结束 | 换场景；再加一镜超过 8 镜；再加一镜引用的造型数超过参考图上限 |
| 一个场景的最后一段可以短 | 比如 15 / 8.5 / 14.5，中间那段是办公室这场戏剩下的部分 |
| 不要瞎拆 | 相邻两段同场景、合起来放得下 = 必须合并：多一次生成，还打断了模型在一个视频里保持的连贯 |

**为什么塞满**：一个片段内部的人物、光线、空间是模型连续保持的；片段之间要靠参考图重新对齐，每多切一次就多一次漂移的机会。

**引用上限**：一个片段引用的造型数（**含场景**）≤ 模型的参考图上限。三个角色 + 一个场景就要 4 张。超了就拆段，或者让某个角色这段不入画。

## 2. 分镜时长怎么估

| 内容 | 估法 |
|---|---|
| 台词 | 中文 ÷ 4 字/秒（快念 ÷ 5.5），英文 ÷ 2.5–3 词/秒，**再加 1–2 秒**：模型开口有延迟，说完还要落一拍 |
| 动作 | 3–5 秒能看清 **2–3 个**连续动作；写多了不会被删，会被压成半秒一个、前后叠在一起 |
| 反应 | 1.5–3 秒：触发 → 情绪落到脸上 → 定住 |
| 建立 / 过渡 | 2–3 秒 |

一个分镜通常 2–5 秒，对白镜 4–8 秒。一句台词放不下就拆成两句分给两个镜头，不要靠「快速地说」硬塞。

## 3. 分镜文字（`text`）怎么写

每个分镜写一个**主导变化**：从起点开始，按顺序发生什么，最后停在哪。

```text
起点：谁在哪、朝哪、手里拿着什么
→ 动作：触发 → 谁做什么 → 碰到什么
→ 落点：停在什么姿态、什么位置、视线看哪
```

**站位**

- 左右用**画面方位**写：「@[林晚 · 基础形象] 在画左」「从画右走入」「看向画右」。
- 前后深度按**机位**写：「她走进前景，背对镜头停在桌子这一侧，桌子在两人之间」。只写「隔桌相对」时，模型常把两人放在桌子同一侧。
- 写人和锚点的距离：「站在沙发旁，右手搭在沙发靠背上」「停在他面前一臂远」。
- **锚点必须在场景图里**。写了场景图里没有的书架，模型会凭空造一个，每次还不一样。
- 同一场戏里没走位的人，跨镜保持在锚点的同一侧；轴线不变，单人反打保持各自朝左或朝右的视线。

**说话人与口型**

- 模型会把口型安到画面里**最显眼的正脸**上。一镜只有一个人说话；其他入画的人背对、侧脸、虚化或出画最稳。
- OS（内心独白）时，让说话人的嘴不在画面里（背影、手部特写、反应镜），只靠「嘴唇闭合」的文字约束不可靠。
- 台词只放进 `dialogue`，不要在 `text` 里再写一遍「她说……」。

**表情与反应**

- 写可见的泄露，不写抽象情绪：「下巴绷紧，盯着他看了两秒，才把视线移开」。
- 不同模型对反应镜的偏好不同：有的模型「点名情绪 + 两处可见泄露 + 一个落点」最好，有的模型「逐段可见反应链」最好。写法细节见 `07-segment-prompt.md`。

**物件与状态**

- 一个状态只改变一次：钥匙放下归一个镜头，拿回归另一个镜头，中间的镜头里它一直在桌上。
- 道具在谁手里、在哪，跨镜继承。画外不等于消失。

**不要写进 `text` 的**

- 景别、角度、运镜：放进 `size` / `angle` / `move`。
- 画幅、风格、画质词、模型参数。
- 否定堆叠（「不要模糊、不要变形」）；想要什么就正面写什么。
- 剧情解释和人物内心（「她其实早就知道」）——模型画不出来。
- 造型的外貌描述：`@[造型名]` 已经带着图，文字只写这一镜的动作和状态，重复外貌会和图打架。

## 4. 景别、角度、运镜与竖屏构图

| 字段 | 竖屏常用 | 说明 |
|---|---|---|
| `size` | `medium_close`、`close`、`medium` 为主 | 竖屏的主角是脸和手；远景少用，画面两侧窄，空间靠纵深 |
| `angle` | `eye_level` 为主；权力关系用 `low` / `high`；对话用 `over_shoulder` | 角度服务关系，不为变化而变化 |
| `move` | 对话用 `static`；情绪推进用 `push_in`；跟人走用 `tracking` | 竖屏里复合运镜容易糊，一镜一个运动 |

**竖屏构图要点**

- 双人镜不要左右排开拉成远景，用**前后纵深**（一人前景过肩、一人中景）或上下错落。
- 脸放在画面中上部；**下方约 20% 留给字幕和平台界面**，关键动作不要放在最底下。
- 建立空间用一个中景带出锚点（桌子、门）就够，省掉纯空景。
- 景别跟着「观众要读的东西」走：读后果用中景，读证据用特写，读关系用双人。
- 只有地点参考、没有首帧时，景别容易偏宽；要近景就把取景写具体：「切在腰部，脸在画面上三分之一」。

## 5. 片段之间的衔接

- 上一段的结束状态 = 下一段的开始状态：谁在哪、朝哪、拿着什么。
- 跨场景切换时，第一个分镜交代新空间里的人物位置。
- 平台支持时，用上一段**实际生成的视频或尾帧**做续接参考，开场连续性明显好于只靠角色和场景图。
- 尾帧只锁最后一格的构图，不保证动作做完；镜内变化默认只给首帧，尾帧留给必须精确对上的转场。

## 6. 示例：一个 15 秒片段

```json
{"scene": "顾家别墅 · 客厅_夜", "shots": [
  {"duration_s": 3, "size": "medium", "angle": "eye_level", "move": "static",
   "text": "@[顾言 · 基础形象] 坐在画右沙发上，把一份协议推到茶几中央；@[林晚 · 重生前·基础形象] 站在画左茶几另一侧，双手垂在身侧。"},
  {"duration_s": 4.5, "size": "medium_close", "angle": "over_shoulder", "move": "static",
   "text": "越过林晚的左肩看向顾言，他抬眼看她，身体后靠进沙发。",
   "dialogue": [{"who": "顾言", "emotion": "冷淡", "text": "签了吧，房子留给你。"}]},
  {"duration_s": 2.5, "size": "close", "angle": "eye_level", "move": "push_in",
   "text": "林晚的脸，视线从协议移到画右，下巴一点点绷紧。"},
  {"duration_s": 5, "size": "medium_close", "angle": "eye_level", "move": "static",
   "text": "林晚俯身，指尖按在协议上，把它推回茶几中央，抬眼直视画右。",
   "dialogue": [{"who": "林晚", "emotion": "平静", "text": "这只手，昨晚也在我的首饰盒里吧？"}]}
]}
```

合计 15 秒、4 镜、引用 3 个造型（含场景）。注意：第 2 镜过肩时林晚背对镜头，口型只会落在顾言脸上；第 3 镜无台词，留给反应；协议的位置在 1、4 镜各变一次。

## 分镜检查

- [ ] 每段只在一个子场景，总时长贴近上限，没有可合并的相邻段？
- [ ] 引用造型数（含场景）≤ 参考图上限？
- [ ] 每镜一个主导变化，写了起点和落点，动作不超过 2–3 个？
- [ ] 对白镜时长 = 字数 ÷ 语速 + 1–2 秒？
- [ ] 一镜一个说话人，其他人不抢正脸？
- [ ] 左右按画面、前后按机位，锚点都在场景图里？
- [ ] 景别角度运镜在枚举字段里，`text` 没有外貌重复、否定堆叠和内心解释？
- [ ] 段与段之间人物位置和道具状态接得上？
- [ ] `scene` 和 `@[]` 里的名字与造型列表逐字一致？

交付：先给分镜表（`templates/drama-storyboard.md`），再给 JSON。镜头描述用说明语言，台词保持剧本原文。

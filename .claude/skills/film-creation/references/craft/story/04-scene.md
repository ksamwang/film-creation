# 场景：一场戏就是一个镜头序列

## 核心判断

AIGC 里，场景不是台词，而是一个 3–8 镜的序列，必须完成一次局面变化。判断只有两条：开头谁想要什么，结尾什么变了；空一条就只是素材。

## 书里的原则

**每个场景必须导致并推进下一个场景（《剧本结构设计》第 10 章 论步调）。** 奥班农提醒，光有好场景不够；场景只是好看、不能暗示下一个，叙事就断了。对应检查：这场最后一镜，是否制造了下一场第一镜的问题。

**展示规则（同章 论展示）。** 背景信息只给理解当前故事必需的部分。书里用“假耳朵”形容硬塞的展示：人物不是对彼此说话，而是对观众说话。AIGC 里最典型的假耳朵，是让角色解释设定；替代是把信息放进环境 token、道具 token 或插入镜头。

**转折—展示—转折（同章 论转折、享乐适应）。** 一次转折后要给停顿，让人物和观众消化新现实；停顿正是放入必要展示的位置。观众刚适应，再用更强的转折击中。书里还讲“虚假的可怕之事”：先用线索把期待引向 A，再揭示更合乎逻辑的 B。

**展示，不要告知；潜台词（《21天搞定电影剧本》第 3 章 3.10）。** 我们只看得到行为，看不到思维；人物常常言行不一。AIGC 的写法是让动作 token 与台词相反：嘴上说“没事”，手却把杯子攥紧。

**并置（同书第 2 章 2.5）。** 两个看似无关的句子放在一起，关系就出来了。影像里就是两个物件同框：不解释，让观众自己连线。

**一个细节同时承重（《从文本到影像》导演艺术）。** 《白色栀子花》用茶几玻璃的反光同时映出两张相爱的脸与 1930 年代上海大户人家的夜晚气氛；AIGC 里就是一个道具 token 同时承担关系与时代。

## AIGC 执行

1. **先填场景卡。** `目标（谁想要什么）| 障碍（谁挡着）| 转折（结束时什么变了）| 与全片关系`。四格填不满，不进入分镜。
2. **拆 3–8 镜。** 第 1 镜建立空间与目标；第 2 镜让障碍进入；第 3 镜转折；第 4 镜给反应；最后一镜留下下一场的问题。镜头多于此，先合并同信息镜头。
3. **展示改成可见证据。** 要交代的信息，优先放进 S1 的环境细节或 P1 的道具；必须说出口的，让台词承担人物关系，不承担设定。
4. **潜台词写成动作对照。** 台词写一套，动作 token 写相反的一套；镜头给手、给背、给空处，不给解释性的正脸。
5. **并置同框。** 两个承重物写进同一图像提示，negative 加 `separated objects | isolated prop`，防止模型把它们拆开摆。
6. **转折后留停顿。** 用 2–4 秒低运动镜头；motion token 只写 `micro movement | static camera | 3s`。停顿里放必要信息，下一次转折必须更强。
7. **“因此/但是”检查。** 两场之间能写成“因此”或“但是”的保留；只能写“然后”的，重写前一场最后一镜。
8. **声音接缝。** 用一声画外音、一个道具声或一段静默把两场缝起来；不要靠字幕交代时间地点。

## 检查清单

- [ ] 这场谁想要什么？能写成带宾语的动词句吗？
- [ ] 结束时局面具体变了什么：信息、关系、权力、位置、资源？
- [ ] 变化是人物选择造成的，还是巧合？
- [ ] 删掉这场，下一场是否仍成立？若是，为什么还留着？
- [ ] 哪句台词在向观众解释背景？能否改成可见证据？
- [ ] 人物说的和做的是否错开？潜台词落在哪个动作上？
- [ ] 转折后有没有停顿？停顿里给的信息是否必要？

## 常见错误

- **把场景当信息容器。** 后果：镜头都在说明，没有变化。替代：先写“什么变了”，再决定要哪些镜头。
- **让角色解释设定。** 后果：假耳朵，观众出戏。替代：把设定放进环境、道具或插入镜头。
- **转折后立刻切走。** 后果：观众没消化，下一次转折失效。替代：留 2–4 秒停顿，再升级。
- **并置靠台词点破。** 后果：观众被替自己想。替代：两个物件同框，闭口不解释。

## 与风格层接口

每场只交三行给调度层：谁想要什么、谁挡着、结束时什么变了；镜头序列由此生成。展示停顿是剪辑的呼吸点：此处允许较长镜头与完整空间，转折处才切碎。潜台词转成动作与镜头距离：嘴上说一套时，镜头给手、给背、给空处。给 AI 的场景提示只写可见变化，不写“紧张”“悲伤”；并置靠两个具体物件同框。

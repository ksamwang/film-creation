# 单集节奏：开场、回合与断章

> 产物：一集剧本的骨架；正文写法见 `04-script.md`，格式见 `standard.md` P3。
> 一句话：**前 3 秒见冲突，15 秒内第一次打脸或反转，之后每 15–20 秒一个转折，身份和困境在冲突里带出，结尾停在高潮前一秒。**

## 1. 时长与体量

| 档位 | 时长 | 中文正文 | 英文正文 | 场景 | 对白行 |
|---|---|---|---|---|---|
| 标准档 | 60–120 秒 | 350–500 字 | 180–260 词 | ≤2 | ≥4 |
| 长档 | 165–195 秒 | 650–850 字 | 330–450 词 | ≤3 | ≥8 |
| 微型档（漫剧、静帧配音） | 60–90 秒 | 260–400 字 | 140–200 词 | ≤2 | ≥4 |

**按形式选档，不按时长**：真人或动态 AI 视频，60–120 秒都走标准档；漫剧、静帧配音才走微型档——配音念得慢、每张画要停够时间，同样 90 秒放的字更少。

正文 = 对白 + 动作行。估时：中文台词 3.5–4.5 字/秒（快念可到 5.5–6），英文约 2.5–3 词/秒；动作、停顿、反应另算。**AI 视频的对白镜实际会比字数估计多 1.5–2.5 秒**（开口延迟），所以剧本宁短勿长。

## 2. 单集骨架（标准档，以 90 秒为例）

| 段 | 时间 | 任务 |
|---|---|---|
| 钩子 | 0–3 秒 | 直接切进冲突顶点：羞辱、威胁、证据、倒计时，第一帧就有情绪，不是静物 |
| 第一次翻转 | 3–15 秒 | 主角第一次反击或打脸（或者反派第一次加码）；**我是谁、我在什么困境、我要什么**在这一来一回里带出来，不单独交代 |
| 转折 × 2–3 | 15–75 秒 | 每 15–20 秒一个：新证据、身份反转、权力易手、反派反扑。每个转折都改变谁压着谁 |
| 顶点 + 断章 | 75–90 秒 | 最大的一次兑现落地，紧接着抛出更大的威胁或悬念，停在它的前一秒 |

一集 90 秒至少 3–4 个转折点，其中 2–4 个是爽点（主角占上风、观众解气的那一下）。数一数：两个转折之间超过 20 秒，中间一定有可以删的东西。

**长档**（约 3 分钟）不是把标准档注水：钩子 0–3 秒 → 第一次翻转 15 秒内 → 回合 A → **中段小钩**约 90 秒（新信息或新威胁，只抬价不放大招）→ 回合 B（施压和反击**各升一档**，不复读 A）→ 顶点 + 断章。转折的密度和标准档一样，每 15–20 秒一个；第 2、3 场必须换空间、换对手或换压力等级。

## 3. 开场

**前 3 秒的五种起手**（选一种，第一帧就能看懂）：

| 起手 | 例 | 第一帧画面 |
|---|---|---|
| 羞辱当场 | 岳母把茶泼在他脸上：「废物！」 | 茶水溅开的特写 |
| 绝境倒计时 | 「签了认罪书，否则你女儿今晚手术台见。」 | 推到面前的文件 + 握笔的手 |
| 身份反差 | 外卖员走进董事会，全场起立 | 门开，西装人群齐刷刷站起 |
| 死亡 / 重生 | 她从楼顶坠落——下一秒在订婚宴前睁眼 | 坠落的仰拍 → 猛然睁眼 |
| 证据亮出 | 亲子鉴定被拍在桌上 | 报告上的「亲生」二字 |

**开场五要素**：人设靠事件立（被泼茶，比旁白说「我是赘婿」有力）；目标具体；困境即时且有压迫感；情绪密集反转；台词一句多用（推进 + 关系 + 矛盾 + 人设）。

**AIGC 提示**：第一镜就是第一个片段的第一帧。开场选一个**能用一张图看懂**的冲突画面，比靠台词解释更稳、也更好生成。

**六个坑**：节奏拖沓（两集才交代主角是谁）；寒暄式台词；人设模糊；自嗨、和受众经验脱节；只套「下跪扇巴掌」的形式而没有尊严被践踏的内核；桥段旧、表达更旧。

**短剧不是电影的压缩版**

电影学院那套讲法（先建立日常和世界观，激励事件在百分之十处到来，人物慢慢立起来）搬到短剧上，就是又臭又长：观众手指在屏幕上，十秒钟看不出发生了什么就划走了。短剧要的是**先让观众知道发生了什么，再告诉他为什么**。

| | 电影的做法 | 短剧的做法 |
|---|---|---|
| 讲述顺序 | 按时间顺序，先铺垫再出事 | 结果先给：先上最炸的那一刻，原因随后补 |
| 世界观 | 开头专门交代 | 不单独交代，只在冲突里顺带带出（被泼茶时才知道他是赘婿） |
| 人物 | 在一连串选择里慢慢立起来 | 第一场就贴标签（废物女婿、恶毒继母），标签之下的复杂性后面再揭 |
| 悬念 | 观众和人物一起不知道 | 信息差：观众先知道真相，看人物什么时候知道、知道了怎么办 |
| 节奏单位 | 场，一场几分钟 | 段，每 10–15 秒一个信息增量或局势变化，不变就删 |
| 闪回 | 可以长，可以抒情 | 最长 2 秒，插在爽点上解释为什么解气，每次带回一条新信息；纯回忆杀不要 |
| 交代 | 允许几场慢慢铺 | 一句台词一个信息，配一个看得见的证据 |

**五种讲述顺序**（选一种，写进单集骨架的钩子段）：

| 顺序 | 怎么做 | 例 |
|---|---|---|
| 结果前置 | 第一镜给结局画面或最惨的一刻，然后跳回「三小时前」 | 她被推下楼——「三小时前」，订婚宴上她还在笑 |
| 因果倒置 | 先给果，让观众带着「怎么会这样」看因 | 总裁跪在雨里求她回来；回到她被赶出门那天 |
| 冷开场插叙 | 开场直接在冲突中间，必要的前情用一两个不超过 2 秒的闪回插在爽点上，每个闪回带一条新信息 | 法庭上她亮出录音；闪回一秒：录音笔藏在花瓶里 |
| 信息先给观众 | 开场就让观众看到真相（他是真千金、她是卧底），人物还蒙在鼓里 | 第一镜：保姆调换婴儿；二十年后，假千金在羞辱真千金 |
| 重生 / 穿越回溯 | 死亡或失败的结局在前，主角带着记忆回到起点，观众和主角一起知道「会发生什么」 | 她从楼顶坠落，下一秒在订婚宴前睁眼 |

这几种可以叠用：结果前置开场，信息先给观众，中间用极短闪回补因。规则只有一条：**观众任何时候都知道眼下的冲突是什么、谁在压谁、主角要什么**；不知道的只能是「接下来会怎样」，不能是「现在在干什么」。

总纲（`references/dramaturgy.md`）里的一个行动、可然与必然、人物是选择照样成立，只是讲述顺序和节奏按这里来。

## 4. 回合怎么写

一个回合 = 一次**施压**和一次**回应**：

1. 施压方抛出具体筹码（证据、命令、威胁、条件）。
2. 主角回应：反击、化解、或反击未遂但换来新信息。
3. 结果改变局势：地位、证据、关系、资源、风险至少变一项。

本集的回应不能和上集同一招。连续使用同类机制时，检查行动、代价、知情或关系有没有递进。

**主角要主动**：受压不等于没有策略。关键转折要能说出主角做了什么选择、付了什么代价。

**反应并进下一个动作，不单独停**：施压落地后，主角的反应不超过 1 秒，而且直接就是下一步的开始：抹掉脸上的酒、笑了一下就开口反击；把文件拍回桌上。电影里那种「看一眼、停一下」的呼吸，在短剧里就是拖。因果仍要读得出来（谁的哪句话招来了哪个反击，`references/writing/doctor.md` #26），靠的是动作的衔接，不是停顿。

**爽点要看得见**：打脸和兑现必须是画面上一眼看懂的变化：称呼变了（保安改口叫「沈总」）、有人下跪或退后、全场起立、证据甩在脸上、东西当场被收走、权力当场易手。不用法律条款、金融操作、设定说明来兑现，那些观众没有感觉；需要的话，用一句最直白的话说结果（「这栋楼现在是我的」），不说过程。

**台词短、狠、口语**：每句都在攻击或防守，一句一个意思，能用五个字说完不用十个。不解释设定，不说文艺腔（「我要的只是一句实话」），不客套。反派嚣张要具体（「赶出去三年，还有脸回来要饭？」），主角回击要短（「拖我？问问他们工资谁发的。」）。

**闪回最长 2 秒，插在爽点上**：闪回不是用来在开头讲背景的。主角打脸的那一刻，插一两秒闪回说明「为什么这一下这么解气」（暴雨里行李箱滚下台阶），然后立刻回到现在。开头第一分钟里不放超过 2 秒的闪回；纯抒情的回忆不要。

**换场时交代画外**：两场之间推动剧情的事（谁报了信、隔了几天、谁反悔了）要在下一场开头用物件、画面或一句台词交代；全集围着黄金三角里那个「我要什么」走，每场看得出离它近了还是远了。

## 5. 断章：停在高潮前一秒

「人会为冲动付费，不会为已经得到的东西付费。」一集讲成完整的起承转合，观众心满意足就走了。短剧的「合」必须**悬而未决**。

**四大断章公式**

| 公式 | 原理 | 例（停在） |
|---|---|---|
| 身份掉马前一秒 | 马甲即将被识破 | 反派翻到合同最后一页，看清印章，瞳孔骤缩：「怎么会是你？！」 |
| 物理危机悬停 | 伤害造成前 0.1 秒 | 车灯直扑女主，男主扑出、指尖刚够到她衣角 |
| 反差金句落地 | 全场嘲讽到顶点，主角一句话震住 | 「这栋别墅写的是我的名字。现在，请你们全家出去。」全场死寂 |
| 绝境二选一 | 两个同样惨烈的代价 + 倒计时 | 「左边是你妈的氧气管，右边是你妹妹的录取通知书，十秒。」 |

**钩子机制**（换着用，别一种用到底）：

| 机制 | 需要已有的依据 | 下一集至少回应 |
|---|---|---|
| 即将兑现 | 目标、阻碍、等待都已建立 | 结果及代价 |
| 错误认知被推翻 | 谁误判了什么、证据为何有效 | 是否承认、怎么反应 |
| 权力转移 | 资源或身份的来源和边界 | 新权力怎么用、旧权力怎么反扑 |
| 关系选择 | 已有关系与动机 | 选择结果与关系后果 |
| 规则的意外后果 | 规则此前已讲清 | 谁付代价、如何应对（不凭空改规则） |
| 不可逆行动 | 理由与损失已建立 | 是否完成、付出什么 |

**两种落法**：一句有指向的台词（未说完的质问、身份暗示、带情绪的宣言），或一个有冲击的画面（对视未开口、门推开一半、信封拆开一角、监控里一闪而过的脸）。

**钩子诊断**（不过关先修）：观众知道在等什么吗？结果和人物处境有关吗？后果是否迫近？是否来自已有的冲突和证据？**不靠解说也能看懂吗？**——用内心独白复述目标不算钩子。

**大小交替**：每集都有钩子，但不是每集都炸。小钩子可以是一句话停在半截；大钩子留给单元接缝和付费卡点。

## 6. 集与集的衔接

- 每集开头 15 秒内回应上集的钩子（付费后第一集尤其如此）；回应可以是兑现，也可以是反向回答（等来的人选择了别人）。
- 写本集前读上一集的结尾和下一集的大纲；本集结束状态 = 下一集开始状态（谁在哪、谁拿着什么、谁知道什么）。
- 同一个场景跨集出现时，沿用同一个子场景造型；人物外形没变就沿用同一个形象。

## 7. 对照：一集 90 秒

```text
0–3s    △ 订婚宴大屏亮起，播放的却是林晚和陌生男人的酒店监控。全场哗然。
3–15s   未婚夫顾言（痛心）：「晚晚，我给过你机会。」
        △ 林晚抹掉眼角，直接走上台，接过话筒。
        林晚：「视频是真的。只是你们没看到前十秒。」                    ← 第一次翻转
15–35s  △ 她按下手机。大屏切换：画面前段，顾言亲手把房卡交给那个男人。
        △ 全场一齐转头看顾言。                                          ← 打脸 1
35–55s  顾言（强笑）：「这是 AI 合成的——」
        林晚：「那这段呢？」
        △ 大屏：停车场里，顾言搂着闺蜜苏蔓。顾言的母亲当场松开他的胳膊。 ← 打脸 2
55–75s  △ 苏蔓贴着墙往门口退。
        林晚：「苏蔓，从我卡里转走的三十万，也是 AI 合成的？」
        △ 苏蔓撞翻香槟塔，玻璃碎了一地。                                ← 打脸 3
75–90s  △ 宴会厅大门被推开，两名警察走进来。
        警察：「请问，谁是林晚？有人举报你伪造证据。」（黑屏）          ← 断章
```

要点：开场即羞辱；第一次翻转在 15 秒内；之后每 20 秒一个打脸，每一下都是画面上看得见的变化（全场转头、母亲松手、香槟塔倒）；她的反应直接就是下一步，没有停下来的镜头；人设靠动作立住，不靠独白；断章把威胁转回主角身上。全集只有一个场景（宴会厅），生成成本低。

## 单集检查

- [ ] 前 3 秒有冲突，第一帧画面能看懂？
- [ ] 15 秒内有第一次打脸或反转？身份、困境、目标是在冲突里带出来的，没有单独交代的段落？
- [ ] 90 秒里有 3–4 个转折点、2–4 个看得见的爽点？两个转折之间没有超过 20 秒的空档？
- [ ] 反应都不超过 1 秒、直接接下一个动作？换场时画外的事交代了，每场看得出离「我要什么」近了还是远了？
- [ ] 爽点是画面上看得见的变化，不是法律、金融、设定说明？
- [ ] 台词短、狠、口语，没有解释设定和文艺腔？闪回不超过 2 秒，插在爽点上？
- [ ] 断在高潮前一秒，钩子不靠独白？
- [ ] 体量和场景数在档位内？

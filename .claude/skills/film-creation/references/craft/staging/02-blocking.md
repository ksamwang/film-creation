# 走位：区域调度与逐个角色调度

## 核心判断

走位不是让演员在画面里动起来，而是把人物关系的变化写成可重复的位置序列。排完之后，演员每次都能走到同一个点，摄影机每次都能在同一刻看见同一个关系。

## 书里的方法

**区域调度**：把场景切成若干表演区（门口、桌边、窗边、走廊），先给每个角色分配起始区和目标区，再安排区域之间的移动。它适合空间大、人物多、需要同时管理几组关系的戏。区域定好，摄影机只要决定当前看哪一个区。

**逐个角色调度**：一次只排一个角色，沿着这个角色的欲望把他从入场到离场的路线走完整，再排下一个，最后合成。它适合对话戏：每个人都有自己的空间逻辑，合在一起才知道谁挡了谁、谁被迫改道。逐角色排完再合成，比让所有人一起“找感觉”更容易复现。

**调度演员和摄影机**：书中把调度的功能分成三类——强调被摄主体、在一组主体中强调其中一个、把注意力从一个主体转向另一个。三种功能对应三种位置关系：主体靠近镜头、主体被其他人夹在中间、主体通过交叉或遮挡被让出。另有起连接或引导作用的调度，用一次穿越或道具传递把两个区域缝起来。

**反向运动**：两个角色朝相反方向移动，距离与画面张力同时变化。它比单向走位更清楚地写出“关系正在分开”或“正在交换位置”，常用于告别、追逐、摊牌。

排完之后必须让演员实地走一遍，用地标和步数计时；只在纸上画箭头，实拍时步速一变，所有构图都会错位。

## 可执行规则

1. 先分区域，再排路线；区域不超过四个，否则观众记不住。
2. 每个角色只给一个主要欲望和一个主要障碍，路线必须经过障碍。
3. 逐个角色排完再合成，合成时只改冲突点，不重排整条路线。
4. 每次走位至少完成一种功能：强调、转移或连接；三种都不是的走动删掉。
5. 关系变化优先用反向运动表达，不用台词说明。
6. 走位必须能被演员用正常步速复现；需要赶步或绕远，就改调度。
7. 排完在地面图上标出每个停点，摄影机据此定机位。

## 检查清单

- [ ] 场景是否被切成可命名的表演区？
- [ ] 每个角色是否有独立的路线与停点？
- [ ] 合成后是否出现遮挡或通道堵塞？
- [ ] 每次移动是否完成强调、转移或连接？
- [ ] 关系变化是否用位置而不仅是台词表达？
- [ ] 反向运动是否用在真正的转折点？
- [ ] 演员能否用正常步速复现全部走位？

## 与风格层接口

走位图直接决定机位表和演员提示。给演员的指令写成“从门边走到桌角，停在椅子后”，不写“更压迫一点”；给摄影的指令写成“守住桌角这一侧，等人物交叉后摇到窗边”。风格层需要的紧张感由距离和遮挡产生，不由形容词产生。

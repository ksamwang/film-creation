# 预算：从分解表和日程里长出来

## 核心判断

预算不是先有一个总数再往下分，而是分解表和日程的算术结果。可靠的预算表只有一种写法：单位×数量×费率；可靠的预算判断只有一个：哪些钱买的是"变化"，哪些钱买的是"时间"。

## 书里的方法

预算摘要被放在创投文案的固定位置：项目信息、投资信息、故事梗概、主创团队、预算摘要、风险揭示。投资人先看故事，再看这笔钱怎么花、最坏会怎样。

样本预算按六个大块组织：劳务、制作设备、录像带与耗材、拍摄制作支出、后期制作、办公室支出。每一行都写清计价方式——"6个月／固定费率""20天@$450/天""100盘@$16/盘"。固定费率和日费率是两种不同的风险：前者买断一段时间，后者随天数上涨；排期多一天，按天计的项目就多一行。

劳务覆盖制片人、导演、联合制片、摄影指导、录音师、制片助理、剪辑师、助理剪辑师、音频剪辑师、办公室助理。设备分摄影机、音频、灯光、场务、电池配件、备用灯泡。拍摄制作支出是每日补贴、泊车、汽车租赁、汽油这类"人一动就要花"的钱。后期制作包含档案资料版权素材与清算、剪辑室租赁、录音材料转录、照片动画、音乐费用、图片、在线剪辑、混音、录像带复制、色彩校正、隐藏字幕。办公室支出里，保险、第三方财产、自有设备、办公室租赁、电话传真手机、邮票快递、法务、会计、导演工会社保福利、错误和遗漏保险（E&O）各占一行。

这份表最值得学的是分类逻辑：凡是随人、设备、场地移动发生的，进拍摄制作支出；凡是随时间发生的，进劳务和租赁；凡是事后才暴露的，进后期和办公室——保险、法务、会计、E&O 都在这一栏。短片预算的核心变量则不是页数：取决于项目的性质、能免费得到多少东西、愿意花多少钱。旧经验是每分钟约一千美元；数字时代可以更低，也可以更高，差别就在这三项。

## 可执行规则

1. 每一行都写单位、数量、费率，不写"杂费"。
2. 固定费率和日费率分栏，排期一变就能看出哪一栏在涨。
3. 把"变化"单列：转场、场地许可、加班、儿童监护、动物训练、特技、保险。
4. 后期不是余数：音乐授权、E&O、调色、混音、字幕各有行。
5. 先算最贵的三场戏，再算其余；三场决定总盘子的下限。
6. 免费资源要写交换条件：谁提供、换什么、什么时候到位。
7. 保险、E&O、法务、会计单列在办公室支出，不塞进后期或杂费。
8. 延期支付和股份写进预算与协议：它压低前期现金，但形成后期负债。

## 检查清单

- [ ] 这张预算能追回到分解表的哪一行？
- [ ] 哪些行按天计？排期加一天会多出多少？
- [ ] 转场、许可、保险、儿童与动物各占多少？
- [ ] 音乐、档案素材的授权与清算在哪一行？
- [ ] E&O、一般责任险、法务、会计都列了吗？
- [ ] 最贵的三场戏是哪三场？有没有降级方案？
- [ ] 哪些资源是免费的？交换条件写下来了吗？
- [ ] 预算摘要能在一页内说清六个大类的钱吗？

## 与风格层接口

预算直接决定画面里有多少"世界"。设备天数决定机位数量和运动方式：有轨道和稳定器的天数，才有移动镜头；只有三脚架的天数，风格必须建立在固定机位、构图和表演上。群众演员、美术密度、服装套数、场地级别决定镜头里能出现多少人、多少层次；钱不够时，改用画外空间、景深遮挡、局部特写和声音暗示规模。后期预算同样反向约束拍摄：音乐授权拿不到，剪辑节奏就得换；混音和调色天数不够，现场就要把声音录干净、把光比控制住。AI 流程也一样，生成成本按镜头数、元素数和一致性要求计价，预算表要能算出每个镜头的钱。

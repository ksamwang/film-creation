# 资产与一致性

> AIGC 项目的一致性问题，本质是**同一个人、同一个地方、同一件东西，在每次生成里都要被认出来**。
> 先定义资产，再分镜头。竖屏短剧另有标准（`references/drama/05-breakdown.md`），冲突时以那里为准。
> 资产定稿后每个镜头怎么生成、镜头之间怎么接，见 `workflow.md`；参考图上限等模型能力见 `models.md`。

## 1. 一致性的四层，按强度排

| 层 | 做法 | 强度 | 什么时候用 |
|---|---|---|---|
| 1 参考图 | 每个资产先出一张定稿图，之后每次生成都挂上 | 强 | 模型支持参考图时**默认** |
| 2 首帧 / 续接 | 用上一镜的尾帧、上一段的视频做下一镜起点 | 强（只管开头） | 镜头之间必须接上的地方 |
| 3 训练身份 | LoRA、角色 ID 等 | 最强，成本高 | 长线 IP、几百个镜头的同一角色 |
| 4 文本锁 | 同一串描述逐字复用 | 弱，只降低漂移概率 | 纯文生、CLIP 系模型、参考图挂不下时的补充 |

几层可以叠：参考图管身份，首帧管衔接，文本锁管参考图没覆盖的细节（比如左手的戒指）。

## 2. 资产清单

三类资产，每个只定义一次：

- **人物**：C1 / C2 ……；同一人物外形持续改变（换装、受伤、年龄跨度）时拆成**造型**：`C1 · 基础形象`、`C1 · 婚礼礼服`。
- **场景**：S1 / S2 ……；同一地点光线差别大时按「区域_时段」拆：`S1 · 客厅_夜`。
- **道具**：P1 / P2 ……；只列必须认得出的物件（一把有缺口的刀、一只特定的手表），普通陈设写进场景描述。

只有入画的东西进清单；工具、模型版本不进。

## 3. 资产卡

每个资产写一张卡，三部分：

```text
名字：C1 · 基础形象
描述（自然语言，给出图用，也给模式 A 的纯文生兜底）：
  三十岁出头的东亚女性，偏瘦，下颌线利落，眼睛细长；齐肩黑发，左眉上方一道浅疤；
  灰色羊毛大衣（#8A8D91）内搭黑色高领毛衣，斜挎一只磨旧的棕色皮包。
token（模式 B 用）：
  30s East Asian woman | slim | sharp jaw | narrow eyes | shoulder-length black hair | scar above left eyebrow | grey wool coat | black turtleneck | worn brown leather bag
参考图：character-sheet / 正面全身定稿 → 存档名与资产名一致
```

字段顺序：

- 人物：年龄 → 体型 → 脸 → 发型 → 肤色 → 服装（带 hex）→ 配饰 → 疤痕 / 纹身 → 左右标记（「左眉」「右手腕」）
- 场景：地点 → 年代 → 结构与出入口 → 材质 → 主色 → 光源与时段 → 天气 → 尺度 → **站位锚点**（之后分镜要用的桌、门、窗）
- 道具：名称 → 材质 → 尺寸 → 磨损 → 颜色 → 在谁手里、怎么用

描述只写**看得见、跨镜头不变**的东西；表情、姿态、动作属于镜头，不进资产卡。

## 4. 参考图怎么出

- **人物**：三面板角色表（`templates/character-sheet.md`），或纯白 / 浅灰背景的正面全身像。脸、服装、身材比例都要清楚；背景干净，不带剧情光。
- **人物造型变体**：以基础形象的图为参考出，提示词开头写明「与参考图是同一个人：脸型、五官、肤色、体型和发型保持完全一致，只改变服装和状态」。
- **场景**：空镜建立镜头，**画面里没有人**；能看到之后分镜要用的全部锚点。一个场景要多个角度时，先出一张主图，其他角度都以它为参考，门窗位置不许变。
- **道具**：中性背景、清楚的形状和材质；需要尺度感时放一只手。
- 定稿后**锁住**：存档名 = 资产名，不再改；要改就出新造型，旧图保留。

## 5. 用在镜头里

**模式 A（有参考图）**：

- 按挂载顺序给每张图写清职责：「参考图 1 是林晚，参考图 2 是顾言，参考图 3 是客厅」。平台支持 `@[资产名]` 之类的引用语法时，用它代替编号。
- 正文**不重复外貌**，只写这一镜的动作、状态、取景和光变。重复外貌会和图打架，脸和衣服反而跑偏。
- 一镜挂的图不超过模型上限；参考图挂得多不一定变差，必须认得出的物件挂图比只写文字稳。
- 多人同框可以直接生成；说话或主导动作的人放在最显眼的位置，其他人侧身、背对或在后景。

**模式 A（纯文生，无参考图）**：把资产卡的「描述」逐字放进正文，再写动作。

**模式 B（token 块）**：

```text
STYLE: ...
SUBJECT: C1 token | 动作
ENVIRONMENT: S1 token | 时间 | 天气
SHOT: 景别 | 机位 | 焦段 | 构图
LIGHT: ...
COLOR: ...
NEGATIVE: ...
```

- token **逐字复用**：不改写、不换同义词、不删修饰。
- 一个提示一个资产主语；多人分开生成再合成。
- 图生视频的运动提示只写运动，首帧已经带着资产。

## 6. 漂移时怎么办

| 症状 | 先查 | 修法 |
|---|---|---|
| 脸像别人 | 参考图挂没挂、挂对没 | 挂对图；删正文外貌；换更清楚的正脸参考 |
| 衣服细节变了 | 资产卡有没有写这处细节 | 写进描述 / token 并带 hex；关键配饰单独出道具参考 |
| 左右标记跳边 | 有没有写左右 | 写死「左眉」「右手腕」；镜头翻转时检查 |
| 场景家具位置变 | 场景图里有没有这个锚点 | 换成图里有的锚点，或改场景描述重出主图 |
| 两镜接不上 | 是否各自从参考图开场 | 用上一镜的真实尾帧或视频续接 |
| 纯文本越跑越偏 | 是否改过描述 | 用原文重跑，不要逐次改词；漂移多就出参考图 |

## 检查清单

- [ ] 每个人物 / 造型 / 场景 / 关键道具都有资产卡和定稿参考图？
- [ ] 描述只写看得见、跨镜不变的东西，带 hex 和左右标记？
- [ ] 场景图里有分镜要用的全部锚点，没有人？
- [ ] 有参考图的镜头，正文没有重复外貌，图的职责写清楚了？
- [ ] 每镜挂图数 ≤ 模型上限？
- [ ] 纯文本 / token 模式下，描述逐字复用，没有改写？
- [ ] 需要衔接的镜头用了尾帧或视频续接？

# 拆析：从剧本到调度方案

## 核心判断

调度方案不是开机前等来的灵感，而是把剧本拆到“可拍”的程度后剩下的东西。拆得够细，现场只剩下执行和微调；拆得不够，所有决定都会挤到最贵的时间里。

## 书里的方法

**视觉化的剧本拆析**：把文字转成空间与动作。每场标出地点、时间、人物进出、关键道具、可用的出入口和障碍。文字里的“他们争吵”必须变成“谁站在哪、谁挡住谁、谁先转身”。

**三遍拆析**：第一遍只读故事与人物，标出戏剧性单元和节拍，不画镜头；第二遍找视觉机会——空间对比、可重复的视觉母题、可以不说而用动作表达的段落；第三遍做技术拆析——机位、镜头、设备、时间、备用镜头。三遍分开，是为了不让技术问题过早压掉人物问题。

**头脑风暴**：先不判断，把所有调度可能性列出来，再按“是否推进人物关系”筛选。书中强调，头脑风暴阶段的价值在于数量，不在于正确；过早否定会只剩最安全的方案。

**视觉化方案**：为每场画平面图和简笔故事板，标出入口、表演区、机位、运动路径。平面图解决地理，故事板解决顺序；两者都不能替代实地勘景。

**预估备选镜头**：在方案旁列出“如果主方案不成立，备选是什么”，并估算时间。备选不是多拍，而是提前决定在哪种条件下换方案。

**数字化故事板与动态故事板**：用预演检查运动、遮挡和镜头衔接，但不把预演当最终答案。预演越精确，越容易掩盖表演和现场空间的问题。

**最终的技术性剧本拆析**：把每场拆成镜位表，按拍摄顺序而非剧本顺序排列，标出共享灯光、共用机位和需要移动设备的镜头。

## 可执行规则

1. 每场先做一遍纯故事拆析，不写任何镜头。
2. 第二遍只找三样东西：空间机会、视觉母题、可用动作替代的台词。
3. 第三遍才写机位、镜头、设备和时间。
4. 头脑风暴至少列出五种调度方案，再筛。
5. 每场画一张平面图，标出入口、表演区、机位和运动路径。
6. 每个主方案配一个备选，并写明触发条件。
7. 镜位表按拍摄顺序排，标出可共享灯光的镜头。
8. 预演只用来检查遮挡和衔接，不用来定表演。

## 检查清单

- [ ] 每场是否完成了三遍拆析？
- [ ] 文字动作是否已经转成位置与朝向？
- [ ] 是否找到可重复的视觉母题？
- [ ] 平面图是否标全入口、障碍和机位？
- [ ] 主方案是否有备选与触发条件？
- [ ] 镜位表是否按拍摄顺序排列？
- [ ] 是否标出了共享灯光与共用机位？
- [ ] 预演是否被误当成最终答案？

## 与风格层接口

拆析表是把风格意图落到执行层的接口：导演/摄影参考决定“看什么”，拆析表决定“怎么拍到”。给美术的平面图、给摄影的机位表、给剪辑的镜位顺序都从同一张拆析表出；风格词只在能改变机位、镜头或顺序时才有意义。

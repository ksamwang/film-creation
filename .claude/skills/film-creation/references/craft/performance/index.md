# 表演

## 这个模块解决什么

片场最常听到的指令是“再来一条，多一点”。这句话没有信息。表演模块把“多一点”翻译成三样可执行的东西：演员所处的具体情境、他要完成的动作、这个动作在什么景别下需要多大。依据是乌塔·哈根的《尊重表演艺术》与斯特拉·阿德勒的《表演的艺术》——两本书都把工作落在“做”上。

## 先读哪篇

| 情况 | 读 |
|---|---|
| 现场要给指令，只有十分钟 | `02-action.md` |
| 剧本刚到手，判断这场戏成不成立 | `01-given-circumstances.md` |
| 要进排练场 | `03-rehearsal.md` |
| 要给演员笔记，处理导演与演员的权责 | `04-direction.md` |
| 要选人 | `05-casting.md` |

## 子文件

- `01-given-circumstances.md`：规定情境怎么填满，从“她是谁”改成“我是谁”。
- `02-action.md`：目标、障碍、行动三层结构，以及行动的尺寸与“得分”。
- `03-rehearsal.md`：初读、研究、即兴、定分的顺序，初次印象为什么不能带进角色。
- `04-direction.md`：导演能导什么、不能导什么，笔记怎么写才不替演员演。
- `05-casting.md`：位置、工具、反应速度，以及“像不像”为什么不是选角标准。

## 两本书的分工

哈根给顺序和判据：先填情况，再定目标与障碍，最后落实为行动；排练允许即兴，但结束前必须把所有举动果决化。她反复提醒，初读剧本时的认同属于观众，不属于角色。

阿德勒给具体化的标准：情境必须细到你身处何处、看见什么、一把椅子要求你怎么坐；她把这叫作情境的真实，把“让观众看见你所看见的”叫作视像。

## 一条底线

表演不能被命令，只能被安排。导演安排情境、障碍、对手和尺寸，演员在这些安排里做事。凡是不能落成“对谁做什么”的指令，都不属于这个模块；凡是需要演员解释“我心里在想什么”的问题，都问错了方向。

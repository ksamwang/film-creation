# 迭代预算与一致性 pass：把生成次数当成本

## 核心判断

迭代预算不是先有一个总额再往下分，而是镜头清单与生成顺序的算术结果。可靠的写法只有一种：镜头数 × 尝试次数 × 单次成本；可靠的判断只有一个：哪些成本买"一次成型"，哪些买"反复重试"。

## 书里的原则

**每一行写单位、数量、费率，不写"杂费"。** 第三章的成本表之所以可信，是每个数字都能追到具体项目和计价方式。AIGC 版把这条落成：每个镜头写尝试条数、单条成本、通过标准，不写"看情况"。

**固定费率与按天计价是两种风险。** 书里前者买断一段时间，后者随周期上涨。AIGC 里对应"固定成本"与"按次成本"：资产建设、关键帧、角色表是一次性；视频生成、重试、合成按条或按次上涨。多一个镜头变体，就多一次一致性 pass。

**分类逻辑比分类名称重要。** 书里把成本分成随变化发生的、随次数发生的、事后才暴露的。AIGC 对应六类：资产建设、生成额度、一致性 pass、后期、交付与版本、风险缓冲。分类是为了任何变化都能落到具体一行。

**后期不是余数。** 书里把音乐、调色、混音、字幕等逐项单列。AIGC 同样：剪辑、声音、字幕、导出、归档都不是"剩下的额度"，必须单列，否则最后只能拿生成额度去补。

**资源判断看三个变量。** 书里说短片取决于项目性质、免费资源、愿意花多少。AIGC 里读作：可复用资产有多少、模型是否一次听懂、愿意为一致性付多少重试。

## AIGC 执行

1. 每个镜头一行：基础尝试三条，复杂镜头六到十条，多人、动物、火、水十到二十条。写上限，不写"看情况"。
2. 一致性 pass 单独列：角色 pass、道具 pass、环境 pass、光色 pass。每 pass 有验收标准：参考图定稿并锁名，文本描述逐字复用。
3. 先算最贵三镜，再算其余；三镜决定总盘下限。最贵通常不是最长的镜头，而是同屏元素最多的镜头。
4. 把"变化"单列：换角色状态、换环境、换光位、换服装、加群像/动物/特效，每项加一个批次和一次一致性 pass。
5. 固定与按次分栏：资产建设一次；视频按条；合成、剪辑按工时。任何一项增加，立刻能看出哪栏在涨。
6. 每个最贵镜头写降级额度：固定机位、剪影、画外、局部特写、分层合成；写明触发条件，如连续十条未通过。
7. 把"免费"写成复用条件：可复用角色 token、场景底、运动模板；同时写复用边界，避免把不同镜头硬套同一 token。
8. 选片、命名、归档、版本管理也占时间，单列一行。
9. 迭代表要能反算：每个镜头的成本等于尝试条数乘单次成本，加该镜分摊的一致性 pass 与后期工时。

## 检查清单

- [ ] 这张表能追回到镜头清单的哪一行？
- [ ] 哪些行按次计？多一条尝试会多出多少？
- [ ] 换角色状态、换环境、换光位各占多少批次？
- [ ] 一致性 pass 有几轮？每轮验收标准是什么？
- [ ] 最贵三镜是哪三镜？降级方案写了吗？
- [ ] 剪辑、声音、字幕、导出各有行吗？
- [ ] 迭代摘要能在一页内说清六类的花法吗？

## 常见错误

- 按镜头数平均分配尝试额度 → 最贵三镜中途断粮 → 先给复杂镜头定量，再分其余。
- 把生成条数当可用镜头数 → 以为够了，剪辑时发现通过率低 → 只按通过条数结算。
- 一致性 pass 留到最后 → 角色漂移时已无法重生成 → 每批次结束做一次 pass。
- 只算视频生成，不算后期 → 剪辑、字幕、声音挤在一起 → 后期与交付单列成行。

## 与风格层接口

迭代预算决定画面里有多少"世界"。可复用资产多，才能做多景别、多机位变体；额度紧，风格就建立在固定机位、构图、光色和单角色动作上。群像、美术密度、环境复杂度决定镜头里能出现多少层次；不够时用画外空间、景深遮挡、局部特写和声音暗示规模。后期额度也反向约束生成：音乐、字幕、混音不够，生成阶段就要控制镜头长度、对白量和画面文字。给 AI 流程时，迭代量按镜头数、资产数和一致性要求计价，表要能算出每个镜头多少次、多少工时。

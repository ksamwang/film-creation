# 多人：表演区域与三角群

## 核心判断

三人以上，画面很难维持唯一焦点。调度的任务不是让所有人都被看见，而是随时指定“这一刻谁和谁是一组”，并让其余人退成环境。

## 书里的方法

**表演区域**：把多人场景划成几个区域，每组人占一个区域，区域之间留出走动通道；镜头只处理当前区域，其他区域用景深、背身或暗部降级。区域一多，必须靠走位把人物在区域间搬运，不能靠剪辑硬跳。

**三角群**：三人或四人构图时，用身体朝向和视线把人物组织成三角形。多人场景可以拆成若干三角群，换组时用一次走位或一次视线转移过渡。三角形给观众一个自然的阅读顺序：先看最近的一角，再顺着视线看另外两角。

**三人对话的形态A和L**：三人站位有基本形态。A形通常是一人在前、两人在后，前方的人被两人共同注视，适合表现被质问或被孤立；L形是一人占侧翼、两人成一线，侧翼的人可以观察也可以插入，适合表现结盟与旁观。形态不是固定构图，而是权力关系的平面图。

**面向观众原则**：在关键台词和反应时，让相关脸部朝向摄影机可读的一侧。不是所有人都正对镜头，而是让当前说话者和当前听者都可见；背对镜头的人承担“被排除”的信息。

**四人以上的处理**：可以用单一机位的正面位置，让所有人面向镜头排开；也可以用有纵深的正面位置，把人群分成前、中、后三层。远摄镜头压缩人群，适合表现拥挤与无法脱身；广角镜头拉开距离，适合表现空间关系与孤立。

**层次**：前景、中景、后景各放一组信息，观众可以选择看谁；但同一时刻只让一个层次“响”，否则焦点散掉。

## 可执行规则

1. 三人以上先划表演区域，每区不超过三人。
2. 每场指定一个主三角群，其余人物退到环境层。
3. 用A形或L形先写出权力关系，再调具体站位。
4. 关键台词时，说话者与听者至少各有一侧脸可读。
5. 换组只用一次走位或一次视线转移，不靠连续剪辑硬切。
6. 四人以上先决定用正面排开还是有纵深的层次，不要两者混用。
7. 同一画面只允许一个层次承担主要信息。

## 检查清单

- [ ] 多人场景是否被划成可命名的表演区域？
- [ ] 当前的主三角群是否明确？
- [ ] 站位形态是否对应权力关系？
- [ ] 说话者与听者是否都可读？
- [ ] 换组是否有走位或视线过渡？
- [ ] 人群是用压缩还是用纵深处理？
- [ ] 是否只有一个层次在“响”？

## 与风格层接口

多人调度图决定群戏的机位与镜头选择。给摄影的提示要写清“当前三角群 + 前景层 + 后景层”，给演员的提示要写清“谁和谁成组、谁背对”。风格层若想要拥挤感，用远摄压缩和窄区域；若想要孤立感，用广角、纵深和空出的通道。

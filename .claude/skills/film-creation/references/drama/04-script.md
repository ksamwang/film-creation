# 剧本写法：写给观众，也写给生成

> 产物：P3 script（`standard.md`）。单集骨架见 `03-episode.md`。
> 一句话：**剧本里每一行，最后都会变成一个镜头里看得见、听得见的东西；写不成画面的，就不要写。**

## 1. 格式

```text
场 1-1  夜  内  顾家别墅·客厅
人物：林晚、顾言、苏蔓

△ 水晶灯下，顾言把一份离婚协议推到茶几中央。
顾言（冷淡）：签了吧，房子留给你，算我仁至义尽。
△ 林晚没看协议，看着苏蔓搭在顾言肩上的手。
林晚：这只手，昨晚也在我的首饰盒里吧？
苏蔓（OS）：她怎么会知道？
【字幕】三天前
```

| 行 | JSON `type` | 规则 |
|---|---|---|
| 场头 | `heading` | 场号、时间（日 / 夜 / 晨 / 昏）、内外景、地点。同一地点同一时段 = 同一场 |
| △ 动作 | `action` | 只写**看得见的**：谁、做什么、碰到什么、停在哪 |
| 对白 | `dialogue` | `角色（情绪）：台词`；情绪一两个词 |
| 画外音 | `vo` | 角色不在画面里、或旁白叙述 |
| 内心独白 | `os` | 角色在画面里，嘴不动 |
| 字卡 | `caption` | 时间地点卡、短信内容等**必须让观众读到**的字 |

角色名在全剧逐字一致（和人物小传一样），换称呼写在台词里，不改 `who`。

## 2. 动作行：写成能生成的样子

动作行是分镜的原料。写成**起点 → 动作 → 落点**，而不是形容词。

| 写法 | 例 |
|---|---|
| ❌ 情绪形容词 | △ 林晚非常愤怒，内心充满了绝望。 |
| ✅ 可见泄露 | △ 林晚把协议撕成两半，纸边划破了指尖，她没低头看。 |
| ❌ 动作全挤在一起 | △ 她冲过去打了他一巴掌然后转身哭着跑出门外上了车。 |
| ✅ 一行一个主导动作 | △ 她抬手，一巴掌落在顾言脸上。△ 顾言偏过头，嘴角渗出血。 |
| ❌ 依赖剧外信息 | △ 苏蔓想起了十年前那场火灾。 |
| ✅ 用道具和动作带出 | △ 苏蔓下意识摸了摸左腕的烧伤疤，把袖子往下拽。 |

规则：

- **一行一个主导动作**。AI 视频一镜（3–5 秒）能看清的动作约 2–3 个，多写不会被删，会被压扁成半秒一个。
- **写接触点和落点**：「递过去」不如「把钥匙放进他摊开的手心」。
- **空间关系写清**：谁站谁坐、隔着什么、离多远（「隔着茶几」「一臂远」）。
- **关键物件出场即写清**：颜色、材质、在谁手里。它会进造型描述（`05-breakdown.md`）。
- 不写镜头术语（推、拉、特写）——那是分镜的事；可以写观众必须看清的细节（「戒指内圈刻着她的名字」）。

## 3. 台词

> 潜台词、攻防、人物声口等通用对白手法见 `references/writing/dialogue.md`；本节的短剧规则优先。

**精简、高负载**：一句台词同时推剧情、立人物、制造冲突、埋伏笔。

| 规则 | 说明 |
|---|---|
| 短 | 中文常规 12–18 字一句，爆发金句 8–12 字，硬上限约 25 字；英文常规 6–12 词 |
| 一句一功能以上 | 揭新信息（「你父亲不是病死的。」）、下决定（「这婚，我离。」）、制造冲突（「这合同我今天不签。」） |
| 像这个人说的 | 直率的人说「不行」，心机深的人委婉推脱，怯懦的人先道歉再找借口 |
| 朗读减三成 | 大声念，砍掉三分之一后核心信息还在，就砍 |
| 攻防不复读 | 反驳必须带新增量，不能把上一句换个说法再说一遍 |
| 少说设定 | 背景走物证、反差和别人一句话（「你这趟南方，折腾了小半年吧？」），不走旁白 |

**AIGC 专属：台词会被视频模型直接说出来。**

- 每句台词都要能在它所在的镜头里说完。按语速估：中文约 4 字/秒（快念 5.5–6），英文约 2.5–3 词/秒；再加约 1–2 秒开口延迟。一句 30 字的台词至少要一个 9–10 秒的镜头，所以长台词要拆成两句、分给两个镜头。
- **一镜一个说话人最稳**。抢话、齐声、三人以上轮流说，模型容易把口型安到错的人脸上。
- `emotion` 写成可演的语气：「冷笑」「压着火」「哽咽」「轻描淡写」，不写「复杂的心情」。
- 喊名字、拟声词、外语夹杂单独成句时发音不稳，必要时改成完整短句。
- 古装、奇幻用词可以雅，但必须听得懂、不拗口；方言只点缀，关键信息不用方言。

## 4. VO、OS 与字卡：少用，且知道代价

> 能用对白表达的不用画外音；能用表演呈现的内心活动不用独白。

| 类型 | 什么时候用 | 生成上的代价 |
|---|---|---|
| `os` 内心独白 | 隐秘心思、反差（嘴上认错、心里冷笑） | 画中人正脸时，模型常让她**动嘴**；安排成背影、侧脸或嘴不在画面里更稳 |
| `vo` 画外音 | 开场时代交代、电话那头、回忆叙述 | 说话人不在画面里，音色难统一；必要时用音色参考或后期配音 |
| `caption` 字卡 | 时间跳跃、短信、关键文件名 | **视频模型不画字**；字卡在成片阶段由剪辑加 |

- 用 OS 复述剧情、解释目标，等于剥夺观众思考，也不算钩子。
- 一集 OS 超过两句，先想能不能改成动作或对白。

## 5. 每集上限（控制生成成本）

| 项 | 标准档建议 | 理由 |
|---|---|---|
| 场景 | ≤2（长档 ≤3） | 每个新子场景都要一张参考图；同一场景的连续戏能塞进同一个片段 |
| 出场有名角色 | ≤4 | 一个片段能带的参考图有限（常见 3–9 张，含场景） |
| 同框说话人 | 一镜 1 人，一场 ≤3 人轮流 | 口型归属 |
| 打戏 / 推搡 | 一集 ≤1 段，只拍决定性的一下 | 接触与受力最难生成 |
| 新形象 | 只在外形真正持续改变时 | 每个形象一张参考图，见 `05-breakdown.md` |

## 6. 去 AI 味

- 不要人人都用排比和金句；配角说话要有职业和身份的口音（律师谨慎、街头混混市井）。
- 反派刻薄要具体（「你那点工资，够买我这双鞋的鞋带吗」），不要抽象骂「贱人」。
- 不要每句都带情绪标签和感叹号；冷场、打断、答非所问是活人感。
- 删掉「我知道你很难过，但是……」这类解释性开头。
- 合规：暴力写成受力结果（震飞、倒地）不写血腥细节；不靠践踏弱者、女性、公职人员制造爽感。

## 7. 写完自检

- [ ] 每一行动作都能画成一个画面，且一行一个主导动作？
- [ ] 关键信息全部在正文里出现，不依赖人物小传？
- [ ] 每句台词能在一个镜头内说完，一镜一个说话人？
- [ ] 朗读一遍，砍掉三分之一后信息还在？
- [ ] OS / VO 不超过必要，字卡留给后期？
- [ ] 场景、角色、打戏在档位上限内？
- [ ] 角色名与小传逐字一致？

交付：先给剧本格式（第 1 节），再给 `standard.md` P3 的 JSON。台词用台词语言，动作和情绪用说明语言。

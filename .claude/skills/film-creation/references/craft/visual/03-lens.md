# 焦距与景深

## 核心判断

镜头决定“站多远看”和“看多清”。同一景别可由广角贴近或长焦退远得到，但透视、前后景比例、景深和脸型完全不同。选镜头不是选品牌，是选观众与对象的物理关系；焦距一换，空间关系就换。

## 书里的方法

《电影语言的语法》说，摄影机与拍摄对象的距离可以用实际的方法或光学的方法获得。走近是实际距离，变焦或换长焦是光学距离；两者都能把人物拍大，但空间被压扁的程度不同。

《导演的摄影课》把光学镜头的美学分四块：镜头基础、镜头上的数字、理解景深、变形镜头。镜头上的两个关键数字是焦距与光圈：焦距决定视野与透视，光圈决定进光量与景深。焦距越短，视野越广，前后景都被收进来，靠近镜头的东西被夸张；焦距越长，视野越窄，前后景被压缩，人物从背景中“剥”出来。变形镜头拍摄时横向压缩画面，再在放映或后期展开，得到更宽画幅和不同焦外形状。

《镜头的语法》把景深写成可操作的变量：光圈、焦距、拍摄距离、感光材料尺寸与感光度。光圈越小，景深越大；焦距越短，景深越大；被摄对象离摄影机越远，景深越大；大画幅更难得到大景深。聚焦平面只有一个，景深约三分之一在平面前、三分之二在平面后。要人物清晰、背景模糊，就靠近、长焦、大光圈；要前后都清晰，就退远、广角、小光圈。

广角有三条后果：靠近拍特写会夸张鼻子、让耳朵后缩，适合喜剧或噩梦，不适合普通肖像；广角景深大，适合全景和空间交代；手持时广角能隐藏抖动。长焦有三条后果：压缩空间，适合肖像和“人群中的孤独”；景深浅，焦点必须跟住；手持时抖动被放大，必须上稳定设备。变焦方便，但推拉必须有动机；定焦的视角约束会逼出更明确的机位。

## 可执行规则

1. 先定机位距离，再选焦距；不要用变焦代替走位。
2. 普通特写用较长焦距、稍远距离；不要用广角贴近拍脸。
3. 要夸张空间或权力，用广角贴近；要压缩或孤立，用长焦退远。
4. 深焦用小光圈、广角、远距离；浅焦用大光圈、长焦、近距离。
5. 每个角色或空间固定一个主焦段；换焦段必须给理由。
6. 手持用广角；长焦手持必抖，需稳定设备。
7. 变焦只在有动机时用；推拉要落到新的构图关系上。
8. 焦点是注意力：先定观众该看清什么，再定景深。

## 检查清单

- [ ] 这个景别是走出来的还是变焦出来的？
- [ ] 焦距给了什么透视？脸型对吗？
- [ ] 景深够不够？背景该虚还是该实？
- [ ] 焦点落在视觉主语上吗？
- [ ] 前后景比例是否服务于关系？
- [ ] 变焦有动机吗？
- [ ] 同一角色跨镜头焦段一致吗？
- [ ] 低照度下光圈全开，景深还够吗？

## 与风格层接口

- 镜头语法写：主焦段（毫米数）、变焦许可、景深策略、焦点归属。
- 导演档案的“镜头”格只写后果：`35mm，靠近时前景夸张`；`85mm，人物从背景剥出`。
- AI 提示写毫米数与后果：`24mm wide-angle distortion, deep focus` 或 `85mm compression, shallow depth of field`；不只写“特写”。
- 分镜表标：机位距离、焦段、光圈档、焦点对象。

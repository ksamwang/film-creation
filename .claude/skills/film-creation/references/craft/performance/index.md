# 表演

## 这个模块解决什么

AIGC 里的“表演”不是让模型演情绪，而是把人物的意图拆成可见的微动作 token：视线、呼吸、手、重心、距离。这五项是本模块的最小单位。模型不理解“更悲伤”，只响应这些可观察量。本模块把书里的规定情境、目标—障碍—行动、定分与尺寸，翻译成生成上下文、镜头内动作序列和可复用的资产 token。

## 先读哪篇

| 情况 | 读 |
|---|---|
| 生成的人物像摆拍，不知道在看什么 | `01-given-circumstances.md` |
| 动作写成形容词，画面不动 | `02-action.md` |
| 同一条反复生成，越改越飘 | `03-rehearsal.md` |
| 要统一调整多条镜头的人物状态 | `04-direction.md` |
| 角色跨镜头变脸、变装、变体态 | `05-casting.md` |

## 子文件

- `01-given-circumstances.md`：规定情境 = 生成上下文 token，模型需要知道的七类事实。
- `02-action.md`：目标、障碍、行动三层，及物动词转成画面内微动作。
- `03-rehearsal.md`：表演 token 五元组与迭代，一次只改一个变量，定分后再批量生成。
- `04-direction.md`：导演层只管条件与剪裁，用 token 差分调整，不写“更悲伤”。
- `05-casting.md`：角色设计 token 与跨镜头一致性，位置、工具、可执行动作范围。

## 两本书的分工

哈根给顺序：先填规定情境，再定目标与障碍，最后把行动果决化为“得分”。《尊重表演艺术》第 11 章《基本的目标训练》给出六类情境与行动序列，第 21 章《初次接触一出戏》说明初次印象属于观众。阿德勒给颗粒度与尺寸：《表演的艺术》第 2 课要求情境具体到“我身处何处”，第 13 课《赋予动作尺寸》把同一动作在特写与全景中的大小分开。

## 一条底线

表演不能被命令，只能被安排。在 AIGC 里，“安排”就是写清情境、动作对象与 token 值；凡是落不到视线、呼吸、手、重心、距离的指令，都不进入提示词。情绪词只用于内部判断，不进入正向 prompt。

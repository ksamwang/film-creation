# 镜头功能词典

景别、角度、运镜回答「怎么拍」（`camera/lexicon-*.md`）；功能回答「**这一镜是干什么的**」。拆镜时先定功能，再选拍法。同一个特写，可以是插入、反应或情绪强调，拍法相近，在序列里的位置和时长完全不同。

每条写：
- **是什么**；
- **什么时候要**；
- **一场放几个**；
- **剧本里**：剧本通常写了没有。写「常缺」的，拆镜时要主动补；
- **拍法**；
- **生成**；
- **失败**。

功能的分组和条目是行业惯例的整理；书里有的地方标了出处。

---

## 1. 交代

### 建立镜头 Establishing
- **是什么**：告诉观众在哪、什么时间、谁在场、彼此距离多远。
- **什么时候要**：每个新场景的开头；时间或地点跳转之后。
- **一场放几个**：1 个。短场景可以用一个带出锚点的中景代替纯空景（`references/drama/06-storyboard.md` §4）。
- **剧本里**：场头写了地点，但没写观众从什么角度认识这个空间——常缺。
- **拍法**：全景或大远景；高角能表达孤立或全知；人物放在锚点旁（门、桌、窗）。
- **生成**：稳；参考图生，场景参考图同时作为后面各镜的空间锚点。
- **失败**：建立镜头里的空间和后面的镜头对不上（门换了位置）；建立镜头太长，开场拖沓。

### 重新交代 Re-establishing
- **是什么**：戏进行到一半，再给一次全景。
- **什么时候要**：人物走位改变了空间关系；有新人物进入；转折之后需要喘一口气。
- **一场放几个**：长场景 1 个；短场景不需要。
- **剧本里**：常缺。
- **拍法**：全景，最好换一个与建立镜头不同的角度，让空间更立体。
- **生成**：稳；用同一张场景参考图。
- **失败**：位置和前面的近景不一致——重新交代反而让观众迷路。

### 入场 / 出场 Entrance / Exit
- **是什么**：人物进入或离开画面、离开场景。
- **什么时候要**：新人物登场；一场戏的结束。
- **一场放几个**：每次进出 1 个。
- **剧本里**：写了「走进来」「离开」，没写从哪边、往哪边——方向常缺。
- **拍法**：人物从画边入画、出画；出画后留一拍空景再切（《电影镜头设计》7.11–7.12 出镜与入镜、清空画面）。
- **生成**：稳；入画、出画写成起点和落点。出画后的空景可以裁剪同一镜的尾部，不必另外生成。
- **失败**：入画方向和上一镜的出画方向矛盾；人物在画面中间凭空出现。

## 2. 关系

### 关系镜 / 双人 Two-shot
- **是什么**：两个或几个人物同框，交代他们的距离和权力。
- **什么时候要**：对话的开始；关系发生变化的时候；转折之后。
- **一场放几个**：对话戏 1–3 个。
- **剧本里**：剧本写台词，不写两个人站在哪——常缺。
- **拍法**：侧面双人、过肩、前后纵深；距离和高低直接表达关系（`camera/lexicon-frame.md`）。
- **生成**：两张脸同框是风险点，一镜只让一人说话；另一人侧对、背对或在虚焦里。
- **失败**：两张脸长得越来越像；说话的口型落在错的人脸上。

### 过肩 Over-the-shoulder
- **是什么**：越过一个人的肩看另一个人。
- **什么时候要**：对话中保持两人的空间联系；需要说话人正脸，又要提醒观众对方在场。
- **一场放几个**：正反打各 1–2 个。
- **剧本里**：不写。
- **拍法**：前景肩膀占画面 1/4–1/3，焦点在对面人物（`camera/lexicon-shot.md`）。
- **生成**：稳；前景人物只露后脑和肩，不需要脸部一致。
- **失败**：前景人物转过脸来抢口型。

### 单人 Single
- **是什么**：一个人物独占画面，通常是说话或做决定的时刻。
- **什么时候要**：这一刻属于他：重要台词、决定、被逼到角落。
- **一场放几个**：对话戏里最多的镜头。
- **剧本里**：不写。
- **拍法**：中近景到近景；景别和角度表达权力（微仰 = 强，微俯 = 弱）。
- **生成**：稳；一张脸最容易保持一致。
- **失败**：正反打两边的景别、角度不对称，而且不是有意为之。

## 3. 视线

### 视线对象 Eyeline target
- **是什么**：人物看到的东西。
- **什么时候要**：**每次有人「看」**。人物看了，观众却没看到他看的东西，观众就被关在外面。
- **一场放几个**：每次「看」1 个。
- **剧本里**：常写「她看到……」，但经常只写在动作行里，没有单独成镜——常缺。
- **拍法**：从人物的视线方向和高度拍；可以是主观镜，也可以是客观镜。
- **生成**：视物体：稳。视人：参考图生，方向和人物的视线一致。
- **失败**：视线方向和上一镜相反（她看画右，下一镜的东西在画左）。

### 主观镜 POV
- **是什么**：完全从人物的眼睛看出去。
- **什么时候要**：要观众**成为**这个人物：发现、恐惧、窥视。
- **一场放几个**：0–2 个。用多了观众会累。
- **剧本里**：偶尔写「（主观）」。
- **拍法**：人物视线高度；可以带一点手持晃动或前景遮挡（门缝、手）（《电影镜头设计》第十六章 视点）。
- **生成**：稳；画面里不出现主角自己的脸，一致性压力小。
- **失败**：主观镜里出现了主角自己；主观镜之后没有回到人物的脸，观众不知道刚才是谁在看。

### 反应镜 Reaction
- **是什么**：人物接收到信息、台词或动作后的反应。
- **什么时候要**：每个重要信息之后。**观众通过反应知道这件事有多重要。**
- **一场放几个**：对话戏里常常和台词镜一样多；转折那一拍最重要。
- **剧本里**：动作行偶尔写「她愣住」，大多数没写——常缺。
- **拍法**：近景，固定或缓推；1.5–3 秒：触发 → 落到脸上 → 定住。
- **生成**：稳；不张嘴，比台词镜更稳。写可见的泄露（下巴绷紧、视线移开），不写抽象情绪（`references/drama/06-storyboard.md` §3）。
- **失败**：反应太大（大哭、大惊）；反应镜太短，表情还没落下就切走了。

## 4. 信息

### 插入 Insert
- **是什么**：一个物件、一行字、手上的一个动作的特写。
- **什么时候要**：观众必须看清的细节：证据、短信、伏笔物件、关键动作。
- **一场放几个**：每条关键细节 1 个。
- **剧本里**：写了物件，不一定写它要单独成镜——常缺。
- **拍法**：特写或大特写；固定；时长按要读的内容定（字按每秒 4–6 个字留时间）。
- **生成**：物件：稳。字和屏幕：后期合成或定帧（`camera/index.md`）。伏笔物件进资产表，建立和回收用同样的外观（`writing/devices.md` 伏笔与回收）。
- **失败**：字被模型画错；插入镜里的物件和全景里的不一样。

### 揭示镜 Reveal
- **是什么**：把观众之前没看到的东西露出来。
- **什么时候要**：反转、惊吓、真相、身份。
- **一场放几个**：一场最多 1 个。
- **剧本里**：写了揭示的内容，不写揭示的方式。
- **拍法**：后拉揭示、摇过去、焦点转移、人物移开露出背后（`camera/intent.md`「揭示 / 反转」）。
- **生成**：后拉和焦点转移常需首尾帧或定帧；也可以拆成两镜：遮挡 → 切到揭示。
- **失败**：揭示前没有建立期待；揭示的东西在前面的镜头里已经被看到了。

## 5. 动作

### 动作镜 Action
- **是什么**：承担一个主导动作的镜头。
- **什么时候要**：剧情靠这个动作推进（转屏幕、递钥匙、一巴掌）。
- **一场放几个**：每个关键动作 1 个；打斗戏一镜一个动作。
- **剧本里**：写了。
- **拍法**：动作写成起点 → 动作 → 落点；切点放在动作中间，下一镜接着做完（《电影镜头设计》7.10 动接动剪切）。
- **生成**：一镜 2–3 个连续动作以内；有接触的动作把起势和结果拆成两镜（`camera/recipes/fight.md`）。
- **失败**：动作太多被压扁；两镜之间动作重复或跳过一段。

### 结果镜 Result
- **是什么**：动作之后的结果：倒下的人、碎掉的杯子、被撕开的协议。
- **什么时候要**：动作本身难生成或太暴力时，用结果代替过程。
- **一场放几个**：每个关键动作 0–1 个。
- **剧本里**：常缺。
- **拍法**：静止画面，特写或中景。
- **生成**：稳；静止的结果比运动的过程容易得多。
- **失败**：结果和前面的动作对不上（左手打的，右脸红了）。

## 6. 节奏

### 切出镜头 Cutaway
- **是什么**：暂时离开主要动作，切到同一时空里的另一样东西。
- **什么时候要**：压缩时间；遮住两镜之间接不上的地方；给观众一点别的信息（《电影镜头设计》6.10 切出镜头和过渡镜头；《导演创作完全手册》30.3「切至海鸥」）。
- **一场放几个**：0–2 个。
- **剧本里**：常缺。
- **拍法**：同一空间里的物件、窗外、旁观者。
- **生成**：稳；是修补连续性最便宜的办法。
- **失败**：切出去的东西和戏毫无关系，观众以为它是线索。

### 过渡镜 / 空镜 Transition
- **是什么**：场与场之间的连接：空景、天空、街道、时间标志。
- **什么时候要**：时间或地点跳转；情绪需要换挡。
- **一场放几个**：场与场之间 0–1 个。
- **剧本里**：常缺。
- **拍法**：2–4 秒；最好带一点下一场的信息（下一场是雨夜，过渡镜就是雨）（`camera/lexicon-transition.md`）。
- **生成**：稳；纯环境，没有人物一致性的问题。
- **失败**：为了好看塞空镜，节奏被拖慢。

### 停顿镜 Beat
- **是什么**：转折之后留一拍，什么都不发生，让观众消化。
- **什么时候要**：揭示、打击、告白之后（`writing/devices.md` 转折与停顿）。
- **一场放几个**：每个大转折 1 个。
- **剧本里**：剧本常写「沉默」，但很少写成一个镜头——常缺。
- **拍法**：低运动的反应镜或环境镜，3–5 秒；不放台词，音乐常常也停（`craft/sound/03-silence.md`）。
- **生成**：稳。
- **失败**：停顿太长，节奏塌了；停顿里又塞了新信息。

### 时间流逝 Time passage
- **是什么**：告诉观众过了多久。
- **什么时候要**：省略一段时间。
- **一场放几个**：0–1 个，或一组蒙太奇。
- **剧本里**：写「三天后」这类字卡，不写画面。
- **拍法**：同一机位不同时段、光影移动、物件状态变化（烟灰缸满了、花枯了）（`camera/recipes/montage.md`）。
- **生成**：同一机位多时段，用同一张关键帧换光（定帧）。
- **失败**：用字卡解决一切；变化太细，观众没看出来。

## 7. 情绪与结构

### 情绪强调 Emphasis
- **是什么**：在一场戏最重要的时刻，景别突然收到最近。
- **什么时候要**：转折那一拍。
- **一场放几个**：1 个。用多了就不再是强调。
- **剧本里**：不写。
- **拍法**：特写或大特写；缓推；前后的镜头保持更宽的景别，强调才成立。
- **生成**：稳；推镜写成缓推，避免急推变形。
- **失败**：整场都是特写，没有对比。

### 拉远 / 孤立 Pull away
- **是什么**：情绪最高点反而拉开距离，让人物变小。
- **什么时候要**：告别、失去、孤独、无力；不想让观众看清眼泪的时候。
- **一场放几个**：0–1 个，通常在场尾。
- **剧本里**：不写。
- **拍法**：大全景、高角、后拉（`camera/intent.md`「孤独 / 孤立」「结局 / 告别」）。
- **生成**：固定大全景稳；后拉可用首尾帧。
- **失败**：用在情绪还没到的地方，显得冷漠。

### 母题镜 Motif
- **是什么**：一个反复出现的物件或构图，每次出现状态不同。
- **什么时候要**：全片有视觉母题时，每个关键节点出现一次（`writing/devices.md` 视觉母题）。
- **一场放几个**：0–1 个。
- **剧本里**：写了物件，不一定写它要单独成镜。
- **拍法**：同一构图、同一景别，只改物件状态。
- **生成**：同一张关键帧做参考，构图不变，状态改变。
- **失败**：母题每次拍法不同，观众连不起来。

## 速查：剧本里常缺的镜头

拆完一场戏，对照这一列补镜：

| 功能 | 漏了会怎样 |
|---|---|
| 建立镜头 | 观众不知道在哪、谁离谁多远 |
| 视线对象 | 观众被关在人物的视线之外 |
| 反应镜 | 信息落不到人身上，观众不知道它有多重要 |
| 插入 | 关键细节看不清，伏笔埋不下去 |
| 入场 / 出场方向 | 空间乱，观众迷路 |
| 停顿镜 | 转折一个接一个，观众麻木 |
| 结果镜 | 难拍的动作没有替代方案 |
| 切出镜头 | 镜头之间接不上时没有补救 |

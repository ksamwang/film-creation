# 目标、障碍、行动：把动词写成微动作

## 核心判断

生成模型的最小表演单位不是情绪，而是一个人对另一个人或物件做的及物动作。导演无法命令情绪，但可以设定目标、放置障碍、指定行动；三者确定后，画面才有可生成的落点。提示词里写“愤怒”，模型给的是通用表情；写“把杯子推到桌对面，手指仍按在杯沿”，模型才知道手、眼、距离各做什么。

## 书里的原则

哈根在《尊重表演艺术》第 11 章把一场戏拆成层级：主要目标、眼前目标、障碍、行动；第 25 至 27 章分别展开目标、障碍、行动。她那个回家的例子里，目标是让自己舒服一点，障碍是十点面试、宿醉头疼、剧本印不清、对面偷窥者不走，行动是跳下床、猛拉窗帘、让闹钟面壁、倒烟灰缸、找阿司匹林。这些行动全部及物，全部落在身体和物件上。她把最终固定下来的行动序列叫“得分”，并说举动的果决化是从特殊化发展出来的。

阿德勒在《表演的艺术》第 3 课给出同一件事的质地：表演就是去做。第 10 课要求建立动作的词汇表，第 11 课要求每个动作有瞬间及内在的理由——握长矛要先搞清是为仪式还是为战争。第 13 课《赋予动作尺寸》指出，同一动作在舞台上和特写里不是同一个大小。结构保证有冲突，尺寸保证冲突不是喊出来的。

## AIGC 执行

一个镜头只放一个及物动作。把“她生气地收拾东西然后离开”拆成三条：推椅、抓包、停在门口。每条写成 action token，动词必须具体：按、压、捏、推、抽、扣、松、挡、递、收回，而不是“动”“反应”“表演”。

```text
SUBJECT: C1
ACTION: right palm presses cup to table edge | fingers stay on rim | gaze at C2
MOTION: slow push | 2s hold | static camera | 4s
```

动作链写成得分表，四列：起始状态、动作、结束状态、尺寸。尺寸跟景别绑定：全景给位移和重心变化，中景给手与前臂，特写给视线与呼吸，大特写给眼睑与指尖。动作结束处就是剪辑落点，不是台词结束处。

每个动作追问一次“为什么是现在”：画面里要有一个触发物——门响、电话亮、对方伸手。触发物缺失，模型会把动作生成成无原因的摆拍。多人同框时分开写动作，不要在一个 prompt 里塞两个主语。

NEGATIVE 针对表演失败模式：`waving arms | theatrical gesture | crying face | frozen smile | idle hands | floating weight`。

## 检查清单

- [ ] 每个镜头是否只有一个及物动作？
- [ ] 动词是否具体到手、眼、重心或接触点？
- [ ] 动作是否落在物件或对手身上？
- [ ] 画面里是否有“为什么现在做”的触发物？
- [ ] 动作尺寸是否与景别匹配？
- [ ] 动作结束点是否就是剪辑点？
- [ ] 多人镜头是否拆开生成？

## 常见错误

- 写“她愤怒地摔门” → 模型给夸张手臂和通用怒脸；改成“右手抓住门把，拉回，肩先转”。
- 一个 prompt 连写三个动作 → 注意力平均，三个都不到位；拆成三个镜头，分别定分。
- 特写里写大幅位移 → 构图崩、脸变形；特写只保留视线、呼吸、手指。
- 动作没有对象 → 人物在空中比划；给一个杯子、一扇门或另一个人的肩。

## 与风格层接口

动作 token 直接进分镜：一行动作对应一个镜头，得分表就是 shot list 的表演列。与调度模块的分界是：调度给行动的位置与路线，表演给行动的对象、力度与尺寸。与视觉模块的分界是：视觉决定观众离多近，表演决定这个距离上该看见哪一块身体。写 prompt 时先定动作，再选景别，最后才加光色；顺序反过来，动作会被风格词挤掉。

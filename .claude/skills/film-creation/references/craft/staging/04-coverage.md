# 覆盖：主镜头、长镜头与备用镜头

## 核心判断

覆盖不是拍得多，而是用最少的镜位回答观众关于空间与因果的问题。每多一个镜位，就多一次灯光、走位和剪辑匹配的成本；不能回答新问题的镜头，不该拍。

## 书里的方法

**主镜头**：用一个机位完整交代地理、人物相对位置和整场动作。它是剪辑的安全网，也是判断其他镜头是否必要的参照。主镜头里必须发生空间事件，否则只是一份全景记录。

**长镜头**：以不切开动作为前提，保留表演的连续和空间的完整。它和主镜头不是同义词：主镜头可以切开使用，长镜头则以“不切”为形式。长镜头适合关系微妙、需要演员彼此反应的戏；如果镜头内部没有注意力的转移，长镜头会变成拖沓的跟拍。

**多机位拍摄和备用镜头**：多机位保表演连续性，备用镜头保剪辑余地。两者都增加灯光与调度成本，不能替代计划。书中提醒，备用镜头是保险，不是默认选项；拍之前要知道它准备回答哪个问题。

**剪辑风格与问答模式**：每切一个镜头，等于向观众提一个问题或回答一个问题。覆盖按“问题—回答”组织，不按台词句子组织。主镜头回答“他们在哪”，双人镜头回答“他们怎么相对”，单人镜头回答“谁在承受”，特写回答“这一刻谁变了”。

**机上剪辑**：在拍摄时就想好切点，让动作给切点留余地——人物出镜、入镜、清空画面、动作交接。机上剪辑不是省掉剪辑，而是让素材自带可接的缝。

**分离拍摄法与综合拍摄法**：把动作拆成单人分别拍，和把关系保留在同一画面里拍，是两种关联方式。前者让观众看内心，后者让观众看关系；选择取决于这场戏的核心是“谁怎么想”还是“谁对谁做了什么”。

## 可执行规则

1. 先拍主镜头，确认地理与空间事件成立，再拍覆盖。
2. 每个覆盖镜头写一句“它回答主镜头没有回答的哪个问题”；写不出就删。
3. 长镜头内部至少安排一次注意力转移，否则改成分切。
4. 多机位只在表演连续性比机位精度更重要时使用。
5. 备用镜头按“如果主方案失败，缺的是地理还是情绪”来补，不按“多拍几个角度”来补。
6. 按问答顺序排镜位，不按剧本台词顺序排。
7. 拍摄时给每个动作留出镜、入镜和清空画面的切点。

## 检查清单

- [ ] 主镜头是否独立交代了地理与空间事件？
- [ ] 每个覆盖镜头是否回答了新问题？
- [ ] 长镜头内部是否有注意力转移？
- [ ] 多机位是否真的为了表演连续性？
- [ ] 备用镜头是否针对具体风险？
- [ ] 镜位顺序是否按问答模式组织？
- [ ] 动作是否给剪辑留了切点？
- [ ] 是否存在信息重复的镜头？

## 与风格层接口

覆盖表决定剪辑节奏和镜头清单。给剪辑的素材要按“问题—回答”标注，而不是按景别堆叠；给摄影的机位表要标出哪些镜头共享灯光、哪些需要重新布光。风格层想要的“冷静”或“压迫”，可以通过选择长镜头还是分切来实现，而不必靠后期加快切。

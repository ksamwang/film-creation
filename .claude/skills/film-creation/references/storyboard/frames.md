# 分镜图：把分镜脚本画出来

分镜脚本是文字，分镜图是同一批镜头的**画面**：每镜一格，看构图、方向、景别跳跃和空间是否成立。实拍里分镜图由画师画；AIGC 里分镜图有两种来源：**草图分镜**（便宜、快，只检查镜流）和**成片风关键帧**（直接当首帧用，`references/aigc/workflow.md` §1 关键帧先行）。

先有分镜脚本，再画分镜图。分镜图画出问题，回分镜脚本改，不要直接在图上改镜头设计。

---

## 1. 草图分镜还是成片风关键帧

| | 草图分镜 | 成片风关键帧 |
|---|---|---|
| 样子 | 灰度线稿、简单人形、少量明暗 | 最终风格、真实人物资产、最终光色 |
| 检查什么 | 镜流、方向、景别节奏、空间关系 | 以上全部 + 身份、造型、光、质感 |
| 成本 | 低；可以一次出整场 | 高；每镜多次迭代 |
| 一致性要求 | 只要求空间和方向对 | 人物、场景、道具全部一致 |
| 能直接当首帧吗 | 不能 | 能 |
| 什么时候用 | 镜头多（20 镜以上）、空间复杂、要先给人审镜流 | 镜头少、空间简单、风格已定 |

**默认**：15 镜以内的短片直接出成片风关键帧；超过 20 镜、或有复杂调度（追逐、多人走位）的，先出草图分镜审镜流，通过后再出关键帧。

## 2. 草图分镜怎么出

**提示写法**（模式 A；模式 B 写进 STYLE）：

```text
Rough storyboard sketch, grayscale pencil and marker, simple figures, minimal detail, clear silhouettes.
Medium shot at eye level: a man (figure A) at frame left sits at a desk facing right; a woman (figure B) stands at frame right, a coffee cup between them on the desk.
```

- **只写构图要素**：谁在画面哪里、朝哪、景别、锚点、前后关系。不写表情细节和质感。
- 人物用「A / B」或简单的区分特征（一个戴帽子、一个长发），不需要人物资产。
- 场景要有锚点（门、桌、窗），草图分镜的主要任务就是检查锚点在各镜里的位置是否一致。

**多格拼版**：一张图里出 6–9 格（`a 3x3 storyboard grid, panel 1: ..., panel 2: ...`）。

- 好处：风格统一、一次看完一场的镜流、成本低。
- 风险：格子分辨率低；模型会把相邻格子的内容混在一起，或画错格子顺序；超过 9 格基本不可控。
- 用法：只用于草图分镜。每格写短句，格数 ≤ 9；画完逐格对照分镜脚本，错的格子单独重出。
- 不要用拼版出成片风关键帧：裁出来的格子分辨率不够当首帧。

## 3. 标注

分镜图上要标出图本身表达不了的东西：运镜、人物运动、镜头之间的转换（《电影镜头设计》第三章 3.10–3.14 图解摄影技巧、摇镜和移镜头、推轨镜头和变焦镜头、镜头间的转换、升降镜头）。

| 要表达 | 标注方式 |
|---|---|
| 推近 / 拉远 | 画内再画一个小框（终点构图），四角用箭头连到外框；推近箭头朝内，拉远箭头朝外 |
| 横摇 / 横移 | 画格加宽，或画两个相连的格子，上方一条横向箭头 |
| 竖摇 / 升降 | 画格加高，侧边一条竖向箭头 |
| 跟移 | 人物运动箭头 + 画格外一条平行的摄影机箭头 |
| 人物运动 | 实心箭头，从起点画到落点；落点处画一个淡的人形 |
| 视线方向 | 一条虚线箭头 |
| 镜头之间的转换 | 两格之间写「切」「叠」「黑」「匹配」 |
| 镜号、时长、台词 | 写在格子下方 |

**AIGC 里标注不要让模型画。** 模型画的箭头和小框不可靠，还会被当成画面内容带进视频。分镜图生成干净的画面，标注在排版或剪辑软件里加，交付时一格一张图 + 一行文字说明。

## 4. 构图要点

- **画幅按项目定**，所有格子同一画幅（《电影镜头设计》3.15 画幅制式与呈现方法）。提示词里仍不写画幅参数，画幅由生成设置决定。
- **画动作的起点**，不画高潮瞬间（`references/aigc/workflow.md` §1）：这一格要当首帧，视频从这里开始动。
- **给运动留空间**：要推近就构图稍宽；人物要走出画，就在他走向的那一侧留空。
- **竖屏**：脸在画面中上部，下方约 20% 留给字幕和平台界面；双人用前后纵深，不左右排开（`references/drama/06-storyboard.md` §4）。
- **横屏**：用好左右空间，双人可以分居两侧；视线前方留空（`camera/lexicon-frame.md`）。

## 5. 从分镜图到首帧

1. **草图分镜审过**：镜流、方向、景别节奏都对。
2. **出成片风关键帧**：用人物、场景、道具的参考图，按草图的构图出图。模型支持构图参考（结构图、线稿控制）时，草图直接作构图参考；不支持时，把草图里的站位和景别逐条写进提示。
3. **审关键帧**：身份、造型、光、锚点；按第 6 节的清单。
4. **首帧生视频**：提示只写运动（`references/aigc/workflow.md` §1）。

关键帧就是给用户审的分镜图。用户在这一步改，成本最低；进了视频再改，每改一次都是一次完整生成。

## 6. 审分镜图

- [ ] 每格和分镜脚本的镜号、景别、角度一一对应？
- [ ] 轴线和画面方向全场一致？人物的左右没有互换？
- [ ] 视线方向和视线对象的位置对得上？
- [ ] 锚点（门、桌、窗）在各格里的位置一致？
- [ ] 相邻格子景别或角度有明显差别（除非有意跳切）？
- [ ] 动作起点画对了，运动方向留了空间？
- [ ] 成片风关键帧：脸、造型、道具和资产一致？没有多余的人和手？

## 7. 失败与修法

| 失败 | 原因 | 修法 |
|---|---|---|
| 人物左右互换 | 提示没写画面方位，或模型镜像了构图 | 每格写「在画左 / 画右」；出图后对照前一格检查，镜像的直接重出 |
| 锚点位置每格不同 | 没有场景参考图，或只靠文字 | 先出场景主图，所有格子用同一张作参考 |
| 拼版格子内容混在一起 | 格数太多，或每格描述太长 | 降到 6 格以内；每格一句；错格单独重出 |
| 草图画成了成片 | 风格词不够 | 写明「rough sketch, grayscale, minimal detail」，并去掉质感、光色词 |
| 关键帧好看但接不上 | 每格单独追求好看，没对照前后格 | 按剪辑顺序排在一起审，不单格审 |
| 模型画出了箭头和文字 | 把标注写进了提示 | 提示里只写画面；标注后期加 |

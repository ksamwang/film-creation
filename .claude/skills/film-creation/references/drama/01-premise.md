# 立项：题材、受众与核心梗

> 产物：P1 setting（`standard.md`）。出海项目再读 `09-overseas.md`。
> 一句话：**短剧卖的是情绪，先锁定观众要什么情绪，再找能持续兑现它的引擎，最后算这个引擎生成起来贵不贵。**

## 1. 先定观众，再定故事

短剧是情绪商品。立项第一步不是构思剧情，而是回答「谁在看、他想被满足什么」。

| 情绪导向 | 观众要什么 | 典型兑现 |
|---|---|---|
| **获得感** | 主角拿到钱、权、地位，尤其是**他人的认可**，再对轻视过自己的人打脸 | 亮身份、反杀、当众翻盘 |
| **关系感** | 关系的试探、拉扯、确认；一个眼神、一次站队都是爽点 | 吃醋、护短、公开选择、和解 |

**痛点是爽点的前提。** 没有被刺痛过，打脸就是空的。常用痛点：

- 男频：安全感被打破（背叛、失业、被逐出家门）；**尊严受损**（当众被叫废物，比单纯贫穷更刺痛）；保护不了家人。
- 女频：情感安全被打破（出轨、闺蜜背叛、被陷害）；付出不被认可。
- 把抽象痛点写成**具体画面**：「尊严被践踏」= 酒席上被当众泼酒；「付出不被认可」= 省吃俭用买的礼物被男友转手送人。这一步同时是在给分镜准备素材。

## 2. 选赛道

赛道决定观众的预期和爽点密度。先选一个**主卡**（观众主要在等什么），最多再挂一个**副卡**（改变行动条件）。说不出「没有副卡，主角哪个选择会不同」，就不要副卡。

| 频道 | 赛道 | 底层心理 | 一句话执念 | 爽点密度 |
|---|---|---|---|---|
| 男频 | 战神 / 龙王归来 | 权力补偿 | 你们口中的废物是你们的王 | 每集小打脸，每回合一次跪拜 |
| 男频 | 神豪 / 鉴宝 / 神医 | 金钱或专业碾压 | 你这行我玩剩下的 | 每集一个专业名场面 |
| 男频 | 赘婿 / 出狱归来 | 延迟清算 | 今天踩我的，明天一个个还 | 憋屈:释放 ≈ 3:1 |
| 女频 | 重生复仇 | 重来掌控 | 上辈子的账这辈子一笔笔收 | 每集撕一层伪装 |
| 女频 | 真假千金 | 身份正名 | 我的身份轮不到你们盖章 | 掉马三档：小圈子 → 家族 → 公开 |
| 女频 | 追妻火葬场 / 带球跑 | 高傲者低头 | 当年你爱答不理 | 爽点是「他跪」 |
| 女频 | 大女主事业 | 能力自证 | 位置是我自己挣的 | 每回合赢一单 |
| 中性 | 萌宝 / 家庭伦理 | 亲情 + 公道 | 我爸不认识我，我认识我爸 | 温情与打脸交替 |
| 剧情流 | 悬疑 / 规则怪谈 / 智斗 | 解谜与掌控 | 不闭环不罢休 | 每 3–5 集一个「线索 → 误判 → 翻案」 |

**流派判断**（判错全白写）：观众追的是「他什么时候信 / 认 / 跪」→ **情绪流**（大多数赛道）；追的是「接下来发生什么」→ **剧情流**。两者的全剧结构不同，见 `02-season.md`。

出海赛道（CEO romance、狼人、复仇、隐藏身份继承人等）见 `09-overseas.md`。

## 3. 核心梗与信息差引擎

**核心梗**（setting 的 `hook`）是观众为之而来的套路，必须能撑 20–30 集一个单元，而不是一集。检验：把两个角色放进一个房间，**没开口就有张力**，梗才成立。

短剧的悬念不是「结局是什么」，而是「已知目标，不知过程」。驱动它的是**信息差**——剧中人和观众知道的不一样：

| 模型 | 谁知道 | 观众在等什么 | 用法 |
|---|---|---|---|
| A | 主角知道，观众和配角不知道 | 主角什么时候揭晓 | 解谜、底牌 |
| B | 观众和配角知道，主角不知道 | 主角知道后什么反应 | 身份觉醒、认亲 |
| C | 观众知道，剧中人都不知道 | 剧中人会被震成什么样 | 穿越、重生、年代 |
| D | **主角和观众知道，配角不知道** | 反派还能作死到什么程度、第几集亮身份 | 隐藏大佬，**最常用** |

一部剧要在不同阶段**切换**信息差组合，一套用到底观众会麻。每次切换都应写进大纲（见 `02-season.md`）。

## 4. 一句话故事

`logline` = **主角 + 目标 + 阻碍 + 亮点**。

- 目标要具体：「三个月内赚到一千万」优于「成为有钱人」；只有一个核心目标。
- **大期待最晚第 2 集直白亮出**，不要藏、不要让观众猜。
- 例：「被未婚夫和闺蜜推下楼的林晚重生回订婚宴前一天，她要在婚礼上当众拿回被偷走的设计专利，而这一次，她先一步握住了录音。」

## 5. 选题五问（任一答不上就换题）

1. 目标观众是谁？
2. 核心情绪共鸣点明确吗？
3. **视觉化落地难度高不高？**（AIGC 里就是生成成本，见第 6 节）
4. 有没有踩政策与平台红线？
5. 有没有同类作品或市场数据支撑？

## 6. AIGC 可做性：题材的生成成本

AI 短剧的成本是「片段秒数 × 重试次数」。立项时就要知道这个题材贵在哪，而不是写完剧本才发现生成不出来。

| 元素 | 成本 | 原因 | 省法 |
|---|---|---|---|
| 对话戏（办公室、客厅、宴会） | 低 | 固定空间、少人、动作小，模型最稳 | 多数集以此为主 |
| 打戏、推搡、掌掴 | 高 | 接触、受力、回合衔接容易糊；常需拆镜和多次重试 | 只给关键回合；一个决定性动作拍清楚 |
| 群戏（宴会全场、围攻） | 高 | 人数一多就复制人、换装、乱站位 | 用前景主角 + 背景虚化人群；等待者从首帧就在画面里 |
| 特效（法术、变身、异能） | 中高 | 画风易跑；需要固定形状和材质 | 每种能力定一个固定视觉，全剧复用 |
| 儿童、动物 | 中 | 比例和动作不稳 | 少给全身动作，多给反应和对白 |
| 车戏、水、火、高空 | 高 | 物理和空间复杂 | 用车内、窗外、声音和反应暗示 |
| 频繁换场景 / 换形象 | 中 | 每个新造型都要一张参考图 | 每集场景 ≤2，形象只在剧情真正改变外形时新增 |

**建议的项目上限**（标准档、60 集）：常驻场景 6–10 个，主要角色 4–6 个，每个角色 1–3 个形象，全剧特效视觉 ≤3 种。超出不是不能做，而是要知道钱花在哪。

## 7. 人物小传怎么写

`characters` 每人一份，字段见 `standard.md` P1。写给两个下游用：

- **编剧用**：`personality` 写说话方式和底线（他怎么拒绝别人？），`relations` 写和每个主要角色的利害，`arc` 写他在全剧里变成什么。每个有名字的角色都要能回答「他为什么必须存在」。
- **生成用**：`visual` 是之后所有造型图的源头，写成特征卡：年龄、体型、脸型与五官、发型发色、主服装（**颜色用 hex**，如 `#1F2A44 藏青西装`）、标志性配饰。不写画幅、构图、风格词，不写性格。

反派要强：反派越聪明、越嚣张，打脸越值钱；反派降智只为衬托主角，观众会出戏。**打脸对象必须是推动剧情的主要反派**，不是路人、弱者或公职人员。

## 立项产出检查

- [ ] `audience` 写了情绪导向和痛点？
- [ ] `genre` 是一个主卡（最多一个副卡），并判定了情绪流 / 剧情流？
- [ ] `hook` 能撑一个 20–30 集的单元？
- [ ] `logline` 四要素齐全，目标具体？
- [ ] 前两集要用的信息差模型想好了？
- [ ] 主要角色 `visual` 是能画出同一个人的特征卡？
- [ ] 知道这个题材最贵的元素是什么、怎么省？

创意模糊时给 **3 个方向**让用户选（各含赛道、一句话故事、核心梗、受众）；创意已经完整时给 1 个方案确认。确认后再写 setting。

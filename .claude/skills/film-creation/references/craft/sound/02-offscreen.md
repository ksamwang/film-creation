# 画外：扩展域与无形音角色

## 核心判断

画外不是“没拍到的地方”，而是声音在后期替画面造出来的空间。AIGC 里它首先是一张画外地图：哪一层、哪个方向、持续多久；其次才是提示词。地图没写，生成出来的画外声只会是随机装饰。

## 书里的原则

**相对画外与绝对画外。** 书里把画外分成相对（紧贴画框外、仍属同一空间）与绝对（画框永远够不到，如旁白、乐池音乐）；非叙境则根本不属于故事世界。三类不能共用一种空间处理。

**声音位置不等于声源位置。** 声源在画外某一点，声音却从扬声器出来；观众判断的是声音位置，不是物理声源。所以画外声源要稳定，移动要有过程，否则观众无法把它钉在画外。

**扩展域。** 多声道把环境声铺到画框之外，形成连续、半自主的空间，书里叫扩展域。声音先把房间四周建好，画面才敢一直停在特写。

**无形音角色。** 只听见声音、看不见身体的人。力量来自身体缺席：声音可以无处不在、全知、控制局面。身体一旦被看见，书里叫解除无声源化，这些能力随之消失。

**视听幻象。** 观众同意把声音和影像当成一个整体，于是相信画框外继续存在，哪怕画面从没拍过。画外声音就是这条“影像的另一边”。

## AIGC 执行

1. 先做画外地图表：声源 | 层级（相对/绝对/非叙境）| 方位 | 距离 | 持续或进出 | 首次出现时间。地图作为资产文件保存，跨镜头复用。
2. 每条画外声单独生成一条 stem，固定声像与距离；需要移动就生成带位移的版本，或在后期做声像自动化，不让声音瞬移。
3. 用一个连续画外声源串起多个镜头，替代定场镜头；画面可以更近，空间由环境层建立。这是扩展域在 AIGC 里最实用的做法。
4. 环境声给地域，内部的声音给体内感，远距离传播的声音（电话、广播、邻居音响）把另一个空间压进来。三类分开生成，不共用混响。
5. 隔墙、隔门必须被墙体处理：低通、混响变化、电平下降；提示写 `muffled through wall, no visible speaker`。
6. 无形音角色先定能力：全知、全视、无处不在、控制局面。生成时用无身体线索的声音：没有近场呼吸、空间感异常稳定、距离不可判。解除无声源化时，画面必须给出身体，同时声音失去一项能力。
7. 绝对画外少用；旁白与乐池音乐不加房间混响，除非它故意进入故事世界。
8. 图像提示补证据：声源在画外时，画面给门缝、影子、人物视线或空位；否则观众与模型都对不上方位。

## 检查清单

- [ ] 画外地图写了吗？每个声源属于哪一层？
- [ ] 画外声源有稳定方位吗？移动有过程吗？
- [ ] 是否用画外声替代了不必要的定场镜头？
- [ ] 环境、内部、远距离传播三类分开生成了吗？
- [ ] 隔墙声真的有墙体处理吗？
- [ ] 无形音角色的能力是什么？观众能感到吗？
- [ ] 解除无声源化在哪一刻？代价是什么？
- [ ] 非叙境声音是否被误当成画外声源？

## 常见错误

- 画外声与画内声共用一套混响 → 空间塌成一层 → 至少给画外加距离、遮挡、低通。
- 声音方位随镜头乱跳 → 观众失去画外空间 → 固定声像，移动写成轨迹。
- 用旁白当万能解说 → 世界失去边界 → 旁白归绝对画外，少用，且不加房间混响。
- 无形音角色一开口就露脸 → 权力关系提前消失 → 先让能力成立，再决定是否解除无声源化。
- 画外声没有画面证据 → 模型生成的画面与声音对不上 → 补门缝、影子、视线或空位。

## 与风格层接口

调度上，画外声源决定是否给空镜、人物是否回头、镜头是否越轴；声音说“在左边”，镜头却往右切，观众会迷路。导演档案写“画外规则”：允许哪几层、每层几个声源、是否解除无声源化。图像提示写清声源与遮挡：`voice from adjacent room, muffled through wall, no visible speaker`；若模型不生成可靠音频，这段提示真正约束的是画面，门缝、墙面、人物朝向必须和声源一致。Negative 写 `no visible speaker, no lip-sync mismatch, no clean studio voice`。

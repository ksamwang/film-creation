# 音乐：情感共鸣、非情感共鸣与位置

## 核心判断

音乐的第一决定不是风格，是位置和功能：它从哪儿来、角色听不听得见、它站在人物这边还是拒绝参与。AIGC 里音乐应作为独立 stem 生成，不要交给视频模型顺手配；位置定错，再好听的 cue 也只是贴片。

## 书里的原则

**情感共鸣与非情感共鸣。** 书里把电影音乐分两类：情感共鸣顺着场景情绪走，用文化编码放大悲伤或喜悦；非情感共鸣故意无动于衷，用稳定、天真、近乎机械的方式继续，反而把情绪压得更重。八音盒、钢片琴、自动钢琴常干这件事。还有第三种，只当路标的音乐。

**音乐产生的增值。** 音乐让观众觉得情绪是从画面里自然长出来的，其实是被加进去的。增值越成功，观众越不觉得有音乐。判断音乐是否必要，不看它好不好听，看把它拿走之后画面还剩什么。

**乐池音乐与银幕音乐。** 书里按位置分：乐池音乐在故事世界之外，评论、引导、穿越时空；银幕音乐有可见或可指认的声源，角色听得见。远距离传播的音乐（收音机、邻居音响、电话）把另一个空间带进来。位置决定音乐能知道什么、能做什么。

**作为标点符号的音乐。** 音乐可以当标点；同步点过密，它就变成动作的音效，失去自己的时间。

**作为时空转换的音乐。** 音乐可以跨时间或空间省略，但前提是省略本身成立，不是拿音乐盖剪辑。

## AIGC 执行

1. 每条 cue 先写位置表：乐池/银幕/远距离传播 | 角色是否听见 | 进入时间码 | 退出时间码 | 主功能。
2. 主功能只选一个：共鸣、拒绝（非情感共鸣）、结构标点。不要一条兼三职。
3. 音乐生成提示写编制、速度、音区、动态、是否循环；不写“温暖”“紧张”“史诗”。非情感共鸣写 `steady mechanical music box, no crescendo, no tempo change, loopable`。
4. 进入点避开情绪转折；提前或延后，让转折归画面与角色动作。退出点同理。
5. 不把音乐砸在动作同步点；要砸就把它降级为音效层，而不是配乐。
6. 画内音乐当声音物体处理：提示加距离、房间、失真；后期可被打断、被门压住。乐池音乐反之，不加房间混响。
7. 用音乐跨时间或空间省略；没有音乐也成立的转场不要加。
8. 关掉音乐试一遍：只少了气氛就删；少了结构才留，并把结构写进 cue 表。

## 检查清单

- [ ] 音乐位置写了吗？角色听不听得见？
- [ ] 主功能是一个还是三个？
- [ ] 非情感共鸣的音乐是否真的无动于衷？
- [ ] 进入点是否避开了情绪转折？
- [ ] 有没有音乐砸在动作同步点上？
- [ ] 画内音乐有距离、房间、失真处理吗？
- [ ] 音乐是在跨省略，还是在盖剪辑？
- [ ] 关掉音乐，这场戏还剩下什么？

## 常见错误

- 用“emotional score”当提示 → 模型给泛化情绪垫，和画面无关 → 写编制、速度、动态、进出点。
- 音乐从第一个镜头铺到最后一个 → 没有呼吸，观众听不见结构 → 按 cue 表进出，留无音乐段。
- 非情感共鸣写成渐强 → 变成普通配乐，冷漠感消失 → 锁定速度与动态，不跟动作。
- 画内音乐和乐池音乐共用一条混响 → 空间层级消失 → 画内加房间与距离，乐池保持干。
- 用音乐盖住转场问题 → 剪辑漏洞更明显 → 先修转场，再决定是否加音乐。

## 与风格层接口

导演档案的音乐栏写四件事：位置、功能、进入时机、编制；不写“温暖”“紧张”。摄影与剪辑据此决定段落呼吸：乐池音乐可以跨剪辑，画内音乐必须被空间约束。音乐生成提示写成可执行的声源或明确的“无音乐”：`diegetic radio, distorted, offscreen` 或 `no music`；不要写 `emotional score`，模型既不会按情绪作曲，也会把“情绪”翻译成廉价的画面滤镜。Negative 写 `no emotional score, no crescendo, no trailer drums`。

# 条形板：用变化次数而不是页数排日程

## 核心判断

拍摄顺序不等于故事顺序。排期的任务不是把场景按剧本先后摆好，而是把相同的场地、日夜、演员和特殊元素压到一起，让一天里"换"的次数最少。日程同时是承诺和可修改的工作稿：全组按它行事，但它必须留出改动的余地。

## 书里的方法

先把每个场景的制片元素按故事时间顺序录进软件，每条信息组成一根"条"，所有条排在一起就是条形板（stripboard）。这个名字来自电脑软件之前的做法：把每场戏的主要信息写在硬纸细条上，靠挪动纸条来排日程，条形板由此得名并沿用到排期软件里。

第一稿的做法很具体：看着条形板，依照一系列日程安排原则，以最经济合理的方式重新组织场景。重排时看四组关系：场地是否相同、内外景与日夜是否相同、演员是否连续、特殊元素是否集中。故事顺序只用来检查叙事有没有被破坏，不用来决定拍摄先后。

每天收工要记总页数。示例按八分之一页累计，第一日结束写"总页数：10 3/8"。这个数字是负载表：它不告诉你拍得多好，只告诉你今天装了多少。

日程有两副面孔。一方面全组按它行事，各部门据此决定何时拿设备、何时备道具、哪个演员哪天进组，服装、发型、化妆也跟着演员走；另一方面它永远不能定死。书中举的例子是公园外景遇到暴雨预警，通告前二十四小时必须改到备用场地，全天改拍室内，而且所有部门都要知道。不能改的日程不是严谨，是脆弱。

制定者也有分工。常规由副导演做；低成本项目请不起前期副导演时，制片人先做第一稿。《走钢丝的人》就是制片人先排一版，开拍前一周第一副导演和第二副导演进来定稿，两版计划相近，最后准备阶段进展很快。定稿之后，剧本只允许对白和词句修改，不能再动场地、道具、服装、灯光和发型化妆——这些一改，条形板、预算和通告会一起作废。

## 可执行规则

1. 每场一条，条上写：场景号、场地、内外景、日夜、页数、演员、特殊元素。
2. 先按场地聚，再按日夜分，再让同一演员的戏连续，最后核对故事顺序。
3. 每重排一次，数三个数字：转场次数、演员工作日、特殊元素日。
4. 每天日尾累计总页数，作为下一天装场的依据，不靠"拍快点"。
5. 儿童、动物、夜外、特技、群众场面各自成组，不拆散到多天。
6. 先锁不可移动项：演员档期、场地许可、季节与自然光、儿童工时。
7. 每个外景预设备用片场，把改动控制在二十四小时通告内。
8. 任何变动同时改三处：条形板、分解表、通告；并在二十四小时前通知全部门。

## 检查清单

- [ ] 这场戏的场地和上一场相同吗？不同的话，转场要多久？
- [ ] 这是日景还是夜景？自然光窗口够拍几页？
- [ ] 这个演员今天只拍这一场，还是能连拍三场？
- [ ] 服装、发型、化妆要换几次？换装时间算进当天了吗？
- [ ] 儿童和动物的工时上限是多少？超时前能拍到哪一镜？
- [ ] 特殊元素（火、雨、车、武器、特技）集中在同一天了吗？
- [ ] 今天的总页数是多少？和前一天比是多了还是少了？
- [ ] 如果明天外景取消，备用片场改拍哪几场？

## 与风格层接口

排期决定覆盖策略。场地集中、演员连续，才有条件在同一空间里做长镜头和分区布光；一天跨三个场地，镜头只能退回到"主镜头加必要插入"。反过来，风格如果要求大量运动镜头和多次布光，排期必须把每个运动镜头折算成额外时间，并在预算里单列轨道、稳定器和跟焦。条形板还能提前暴露"哪些场景可以合成一个连续镜头"：同一场地、同一日夜、演员不变的相邻场景，是长镜头调度的候选；被拆到不同拍摄日的场景，只能靠剪辑连接。

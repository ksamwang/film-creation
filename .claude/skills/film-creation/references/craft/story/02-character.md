# 人物：障碍前的选择，与从钩子倒推的阵容

## 核心判断

人物不是小传，是在障碍前做出的选择；观众看见选择，才相信有内在生活。所有配角都应为推动故事而存在，并且可以从钩子和主角反推出来。

## 书里的方法

**内在生活只能被障碍逼出来。** 奥班农引霍华德与马布里：人物塑造的精髓是揭示内在生活。小说可以直接叙述内心，电影不能，除非以某种外在方式揭示。办法是设置障碍：人物克服障碍时作出选择，选择把内在生活暴露出来。他把这写成一条结构配方：第一幕人物进入冲突，第二幕压力迫使他改变，第三幕改变显现。人物不是先有性格再行动，而是行动揭示性格；用他的话说，性格展示抉择的性质。

**逆向工程。** 爱泼斯坦的做法是从钩子倒推人物：钩子通常已经介绍主人公和对手；每一个新人物都从钩子出发，也立足在已有人物之上。理想状态下，对手是主人公的反射，是一枚硬币的正反面：蝙蝠侠与小丑都愤怒、暴力、游离法外，只是一个站在正义一边。主人公与对手还应当诠释主题的不同层面：主题是救赎，主人公完成救赎，对手不完成。

**配角有功能，不是人数。** 他列出几种功能位：爱慕对象或密友给主人公一个倾诉对象，同时应当制造张力，甚至承担"亲密对手"的功能；解说者向主人公和观众说明正在发生什么、赌注是什么、对手是谁；跟班是脱掉英雄或坏蛋外衣后的普通人，好跟班暴露英雄的软弱，坏跟班摇摆甚至背叛。他把人物比作乐谱：主人公是基调，其他角色是和弦。功能重复的合并。

**两种失败人物。** 需要他做什么就做什么、却不真实的是扁平人物或功能人物，要赋予活力；活灵活现却不推动故事的是无用人物，他们可能让某场戏好看，却在破坏故事。次要人物要写得强势，才能给主角找麻烦；第一个想到的人物特质通常不是最好的，要再调一调。

**人物的声音与基调。** 《21天搞定电影剧本》建议把人物当演员来选：你想让谁来演，基调就定了；然后听她说话的语气，是激动、惊恐、大方还是冷静。基调一变，整个故事都变。

## 可执行规则

1. 为每个主要人物写"障碍—选择—代价"三行，不写身世小传；选择必须改变后面的局面。
2. 从钩子列出必需功能位：主角、对手、爱慕/密友、解说者、跟班；每个位置问"删掉他，哪场戏不成立"。
3. 对手写成主角命题的反面，而不是更坏的坏人；两人对同一议题给出不同答案。
4. 第二幕给主角的压力要具体到"他会失去什么"，第三幕只显现他在压力下已经变成的样子。
5. 配角第一次出场就给他一个强势动作或一项反差特质，不要用介绍性台词。
6. 把人物第一个想到的特质写下来，划掉，再写第二个；用第二个。

## 检查清单

- [ ] 主角在压力下做过的哪个选择，是观众能看见的？
- [ ] 这个选择暴露的是内在生活，还是只为推进情节？
- [ ] 对手是否与主角共享一个议题，只是答案相反？
- [ ] 每个配角是否能说出他推动了哪一场、改变了什么？
- [ ] 有没有一个"很好看但不推动故事"的人物？删掉或合并。
- [ ] 人物说话的语气是否可辨，遮住名字还能认出是谁？
- [ ] 第三幕的人物变化，是否在第二幕有压力作依据？

## 与风格层接口

- 人物的"障碍—选择"直接交给表演层写成 action，不写情绪形容词。
- 主角与对手的镜像关系转成视觉对照：同构图、反打、冷暖与软硬的两套语法。
- 跟班与解说者的功能位决定群戏里的景别与站位，不额外加人。
- 选角基调决定全片色彩与镜头质感，风格层不另起一套。

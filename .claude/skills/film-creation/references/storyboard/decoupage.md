# 动作拆解：把剧本的一行拍成几个画面

剧本写「发生了什么」，分镜决定「观众怎么看到它」。一行动作在银幕上通常是 2–6 个镜头：先让观众知道在哪、是谁，再把手、脚、脸、物件一个个给到，最后回到整体看后果。只把一行剧本对应成一个镜头，画面里就会塞进好几个动作，观众看不清，模型也拍不清。

用法：`storyboard/breakdown.md` 第三步定了每镜回答什么问题之后，逐行过剧本的动作行，按这一篇拆开。镜头之间怎么接看 `storyboard/flow.md`，每种镜头的功能看 `storyboard/shot-functions.md`。

## 1. 五条原则

1. **一镜一件事**：一个动作、一个信息，或一个反应。镜头里同时发生三件事，观众只会看到其中一件，模型会把三件都压扁。
2. **景别等于此刻的重要性**：一个东西在画面里多大，取决于它在这一刻对故事有多重要（希区柯克与特吕弗的对谈）。观众此刻该看手，就给手的特写；该看人在空间里有多孤单，就给全景。
3. **整体 → 局部 → 整体**：先给观众空间和人物关系，再拆成局部镜头，事件之后回到整体看后果（分析式剪辑 analytical editing / découpage）。只有局部没有整体，观众不知道在哪；只有整体没有局部，动作没有实感。连续特写三四个之后，就回到一个中景或全景。相邻镜头的景别怎么接，见 `storyboard/continuity.md` 景别衔接：同一主体跨两档，换主体可以同景别。
4. **切在动作上**：动作做到一半切，下一镜接着做完，剪辑点被动作盖住（match on action）。两镜里动作的进度、方向、位置要对得上：上一镜脚抬到一半向画左，下一镜脚落地仍向画左。
5. **重要的拉长，不重要的跳过**：关键动作用好几个镜头拉长，银幕上比真实时间更长；过场用省略，人出门的下一镜已经到了。全片镜长一样平，是没有区分轻重。

## 2. 一个动作的六拍

| 拍 | 观众看到什么 | 常用景别 | 作用 |
|---|---|---|---|
| 预兆 | 事情发生之前的那个东西：散开的鞋带、路上的石头、桌角的刀 | 特写 / 插入 | 观众先于人物知道，就有悬念 |
| 发起 | 人开始做：抬手、迈步、伸向某物 | 中景 / 近景 | 交代谁在做、往哪做 |
| 接触 / 顶点 | 手碰到、脚踢到、刀尖抵住、门撞上 | 特写 | 动作的实感来自这一镜 |
| 结果 | 动作造成的变化：人倒在地上、东西落进碗里 | 全景 / 中景 | 回到整体，看清后果和代价 |
| 反应 | 人对结果的反应，或旁人的反应 | 近景 / 特写 | 观众从这里知道该怎么感受 |
| 余波 | 事情之后留下的：滚远的书包、晃动的门、空下来的地方 | 插入 / 全景 | 呼吸，下一拍的起点 |

六拍不是每次都拍全。按重要性取：

- **普通动作**（倒杯水、坐下）：取发起和结果，1–2 镜。
- **有分量的动作**（递一封信、推开门看见人）：再加接触或反应，3–4 镜。
- **关键动作**（转折、不归点、高潮）：六拍取五到六拍，5–8 镜，每一拍都给镜头。

一拍一般一个镜头。同一拍拍了两次（血滴在纸上，又滴在地上），删掉一个；相邻两个 1.5 秒以下的镜头讲的是同一件事，合成一个。

## 3. 示例：小男孩在村口土路上摔倒

剧本只有一行：

```text
△ 黄昏，小男孩沿着村口的土路往家跑，被路上的石头绊倒。
```

一行对一镜的写法（不要这样）：「全景，黄昏的村口，小男孩奔跑中被石头绊倒，摔在地上，尘土飞扬，他委屈地哭了。」——一个镜头里有跑、绊、摔、哭四件事，景别只有一个，观众看不见石头，也看不见他的脸。

拆开（这是全片里的一个小转折，取六拍）：

| # | 拍 | 景别 | 运镜 | 画面 | 时长 |
|---|---|---|---|---|---|
| 1 | 整体 | 全景 | 固定 | 黄昏，土路从画面右下角伸向远处的村子；小男孩从远处朝画左前方跑来，书包在背后一颠一颠 | 2 s |
| 2 | 预兆 | 特写 | 跟移 | 一双旧布鞋踩在土路上朝画左跑，右脚的鞋带散开，拖在土里 | 1.5 s |
| 3 | 人物 | 近景 | 固定 | 男孩的脸，嘴角带笑，眼睛看着画左前方的村子 | 1.5 s |
| 4 | 预兆 | 中景 | 固定 | 前景，一块半埋在土里的石头；男孩从后景朝石头跑来 | 1.5 s |
| 5 | 接触 | 特写 | 固定 | 鞋尖踢在石头上，脚停住，身体继续向画左扑出去 | 1 s |
| 6 | 结果 | 全景 | 固定 | 男孩扑倒在土路上，尘土扬起又落下；书包甩出去，落在一臂外 | 2 s |
| 7 | 结果 | 特写 | 固定 | 他的手掌按在土里，掌根擦破一道红 | 1.5 s |
| 8 | 反应 | 近景 | 固定 | 男孩撑起上身，嘴一瘪，又抿住，转头看向画外的书包 | 2.5 s |

合计 8 镜、约 13.5 秒。几个决定：

- 镜 1 先交代在哪、往哪去；镜 6 回到全景看后果：整体 → 局部 → 整体。
- 镜 4 让观众先于他看见石头，镜 3 他还在笑：观众替他捏一把汗。
- 镜 5 切在动作上：脚停住、身体继续向前，下一镜他已经扑在地上，方向全程是画左。
- 镜 8 的「看向书包」是反应和决定：下一镜他会去捡书包，故事往下走。
- 时间紧时先省镜 2 和镜 7（细节）；镜 4、5、6、8 不省，它们是预兆、接触、结果和反应。
- 生成：多镜头模型一次 10–15 秒能切几个镜头，镜 1–4 和镜 5–8 各是一个生成单位，镜 5 → 6 的动作用续接（`storyboard/flow.md` §7）。

## 4. 常见动作的拆法

按顺序列出常用的镜头，**粗体**是重点镜，时间紧时最后才省。

| 动作 | 常用拆法 | 生成注意 |
|---|---|---|
| 走向某处 | 全景 人从远处来 → 特写 脚或手里的东西 → 近景 **脸，看向目的地** → **视线对象：目的地** → 中景 走到、停下 | 每镜写画面左右的方向，全程一致 |
| 奔跑 / 追 | 见 `storyboard/scene-types.md` B：追者、被追者、**两人距离**三种镜头交替；同机位比距离 | 方向全程一致；越近终点越短 |
| 摔倒 | 见上面 §3：整体 → 预兆 → **接触** → **结果全景** → 细节 → **反应** | 接触镜单独生成，或用首尾帧 |
| 推 / 打 | 中景 两人的距离 → 近景 出手的人发力 → **特写 接触点**（手到肩） → 全景 挨打的人后退、撞上东西 → **近景 挨打的人反应** → 近景 出手的人事后 | 接触点最容易穿模：首尾帧，或切掉接触只拍前后 |
| 拿起 / 放下 | 近景 人看着物件 → **特写 手碰到物件、它的重量**（`video-prompt/compile.md` 物理写进动作句）→ 近景 拿着它的人 | 物件用参考图，大小前后一致 |
| 递交 | 中景 两个人和物件 → **特写 物件从一只手到另一只手**（一镜完成交接，或切成给 / 接两镜，方向一致）→ **近景 接的人低头看它** | 两只手容易粘连：交接镜单独生成，只放两只手 |
| 开门进屋 | 门外 中景 手推门 → 屋内 全景 门开、人入画（切在门开到一半）→ 近景 进门的人看屋里 → **视线对象：屋里有什么** | 内外两镜的进出方向一致 |
| 看见 / 发现 | 近景 人在看 → **视线对象**（主观或客观）→ **近景 反应**；越重要的发现，反应镜越近 | 视线方向和视线对象的方位对上 |
| 读信 / 看字 | 近景 人展开纸 → **插入 字**（每秒 4–6 个字留时长）→ 近景 反应 → 插入 手指停在某一行 | 字在图阶段做对或后期加 |
| 忍住 / 哭 | 中景 人还在忍 → **近景 先破的那个部位**（下巴、捏紧的手）→ 特写 一滴泪或手捂住嘴 → 全景 一个人在空间里 | 拍忍，不拍嚎哭的大特写；表演见 `video-prompt/acting.md` |
| 坐下 / 起身 | 中景 起身（切在一半）→ 近景 站定；重要时插入 手撑着桌面 | 普通情况 1–2 镜就够 |
| 倒下 / 死去 | 近景 脸，力气离开 → **特写 手松开，物件落地** → **全景 身体倒下**（结果）→ 余波 物件或空下来的地方 | 倒地用首尾帧；身体落地写重量 |
| 拥抱 / 牵手 | 中景 两人的距离 → 近景 一人先迈步 → **特写 两只手碰到** → 中近景 抱住 → 特写 越过对方肩膀的一张脸 | 双人粘连：手部特写单独生成 |
| 写字 | 近景 提笔 → 特写 笔尖落纸 → **插入 写出的字** → 近景 停笔看 | 字定帧或后期 |
| 割伤 / 刺伤 | 近景 手握刀 → 特写 刀尖抵到皮肤 → **切出：脸**（咬牙）→ 插入 血滴落在桌面或器物上 → **结果：物件**（肉落进盏里）→ 近景 人靠倒 | 不拍刀进入身体：用切出和结果代替，避开安全拦截 |
| 吃 / 喝 | 近景 端起 → 特写 碗沿或喉咙一动 → 近景 放下后的表情 | 液体见 `video-prompt/physics.md` |
| 等待 | 全景 人在空间里 → **插入 时间的证据**（钟、影子挪了、烟灰变长）→ 同机位 人的姿势变了 | 同机位复用关键帧，只改姿势和光 |

剧本里没有的动作，套 §2 的六拍自己拆。

## 5. 拆镜之前先做视觉设计

每场在拆镜之前写四行（写进 `templates/storyboard-script.md` 的「视觉设计」）：

- **关键画面**：如果这场只能留一张图，是哪一张。拆出来的镜头都朝它走。
- **机位与视点**：摄影机站在谁身边、什么高度。视点人物的镜头更近、更多，对手的镜头更远。
- **景别走向**：从哪个景别开始，在哪一拍最近，事件之后跳到哪。
- **运镜策略**：默认固定；哪几镜动、为什么动（见 §7）。

## 6. 画面栏怎么写

画面栏写的是**一张能画出来的图，加一个动作**：

```text
主体 + 在画面哪里（画左 / 画右 / 前景 / 后景）+ 一个动作（起点 → 落点）+ 方向 + 环境里看得见的东西
```

- **不写形容词和比喻**：看分镜的人画不出「阴风惨惨」「如枯木般」，模型也看不见。写成看得见的东西：风掀起白幡、人一动不动。
- **不写情绪名词**：「绝望」「沉静冰冷」改成可见动作：垂下手、眼睛不看人、不眨眼。
- **一格一个动作**：画面栏里出现两个「然后」，这一镜多半要拆。
- **写方向和位置**：谁在画左、往哪边走、看向哪边。下一镜的视线和运动要接得上。

改前改后（《连城·一钱肉》的分镜）：

| 改前 | 改后 |
|---|---|
| 阴风惨惨的史府正堂，数丈素白经幡从梁上垂落翻飞 | 正堂里，梁上垂下的白幡被门口吹进的风掀起，两列白纸灯笼跟着晃 |
| 史孝廉身披麻衣如枯木般呆立棺侧 | 史孝廉披着麻衣站在棺材画左侧，双手垂着，眼睛看着地面，一动不动 |
| 乔生立在案前，神情彻底沉静冰冷；他抬手扯解青布长衫衣襟 | 乔生站在书案后，看着老仆不眨眼；他抬手解开青衫的衣襟，露出左胸 |

一行塞了一整段戏的，拆开。改前 2-06 一镜 4 秒：「刀锋映照烛火寒芒；刀尖猛力抵入心口左侧三寸割下，暗红鲜血骤然溢出，一小片鲜肉挑落入白瓷药盏中」。按 §4 割伤的拆法：

| # | 景别 | 画面 | 时长 |
|---|---|---|---|
| 1 | 近景 | 乔生右手握住裁纸短刀，刀身映着画右的烛光 | 1.5 s |
| 2 | 特写 | 刀尖抵在左胸的皮肤上，皮肤被压出一个凹 | 1 s |
| 3 | 近景 | 乔生的脸，咬住牙，额头的汗顺着太阳穴流下（刀进入身体在画外） | 1.5 s |
| 4 | 特写 | 一滴血落在案上摊开的诗笺上，洇开 | 1.5 s |
| 5 | 特写 | 一小片肉落进白瓷药盏，盏在案上轻轻一震 | 1.5 s |
| 6 | 中景 | 乔生向后靠在书案边，左手按住胸口，刀从右手滑到案上 | 2 s |

## 7. 运镜：默认固定

固定机位是默认。镜头动，要说得出理由：

- **跟**：人在走、在跑，摄影机跟着他（跟移、跟摇）。
- **揭示**：摇过去、拉出来，画面里出现一个新的信息。
- **情绪推进**：一场里一两次推近，推在转折那一拍。
- **主观**：摄影机就是人物的眼睛，在空间里移动。

说不出理由的「缓推」「缓拉」「微晃」，改成固定。一场里大多数镜头都在动，就等于没有设计过运动，观众也分不清哪一次动是重要的。运动句的写法见 `camera/lexicon-move.md`。

## 8. 数镜头：剪辑镜头和生成单位分开

- **剪辑镜头数由拆解决定**：剧本每行动作按 §2 取拍，加上 `storyboard/breakdown.md` 第三步补的空间、视线、反应、插入镜头。
- **生成预算管的是生成单位，不是剪辑镜头**：多镜头模型一次生成就能切几个镜头（多份第三方 Seedance 2.0 指南建议把一次生成写成带时间码的镜头表），一段 8 镜的摔倒可能只是一到两次生成。不要为了省生成把几个镜头合成一个塞满动作的镜头；切分见 `storyboard/flow.md` §7、`video-prompt/compile.md`。
- **生成单位的交界处换景别**：上一次生成的最后一镜和下一次生成的第一镜，同一主体时跨两档，或者换主体；景别跳开能藏住两次生成之间脸和衣服的漂移。
- **真要压镜头数**：先省 §4 里没加粗的镜头，再省「观众已经知道」的镜头；预兆、接触、结果、反应最后才省。

## 9. 常见错误

- **一行剧本一个镜头**：画面栏里有两三个动作。按 §2 拆。
- **画面栏写成散文**：形容词、比喻、情绪名词。按 §6 改成看得见的东西。
- **镜镜都在动**：缓推、缓拉、微晃铺满全场。按 §7 改回固定，只留有理由的。
- **关键动作和过场一样长**：转折一镜带过，走路拍了三镜。按 §1 第 5 条重新分配。
- **拆过头**：倒杯水也拆成六拍，全场都是特写，观众不知道在哪；或者关键动作里同一拍拍了两三次，节奏拖了。普通动作 1–2 镜；一拍一个镜头；每次进入局部之前，观众要知道整体。
